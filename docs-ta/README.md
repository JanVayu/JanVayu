# JanVayu ஆவணங்கள்

**JanVayu** (जनवायु, "மக்களின் காற்று") என்பது இந்தியாவின் சுதந்திரமான, மக்கள் நடத்தும் காற்று தரக் கண்காணிப்பு தளம். இது 157 இந்திய நகரங்களுக்கான (ஒப்பீட்டிற்காக பெய்ஜிங், லண்டன் மற்றும் சிங்கப்பூர்) நேரடி மாசு தரவுகளைக் கண்காணிக்கிறது, உடல்நல பாதிப்புகளை அளவிடுகிறது, NCAP பட்ஜெட் செலவுகளைக் கண்காணிக்கிறது மற்றும் அரசாங்கங்களை பொறுப்பேற்கச் செய்கிறது.

> **நேரடி தளம்:** [www.janvayu.in](https://www.janvayu.in)
> **GitHub:** [github.com/JanVayu/JanVayu](https://github.com/JanVayu/JanVayu)

## JanVayu என்றால் என்ன?

இந்தியாவில் ஒவ்வொரு ஆண்டும் காற்று மாசுபாட்டால் சுமார் 1.72 மில்லியன் மக்கள் இறக்கின்றனர் (Lancet Countdown 2025). PM2.5 பாதிப்பால் சராசரி இந்தியர்களின் ஆயுட்காலம் 3.5 ஆண்டுகள் குறைகிறது (AQLI 2025), இதில் இந்தோ-கங்கை சமவெளி மக்கள் 5-8 ஆண்டுகளையும், டெல்லி-NCR மக்கள் 8.2 ஆண்டுகள் வரை இழக்கின்றனர். டெல்லியின் வருடாந்திர PM2.5 அளவு 82.2 µg/m³ ஆகும், இது WHO வழிகாட்டுதலான 5 µg/m³-ஐ விட ~16 மடங்கு அதிகம் (IQAir 2025). இதன் பொருளாதார இழப்பு ஆண்டுக்கு $339.4 பில்லியன், இது GDP-யில் ~9.5% ஆகும் (Lancet Countdown 2025).

JanVayu தரவுகளைப் பதிவு செய்கிறதே தவிர, எந்தப் பிரச்சாரங்களையும் நடத்துவதில்லை. இது காற்று தர நெருக்கடியின் நிரந்தர பொது ஆவணக் காப்பகம்: அதன் தரவுகள், அதன் பலியானவர்கள், அதன் கொள்கைகள் மற்றும் அதன் பொது நினைவுகள்.
