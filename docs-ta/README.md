# JanVayu Documentation

**JanVayu** (जनवायु, "மக்களின் காற்று") என்பது இந்தியாவின் சுதந்திரமான, குடிமக்களால் வழிநடத்தப்படும் காற்று தரப் பொறுப்புக்கூறல் தளமாகும். இது 157 இந்திய நகரங்களுக்கான (ஒப்பீட்டிற்காக பெய்ஜிங், லண்டன் மற்றும் சிங்கப்பூர் உட்பட) நேரடி மாசு தரவுகளைக் கண்காணிக்கிறது, சுகாதார பாதிப்புகளை அளவிடுகிறது, NCAP பட்ஜெட் செலவினங்களைக் கண்காணிக்கிறது மற்றும் அரசாங்கங்களை பொறுப்பேற்கச் செய்கிறது.

> **Live platform:** [www.janvayu.in](https://www.janvayu.in)
> **GitHub:** [github.com/JanVayu/JanVayu](https://github.com/JanVayu/JanVayu)

## JanVayu என்றால் என்ன?

இந்தியாவில் காற்று மாசுபாட்டால் ஒவ்வொரு ஆண்டும் சுமார் 1.72 மில்லியன் மக்கள் இறப்பதாக மதிப்பிடப்பட்டுள்ளது (Lancet Countdown 2025). PM2.5 பாதிப்பால் ஒரு சராசரி இந்தியரின் ஆயுட்காலம் 3.5 ஆண்டுகள் குறைகிறது (AQLI 2025), இதில் இந்தோ-கங்கை சமவெளி (Indo-Gangetic Plain) மக்கள் 5-8 ஆண்டுகளும், டெல்லி-NCR (Delhi-NCR) மக்கள் 8.2 ஆண்டுகள் வரையும் இழக்கின்றனர். டெல்லியின் வருடாந்திர PM2.5 அளவு 82.2 µg/m³ என்பது WHO-இன் 5 µg/m³ என்ற வழிகாட்டுதலை விட ~16 மடங்கு அதிகமாகும் (IQAir 2025). இதன் பொருளாதார இழப்பு ஆண்டுக்கு $339.4 பில்லியன் ஆகும், இது GDP-யில் ~9.5% ஆகும் (Lancet Countdown 2025).

JanVayu தரவுகளைப் பதிவு செய்கிறதே தவிர எந்தப் பிரச்சாரத்தையும் நடத்தவில்லை. இது காற்று தர நெருக்கடியின் நிரந்தர பொது ஆவணக் காப்பகமாகும்: அதன் தரவுகள், அதனால் பாதிக்கப்பட்டவர்கள், அதன் கொள்கைகள் மற்றும் அதன் பொது நினைவுகள்.
