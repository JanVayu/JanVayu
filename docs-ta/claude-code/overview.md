## Claude Code என்றால் என்ன?

Claude Code என்பது டெர்மினல் அடிப்படையிலான AI கோடிங் ஏஜெண்ட் ஆகும். இதை உங்கள் ப்ராஜெக்ட் டைரக்டரியில் இயக்கி பின்வரும் வேலைகளைச் செய்யலாம்:

- கோப்புகளைப் படித்து எழுத
- ஷெல் கமாண்டுகளை இயக்க
- கோட் பேஸ்களைத் தேட
- கமிட்கள் மற்றும் புல் ரெக்வெஸ்ட்களை உருவாக்க
- சிக்கலான பல-கோப்பு ரீஃபேக்டர்களை நிர்வகிக்க
- முழு சூழலோடு பிழைகளை டீபக் செய்ய

இது ஒரு ஊடாடும் அமர்வாக செயல்படுகிறது. நீங்கள் என்ன விரும்புகிறீர்கள் என்பதை விவரித்தால், Claude அதைச் செயல்படுத்தும் — உங்கள் கோப்பைப் படித்து, மாற்றங்களைச் செய்து, சோதனைகளை இயக்கி, வேலை முடியும் வரை திரும்பத் திரும்பச் செய்யும்.

### ஆரம்பகட்ட உருவாக்கம்

முக்கிய பிளாட்ஃபார்ம் (`index.html`, அனைத்து Netlify Functions, உள்கட்டமைப்பு உள்ளமைவுகள்) தொடர்ச்சியான Claude Code அமர்வுகள் மூலம் உருவாக்கப்பட்டது:

1. **வசதியை விவரிக்கவும்** — எ.கா., "வயது, உடல்நலப் பிரச்சனைகள் மற்றும் வெளிப்புற நேரங்களை எடுத்துக்கொள்ளும் ஆரோக்கிய பாதிப்பு கால்குலேட்டரைச் சேர்க்கவும்"
2. **Claude தற்போதைய கோப்பைப் படிக்கிறது** — ஜீரோ-ஃப்ரேம்வொர்க் கட்டுப்பாடு, தற்போதைய பேட்டர்ன்களைப் புரிந்துகொள்கிறது
3. **Claude இம்ப்ளிமென்டேஷனை எழுதுகிறது** — `index.html`, `app.js` மற்றும் `styles.css`-இல், அல்லது புதிய Netlify Function ஆக
4. **மதிப்பாய்வு செய்து திரும்பச் செய்யவும்** — மாற்றங்களைக் கோருதல், எட்ஜ் கேஸ்களை சரிசெய்தல்
5. **Claude கமிட் செய்கிறது** — ப்ராஜெக்ட் விதிமுறைகளின்படி சரியான கமிட் மெசேஜ் முன்னொட்டுடன்

## அமர்வு பணிப்பாய்வு

JanVayu-க்கான ஒரு வழக்கமான Claude Code அமர்வு இந்த முறையைப் பின்பற்றுகிறது:
```
1. ரெப்போ ரூட்டில் (repo root) Claude Code-ஐத் தொடங்கவும்
   $ claude

2. வேலையை விவரிக்கவும்
   > "Add an anomaly detection banner that checks PM2.5 against seasonal baselines
     for Delhi, Mumbai, Kolkata, Chennai, and Bengaluru"

3. Claude கோட் பேஸை (codebase) ஆராய்கிறது
   - இருக்கும் UI பேட்டர்ன்களைப் புரிந்துகொள்ள index.html மற்றும் app.js-ஐப் படிக்கிறது
   - கோட் ஸ்டைலுக்காக இருக்கும் Netlify Functions-ஐப் படிக்கிறது
   - கிடைக்கும் டிபென்டென்சிகளை (dependencies) சரிபார்க்க package.json-ஐப் பார்க்கிறது

4. Claude உருவாக்குகிறது
   - netlify/functions/anomaly-check.mjs-ஐ உருவாக்குகிறது
   - index.html-ல் பேனர் மார்க்கப்பை (banner markup) சேர்க்கிறது, styles.css-ல் ஸ்டைலிங் மற்றும் app.js-ல் லாஜிக்கைச் சேர்க்கிறது
   - ஃபங்ஷனை கால் செய்ய கிளையன்ட்-சைடு (client-side) கோடை அப்டேட் செய்கிறது

5. Claude கமிட் செய்து PR-ஐ உருவாக்குகிறது
   - கமிட் மெசேஜ் முறையைப் பின்பற்றுகிறது (Add:, Fix:, போன்றவை)
   - சுருக்கம் மற்றும் டெஸ்ட் பிளானுடன் PR-ஐ உருவாக்குகிறது

6. ரிவியூ, மீண்டும் செய்தல், மெர்ஜ் (merge)
```

## இந்த ப்ராஜெக்ட்டின் முக்கிய பலங்கள்

### சூழல் புரிதல்
Claude Code உங்கள் முழு கோட் பேஸையும் படிக்கிறது. JanVayu-ஐப் பொறுத்தவரை, அது புரிந்துகொண்டவை:
- ஜீரோ-ஃப்ரேம்வொர்க் (zero-framework) கட்டுப்பாடு (React/Vue/Angular இல்லை)
- `index.html` (மார்க்கப்), `styles.css` மற்றும் `app.js` எனப் பிரிப்பது
- Netlify Functions அமைப்பு மற்றும் CORS கையாளுதல்
- Netlify Blobs-ஐப் பயன்படுத்தும் கேச்-ஃபர்ஸ்ட் (cache-first) பேட்டர்ன்
- git ஹூக்ஸ் (git hooks) மூலம் கட்டாயமாக்கப்பட்ட கமிட் மெசேஜ் முறை

### பல ஃபைல்களை ஒருங்கிணைத்தல்
"Ask JanVayu" போன்ற ஒரு அம்சத்தைச் சேர்க்க, இவை அனைத்திலும் மாற்றங்கள் தேவை:
- ஒரு புதிய Netlify Function (`air-query.mjs`)
- ஃபிரண்ட்எண்ட் HTML (`index.html`-ல் புதிய பகுதி)
- ஃபிரண்ட்எண்ட் CSS (சாட் இன்டர்ஃபேஸுக்கான ஸ்டைலிங்)
- ஃபிரண்ட்எண்ட் JS (ஃபங்ஷனுக்கு fetch கால், UI லாஜிக்)
- CHANGELOG.md (அம்சத்தை ஆவணப்படுத்துதல்)

Claude Code இவை அனைத்தையும் ஒரே செஷனில் (session) கையாளுகிறது.

### Git ஒருங்கிணைப்பு
Claude Code இயல்பாகவே இவற்றைக் கையாளுகிறது:

- ப்ராஜெக்ட்டுக்குரிய git ஹூக்ஸைப் பின்பற்றுதல்
