# குடிமக்கள் நடவடிக்கைக்கான கருவிகள்

காற்றின் தரத்தில் நடவடிக்கை எடுக்க விரும்பும் குடிமக்கள், பத்திரிகையாளர்கள், ஆராய்ச்சியாளர்கள் மற்றும் சமூக ஆர்வலர்களுக்கு JanVayu நடைமுறை கருவிகளை வழங்குகிறது.

---

## RTI டெம்ப்ளேட்கள்

முன்பே தயாரிக்கப்பட்ட தகவல் அறியும் உரிமைச் சட்டம் (2005) டெம்ப்ளேட்கள்:

| டெம்ப்ளேட் | இலக்கு அதிகாரம் |
|----------|-----------------|
| NCAP நிதி செலவினம் | மாநில மாசு கட்டுப்பாட்டு வாரியம் |
| GRAP இணக்க அறிக்கை | காற்று தர மேலாண்மை ஆணையம் (CAQM) |
| மூலப் பிரிப்பு ஆய்வு | மத்திய மாசு கட்டுப்பாட்டு வாரியம் (CPCB) |
| தொழில்சார் உமிழ்வு தரவு | மாநில PCB / MoEFCC |
| நகர செயல் திட்ட நிலை | மாநகராட்சி |

இந்த டெம்ப்ளேட்கள் ஆங்கிலம் மற்றும் இந்தியில் [rtionline.gov.in](https://rtionline.gov.in) என்ற RTI ஆன்லைன் போர்ட்டலுக்காக வடிவமைக்கப்பட்டுள்ளன. அந்த போர்ட்டல் மத்திய அரசு அதிகாரிகளுக்கான (CAQM, CPCB, MoEFCC) விண்ணப்பங்களை மட்டுமே ஏற்கும்; மாநில மாசு கட்டுப்பாட்டு வாரியங்கள் மற்றும் மாநகராட்சிகள் மாநில அதிகாரிகளாகும், எனவே அந்த விண்ணப்பங்கள் மாநிலத்தின் சொந்த RTI போர்ட்டல் மூலமாகவோ அல்லது தபால் மூலமாகவோ செல்ல வேண்டும்.

---

## வாதாடல் வழிகாட்டிகள்

RTI தாக்கல் செய்வது எப்படி (சமர்ப்பிப்பது முதல் முதல் மேல்முறையீடு வரை), வார்டு அளவிலான பொறுப்புணர்வு சுருக்கத்தை உருவாக்குபவரைப் பயன்படுத்தி உங்கள் வார்டு கவுன்சிலரை எப்படி அணுகுவது, தரவுகளுடன் காற்றின் தரக் கதையை வடிவமைத்து ஊடகங்களுடன் எப்படி இணைந்து செயல்படுவது, மற்றும் சுற்றுச்சூழல் தாக்க மதிப்பீடுகளுக்கான பொது விசாரணைகளில் எப்படி பங்கேற்பது போன்ற படிப்படியான வழிகாட்டிகள் இதில் அடங்கும்.

---

## வார்டு அளவிலான பொறுப்புணர்வு சுருக்கம்

இந்த சுருக்கத்தை உருவாக்கும் கருவி, வார்டு கவுன்சிலர்கள், குடியிருப்போர் நலச் சங்கங்கள் அல்லது பத்திரிகையாளர்களுக்கு ஏற்ப எந்தவொரு நகரத்திற்கும் பொறுப்புணர்வு சுருக்கத்தை எழுத ஒரு AI மாடலைப் (OpenAI gpt-oss-120b, Groq மூலம் இயக்கப்படும் ஒரு ஓபன்-வெயிட் மாடல்) பயன்படுத்துகிறது. ஒவ்வொரு சுருக்கத்திலும் பின்வருவன அடங்கும்:

- நகரத்திற்கான தற்போதைய AQI அளவீடுகள்
- NCAP இலக்குகளுடனான ஒப்பீடு
- முக்கிய உள்ளூர் மாசு ஆதாரங்கள்
- தேர்ந்தெடுக்கப்பட்ட அதிகாரிகளிடம் கேட்க வேண்டிய பரிந்துரைக்கப்பட்ட கேள்விகள்

டெவலப்பர்கள் `/.netlify/functions/accountability-brief` என்ற முகவரிக்கு JSON body உடன் (`city` மற்றும் `area` ஆகியவை கட்டாயம்) ஒரு `POST` கோரிக்கையை அனுப்புவதன் மூலம் சுருக்கத்தைக் கோரலாம்.

---

## முகக்கவசம் தேர்வு வழிகாட்டி

வெவ்வேறு AQI அளவுகளில் முகக்கவசத்தைத் தேர்ந்தெடுப்பதற்கான நடைமுறை வழிகாட்டி. இது பொதுவான வழிகாட்டுதல் மட்டுமே, எந்தவொரு சுகாதார அதிகாரியிடமிருந்தும் பெறப்படவில்லை, மேலும் இதன் வகை பெயர்கள் டேஷ்போர்டின் சொந்த பேண்டுகளுக்குப் பதிலாக US EPA அளவைப் பின்பற்றுகின்றன:

| AQI அளவு | பரிந்துரைக்கப்படும் பாதுகாப்பு |
|-----------|----------------------|
| நல்லது முதல் மிதமானது வரை | முகக்கவசம் தேவையில்லை |
| உணர்திறன் குழுக்களுக்கு ஆரோக்கியமற்றது | உணர்திறன் உள்ள நபர்களுக்கு N95/KN95 |
| ஆரோக்கியமற்றது | அனைவருக்கும் N95/KN95 பரிந்துரைக்கப்படுகிறது |
| மிகவும் ஆரோக்கியமற்றது | N95/KN95, வெளியே செல்லும் நேரத்தைக் குறைக்கவும் |
| ஆபத்தானது | வீட்டிற்குள்ளேயே இருங்கள்; வெளியே சென்றால் N95 அணியவும் |

## உட்புற காற்றின் தரம்

உட்புற காற்றின் தரம் பகுதி கீழ்க்கண்டவற்றை உள்ளடக்கியது:

- பல்வேறு வகையான கட்டிடங்களில் காற்றோட்டம்
- காற்று சுத்திகரிப்பானைத் தேர்ந்தெடுத்தல் (HEPA வடிகட்டி தரநிலைகள் மற்றும் அறையின் அளவிற்கான CADR மதிப்பீடுகள்)
- சமையல் எரிபொருட்களும் ஆரோக்கியமும்: திண்ம எரிபொருட்களுக்கு எதிராக LPG, மற்றும் உஜ்வாலா திட்டம் எந்தளவுக்குச் சென்றடைந்துள்ளது
- குறைந்த விலையிலான சென்சார்களைக் கொண்டு உட்புற காற்றின் தரத்தை அளவிடுதல்
