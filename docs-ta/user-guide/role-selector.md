# பங்கு அடிப்படையிலான பார்வைகள்

பார்வையாளர்கள் யார் என்பதைப் பொறுத்து, அவர்களுக்கு மிகவும் பொருத்தமான தரவு, கருவிகள் மற்றும் செயல்களை நோக்கி JanVayu-இன் role selector வழிகாட்டுகிறது. அனைவருக்கும் சுமார் 58 பேனல்களைக் கொண்ட முழு டேஷ்போர்டைக் காட்டுவதற்குப் பதிலாக, ஒவ்வொரு பார்வையாளருக்கும் தேவையான, தேர்ந்தெடுக்கப்பட்ட சிறிய தொகுப்பை இது வழங்குகிறது.

## இது எப்படி வேலை செய்கிறது

### முதல் வருகை

முதல் வருகையின் போது, இது காற்றின் தரத்தைக் காட்டிவிட்டு வேறு எதையும் கேட்காது. 18 செப்டம்பர் 2026 வரை, வேறு எதையும் பார்ப்பதற்கு முன்பாக முகப்புப் பக்கத்தில் முழுத் திரையும் மூடியது போல் ஒரு overlay திறக்கப்படும். இதனால், புதிய பார்வையாளர்கள் தாங்கள் தேடி வந்த தகவலைப் பார்க்க, பன்னிரண்டு தேர்வுகளைக் கொண்ட ஒரு பிக்கரைத் தாண்டிச் செல்ல வேண்டியிருந்தது. இப்போது அது தானாகத் திறக்கப்படுவதில்லை. பகிரப்பட்ட லிங்க் மூலம் வருபவர்கள் உடனடியாக நேரடி PM2.5 அளவைப் பார்க்கலாம், மேலும் ஒரு role-ஐத் தேர்ந்தெடுப்பது அவர்களுக்கு விருப்பப்பட்டால் மட்டுமே.

Role-களை header-லிருந்து அணுகலாம். ஒரு role செட் செய்யப்பட்டிருந்தாலும் இல்லாவிட்டாலும், role switcher-ல் அனைத்து பன்னிரண்டும் மற்றும் "Show Everything" என்பதும் பட்டியலிடப்பட்டிருக்கும். இதற்கு ஒரு தட்டு (tap) மட்டுமே போதும், இடைப்பட்ட திரைகள் எதுவும் இல்லை, மேலும் ஒவ்வொரு role-க்கும் அருகில் ஒரு வரி விளக்கம் இருக்கும். பழைய முழுத் திரைக் overlay (`#roleOverlay`) கோடிலிருந்து நீக்கப்பட்டுள்ளது.

Role-ஐத் தேர்ந்தெடுக்காத பார்வையாளருக்கு, ஒவ்வொரு செஷனிலும் ஒரு முறை switcher-ஐப் பயன்படுத்த ஒரு குறிப்பு காட்டப்படும்.

பன்னிரண்டு role-கள்:

| Role | Key | Example action |
|------|-----|----------------|
| பெற்றோர் / குடும்பம் | `parent` | "Should my child go outside?" |
| மாணவர் | `student` | "Explore historical AQI trends" |
| ஆராய்ச்சியாளர் | `researcher` | "Access the data archive" |
| கொள்கை வகுப்பாளர் | `policymaker` | "Track NCAP mission targets" |
| பத்திரிகையாளர் | `journalist` | "Generate an accountability brief" |
| குடிமகன் / ஆர்வலர் | `activist` | "File an RTI request" |
| மருத்துவர் / சுகாதாரப் பணியாளர் | `doctor` | "Health risk calculator" |
| ஆசிரியர் | `teacher` | "Should school close today?" |
| NGO / CSO | `ngo` | "Generate an advocacy brief" |
| வணிக உரிமையாளர் | `business` | "See the economic impact" |
| பெண் / பராமரிப்பாளர் | `woman` | "Indoor cooking and maternal exposure" |
| குடிமகன் | `citizen` | "What is my city doing about it?" |

Header switcher-ல் உள்ள "Show Everything" தேர்வு, role-ஐ நீக்கிவிட்டு முழு டேஷ்போர்டையும் காட்டும்.

### Role டேஷ்போர்டு

ஒரு role-ஐத் தேர்ந்தெடுத்த பிறகு, பார்வையாளர் 3 action card-களைக் கொண்ட ஒரு பிரத்யேக டேஷ்போர்டைப் பார்ப்பார். இவை நேரடி பட்டன்களைக் கொண்ட (உதாரணமாக "Check now" அல்லது "Calculate risk") அதிக முன்னுரிமை கொண்ட கருவிகளாகும். மேலும், முழுத் தொகுப்பிலிருந்தும் மிகவும் பொருத்தமான பிரிவுகளான 6 பரிந்துரைக்கப்பட்ட பேனல்களையும் பார்ப்பார். "Explore everything" பட்டன் முழு டேஷ்போர்டையும் திறக்கும்.

### Role switcher (header)
மொழித் தேர்வி மற்றும் தீம் டாக்ல் (theme toggle) ஆகியவற்றிற்கு அருகில், ஹெட்டரில் (header) எப்போதும் ஒரு ரோல் ஸ்விட்சர் (role switcher) பட்டன் தெரியும். நீங்கள் ஒரு ரோலைத் தேர்ந்தெடுப்பதற்கு முன்பு, அது யூசர் ஐகானுடன் (user icon) "Role" என்ற பொதுவான லேபிளைக் காட்டும். அதன்பிறகு, தேர்ந்தெடுக்கப்பட்ட ரோலின் சர்கம் (Sargam) ஐகான் மற்றும் சிறிய லேபிளைக் காட்டும் (உதாரணமாக "Parent").

அதை கிளிக் செய்தால், அனைத்து 12 ரோல்கள் மற்றும் "Show Everything" ஆகியவற்றுடன் ஒரு டிராப்டவுன் (dropdown) திறக்கும். உங்கள் முதல் தேர்வுக்குப் பிறகு, ஒரு சிறிய பல்ஸ் (pulse) மற்றும் ஒரு டூல்டிப் (tooltip) ("Change your role anytime here") உங்களை ஸ்விட்சருக்கு வழிகாட்டும்.

### உங்கள் ரோலை நினைவில் வைத்திருத்தல்

உங்கள் தேர்வு `janvayu-role` என்ற கீயின் (key) கீழ் பிரவுசரில் சேமிக்கப்படுகிறது (பழைய `sessionStorage` மதிப்பு ஒரு முறை மாற்றப்படும்). இது டேப்கள் (tabs) மற்றும் மீண்டும் வரும் விசிட்களில் (return visits) தொடரும், எனவே மீண்டும் வரும் விசிட்டர் ரோல் ஸ்கிரீனில் அல்லாமல் டேட்டாவில் (data) வந்து சேருவார். காட்டவோ அல்லது தவிர்க்கவோ எந்த ஓவர்லேவும் (overlay) இல்லை, மேலும் டீப் லிங்க்கள் (deep links) (உதாரணமாக `janvayu.in/#health`) நேரடியாக அவற்றின் பேனலுக்குச் (panel) செல்லும்.

## கட்டமைப்பு (டெவலப்பர்களுக்கானது)

அனைத்து ரோல் வரையறைகளும் `index.html` இல் உள்ள `ROLE_CONFIG` ஆப்ஜெக்ட்டில் (object) உள்ளன. ஒவ்வொரு ரோலிலும் இவை உள்ளன:

```javascript
{
    icon: '<span class="si si-home"></span>',  // Sargam Icon HTML
    label: 'Parent / Family',
    heading: 'Protect your family from air pollution',
    description: 'Real-time safety checks, school closure info...',
    actions: [
        { icon: '...', panel: 'go-outside', title: '...', desc: '...', cta: 'Check now →' },
        // 3 action cards total
    ],
    panels: [
        { panel: 'children', title: "Children's Health", desc: '...' },
        // 6 recommended panels total
    ]
}
```

### புதிய ரோலைச் சேர்த்தல்

1. `icon`, `label`, `heading`, `description`, `actions` (3), மற்றும் `panels` (6) ஆகியவற்றுடன் `ROLE_CONFIG` இல் புதிய கீயைச் (key) சேர்க்கவும்.
2. HTML மாற்றம் எதுவும் தேவையில்லை: ரோல் ஸ்விட்சர் தானாகவே `ROLE_CONFIG` இலிருந்து `#rolePopoverGrid` க்கு உருவாக்கப்படுகிறது.
3. ரோலை மொழிபெயர்க்க `data-i18n` ஆட்ரிபியூட்டைச் (attribute) சேர்க்கவும்.

### ஐகான்கள்

அனைத்து ரோல் மற்றும் ஆக்‌ஷன் ஐகான்களும் CSS mask-image மூலம் [Sargam Icons](https://sargamicons.com/) v1.6.7 ஐப் பயன்படுத்துகின்றன. ஐகான்கள் `<span class="si si-{name}"></span>` ஆக ரெண்டர் (render) ஆகின்றன மற்றும் அவற்றின் பேரன்ட் எலிமெண்ட்டிலிருந்து (parent element) நிறத்தைப் பெறுகின்றன. கிடைக்கும் ஐகான்கள் `<style>` பிளாக்கில் `.si-*` கிளாஸ்களாக (classes) வரையறுக்கப்பட்டுள்ளன.

## வடிவமைப்பு முடிவுகள்

பயனர் கருத்துக்களின் மூலம் கண்டறியப்பட்ட முக்கிய பார்வையாளர்களை உள்ளடக்கும் வகையில் 12 ரோல்கள் உள்ளன, கவலைப்படும் பெற்றோர்கள் முதல் கொள்கை ஆராய்ச்சியாளர்கள் வரை, மேலும் ஒவ்வொன்றும் வெவ்வேறு பேனல்கள் மற்றும் செயல்களைப் பெறுகின்றன.

இந்தத் தேர்வு `localStorage` இல் வைக்கப்படுகிறது, `sessionStorage` இல் அல்ல, ஏனெனில் மீண்டும் வரும் விசிட்டர்கள் டேட்டாவில் வந்து சேர வேண்டும் மற்றும் மீண்டும் தங்கள் ரோலைத் தேர்ந்தெடுக்க வேண்டியதில்லை. பழைய `sessionStorage` மதிப்பு ஒரு முறை மாற்றப்படும்.
---
பங்கு தேர்வு என்பது ஒரு வழித்தடம் அல்ல. JanVayu என்பது ஹாஷ்-அடிப்படையிலான வழித்தடத்தைக் கொண்ட ஒரே `index.html` ஆகும், எனவே பங்கு என்பது அதன் மேல் உள்ள ஒரு அடுக்கு மட்டுமே, முகவரியை மாற்றாது.

"Parent" என்பதைத் தேர்ந்தெடுத்துவிட்டு, பின்னர் பட்ஜெட் தரவை விரும்பும் ஒருவர் சிக்கிக்கொண்டது போல் உணரக்கூடாது என்பதற்காக, இந்த மாற்றுப் பொறி எப்போதும் கண்ணுக்குத் தெரியும்.
