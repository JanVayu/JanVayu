# பாத்திர அடிப்படையிலான பார்வைகள்
ஜான்வாயுவின் (JanVayu) பாத்திரத் தேர்வி, பார்வையாளர்கள் யார் என்பதைப் பொறுத்து அவர்களுக்கு மிகவும் பொருத்தமான தரவுகள், கருவிகள் மற்றும் செயல்களைக் காட்டுகிறது. அனைவருக்கும் 60 இடங்களின் முழுப் பட்டியலைக் காட்டுவதற்குப் பதிலாக, ஒவ்வொரு பார்வையாளருக்கும் சிறிய, தேர்ந்தெடுக்கப்பட்ட தொகுப்பை இது வழங்குகிறது.
## இது எவ்வாறு செயல்படுகிறது
### முதல் வருகை
முதல் வருகையின்போது, காற்றுத் தரத்தைக் காட்டிவிட்டு வேறு எதையும் கேட்காமல் இருக்கும். 18 September 2026 வரை, வேறு எதையும் பார்ப்பதற்கு முன்பாக முகப்புப் பக்கத்தில் முழுத் திரையிலான ஓவர்லே (overlay) திறக்கப்படும். இதனால் புதிய பார்வையாளர்கள் தாங்கள் வந்த தரவைப் பார்க்க, 12 தேர்வுகள் கொண்ட பிக்கரைத் தாண்டிச் செல்ல வேண்டியிருந்தது. இப்போது அது தானாகத் திறக்கப்படுவதில்லை. பகிரப்பட்ட இணைப்பிலிருந்து வரும் ஒருவர் நேரடி PM2.5 அளவை உடனடியாகக் காண்பார், மேலும் ஒரு பாத்திரத்தைத் தேர்ந்தெடுப்பது விருப்பத்திற்குரியது.
இந்தப் பக்கத்தின் மேற்புறத்தில் உள்ள பட்டையிலிருந்து (போனில் Menu-க்குள்) பாத்திரங்களை அணுகலாம். ஒரு பாத்திரம் அமைக்கப்பட்டிருந்தாலும் இல்லாவிட்டாலும், பாத்திர மாற்றி (role switcher) அனைத்து 12 பாத்திரங்களையும் மற்றும் "Show Everything" என்பதையும் பட்டியலிடுகிறது. இதற்கு ஒரு தட்டு தேவைப்படும், இடைநிலைத் திரை எதுவும் இல்லை, மேலும் ஒவ்வொரு பாத்திரத்திற்கும் அருகில் ஒரு வரி விளக்கமும் இருக்கும். பழைய முழுத் திரையிலான ஓவர்லே (`#roleOverlay`) குறியீட்டிலிருந்து நீக்கப்பட்டுள்ளது.
12 பாத்திரங்கள்:
| பாத்திரம் | Key | உதாரணச் செயல் |
|------|-----|----------------|
| பெற்றோர் / குடும்பம் | `parent` | "Should my child go outside?" |
| மாணவர் | `student` | "Explore historical AQI trends" |
| ஆராய்ச்சியாளர் | `researcher` | "Access the data archive" |
| கொள்கை வகுப்பாளர் | `policymaker` | "Track NCAP mission targets" |
| பத்திரிகையாளர் | `journalist` | "Generate an accountability brief" |
| குடிமகன் / ஆர்வலர் | `activist` | "File an RTI request" |
| மருத்துவர் / சுகாதாரப் பணியாளர் | `doctor` | "Health risk calculator" |
| ஆசிரியர் | `teacher` | "Should school close today?" |
| NGO / CSO | `ngo` | "Generate an advocacy brief" |
| வணிக உரிமையாளர் | `business` | "See the economic impact" |
| பெண் / பராமரிப்பாளர் | `woman` | "Indoor cooking and maternal exposure" |
| குடிமகன் | `citizen` | "What is my city doing about it?" |
தலைப்பு மாற்றி (header switcher)-இல் உள்ள "Show Everything" உள்ளீடு பாத்திரத்தை நீக்கிவிட்டு முழு டேஷ்போர்டையும் காட்டுகிறது.
### பாத்திர டேஷ்போர்டு
ஒரு பாத்திரத்தைத் தேர்ந்தெடுத்த பிறகு, பார்வையாளர் 3 செயல் அட்டைகள் (action cards) கொண்ட தொகுக்கப்பட்ட டேஷ்போர்டைக் காண்பார். இவை நேரடி பொத்தான்களைக் கொண்ட உயர் முன்னுரிமை கருவிகளாகும் (உதாரணமாக "Check now" அல்லது "Calculate risk"), மேலும் 6 பரிந்துரைக்கப்பட்ட பேனல்கள், முழுத் தொகுப்பிலிருந்தும் மிகவும் பொருத்தமான பிரிவுகளாகும். "Explore everything" பொத்தான் முழு டேஷ்போர்டையும் திறக்கிறது.
### பாத்திர மாற்றி (தலைப்பு)
பக்கத்தின் மேல் பகுதியில் உள்ள பட்டியில், மொழி கட்டுப்பாடு, Simple, வாசிப்பு எழுத்துரு, Theme மற்றும் Index ஆகியவற்றுக்கு முன்னால் இருக்கும் முதல் கட்டுப்பாடுதான் role switcher. நீங்கள் தேர்ந்தெடுப்பதற்கு முன், இது "Who you are" என்று காட்டும். அதன் பிறகு தேர்ந்தெடுக்கப்பட்ட role-இன் label-ஐக் காட்டும் (உதாரணமாக "Parent / Family"). போனில் (620 பிக்சல்களுக்குக் குறைவான அகலம்), ஆறு கட்டுப்பாடுகளும் ஒரே Menu கட்டுப்பாட்டின் பின்னால் மடிந்துவிடும், எனவே role switcher-ஐ அடைய ஒரு தட்டு கூடுதலாகத் தேவைப்படும்.
இதை கிளிக் செய்தால், அனைத்து 12 roles மற்றும் "Show Everything" ஆகியவற்றுக்கான பட்டியல் திறக்கும். இந்தத் தேர்வு உங்கள் சாதனத்திலேயே வைக்கப்படும் என்றும், வேறு எங்கும் அனுப்பப்படாது என்றும் அதில் ஒரு குறிப்பு இருக்கும்.
### உங்கள் role-ஐ நினைவில் கொள்வது

உங்கள் தேர்வு browser-இல் `janvayu-role` என்ற key-இன் கீழ் சேமிக்கப்படுகிறது (பழைய `sessionStorage` மதிப்பு ஒருமுறை மாற்றப்படுகிறது). இது tabs மற்றும் மீண்டும் வரும் வருகைகள் முழுவதும் தொடரும், எனவே மீண்டும் வரும் பார்வையாளர் role screen-இல் அல்லாமல் data-விலேயே இறங்குவார். காட்டவோ அல்லது தவிர்க்கவோ எந்த overlay-உம் இல்லை, மேலும் deep links (உதாரணமாக `janvayu.in/#health`) நேரடியாக அவற்றின் panel-க்குச் செல்லும்.
## Configuration (for developers)

அனைத்து role வரையறைகளும் `index.html`-இல் உள்ள `ROLE_CONFIG` object-இல் உள்ளன. ஒவ்வொரு role-க்கும் இவை இருக்கும்:
```javascript
{
    icon: '<span class="si si-home"></span>',  // Sargam Icon HTML
    label: 'Parent / Family',
    heading: 'Protect your family from air pollution',
    description: 'Real-time safety checks, school closure info...',
    actions: [
        { icon: '...', panel: 'go-outside', title: '...', desc: '...', cta: 'Check now →' },
        // 3 action cards total
    ],
    panels: [
        { panel: 'children', title: "Children's Health", desc: '...' },
        // 6 recommended panels total
    ]
}
```

### புதிய role-ஐச் சேர்த்தல்
1. `ROLE_CONFIG`-இல் `icon`, `label`, `heading`, `description`, `actions` (3), மற்றும் `panels` (6) ஆகியவற்றுடன் ஒரு புதிய key-ஐச் சேர்க்கவும்
2. எந்த HTML மாற்றமும் தேவையில்லை: role switcher தானாகவே `ROLE_CONFIG`-இலிருந்து `#rolePopoverGrid`-க்கு உருவாக்கப்படுகிறது
3. role-ஐ மொழிபெயர்க்கக்கூடியதாக மாற்ற ஒரு `data-i18n` attribute-ஐச் சேர்க்கவும்
### Icons

அனைத்து role மற்றும் action icons-உம் CSS mask-image வழியாக [Sargam Icons](https://sargamicons.com/) v1.6.7-ஐப் பயன்படுத்துகின்றன. Icons `<span class="si si-{name}"></span>` ஆக render ஆகின்றன, மேலும் அவற்றின் parent element-இலிருந்து நிறத்தைப் பெறுகின்றன. கிடைக்கக்கூடிய icons `<style>` block-இல் `.si-*` classes ஆக வரையறுக்கப்பட்டுள்ளன.
## வடிவமைப்பு முடிவுகள்

பயனர் கருத்துக்களின் மூலம் அடையாளம் காணப்பட்ட முக்கிய பார்வையாளர்களை உள்ளடக்கும் வகையில் 12 roles உள்ளன, கவலைப்படும் பெற்றோர்கள் முதல் கொள்கை ஆராய்ச்சியாளர்கள் வரை, ஒவ்வொருவருக்கும் வெவ்வேறு panels மற்றும் actions கிடைக்கும்.
---
இந்தத் தேர்வு `localStorage`-ல் சேமிக்கப்படுகிறது, `sessionStorage`-ல் அல்ல, ஏனெனில் மீண்டும் வரும் பயனர்கள் நேரடியாகத் தரவுகளைப் பார்க்க வேண்டும், மேலும் அவர்கள் தங்கள் பாத்திரத்தை மீண்டும் தேர்ந்தெடுக்க வேண்டியதில்லை. பழைய `sessionStorage` மதிப்பு ஒருமுறை மாற்றப்படுகிறது.
பாத்திரத் தேர்வு என்பது ஒரு வழித்தடம் அல்ல. JanVayu என்பது ஹாஷ் அடிப்படையிலான வழித்தடத்துடன் கூடிய ஒற்றை `index.html` ஆகும், எனவே பாத்திரம் என்பது அதன் மேல் உள்ள ஒரு அடுக்கு மட்டுமே, இது முகவரியை மாற்றாது.
"Parent" என்பதைத் தேர்ந்தெடுத்த ஒருவர் பின்னர் பட்ஜெட் தரவுகளைப் பார்க்க விரும்பினால், அவர்கள் சிக்கிக்கொண்டதாக உணரக்கூடாது என்பதற்காக, இந்த மாற்றி எப்போதும் தெரியும் நிலையில் இருக்கும்.
