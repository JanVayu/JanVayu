# கட்டமைப்பு

JanVayu என்பது **ஜீரோ-ஃப்ரேம்வொர்க், சிங்கிள்-பேஜ் அப்ளிகேஷன்** (zero-framework, single-page application) ஆகும். இது தரவுகளை ப்ராக்ஸி செய்ய, கேச் செய்ய மற்றும் திட்டமிடப்பட்ட பணிகளைச் செய்ய சர்வர்-சைடு சர்வர்லெஸ் ஃபங்ஷன்களுடன் Netlify-யில் பயன்படுத்தப்படுகிறது.

## முக்கிய வடிவமைப்பு முடிவுகள்


---
### ஸ்டாட்டிக் ஃபிரண்ட்-எண்ட், பண்ட்லர் இல்லை
ஃபிரண்ட்-எண்ட் என்பது `index.html` மற்றும் `styles.css`, `app.js`, `games.js`, `panels/` இல் உள்ள 19 லேஸி-லோடட் பேனல் துண்டுகளைக் கொண்டது, இதில் பண்ட்லரோ அல்லது ஃபிரேம்வொர்க்கோ இல்லை (பார்க்க [Frontend Stack](../tech-stack/frontend.md)). இது அடிப்படை HTML/JS திறன்களைக் கொண்ட பங்களிப்பாளர்களுக்கும் கோட் பேஸை எளிதாக அணுக உதவுகிறது மற்றும் பில்ட்-டைம் சிக்கலை பூஜ்ஜியத்திற்கு அருகில் வைத்திருக்கிறது.

### சர்வர்-சைடு ப்ராக்ஸிங்
CORS சிக்கல்களைத் தவிர்க்கவும் API கீகளைப் பாதுகாக்கவும் சோஷியல் மீடியா மற்றும் நியூஸ் API-கள் Netlify Functions மூலம் பெறப்படுகின்றன. கிளைண்ட் இந்த API-களை நேரடியாகத் தொடர்புகொள்வதில்லை.

### பிளாப் கேஷிங்
`scheduled-fetch.mjs` ஃபங்ஷன் ஒவ்வொரு 4 மணி நேரத்திற்கும் இயங்கி, ஃபீட் டேட்டாவை (Reddit, செய்திகள்; Instagram முயற்சிக்கப்பட்டு, பொதுவாக எதுவும் திருப்பித் தராது) Netlify Blobs-ல் எழுதுகிறது. பயனர்கள் ஃபீட்களைக் கேட்கும்போது, ஆன்-டிமாண்ட் ஃபங்ஷன்கள் கேஷிலிருந்து உடனடியாக வழங்குகின்றன — இது தாமதம் மற்றும் API ரேட் லிமிட்களை நீக்குகிறது.

### கிளைண்ட்-சைடு AQI
WAQI API ஒவ்வொரு 10 நிமிடங்களுக்கும் பிரவுசரில் இருந்து நேரடியாக அழைக்கப்படுகிறது. இந்த டோக்கன் WAQI-ஆல் அதன் சேவை விதிமுறைகளின் கீழ் வழங்கப்படுகிறது மற்றும் இது கிளைண்ட் கோடில் தெரியும். இதன் பொருள் சர்வர்-சைடு உள்கட்டமைப்பு இல்லாமல் ரியல்-டைம் AQI டேட்டா வேலை செய்கிறது.

### ஃபிரேம்வொர்க் இல்லை, பில்ட் ஸ்டெப் இல்லை
`npm run build` இல்லை, Webpack இல்லை, React இல்லை. ஒரே ஒரு பில்ட் கமாண்ட் `node scripts/bump-version.mjs` மட்டுமே, இது வெர்ஷனை முத்திரையிடுகிறது, மேலும் டெப்லாய் ஆர்ட்டிஃபேக்ட் என்பது ரெபாசிட்டரி ஆகும். Netlify ரூட்டிலிருந்து `index.html`-ஐ வழங்குகிறது.

## ஃபைல் அமைப்பு
```
JanVayu/
├── index.html                    # SPA shell (plus styles.css, app.js, games.js, panels/)
├── favicon.svg
├── package.json                  # Node.js deps (Netlify Blobs, Resend, web-push)
├── netlify.toml                  # Build & deploy config
├── CNAME                         # Custom domain
├── docs/                         # இந்த ஆவணங்கள் (Docsify)
├── downloads/                    # பதிவிறக்கம் செய்யக்கூடிய அறிக்கைகள் (PDF, PPTX, DOCX)
└── netlify/
    └── functions/
        ├── scheduled-fetch.mjs   # Cron: அனைத்து ஃபீட்கள், ஒவ்வொரு 4h-க்கும்
        ├── daily-digest.mjs      # Cron: மின்னஞ்சல் சுருக்கம், காலை 8am IST
        ├── reddit-feed.js        # API: கேச் செய்யப்பட்ட Reddit பதிவுகள்
        ├── twitter-feed.js       # API: நிறுத்தப்பட்டது — Nitter-ஐப் படிக்கவும், அதன் பொது இன்ஸ்டன்ஸ்கள் மறைந்துவிட்டன
        ├── news-proxy.js         # API: கேச் செய்யப்பட்ட செய்தி கட்டுரைகள்
        ├── instagram-feed.js     # API: கேச் செய்யப்பட்ட Instagram பதிவுகள்
        ├── feed-status.js        # API: ஃபீட் ஃப்ரெஷ்னஸ் ஹெல்த் செக்
        ├── subscribe.js          # API: மின்னஞ்சல் சந்தா மேலாண்மை
        ├── blob-store.js         # பகிரப்பட்டது: Blobs store ஹெல்பர்
        ├── air-query.mjs         # AI: இயற்கை மொழி AQI வினவல்கள்
        ├── health-advisory.mjs   # AI: தனிப்பயனாக்கப்பட்ட சுகாதார ஆலோசனைகள்
        ├── accountability-brief.mjs  # AI: வார்டு அளவிலான பொறுப்புக்கூறல் சுருக்கங்கள்
        └── anomaly-check.mjs     # AI: PM2.5 ஸ்பைக் கண்டறிதல்
```

இந்தப் பட்டியல் முழுமையானது அல்ல: `netlify/functions/`-ல் 28 ஃபங்ஷன் ஃபைல்கள் மற்றும் பகிரப்பட்ட `lib/` (உதாரணமாக `waqi-proxy`, `rankings`, `data-api`, `push-send`, `fire-tracker` மற்றும் `terra-collab`) உள்ளன.
