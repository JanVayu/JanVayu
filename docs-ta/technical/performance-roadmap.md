# செயல்திறன் வரைபடம்
இந்தப் பக்கம் JanVayu-வின் மொபைல்-செயல்திறன் பணிக்கான திட்டமிடப்பட்ட அணுகுமுறையை ஆவணப்படுத்துகிறது — இது v26.5.4-இல் (Lighthouse CI + பட்ஜெட் கட்டமைப்பு) கட்டமைக்கப்பட்டுள்ளது, உண்மையான மறுசீரமைப்பு அதற்கென பிரத்யேகமான சுழற்சிக்காக காத்திருக்கிறது.
[issue #3](https://github.com/JanVayu/JanVayu/issues/3)-இல் கண்காணிக்கப்படுகிறது.

## தற்போதைய நிலை (மே 2026)
- ஒற்றை `index.html`, ~990 KB மினியஃபை செய்யப்பட்டது.
- Chart.js 4.x (~70 KB gzipped) மற்றும் Leaflet 1.9 + leaflet.heat (~50 KB gzipped) ஆகியவை பக்கத்தின் மேற்புறத்தில் `defer` உடன் ஏற்றப்படுகின்றன. அவை பார்ஸிங் அல்லது முதல் பெயிண்ட்டைத் தடுக்கவில்லை, ஆனால் பெரும்பாலான செஷன்கள் Trends அல்லது Live Map பேனல்களைத் திறக்காத போதிலும், ஒவ்வொரு வருகையிலும் ~120 KB அலைவரிசையை அவை பயன்படுத்துகின்றன.
- CSS `mask-image` மூலம் Sargam Icons — ஐகான் ஃபான்ட் பதிவிறக்கம் இல்லை.
- Service worker (`sw.js`) ஷெல் + கடைசியாகத் தெரிந்த AQI-ஐ கேச் செய்கிறது.
- Netlify இயல்புநிலை மூலம் Brotli சுருக்கம் எதிர்பார்க்கப்படுகிறது (இன்னும் சரிபார்க்கப்படவில்லை; கீழே உள்ள curl சோதனையைப் பார்க்கவும்).
> **புதுப்பிப்பு 2 அக்டோபர் 2026:** மேலே உள்ள குறிப்புகள் மே 2026 பதிவு மற்றும் முன்னேறிவிட்டன. `index.html` இப்போது சுமார் 621 KB ஆக உள்ளது, `styles.css` மற்றும் `app.js` தனித்தனி கோப்புகளாக உள்ளன. Chart.js மற்றும் Leaflet இனி பக்கத்தின் மேற்புறத்தில் ஏற்றப்படுவதில்லை: v26.5.6 மூலம் லேஸி-லோடிங் அனுப்பப்பட்டது (`app.js`-இல் `ensureChartJs()` / `ensureLeaflet()`, லேஸி-லோட் செய்யப்பட்ட ஸ்கிரிப்ட்களில் SRI ஹாஷ்களுடன்), எனவே கீழே உள்ள பிரிவு 1-இல் திட்டமிடப்பட்ட மறுசீரமைப்பு முடிந்தது. இன்லைன் CSS இப்போது ஒரு கிரிட்டிகல்-CSS துணைக்குழுவாக உள்ளது, மீதமுள்ளவை `/styles.css`-இல் உள்ளன (பார்க்க [Frontend Stack](../tech-stack/frontend.md)), எனவே பிரிவு 2-இல் விவரிக்கப்பட்டுள்ள ~85 KB இன்லைன் பிளாக் இனி இல்லை. 21 நவம்பர் 2026 அன்று `index.html` 602,507 பைட்டுகள், `styles.css` 187,875 மற்றும் `app.js` 641,719 ஆக உள்ளது.

## திட்டமிடப்பட்ட மறுசீரமைப்பு (ஒற்றை பிரத்யேக சுழற்சி)
### 1. Chart.js மற்றும் Leaflet-ஐ லேஸி-லோட் செய்தல்
எதிர்கொள்ளும் `<script src="...chart.js" defer>` மற்றும் `<script src="...leaflet.js" defer>` குறிப்புகளை அகற்றவும். அதற்குப் பதிலாக ஒரு சிறிய லோடர் முறையைப் பயன்படுத்தவும்:
```js
let _chartJsLoaded = null;
async function ensureChartJs() {
  if (window.Chart) return;
  if (_chartJsLoaded) return _chartJsLoaded;
  _chartJsLoaded = new Promise((resolve, reject) => {
    const s = document.createElement('script');
    s.src = 'https://cdn.jsdelivr.net/npm/chart.js@4.4.7/dist/chart.umd.min.js';
    s.onload = resolve;
    s.onerror = reject;
    document.head.appendChild(s);
  });
  return _chartJsLoaded;
}

let _leafletLoaded = null;
async function ensureLeaflet() {
  if (window.L?.heatLayer) return;
  if (_leafletLoaded) return _leafletLoaded;
  _leafletLoaded = (async () => {
    await loadCSS('https://unpkg.com/leaflet@1.9.4/dist/leaflet.css');
    await loadScript('https://unpkg.com/leaflet@1.9.4/dist/leaflet.js');
    await loadScript('https://unpkg.com/leaflet.heat@0.2.0/dist/leaflet-heat.js');
  })();
  return _leafletLoaded;
}
```
பின்னர் சார்ட்டுகள் அல்லது மேப்பைப் பயன்படுத்தும் ஒவ்வொரு பேனலிலும், init அழைப்பின் முன் சேர்க்கவும்:
```js
async function initTrendsCharts() {
  await ensureChartJs();
  // existing chart-init code unchanged
}

async function initMap() {
  await ensureLeaflet();
  // existing map-init code unchanged
}
```
`initTrendsCharts` / `initMap` ஐ அழைக்கும் ஃபங்ஷன்களுக்கு `await` (அல்லது `.then()`) தேவை. தற்போதைய அனைத்து அழைப்பு இடங்களும் கிளிக் செய்யும்போது இயங்கும் `loadPanel(panelId)` க்குள் உள்ளன, எனவே அங்கு ஒரு `async` அப்கிரேடு பாதுகாப்பானது.
**எதிர்பார்க்கப்படும் சேமிப்பு:** ட்ரெண்ட்ஸ் அல்லது லைவ் மேப்பைத் திறக்காத செஷன்களுக்கு முதல் பெயிண்டில் ~120 KB (பெரும்பாலும் 70%+ செஷன்கள்). மொபைல் FCP மேம்பாடு: 3G இல் ~600 ms.
### 2. முக்கியமானதல்லாத CSS ஐ ஒத்திவைத்தல்
தற்போதைய இன்லைன் CSS பிளாக் ~85 KB ஆக உள்ளது. இதில் பெரும்பாலானவை முதல் பெயிண்டிற்குத் தேவையில்லாத பேனல் சார்ந்த ஸ்டைலிங் ஆகும். இவற்றை இவ்வாறு பிரிக்கவும்:
- **முக்கியமானது** (~10 KB): ஹீரோ, டாப்-நாவ், டேஷ்போர்டு விரைவு-இணைப்பு கிரிட். இன்லைன் செய்யவும்.
- **முக்கியமற்றது** (~75 KB): மற்ற அனைத்தும். `assets/main.css` க்கு நகர்த்தி, `<link rel="preload" as="style" onload="this.rel='stylesheet'">` மூலம் லோட் செய்யவும்.
**எதிர்பார்க்கப்படும் சேமிப்பு:** பிராட்லிக்குப் (Brotli) பிறகு முதல் பெயிண்டில் ~20 KB; மொபைல் FCP மேம்பாடு: ~200 ms.
### 3. பிராட்லி சரிபார்த்தல்
Netlify இயல்புநிலை தலைப்புகள் மூலம் ஏற்கனவே செயலில் உள்ளது, ஆனால் சரிபார்ப்பது நல்லது:
```bash
curl -H "Accept-Encoding: br" -I https://www.janvayu.in/ | grep -i content-encoding
# Expected: content-encoding: br
```
அதற்குப் பதிலாக `gzip` திரும்பக் கிடைத்தால், `netlify.toml` இல் வெளிப்படையான தலைப்புகளை அமைக்கவும்.
### 4. படம் / ஐகான் மேம்படுத்தல்
- `og-image.png` இங்கு 39 KB எனப் பதிவு செய்யப்பட்டது; 2 Oct 2026 அன்று `ls -l` 133,256 bytes (சுமார் 130 KB) எனக் காட்டுகிறது, இது பரவாயில்லை, ஆனால் அது தற்போதைய எண்களைக் காட்டுகிறதா என்பதைச் சரிபார்க்கவும் (தனிப் பிரச்சினை, [audit deferred items](../../docs/wiki/Roadmap.md) ஐப் பார்க்கவும்).
- `favicon.svg` 1.5 KB — பரவாயில்லை.
- mask-image வழியாக Sargam Icons — ஏற்கனவே உகந்ததாக உள்ளது.
### 5. மொபைல் ரெஸ்பான்சிவ்னஸ் தணிக்கை
[issue #33](https://github.com/JanVayu/JanVayu/issues/33) இல் தனித்தனியாகக் கண்காணிக்கப்படுகிறது. இது Lighthouse அணுகல்தன்மை + சிறந்த-பயிற்சிகள் மதிப்பெண்களுக்குப் பங்களிக்கிறது, ஆனால் இது வேறுபட்ட பணிப்பாய்வு ஆகும்.

## தாக்குதல் வரிசை
1. **அடிப்படை Lighthouse-ஐ இயக்குதல்** — `gh workflow run lighthouse.yml` மற்றும் எண்களைப் பதிவு செய்தல்.
2. **Chart.js + Leaflet-ஐ லேசியாக ஏற்றுதல்** — மிகப்பெரிய ஒற்றை வெற்றி (கணிக்கப்பட்ட ~600 ms FCP).
3. **மீண்டும் அளவிடுதல்** — அடுத்த கட்டத்திற்குச் செல்வதற்கு முன் 600 ms மேம்பாடு உண்மையானது என்பதை உறுதிப்படுத்தவும்.
4. **CSS பிரித்தல்** — இரண்டாவது மிகப்பெரிய வெற்றி (~200 ms).
5. **Lighthouse அடுத்து சுட்டிக்காட்டும் எதன் மீதும் மீண்டும் செய்தல்**: பயன்படுத்தப்படாத JS, லேஅவுட் ஷிப்ட் போன்றவை.
வரவுசெலவுத் திட்டம் தொடர்ந்து பூர்த்தி செய்யப்படும் வரை, `.lighthouserc.json` உறுதிப்பாடுகளை `warn` என்ற நிலையிலேயே வைக்கவும். `main`-இல் தொடர்ந்து மூன்று முறை வெற்றிகரமாகச் செயல்பட்ட பிறகு, perf-score மற்றும் FCP உறுதிப்பாடுகளை `error` ஆக மாற்றவும்.
