### ஏற்றுக்கொள்ளப்பட்ட சமரசங்கள்

- **GPT-4 / Claude அல்ல** — JanVayu செலவு மற்றும் வேகத்திற்காக Groq மூலம் வழங்கப்படும் ஓப்பன்-வெயிட் மாடலைப் பயன்படுத்துகிறது.
- **அவுட்புட் டோக்கன் வரம்பு** — அவுட்புட் ஒரு ஃபங்ஷனுக்கு 512 முதல் 1,024 `max_tokens` வரை வரம்பிடப்பட்டுள்ளது (air-query 700, accountability-brief 1,024, health-advisory 768, anomaly-check 512). ரீசனிங் மாடல்கள் அந்த வரம்பின் ஒரு பகுதியை ரீசனிங்கிற்காகச் செலவிடுகின்றன, எனவே இந்த வரம்பு முழு பதிலையும் கட்டுப்படுத்துகிறதே தவிர, தெரியும் உரையை மட்டும் அல்ல.
- **ஃபைன்-டியூனிங் இல்லை** — ப்ராம்ப்ட் இன்ஜினியரிங் மட்டுமே. ஒவ்வொரு திறனும் ஒரு சிஸ்டம் ப்ராம்ப்ட் தான், ஃபைன்-டியூன் செய்யப்பட்ட மாடல் அல்ல.

## ஒருங்கிணைப்பு கட்டமைப்பு

```
Browser (client)
    │
    │ POST /.netlify/functions/air-query
    │ POST /.netlify/functions/health-advisory
    │ POST /.netlify/functions/accountability-brief
    │ GET  /.netlify/functions/anomaly-check
    │
    ▼
Netlify Function (server-side)
    │
    │ 1. Parse user input
    │ 2. Fetch live AQI data from WAQI
    │ 3. Construct prompt with real data
    │ 4. Call Groq API
    │ 5. Return response (or fallback to raw data)
    │
    ▼
Groq API
    │
    │ openai/gpt-oss-120b model
    │ max_tokens: 512-1,024 (per function)
    │
    ▼
Structured response → Browser
```

**முக்கிய பாதுகாப்பு விதி:** `GROQ_API_KEY` ஒருபோதும் கிளையண்டை அடைவதில்லை. அனைத்து AI அழைப்புகளும் Netlify Functions வழியாக சர்வர்-சைடில் செய்யப்படுகின்றன.

## நான்கு AI அம்சங்கள்

### 1. Ask JanVayu (`air-query.mjs`)
- **உள்ளீடு:** நகரத்தின் பெயர் + ஃப்ரீ-டெக்ஸ்ட் கேள்வி
- **சேர்க்கப்பட்ட சூழல்:** WAQI-லிருந்து நேரடி PM2.5 மற்றும் AQI
- **வெளியீடு:** உண்மையான அளவீடுகளின் அடிப்படையில்
- **மொழிகள்:** கேள்வியின் மொழியிலேயே பதில்கள் கிடைக்கும்; Ask JanVayu UI 10 மொழிகளில் கிடைக்கிறது
- **ஃபால்பேக்:** Groq-இல் ரேட் லிமிட் இருந்தால், மூல AQI தரவை வழங்கும்
### 2. சுகாதார ஆலோசனை (`health-advisory.mjs`)
- **உள்ளீடு:** நகரம் + வயது + உடல்நலக் குறைபாடுகள் + வெளிப்புற நேரம்
- **உட்செலுத்தப்பட்ட சூழல்:** அந்த நகரத்திற்கான நேரடி AQI
- **வெளியீடு:** வண்ணக் குறியீடு செய்யப்பட்ட ஆபத்து நிலை + உறுதியான பரிந்துரைகள்
- **மாற்று வழி:** பொதுவான WHO-வழிகாட்டுதல் ஆலோசனை

### 3. பொறுப்புக்கூறல் சுருக்கம் (`accountability-brief.mjs`)
- **உள்ளீடு:** நகரத்தின் பெயர்
- **உட்செலுத்தப்பட்ட சூழல்:** நேரடி AQI + பருவகால அடிப்படை அளவுகள் + GRAP நிலைகள்
- **வெளியீடு:** கட்டமைக்கப்பட்ட சுருக்கம் (தற்போதைய நிலை, NCAP இலக்குகள், 5 பொறுப்புக்கூறல் கேள்விகள்)
- **அதிகபட்ச டோக்கன்கள்:** 1,024
- **மாற்று வழி:** மூல தரவு அட்டவணையை வழங்குகிறது

### 4. முரண்பாடு கண்டறிதல் (`anomaly-check.mjs`)
- **உள்ளீடு:** இல்லை (5 பெருநகரங்களை தானாகவே கண்காணிக்கிறது)
- **வரம்பு:** 2× பருவகால அடிப்படை = முரண்பாடு
- **வெளியீடு:** ஒவ்வொரு முரண்பாட்டிற்கும் ஒரு வாக்கிய AI விளக்கம்
- **கேச்:** 10 நிமிட HTTP `Cache-Control` தலைப்பு (Netlify Blobs அல்ல)
- **மாற்று வழி:** AI விளக்கம் இல்லாமல் முரண்பாடு கொடியை வழங்குகிறது

மூலம்: [Groq rate limits](https://console.groq.com/docs/rate-limits). நீண்ட air-query system prompt காரணமாக 8,000 டோக்கன்கள்-ஒரு-நிமிட வரம்பு குறைவாக உள்ளது, எனவே 429 பதில்களைக் கண்காணிப்பது மதிப்புமிக்கது.

JanVayu இந்த பட்ஜெட்டை அம்சங்களுக்கு இடையே பிரிக்கிறது (Netlify பதிவேடுகளிலிருந்து அளவிடப்படாத மதிப்பீடுகள்):
- முரண்பாடு சரிபார்ப்பு: ~144/நாள் (கேச் செய்யப்பட்டது, பக்கத்தை ஏற்றும் போது செயல்படும்)
- காற்று வினவல்: ~50/நாள் (பயனர் தொடங்குவது)
- சுகாதார ஆலோசனை: ~30/நாள் (பயனர் தொடங்குவது)
- பொறுப்புக்கூறல் சுருக்கம்: ~20/நாள் (பயனர் தொடங்குவது)

வரம்புகள் எட்டப்பட்டால், ஒவ்வொரு செயல்பாடும் மூல தரவுக்கு மாறும். பயனருக்கு எப்போதும் ஒரு பதில் கிடைக்கும் — AI பகுப்பாய்வு இல்லாமல்.

## Prompt Engineering

அனைத்து தூண்டுதல்களும் இந்த கொள்கைகளைப் பின்பற்றுகின்றன:

1. **எப்போதும் உண்மையான தரவைச் செலுத்துங்கள்** — மாடல் ஒருபோதும் நினைவகத்திலிருந்து உருவாக்காது
2. **சரியான வெளியீட்டு வடிவமைப்பைக் குறிப்பிடவும்** — குறிப்பாக கட்டமைக்கப்பட்ட சுருக்கங்களுக்கு
3. **சொல் எண்ணிக்கையைக் கட்டுப்படுத்துங்கள்** — ஒவ்வொரு தூண்டுதலிலும் வெளிப்படையான வரம்புகள்
4. **தோல்வி முறைகளைக் குறிப்பிடவும்** — "பொதுவான ஆலோசனைகளை வழங்க வேண்டாம்", "தெளிவற்ற பதில்களை வழங்க வேண்டாம்"
5. **பல்மொழி அறிவுறுத்தல்** — "கேள்வியின் மொழியில் பதிலளிக்கவும்"
6. **தடையற்ற வீழ்ச்சி** — ஒவ்வொரு செயல்பாட்டிற்கும் AI அல்லாத மாற்றுப் பாதை உள்ளது
முழுமையான ப்ராம்ப்ட் (prompt) ஆவணங்களுக்கு [Skills & AI Prompts](../skills/README.md) பகுதியை பார்க்கவும்.
