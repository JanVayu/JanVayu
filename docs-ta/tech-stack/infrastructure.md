# உள்கட்டமைப்பு
ஜான்வாயு (JanVayu) முழுமையாக நெட்லைஃபியின் (Netlify) தளத்தில் இயங்குகிறது, மேலும் கிட்ஹப் (GitHub) தான் உண்மைக்கான ஆதாரமாக உள்ளது. இதில் பாரம்பரிய சர்வர்கள், தரவுத்தளங்கள் அல்லது கண்டெய்னர் ஆர்கெஸ்ட்ரேஷன் எதுவும் இல்லை.

## நெட்லைஃபி (Netlify)
### ஹோஸ்டிங்
- **CDN:** நெட்லைஃபியின் உலகளாவிய எட்ஜ் நெட்வொர்க்
- **டெப்லாய் ட்ரிக்கர்:** கிட்ஹப்பில் உள்ள `main` பிரிஷுக்கு புஷ் (Push) செய்வது
- **பில்ட் கமாண்ட்:** `node scripts/bump-version.mjs` (வெர்ஷன் ஸ்டாம்ப் மட்டும்; பண்ட்லர் இல்லை)
- **பப்ளிஷ் டைரக்டரி:** `.` (ரெபாசிட்டரி ரூட்)
- **ஃபங்ஷன்ஸ் டைரக்டரி:** `netlify/functions/`
### கட்டமைப்பு (`netlify.toml`)
```toml
[build]
  command = "node scripts/bump-version.mjs"
  publish = "."
  functions = "netlify/functions"
[build.environment]
  NODE_VERSION = "24"
```
### பாதுகாப்பு தலைப்புகள் (Security Headers)
இரண்டு விதிவிலக்குகளைத் தவிர மற்ற அனைத்து பாதைகளுக்கும் (`/*`) இவை பயன்படுத்தப்படுகின்றன: `/embed/*` என்பது `X-Frame-Options = "ALLOWALL"` என அமைக்கிறது, இதனால் விட்ஜெட்களை எந்தவொரு மூலத்திலிருந்தும் ஃப்ரேம் செய்ய முடியும், மேலும் `/walkthrough/*` என்பது `SAMEORIGIN` என அமைக்கிறது:
| தலைப்பு | மதிப்பு | நோக்கம் |
|--------|-------|--------|
| `X-Frame-Options` | `DENY` | கிளிக்ஜாக்கிங்கைத் தடுக்கிறது |
| `X-Content-Type-Options` | `nosniff` | MIME ஸ்னிஃபிங்கைத் தடுக்கிறது |
| `Referrer-Policy` | `strict-origin-when-cross-origin` | ரெஃபரர் தரவைக் கட்டுப்படுத்துகிறது |
### ரீடைரக்ட்கள் (Redirects)
- `janvayu.in/*` → `www.janvayu.in/:splat` (301; கேனானிக்கல் URL `www.janvayu.in` ஆகும்)
- மற்ற அனைத்து வழிகளும் (routes) → `/index.html` (SPA ஃபால்பேக்), `/docs`, `/blog`, `/embed`, `/api`, `/ask`, `/status` மற்றும் ஒவ்வொரு மாசுக்கான பக்கங்களுக்கான `netlify.toml` இல் உள்ள குறிப்பிட்ட விதிகளுக்குப் பிறகு இது செயல்படும்
- `/robots.txt` மற்றும் `/sitemap.xml` ஆகியவை SPA ஃபால்பேக்கை தவிர்க்கின்றன

- **டீஃபால்ட் பிரான்ச்:** `main`
- **டெப்லாய்ஸ்:** `main` பிரிஷுக்கு புஷ் செய்யப்படும் ஒவ்வொரு முறையும் நெட்லைஃபி பில்ட் செய்யும் (`build` எப்போது லைவ் ஆகும் என்பதை அறிய [Deployment](../technical/deployment.md) ஐப் பார்க்கவும்)
### CI/CD
- **GitHub Actions** (`.github/workflows/`, 16 ஒர்க்ஃப்ளோக்கள்): `ci.yml` (`index.html`, தள புள்ளிவிவரங்கள் மற்றும் நெட்லைஃபி ஃபங்ஷன்களுக்கான பாதுகாப்புகள், யூனிட் டெஸ்ட்கள் மற்றும் Lychee லிங்க் செக்கர்), `link-audit`, `accessibility`, `lighthouse`, `codeql`, `translations`, `quality`, `cpcb-bulletins` (தினசரி CPCB ஃபெட்ச்), `live-audit` (CPCB-க்கு எதிரான நேரடி அளவீடுகள்), `function-health`, `ask-eval`, `current-year-air` மற்றும் பிற ஃபைல்கள்
- **Dependabot** (`dependabot.yml`): GitHub Actions மற்றும் npm-க்கான மாதாந்திர அப்டேட்கள், இதில் மைனர் மற்றும் பேட்ச் அப்டேட்கள் ஒன்றாக குழுவாக்கப்பட்டுள்ளன
