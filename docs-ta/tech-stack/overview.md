# தொழில்நுட்ப அடுக்கு கண்ணோட்டம்
ஜனவ்யூ வேண்டுமென்றே மிகக் குறைந்த தொழில்நுட்ப அடுக்குகளைக் கொண்டு உருவாக்கப்பட்டுள்ளது — பூஜ்ஜிய முன்முனை கட்டமைப்புகள் (frontend frameworks), மூன்று npm சார்புகள் (dependencies), மற்றும் ஒரு சர்வர்லெஸ் பின்புலம். பயன்படுத்தப்பட்ட ஒவ்வொரு தொழில்நுட்பமும் அது ஏன் தேர்ந்தெடுக்கப்பட்டது என்பதையும் இந்தப் பக்கம் விளக்குகிறது.

| **Docs** | Docsify (5 மொழிகள்) | `/docs/` இல் ஒற்றை ஷெல்; மொழி ஹாஷ் வழிகள் (`/docs/#/hi/` போன்றவை) `docs-{lang}/` மார்க் டவுனை ஏற்றுகின்றன |

## இந்த அடுக்கு ஏன்?
### பூஜ்ஜிய-கட்டமைப்பு முன்முனை
ஜனவ்யூவின் பயனர்களில் இந்தியா முழுவதும் 2G இணைப்புகள் மற்றும் குறைந்த திறன் கொண்ட ஆண்ட்ராய்டு சாதனங்களைப் பயன்படுத்துபவர்கள் அடங்குவர். React அல்லது Vue போன்ற ஒரு கட்டமைப்பு, ஒரு அம்சம் கூட செயல்படுவதற்கு முன் பதிவிறக்கம் செய்ய வேண்டிய ஒரு கட்டமைப்பு இயக்கநேரத்தை (runtime) சேர்க்கும். அதற்குப் பதிலாக:
- இந்த செயலி `index.html` மற்றும் `styles.css`, `app.js`, `games.js` மற்றும் 19 சோம்பேறி-ஏற்றப்பட்ட (lazy-loaded) பேனல் துண்டுகளைக் கொண்டுள்ளது, இதில் எந்த பண்ட்லரும் (bundler) இல்லை
- எந்த டிரான்ஸ்பைலேஷன், பண்ட்லிங், ட்ரீ-ஷேக்கிங் ஆகியவையும் தேவையில்லை
- பயன்படுத்தும் கலைப்பொருள் (Deploy artefact) = ரெபாசிட்டரியே
- அடிப்படை HTML/JS திறன்களைக் கொண்ட எந்தவொரு பங்களிப்பாளரும் பங்களிக்க முடியும்
### 3 npm சார்புகள் மட்டுமே
```json
{
  "@netlify/blobs": "^11.0.2",
  "resend": "^6.14.0",
  "web-push": "^3.6.7"
}
```
இந்த மூன்றிலும் சர்வர்-பக்கத்திற்கு மட்டுமே பயன்படும் (Netlify Functions மூலம் பயன்படுத்தப்படுகிறது). AI அம்சங்கள் `fetch` வழியாக நேரடியாக Groq REST API-ஐ (OpenAI-இணக்கமானது) பயன்படுத்துகின்றன — SDK தேவையில்லை. கிளையண்டில் பூஜ்ஜிய npm சார்புகள் உள்ளன — Chart.js மற்றும் Leaflet.js ஆகியவை CDN இலிருந்து ஏற்றப்படுகின்றன.
### சர்வரை விட சர்வர்லெஸ்
###
Netlify Functions ஒரு நிலையான சர்வரின் தேவையை நீக்குகிறது. நன்மைகள்:
- செயல்பாட்டுச் சுமை இல்லை (சர்வர் பேட்சிங் இல்லை, ஸ்கேலிங் இல்லை)
- தானியங்கி HTTPS, CDN மற்றும் எட்ஜ் டிப்ளாய்மென்ட்
