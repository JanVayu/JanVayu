# மொழிபெயர்ப்பு வழிகாட்டி

JanVayu 5 மொழிகளை ஆதரிக்கிறது: ஆங்கிலம், இந்தி, தமிழ், மராத்தி மற்றும் பெங்காலி.

---

## மொழிபெயர்ப்பு எவ்வாறு செயல்படுகிறது

### UI உரை (data-i18n)

```html
<span data-i18n="tagline">Citizen Air Quality Platform</span>
```

மொழிபெயர்ப்புகள் ஒரு JavaScript ஆப்ஜெக்ட்டில் சேமிக்கப்பட்டு `setLanguage()` மூலம் பயன்படுத்தப்படுகின்றன.

### ஆவணங்கள்

மொழிபெயர்க்கப்பட்ட ஆவணங்கள் அந்தந்த மொழி டைரக்டரிகளில் உள்ளன:
- `docs/` — ஆங்கிலம் (அடிப்படை)
- `docs-hi/` — இந்தி
- `docs-ta/` — தமிழ்
- `docs-mr/` — மராத்தி
- `docs-bn/` — பெங்காலி

### எளிய மொழி (data-simple)

தற்போது ஆங்கிலம் மட்டுமே. எதிர்காலத்தில்: `data-simple-hi`, `data-simple-ta`, போன்றவை.

---

## மொழிபெயர்ப்புகளை வழங்குதல்

### விருப்பம் 1: UI ஸ்ட்ரிங்குகளை மொழிபெயர்த்தல்

1. `index.html`-ல் `data-i18n` உள்ள எலிமெண்ட்களைக் கண்டறியவும்
2. மொழி ஆப்ஜெக்ட்டில் மொழிபெயர்க்கப்பட்ட ஸ்ட்ரிங்கைச் சேர்க்கவும்
3. ஹெடரில் மொழிகளை மாற்றுவதன் மூலம் சோதிக்கவும்

### விருப்பம் 2: ஆவணங்களை மொழிபெயர்த்தல்

1. உங்கள் மொழி டைரக்டரியில் இல்லாத `docs/` இலிருந்து ஒரு ஃபைலைத் தேர்ந்தெடுக்கவும்
2. `docs-{lang}/`-ல் அதற்கு இணையான ஃபைலை உருவாக்கவும்
3. அதே அமைப்பைப் பராமரித்து மொழிபெயர்க்கவும்
4. ஒரு PR-ஐ சமர்ப்பிக்கவும்

### விருப்பம் 3: எளிய மொழி உரையை மொழிபெயர்த்தல்

1. `data-simple` பண்புகளைக் கொண்ட எலிமெண்ட்களைக் கண்டறியவும்
2. உங்கள் மொழியில் மொழிபெயர்க்கவும்

---

## மொழிபெயர்ப்பு CI

`translations.yml` GitHub Action பின்வருவனவற்றைச் சரிபார்க்கிறது:
- ஒவ்வொரு மொழி டைரக்டரியிலும் எந்த ஃபைல்கள் உள்ளன
- ஒவ்வொரு மொழிக்கும் கவரேஜ் சதவீதம்
- CI அவுட்புட்டில் விடுபட்ட ஃபைல்கள் குறித்து தெரிவிக்கப்படுதல்

---

## வழிகாட்டுதல்கள்

- மொழிபெயர்ப்புகளை இயல்பாக வைத்திருங்கள் — வார்த்தைக்கு வார்த்தை மொழிபெயர்க்க வேண்டாம்
- காற்றின் தர விதிமுறைகள் (PM2.5, AQI, NCAP) ஆங்கிலத்திலேயே இருக்கலாம்
- பொருத்தமான இடங்களில் ஸ்கிரிப்ட்டின் சொந்த எண்களைப் பயன்படுத்தவும்
- மொபைலில் சோதிக்கவும் — சில ஸ்கிரிப்ட்களுக்கு அதிக கிடைமட்ட இடம் தேவைப்படும்
- தொனியைப் பொருத்தவும்: அவசரம் ஆனால் பீதியடையச் செய்யாதது, தொழில்நுட்பம் ஆனால் எளிதில் புரிந்துகொள்ளக்கூடியது
