# எளிய மொழி முறை
JanVayu-வில் சிக்கலான தொழில்நுட்பத் தகவல்கள் (PM2.5 செறிவுகள், GEMM இறப்பு மாதிரிகள், கொள்கை சுருக்கப்பெயர்கள்) உள்ளன. எளிய மொழி முறை இந்தத் தகவல்களை யார் வேண்டுமானாலும் எளிதில் புரிந்துகொள்ளும் வகையில், எந்தக் கடினமான சொற்களும் இல்லாத எளிய மொழியில் மாற்றியமைக்கிறது.
---
## இது எவ்வாறு செயல்படுகிறது
1. **மாற்றுதல் (Toggle)**: பக்கத்தின் மேற்புறத்தில் உள்ள பட்டியில் உள்ள Simple என்பதைக் கிளிக் செய்யவும் (மொபைலில் Menu-க்குள் இருக்கும்), அல்லது சொற்களஞ்சியப் பலகத்தில் உள்ள மாற்று பொத்தானைப் பயன்படுத்தவும்
2. **மாற்றுதல் (Swap)** — `data-simple` பண்புக்கூறுகளைக் கொண்ட அனைத்து கூறுகளின் உள்ளடக்கமும் எளிய மொழிப் பதிப்புகளால் மாற்றப்படும்
3. **தொடர்ந்து வைத்திருத்தல் (Persist)** — நிலை `sessionStorage`-இல் சேமிக்கப்பட்டு, பக்கம் மீண்டும் ஏற்றப்படும்போது மீட்டமைக்கப்படும்
4. **காட்சி குறியீடு** — எளிமைப்படுத்தப்பட்ட உரைக்கு அருகில் ஒரு பச்சை நிற "Simple language" பேட்ஜ் தோன்றும்
5. **திரும்பப் பெறக்கூடியது** — தொழில்நுட்ப மொழியை மீட்டெடுக்க மீண்டும் கிளிக் செய்யவும்
---
## தொழில்நுட்பச் செயலாக்கம்
### HTML பண்புக்கூறுகள்
எந்தவொரு கூறுக்கும் `data-simple` பண்புக்கூறைச் சேர்ப்பதன் மூலம் அதை எளிய-முறைக்கு ஏற்புடையதாக மாற்றலாம்:
```html
<p data-simple="அழுக்கான காற்று ஒவ்வொரு ஆண்டும் இந்தியாவுக்கு நிறைய பணத்தை இழக்கச் செய்கிறது.">
    இந்தியாவில் வெளிப்புற காற்று மாசுபாட்டால் ஏற்படும் முன்கூட்டிய மரணங்களின் பண மதிப்பு 2022-இல் $339.4 பில்லியனாக இருந்தது (GDP-இல் 9.5%).
</p>
```
### JavaScript
```javascript
let simpleMode = sessionStorage.getItem('janvayu-simple-mode') === 'true';
function toggleSimpleMode() {
    simpleMode = !simpleMode;
    sessionStorage.setItem('janvayu-simple-mode', simpleMode);
    applySimpleMode();
}
function applySimpleMode() {
    document.body.classList.toggle('simple-language', simpleMode);
    document.querySelectorAll('[data-simple]').forEach(el => {
        if (simpleMode) {
            if (!el.dataset.technical) el.dataset.technical = el.innerHTML;
            el.innerHTML = el.dataset.simple;
        } else {
            if (el.dataset.technical) el.innerHTML = el.dataset.technical;
        }
    });
}
```

## உள்ளடக்கம்
- பேனல் அறிமுகப் பத்திகள்
- 20 சொற்களஞ்சிய வரையறைகள் (தொழில்நுட்ப / எளிய)
- முக்கிய நுண்ணறிவுப் பெட்டிகள், எச்சரிக்கைப் பெட்டிகள், இழுத்துப் பயன்படுத்தும் மேற்கோள்கள் (pull-quotes)
- பட்ஜெட், கொள்கை, சுகாதாரம், குழந்தைகள், உட்புற, சட்ட, செயல் பேனல்கள்
### எளிய உரையைச் சேர்த்தல்
1. `index.html`-இல் உள்ள கூறைக் கண்டறியவும்
2. `data-simple="உங்கள் எளிய மொழிப் பதிப்பு இங்கே"` என்பதைச் சேர்க்கவும்
3. சிறப்பு எழுத்துகளுக்கு HTML என்டிட்டிகளைப் பயன்படுத்தவும்: `&lt;strong&gt;`, `&amp;`
4. 12 வயது குழந்தைக்குப் புரியும் வகையில் எழுதவும்: சிறிய வாக்கியங்கள், சுருக்கப்பெயர்கள் வேண்டாம், உறுதியான எடுத்துக்காட்டுகள்
5. அதே அர்த்தத்தை அப்படியே வைத்திருக்கவும் — மொழியை எளிமையாக்க வேண்டுமே தவிர, உள்ளடக்கத்தை அல்ல
