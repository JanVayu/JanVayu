# எளிய மொழி முறை

ஜான்வாயுவில் சிக்கலான தொழில்நுட்ப உள்ளடக்கங்கள் (PM2.5 செறிவுகள், GEMM இறப்பு மாதிரிகள், கொள்கை சுருக்கப்பெயர்கள்) உள்ளன. எளிய மொழி முறை இந்த உள்ளடக்கங்களை யாருக்கும் புரியும் வகையில், எளிய, தொழில்சார் சொற்கள் இல்லாத மொழியில் மாற்றி எழுதுகிறது.

---

## இது எப்படி வேலை செய்கிறது

1. **மாற்றுதல்** — தலைப்பில் உள்ள கண் ஐகானைக் கிளிக் செய்யவும், அல்லது சொற்களஞ்சியப் பலகையில் உள்ள சுவிட்சைப் பயன்படுத்தவும்
2. **மாற்றுதல்** — `data-simple` பண்புகளைக் கொண்ட அனைத்து கூறுகளின் உள்ளடக்கமும் எளிய மொழிப் பதிப்புகளாக மாற்றப்படும்
3. **நிரந்தரமாக்குதல்** — நிலை `sessionStorage`-ல் சேமிக்கப்பட்டு, பக்கத்தை மீண்டும் ஏற்றும்போது மீட்டமைக்கப்படும்
4. **காட்சி குறியீடு** — எளிமைப்படுத்தப்பட்ட உரைக்கு அருகில் பச்சை நிற "எளிய மொழி" பேட்ஜ் தோன்றும்
5. **மீளமைக்கக்கூடியது** — தொழில்நுட்ப மொழியை மீட்டெடுக்க மீண்டும் கிளிக் செய்யவும்

---

## தொழில்நுட்பச் செயலாக்கம்

### HTML பண்புகள்

எந்தவொரு கூறுக்கும் `data-simple` பண்பைச் சேர்ப்பதன் மூலம் அதை எளிய-முறைக்கு ஏற்றவாறு மாற்றலாம்:

```html
<p data-simple="அழுக்கான காற்று ஒவ்வொரு ஆண்டும் இந்தியாவிற்கு நிறைய பணத்தை இழக்கச் செய்கிறது.">
    இந்தியாவில் வெளிப்புற காற்று மாசுபாட்டால் ஏற்படும் முன்கூட்டிய மரணங்களின் பண மதிப்பு 2022-ல் $339.4 பில்லியன் (GDP-ல் 9.5%) ஆகும்.
</p>
```

### JavaScript

```javascript
let simpleMode = sessionStorage.getItem('janvayu-simple-mode') === 'true';

function toggleSimpleMode() {
    simpleMode = !simpleMode;
    sessionStorage.setItem('janvayu-simple-mode', simpleMode);
    applySimpleMode();
}

function applySimpleMode() {
    document.body.classList.toggle('simple-language', simpleMode);
    document.querySelectorAll('[data-simple]').forEach(el => {
        if (simpleMode) {
            if (!el.dataset.technical) el.dataset.technical = el.innerHTML;
            el.innerHTML = el.dataset.simple;
        } else {
            if (el.dataset.technical) el.innerHTML = el.dataset.technical;
        }
    });
}
```

## உள்ளடக்கங்கள்

- பேனல் அறிமுகப் பத்திகள்
- 20 சொற்களஞ்சிய வரையறைகள் (தொழில்நுட்பம் / எளியது)
- முக்கிய நுண்ணறிவு பெட்டிகள், எச்சரிக்கை பெட்டிகள், புல்-கோட்ஸ்
- பட்ஜெட், கொள்கை, சுகாதாரம், குழந்தைகள், உட்புறம், சட்டரீதியான, நடவடிக்கை பேனல்கள்

### எளிய உரையைச் சேர்த்தல்

1. `index.html`-ல் உள்ள கூறைக் கண்டறியவும்
2. `data-simple="உங்கள் எளிய மொழிப் பதிப்பு இங்கே"` என்பதைச் சேர்க்கவும்
3. சிறப்பு எழுத்துகளுக்கு HTML நிறுவனங்களைப் பயன்படுத்தவும்: `&lt;strong&gt;`, `&amp;`
4. 12 வயது குழந்தைக்குப் புரியும் வகையில் எழுதவும்: குறுகிய வாக்கியங்கள், சுருக்கப்பெயர்கள் இல்லை, உறுதியான எடுத்துக்காட்டுகள்
5. அதே அர்த்தத்தை வைத்திருக்கவும் — மொழியை எளிமையாக்குங்கள், உள்ளடக்கத்தை அல்ல
