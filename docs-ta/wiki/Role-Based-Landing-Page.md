# பாத்திர அடிப்படையிலான முகப்புப் பக்கம்
ஜான்வாயு பல்வேறு தரப்பினருக்கும் சேவை செய்கிறது — தங்கள் குழந்தை வெளியே செல்வது பாதுகாப்பானதா என்று சரிபார்க்கும் பெற்றோர்கள் முதல், தரவுத்தொகுப்புகளை அணுகும் ஆராய்ச்சியாளர்கள், அரசியல் பொறுப்புணர்வை கண்காணிக்கும் பத்திரிகையாளர்கள் வரை. பாத்திர அடிப்படையிலான முகப்புப் பக்கம் ஒவ்வொரு பயனருக்கும் அனுபவத்தை தனிப்பயனாக்குகிறது.
---
## இது எவ்வாறு செயல்படுகிறது
1. **முதல் வருகை** — பக்கம் நேரடி காற்று அளவீட்டுடன் திறக்கப்படும்; முழுத்திரை ஓவர்லே எதுவும் இல்லை (இது செப்டம்பர் 2026 இல் அகற்றப்பட்டது)
2. **பாத்திரத் தேர்வு** — பயனர் தலைப்பில் உள்ள பாத்திர ஸ்விட்சரிலிருந்து ஒரு பாத்திரத்தைத் தேர்ந்தெடுக்கிறார் (அல்லது "எல்லாவற்றையும் காட்டு" என்பதைத் தேர்ந்தெடுக்கிறார்)
3. **தனிப்பயனாக்கப்பட்ட டேஷ்போர்டு** — பாத்திரத்திற்குரிய செயல்கள் மற்றும் பரிந்துரைக்கப்பட்ட பேனல்களைக் காட்டுகிறது
4. **தொடர்ச்சியானது** — பாத்திரம் `localStorage`-இல் சேமிக்கப்பட்டு, அடுத்தடுத்த வருகைகளில் மீட்டமைக்கப்படுகிறது
5. **மாற்றக்கூடியது**: பாத்திர ஸ்விட்சர் பட்டியில் உள்ள முதல் கட்டுப்பாடாகும் ("நீங்கள் யார்", அல்லது தேர்ந்தெடுக்கப்பட்ட பாத்திரத்தின் பெயர்) மற்றும் எப்போது வேண்டுமானாலும் மாற்ற அனுமதிக்கிறது. தொலைபேசியில் இது Menu-க்குள் இருக்கும்

## பாத்திர கட்டமைப்பு
ஒவ்வொரு பாத்திரமும் `index.html`-இல் உள்ள `ROLE_CONFIG` ஆப்ஜெக்ட்டில் பின்வருமாறு வரையறுக்கப்பட்டுள்ளது:
```javascript
{
    icon: '<span class="si si-home"></span>',
    label: 'Parent / Family',
    heading: 'Protect your family from air pollution',
    description: 'Real-time safety checks, school closure info...',
    actions: [
        { icon, panel, title, desc, cta }  // 3 action cards
    ],
    panels: [
        { panel, title, desc }  // 6 recommended panels
    ]
}
```
