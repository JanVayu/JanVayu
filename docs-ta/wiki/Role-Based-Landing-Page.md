# பாத்திர அடிப்படையிலான முகப்புப் பக்கம்

ஜான்வாயூ (JanVayu) பலவிதமான பயனர்களுக்குச் சேவை செய்கிறது — தங்கள் குழந்தை வெளியே செல்வது பாதுகாப்பானதா என்று சரிபார்க்கும் பெற்றோர்கள் முதல், தரவுகளைப் பயன்படுத்தும் ஆராய்ச்சியாளர்கள், அரசியல் பொறுப்புணர்வை கண்காணிக்கும் பத்திரிகையாளர்கள் வரை. பாத்திர அடிப்படையிலான முகப்புப் பக்கம் ஒவ்வொரு பயனருக்கும் ஏற்ற அனுபவத்தை வழங்குகிறது.

---

## இது எப்படி வேலை செய்கிறது

1. **முதல் வருகை** — பக்கம் நேரடி காற்றின் தரத் தகவலுடன் திறக்கும்; முழுத் திரையை மறைக்கும் ஓவர்லே (overlay) எதுவும் இல்லை (இது செப்டம்பர் 2026-ல் நீக்கப்பட்டது)
2. **பாத்திரத்தைத் தேர்ந்தெடுத்தல்** — பயனர் தலைப்பில் உள்ள role switcher-லிருந்து ஒரு பாத்திரத்தைத் தேர்ந்தெடுக்கிறார் (அல்லது "Show Everything" என்பதைத் தேர்ந்தெடுக்கிறார்)
3. **தனிப்பயனாக்கப்பட்ட டேஷ்போர்டு** — பாத்திரம் சார்ந்த செயல்கள் மற்றும் பரிந்துரைக்கப்பட்ட பேனல்களைக் காட்டும்
4. **தொடர்ச்சியானது** — பாத்திரம் `localStorage`-ல் சேமிக்கப்பட்டு, மீண்டும் வரும்போது மீட்டமைக்கப்படும்
5. **மாற்றக்கூடியது** — தலைப்பில் உள்ள role switcher ஐகான் (வலதுபுறம் உள்ள ஐகான்) எப்போது வேண்டுமானாலும் பாத்திரத்தை மாற்ற அனுமதிக்கிறது

## பாத்திர கட்டமைப்பு

ஒவ்வொரு பாத்திரமும் `index.html`-ல் உள்ள `ROLE_CONFIG` ஆப்ஜெக்ட்டில் பின்வருமாறு வரையறுக்கப்பட்டுள்ளது:

```javascript
{
    icon: '<span class="si si-home"></span>',
    label: 'Parent / Family',
    heading: 'Protect your family from air pollution',
    description: 'Real-time safety checks, school closure info...',
    actions: [
        { icon, panel, title, desc, cta }  // 3 action cards
    ],
    panels: [
        { panel, title, desc }  // 6 recommended panels
    ]
}
```

- **Dashboard template:** `#tmpl-role-dashboard`
- **பயண வழிகாட்டி:** பயனர் தனது முதல் role-ஐத் தேர்ந்தெடுத்த பிறகு, பயனர் இதற்கு முன் பயண வழிகாட்டியைக் (tour) கண்டிருக்கவில்லை என்றால் இது தூண்டப்படும்
