# எப்படி பங்களிப்பது

இந்தியாவின் காற்று மாசு நெருக்கடியை விரிவாக ஆவணப்படுத்த, JanVayu சமூகத்தின் பங்கேற்பை நம்பியுள்ளது. ஆராய்ச்சியாளர்கள், பத்திரிகையாளர்கள், டெவலப்பர்கள் மற்றும் குடிமக்கள் என அனைவரின் பங்களிப்புகளும் வரவேற்கப்படுகின்றன.

---

## பங்களிப்புகளின் வகைகள்

### ஆராய்ச்சியாளர்கள்
- காற்று மாசுவால் ஏற்படும் சுகாதார பாதிப்புகள் குறித்த தரவுகள் மற்றும் ஆய்வுக் கட்டுரைகளைப் பகிர்தல்
- ஏற்கனவே உள்ள தகவல்களைச் சரிபார்க்கவும் உண்மைத்தன்மையை உறுதி செய்யவும் உதவுதல்
- பகுப்பாய்வு மற்றும் காட்சிப்படுத்தல்களை (visualisations) வழங்குதல்
- ஆராய்ச்சிச் சுருக்கங்களை இந்திய மொழிகளில் மொழிபெயர்த்தல்

### பத்திரிகையாளர்கள்
- சரிபார்க்கப்பட்ட புலனாய்வு அறிக்கைகளைப் பகிர்தல்
- உள்ளூர் காற்று மாசு குறித்த செய்திகளை ஆவணப்படுத்துதல்
- முக்கியமான ஊடகச் செய்திகளைப் பாதுகாத்தல்
- பொறுப்புக்கூறல் கண்காணிப்பாளருக்கு (accountability tracker) பங்களித்தல்

### டெவலப்பர்கள்
- பிழைகளைப் புகாரளித்தல் மற்றும் மேம்பாடுகளைப் பரிந்துரைத்தல்
- குறியீடு திருத்தங்கள் (code fixes) மற்றும் புதிய அம்சங்களை வழங்குதல்
- தரவுக் காட்சிப்படுத்தல் கருவிகளை உருவாக்குதல்
- அணுகல்தன்மை (accessibility) மற்றும் செயல்திறனை மேம்படுத்துதல்

### குடிமக்கள்
- நேரடி அனுபவங்களைப் பகிர்தல் (விருப்பப்பட்டால் பெயர் குறிப்பிடாமல் பகிரலாம்)
- உள்ளூர் காற்று மாசு நிலைகளை ஆவணப்படுத்துதல்
- தகவல்களை வட்டார மொழிகளில் மொழிபெயர்க்க உதவுதல்
- விழிப்புணர்வை ஏற்படுத்துதல்

### வடிவமைப்பாளர்கள்
- காட்சி அணுகல்தன்மையை மேம்படுத்துதல்
- தகவல் வரைபடங்கள் (infographics) மற்றும் கல்விப் பொருட்களை உருவாக்குதல்
- UI/UX மேம்பாடுகளுக்கு உதவுதல்

## குறியீட்டுப் பங்களிப்புகளுக்கு (Code Contributions)

```bash
# 1. Fork the repository
# 2. Clone your fork
git clone https://github.com/YOUR_USERNAME/JanVayu.git
cd JanVayu

# 3. Create a branch
git checkout -b feature/your-feature-name

# 4. Make your changes and test locally
netlify dev

# 5. Commit with a clear message
git commit -m "Add: PM10 toggle on city cards"

# 6. Push and open a Pull Request
git push origin feature/your-feature-name
```

[github.com/JanVayu/JanVayu](https://github.com/JanVayu/JanVayu) இல் உள்ள `main` branch-க்கு எதிராக உங்கள் PR-ஐத் திறக்கவும்.

---

## உள்ளடக்கப் பங்களிப்புகளுக்கு (Content Contributions)

1. **GitHub-ல் ஒரு Issue-ஐத் திறக்கவும்** — நீங்கள் என்ன பங்களிக்க விரும்புகிறீர்கள் என்பதை விவரிக்கவும்
2. **ஆதாரங்களை வழங்கவும்** — அனைத்து உள்ளடக்கமும் URL அல்லது ஆவணம் மூலம் சரிபார்க்கக்கூடியதாக இருக்க வேண்டும்
3. **பின்னணியைச் சேர்க்கவும்** — இது JanVayu காப்பகத்திற்கு ஏன் பொருத்தமானது என்பதை விளக்கவும்
4. அங்கீகரிக்கப்பட்டால், அதைச் சேர்ப்பதற்கான வழிகாட்டுதலை ஒரு பராமரிப்பாளர் (maintainer) வழங்குவார்

---

## தரவுக் பங்களிப்புகளுக்கு (Data Contributions)

- தரவு முறையான, சரிபார்க்கக்கூடிய ஆதாரத்திலிருந்து வருவதை உறுதிசெய்யவும்
- தெளிவான உரிமையாளர் மற்றும் உரிமத் தகவலை வழங்கவும்
- பொருந்தினால் வழிமுறை ஆவணங்களைச் சேர்க்கவும்
- முடிந்தவரை RTI பதில்கள் அல்லது அசல் ஆவணங்களை இணைக்கவும்

## Pull Request சரிபார்ப்புப் பட்டியல் (Checklist)

PR-ஐச் சமர்ப்பிக்கும் முன், இவற்றைச் சரிபார்க்கவும்:
- [ ] மாற்றங்கள் உள்ளூர் உருவாக்கத்தில் (`netlify dev`) சரியாக வேலை செய்கின்றன
- [ ] எந்த கோப்பிலும் ரகசியங்கள் அல்லது API keys கடினக் குறியீடாக (hardcoded) இல்லை
- [ ] புதிய environment variables `docs/technical/environment-variables.md`-இல் ஆவணப்படுத்தப்பட்டுள்ளன
- [ ] குறியீடு [code standards](code-standards.md)-ஐப் பின்பற்றுகிறது
- [ ] உள்ளடக்கம் [content standards](content-standards.md)-ஐப் பின்பற்றுகிறது
- [ ] மொபைலில் தளம் சரியாகத் தோன்றுகிறது (browser devtools-இல் சரிபார்க்கவும்)
