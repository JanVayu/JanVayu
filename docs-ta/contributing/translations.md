# மொழிபெயர்ப்புகள்
ஜான்வாயு இந்தியாவின் மொழியியல் பன்முகத்தன்மைக்கு ஏற்ப அனைவரையும் சென்றடையும் வகையில் செயல்பட உறுதிபூண்டுள்ளது. இந்தத் தளம் தற்போது ஆங்கிலம், இந்தி, தமிழ், மராத்தி மற்றும் பெங்காலி ஆகிய மொழிகளை ஆதரிக்கிறது. இதன் இடைமுகம் ஐந்து மொழிகளிலும் முழுமையாக மொழிபெயர்க்கப்பட்டுள்ளது; ஆவணங்கள் ஏறக்குறைய முழுமையாக மொழிபெயர்க்கப்பட்டுள்ளன (21 நவம்பர் 2026 நிலவரப்படி, ஒவ்வொரு மொழிபெயர்க்கப்பட்ட பிரிவிலும் உள்ள 74 ஆங்கிலப் பக்கங்களில் 68 முதல் 71 பக்கங்கள் வரை; விடுபட்டவற்றில் பெரும்பாலானவை தேதியிடப்பட்ட உண்மைச் சரிபார்ப்பு அறிக்கைகள் ஆகும்).

## மொழிபெயர்ப்பிற்கு எவ்வாறு பங்களிப்பது
### புதிய மொழியைச் சேர்த்தல்
1. `Translation: Add [Language Name] support` என்ற தலைப்பில் ஒரு Issue-ஐத் திறக்கவும்
2. பின்வருவனவற்றைச் சேர்க்கவும்:
   - உங்கள் பெயர் (அல்லது முகவரி) மற்றும் மொழித்திறன்
   - உள்ளடக்கப் புதுப்பிப்புகளுக்கு ஏற்ப, காலப்போக்கில் மொழிபெயர்ப்புகளைப் பராமரிக்க முடியுமா என்பது
3. ஒரு பராமரிப்பாளர் ஒரு கிளை (branch) உருவாக்கி, மொழிபெயர்ப்பதற்கான மூல சரங்களை (source strings) வழங்குவார்
### ஏற்கனவே உள்ள மொழிபெயர்ப்பை மேம்படுத்துதல்
தவறான அல்லது பொருத்தமற்ற மொழிபெயர்ப்பை நீங்கள் கவனித்தால்:
1. இதனுடன் ஒரு Issue-ஐத் திறக்கவும்: `Translation: Fix [Language Name] — [specific section/string]`
2. வழங்க வேண்டியவை: தற்போதைய உரை, திருத்தப்பட்ட உரை மற்றும் ஒரு சுருக்கமான விளக்கம்

## மொழிபெயர்ப்பு கொள்கைகள்
 
- **சொற்பொருள் துல்லியத்தை விட கருத்துத் துல்லியம்** — வார்த்தைக்கு வார்த்தை மொழிபெயர்க்காமல், சரியான பொருளை இயல்பான மொழியில் வெளிப்படுத்தவும்
- **தொழில்நுட்பச் சொற்களைப் பாதுகாத்தல்** — PM2.5, AQI, NCAP, GEMM போன்ற சொற்கள் அப்படியே இருக்க வேண்டும் (அவை சர்வதேச அளவில் தரப்படுத்தப்பட்டவை)
- **எளிய மொழியைப் பயன்படுத்துதல்** — மொழிபெயர்ப்புகள் ஆங்கிலப் பதிப்பைப் படிக்கும் அதே வாசகர்களுக்குப் புரியும்படி இருக்க வேண்டும்: அதாவது நிபுணர்களுக்கு மட்டும் அல்லாமல், பொதுமக்களுக்கும் புரிய வேண்டும்
- **ஒத்திசைவு** — ஒரே கருத்துக்கு ஒரே மாதிரியான மொழிபெயர்ப்பைப் பயன்படுத்தவும் (எ.கா., "air quality index" என்பதை எப்போதும் ஒரே மாதிரியாக மொழிபெயர்க்கவும்)
- **ஒரே தொனி** — ஆங்கில உரையின் எந்தவொரு கட்சியையும் ஆதரிக்கவோ எதிர்க்கவோ கூடாது என்ற விதியை மொழிபெயர்ப்புகளும் பின்பற்ற வேண்டும்

| CPCB | CPCB என்றே வைத்திருக்கவும்; முதல் முறை பயன்படுத்தும்போது Central Pollution Control Board என முழுப் பெயரைக் குறிப்பிடவும் |

## நேரடி மொழிபெயர்க்கப்பட்ட ஆவணங்கள்
ஒவ்வொரு மொழியும் ரெபோவில் உள்ள `docs-{lang}/` டைரக்டரியில் உள்ளது, மேலும் இது `/docs/` இல் உள்ள ஒரே Docsify ஷெல் மூலம் வழங்கப்படுகிறது, இது ஹாஷ் ரூட்கள் வழியாக மொழி சார்ந்த உள்ளடக்கத்தை வழிநடத்துகிறது.
| மொழி | நேரடி URL | சோர்ஸ் டைரக்டரி |
|----------|----------|------------------|
| ஆங்கிலம் | [/docs/](/docs/ ':ignore') | `docs/` |
| இந்தி | [/docs/#/hi/](/docs/#/hi/ ':ignore') | `docs-hi/` |
| பெங்காலி | [/docs/#/bn/](/docs/#/bn/ ':ignore') | `docs-bn/` |
| மராத்தி | [/docs/#/mr/](/docs/#/mr/ ':ignore') | `docs-mr/` |
| தமிழ் | [/docs/#/ta/](/docs/#/ta/ ':ignore') | `docs-ta/` |
மொழிபெயர்க்கப்பட்ட டாக்குமெண்ட்கள் `.github/workflows/translations.yml` இல் உள்ள `auto-translate` ஜாப் மூலம் புதுப்பிக்கப்படுகின்றன (இதற்கு Sarvam API key தேவை) மற்றும் இவை ஆங்கில டாக்குமெண்ட்களை விட பின்தங்கியிருக்கலாம்.

## CI: Translation Coverage

டாக்ஸ் தொடர்பான ஒவ்வொரு புஷ்ஷிலும் (`main` க்கு) ஒரு GitHub Actions ஒர்க்ஃப்ளோ (`.github/workflows/translations.yml`) இயங்குகிறது. இது பின்வருவனவற்றைச் சரிபார்க்கிறது:
- **ஃபைல் கவரேஜ்** — அனைத்து ஆங்கில டாக்ஸ்களும் ஒவ்வொரு மொழியிலும் பிரதிபலிக்கப்பட்டுள்ளதா?
- **SUMMARY.md பாரிட்டி** — அனைத்து மொழிகளிலும் ஒரே எண்ணிக்கையிலான பக்கங்கள் உள்ளதா?
- **ஸ்டேல் டிடெக்‌ஷன்** — ஒரு ஆங்கில டாக் மாறும்போது, எந்த மொழிபெயர்ப்புகள் புதுப்பிக்கப்படவில்லை?
இதன் முடிவுகள் ஒவ்வொரு ரன்னுக்கான GitHub Actions **Job Summary** டேப்பில் தோன்றும்.

## Directory Structure

ஒவ்வொரு மொழிபெயர்ப்பு டைரக்டரியும் ஆங்கில `docs/` அமைப்பை அப்படியே பிரதிபலிக்கிறது. `api/openapi.yaml` ஆங்கிலத்திற்கு மட்டுமே உரியது:
```
docs-{lang}/
├── README.md
├── SUMMARY.md
├── about/
├── api/
├── claude-code/
├── contributing/
├── data-sources/
├── skills/
├── tech-stack/
├── technical/
├── user-guide/
└── wiki/
```
புதிய ஆங்கில டாக் ஒன்றைச் சேர்க்கும்போது, அனைத்து மொழிபெயர்ப்பு டைரக்டரிகளிலும் அதற்கான ஃபைலை உருவாக்கவும் (ஆரம்பத்தில் ஆங்கிலத்தில் இருந்தாலும் — பின்னர் அதை மொழிபெயர்க்கலாம்).
