# மொழிபெயர்ப்புகள்

இந்தியாவின் மொழி பன்முகத்தன்மைக்கு ஏற்ப JanVayu தளத்தை அனைவருக்கும் எளிதில் அணுகக்கூடியதாக மாற்றுவதில் உறுதியாக உள்ளது. இந்த தளம் தற்போது ஆங்கிலம், இந்தி, தமிழ், மராத்தி மற்றும் பெங்காலி ஆகிய மொழிகளை ஆதரிக்கிறது. இதன் முகப்பு (interface) இந்த ஐந்து மொழிகளிலும் முழுமையாக மொழிபெயர்க்கப்பட்டுள்ளது; ஆவணங்கள் (documentation) ஓரளவு மொழிபெயர்க்கப்பட்டுள்ளன (ஒவ்வொரு மொழிபெயர்க்கப்பட்ட மரத்திலும் 65 பக்கங்களில் 47 பக்கங்கள்).

## மொழிபெயர்ப்பிற்கு எப்படி பங்களிப்பது

### புதிய மொழியைச் சேர்ப்பது

1. `Translation: Add [Language Name] support` என்ற தலைப்பில் ஒரு புதிய Issue-ஐத் திறக்கவும்
2. இதில் சேர்க்க வேண்டியவை:
   - உங்கள் பெயர் (அல்லது பயனர் பெயர்) மற்றும் மொழித் திறன்
   - உள்ளடக்கத்தைப் புதுப்பிக்கும் போது, தொடர்ந்து மொழிபெயர்ப்புகளைப் பராமரிக்க முடியுமா என்பது
3. பராமரிப்பாளர் ஒரு கிளை (branch) உருவாக்கி, மொழிபெயர்க்க வேண்டிய மூல உரைகளை (source strings) வழங்குவார்

### ஏற்கனவே உள்ள மொழிபெயர்ப்பை மேம்படுத்துவது

தவறான அல்லது சரியாக வராத மொழிபெயர்ப்பை நீங்கள் கண்டால்:

1. `Translation: Fix [Language Name] — [specific section/string]` என்றவாறு ஒரு Issue-ஐத் திறக்கவும்
2. இதில் வழங்க வேண்டியவை: தற்போதைய உரை, திருத்தப்பட்ட உரை மற்றும் ஒரு சுருக்கமான விளக்கம்

## மொழிபெயர்ப்பு கொள்கைகள்

- **சொல்லுக்குச் சொல் அல்ல, துல்லியமே முக்கியம்** — வார்த்தைக்கு வார்த்தை மொழிபெயர்க்காமல், சரியான அர்த்தத்தை இயல்பான மொழியில் தெரிவிக்கவும்
- **தொழில்நுட்ப சொற்களை அப்படியே வைத்திருக்கவும்** — PM2.5, AQI, NCAP, GEMM போன்ற சொற்கள் அப்படியே இருக்க வேண்டும் (அவை சர்வதேச அளவில் தரப்படுத்தப்பட்டவை)
- **எளிய மொழியைப் பயன்படுத்தவும்** — மொழிபெயர்ப்புகள் ஆங்கிலப் பதிப்பைப் படிக்கும் அதே மக்களுக்கும் புரியும் வகையில் இருக்க வேண்டும்: படித்த பொதுமக்களுக்கு, நிபுணர்களுக்கு அல்ல
- **ஒத்திசைவு** — ஒரே கருத்துக்கு மொழிபெயர்ப்பு முழுவதும் ஒரே சொல்லைப் பயன்படுத்தவும் (உதாரணமாக, "air quality index" என்பதை எப்போதும் ஒரே மாதிரியாக மொழிபெயர்க்கவும்)
- **நடுநிலையான தொனி** — JanVayu எந்த அரசியல் சார்பும் இல்லாதது; மொழிபெயர்ப்புகள் இந்த நடுநிலையைப் பேண வேண்டும்

## உணர்திறன் வாய்ந்த சொற்கள்

| ஆங்கிலம் | குறிப்புகள் |
|---------|-------|
| Non-Attainment City | தேசிய காற்று தரத் தரநிலைகளை "எட்டாத" (பூர்த்தி செய்யத் தவறிய) நகரம் என்று மொழிபெயர்க்கவும் |
| Graded Response Action Plan (GRAP) | GRAP என்ற சுருக்கப்பெயரைப் பயன்படுத்தவும்; முதல் முறை பயன்படுத்தும் போது முழுமையாக எழுதவும் |
| PM2.5 | அனைத்து மொழிகளிலும் PM2.5 என்றே வைத்திருக்கவும் |
| NCAP | NCAP என்றே வைத்திருக்கவும்; முதல் முறை பயன்படுத்தும் போது National Clean Air Programme என்று முழுமையாக எழுதவும் |
| CPCB | CPCB என்றே வைத்திருக்கவும்; முதல் முறை பயன்படுத்தும் போது Central Pollution Control Board என்று முழுமையாக எழுதவும் |

## நேரடி மொழிபெயர்க்கப்பட்ட ஆவணங்கள்
ஒவ்வொரு மொழியும் ரெப்பொவில் உள்ள `docs-{lang}/` டைரக்டரியில் உள்ளது, மேலும் இது `/docs/` இல் உள்ள ஒரு Docsify ஷெல் மூலம் வழங்கப்படுகிறது, இது ஹாஷ் ரூட்கள் (hash routes) மூலம் மொழி சார்ந்த கன்டென்ட்டை அனுப்புகிறது.

| மொழி | நேரடி URL | சோர்ஸ் டைரக்டரி |
|----------|----------|------------------|
| ஆங்கிலம் | [/docs/](/docs/) | `docs/` |
| இந்தி | [/docs/#/hi/](/docs/#/hi/) | `docs-hi/` |
| பெங்காலி | [/docs/#/bn/](/docs/#/bn/) | `docs-bn/` |
| மராத்தி | [/docs/#/mr/](/docs/#/mr/) | `docs-mr/` |
| தமிழ் | [/docs/#/ta/](/docs/#/ta/) | `docs-ta/` |

மொழிபெயர்க்கப்பட்ட டாக்ஸ் (docs) `.github/workflows/translations.yml` இல் உள்ள `auto-translate` ஜாப் மூலம் புதுப்பிக்கப்படுகிறது (இதற்கு Sarvam API key தேவை) மற்றும் இது ஆங்கில டாக்ஸை விட பின்தங்கியிருக்கலாம்.

## CI: மொழிபெயர்ப்பு கவரேஜ்

`docs`-ஐ மாற்றும் ஒவ்வொரு `main` புஷிலும் ஒரு GitHub Actions ஒர்க்ஃப்ளோ (`.github/workflows/translations.yml`) இயங்குகிறது. இது பின்வருவனவற்றை சரிபார்க்கிறது:

- **File coverage** — அனைத்து ஆங்கில டாக்ஸும் ஒவ்வொரு மொழியிலும் உள்ளதா?
- **SUMMARY.md parity** — அனைத்து மொழிகளிலும் ஒரே எண்ணிக்கையிலான பக்கங்கள் உள்ளதா?
- **Stale detection** — ஒரு ஆங்கில டாக் மாறும்போது, எந்த மொழிபெயர்ப்புகள் அப்டேட் செய்யப்படவில்லை?

முடிவுகள் ஒவ்வொரு ரன்னுக்கான GitHub Actions **Job Summary** டேப்பில் தோன்றும்.

## டைரக்டரி அமைப்பு

ஒவ்வொரு மொழிபெயர்ப்பு டைரக்டரியும் ஆங்கில `docs/` அமைப்பை அப்படியே பிரதிபலிக்கிறது, ஆனால் `api/` மற்றும் `wiki/` ஆகியவை ஆங்கிலத்தில் மட்டுமே உள்ளன:

```
docs-{lang}/
├── README.md
├── SUMMARY.md
├── about/
├── claude-code/
├── contributing/
├── data-sources/
├── skills/
├── tech-stack/
├── technical/
└── user-guide/
```

புதிய ஆங்கில டாக் சேர்க்கும்போது, அனைத்து மொழிபெயர்ப்பு டைரக்டரிகளிலும் தொடர்புடைய ஃபைலை உருவாக்கவும் (ஆரம்பத்தில் ஆங்கிலத்தில் இருந்தாலும் — பின்னர் மொழிபெயர்க்கப்படலாம்).
