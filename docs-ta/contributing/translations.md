# மொழிபெயர்ப்புகள்

இந்தியாவின் மொழியியல் பன்முகத்தன்மைக்கு ஏற்ப அனைவரையும் சென்றடைய JanVayu உறுதிபூண்டுள்ளது. இந்தத் தளம் தற்போது ஆங்கிலம், இந்தி, தமிழ், மராத்தி மற்றும் பெங்காலி ஆகிய மொழிகளை ஆதரிக்கிறது. இந்த ஐந்து மொழிகளிலும் பயனர் இடைமுகம் முழுமையாக மொழிபெயர்க்கப்பட்டுள்ளது; ஆவணங்கள் ஓரளவு மொழிபெயர்க்கப்பட்டுள்ளன (ஒவ்வொரு மொழிபெயர்க்கப்பட்ட பிரிவிலும் 65 பக்கங்களில் 47 பக்கங்கள்).

## மொழிபெயர்ப்புக்குப் பங்களிப்பது எப்படி

### புதிய மொழியைச் சேர்த்தல்

1. `Translation: Add [Language Name] support` என்ற தலைப்பில் ஒரு சிக்கலை (Issue) உருவாக்குங்கள்
2. பின்வருவனவற்றைச் சேர்க்கவும்:
   - உங்கள் பெயர் (அல்லது முகவரி) மற்றும் மொழித் திறன்
   - உள்ளடக்கப் புதுப்பிப்புகளுக்கு ஏற்ப, காலப்போக்கில் மொழிபெயர்ப்புகளைப் பராமரிக்க உங்களால் முடியுமா என்பது
3. ஒரு பராமரிப்பாளர் ஒரு கிளை (branch) உருவாக்கி, மொழிபெயர்ப்பதற்கான மூல உரைகளை வழங்குவார்

### ஏற்கனவே உள்ள மொழிபெயர்ப்பை மேம்படுத்துதல்

தவறான அல்லது பொருத்தமற்ற மொழிபெயர்ப்பை நீங்கள் கண்டால்:

1. `Translation: Fix [Language Name] — [specific section/string]` என்பதைக் குறிப்பிட்டு ஒரு சிக்கலை (Issue) உருவாக்குங்கள்
2. பின்வருவனவற்றை வழங்கவும்: தற்போதைய உரை, திருத்தப்பட்ட உரை மற்றும் ஒரு சுருக்கமான விளக்கம்

## மொழிபெயர்ப்பு நெறிமுறைகள்

- **சொல்லுக்குச் சொல் மொழிபெயர்க்காமல் கருத்தைப் புரிந்துகொள்ளச் செய்தல்** — வார்த்தைக்கு வார்த்தை மொழிபெயர்க்காமல், சரியான அர்த்தத்தை இயல்பான மொழியில் வெளிப்படுத்துங்கள்
- **தொழில்நுட்பச் சொற்களை மாற்றாமல் வைத்திருத்தல்** — PM2.5, AQI, NCAP, GEMM போன்ற சொற்களை அப்படியே வைத்திருக்க வேண்டும் (அவை சர்வதேச அளவில் தரப்படுத்தப்பட்டவை)
- **எளிய மொழியைப் பயன்படுத்துதல்** — ஆங்கிலப் பதிப்பைப் படிக்கும் அதே வாசகர்களுக்கு (அதாவது, நிபுணர்களுக்கு அல்லாமல், படித்த பொதுமக்களுக்கு) இந்த மொழிபெயர்ப்புகளும் எளிதில் புரியும்படி இருக்க வேண்டும்
- **ஒத்திசைவு** — ஒரே கருத்துக்கு எப்போதும் ஒரே மொழிபெயர்ப்புச் சொல்லைப் பயன்படுத்த வேண்டும் (எ.கா., "air quality index" என்பதை எப்போதும் ஒரே மாதிரி மொழிபெயர்க்க வேண்டும்)
- **ஒரே தொனி** — எந்தவொரு அரசியல் கட்சிக்கும் ஆதரவாகவோ அல்லது எதிராகவோ பேசாத ஆங்கில உரையின் நெறிமுறையை மொழிபெயர்ப்புகளும் பின்பற்ற வேண்டும்

| Graded Response Action Plan (GRAP) | GRAP என்ற சுருக்கப்பெயரைப் பயன்படுத்தவும்; முதல் முறை பயன்படுத்தும்போது முழுமையாக எழுதவும் |
| PM2.5 | அனைத்து மொழிகளிலும் PM2.5 என்றே வைத்திருக்கவும் |
| NCAP | NCAP என்றே வைத்திருக்கவும்; முதல் முறை பயன்படுத்தும்போது National Clean Air Programme என்று முழுமையாக எழுதவும் |
| CPCB | CPCB என்றே வைத்திருக்கவும்; முதல் முறை பயன்படுத்தும்போது Central Pollution Control Board என்று முழுமையாக எழுதவும் |

## நேரடி மொழிபெயர்ப்பு ஆவணங்கள்
ஒவ்வொரு மொழியும் repo-வில் உள்ள `docs-{lang}/` directory-யில் உள்ளது, மேலும் இது `/docs/` இல் உள்ள ஒரு Docsify shell மூலம் வழங்கப்படுகிறது, இது hash routes மூலம் மொழி சார்ந்த உள்ளடக்கத்தை அனுப்புகிறது.

| மொழி | நேரடி URL | மூல Directory |
|----------|----------|------------------|
| English | [/docs/](/docs/) | `docs/` |
| Hindi | [/docs/#/hi/](/docs/#/hi/) | `docs-hi/` |
| Bengali | [/docs/#/bn/](/docs/#/bn/) | `docs-bn/` |
| Marathi | [/docs/#/mr/](/docs/#/mr/) | `docs-mr/` |
| Tamil | [/docs/#/ta/](/docs/#/ta/) | `docs-ta/` |

`.github/workflows/translations.yml` இல் உள்ள `auto-translate` job மூலம் மொழிபெயர்க்கப்பட்ட docs புதுப்பிக்கப்படுகின்றன (இதற்கு Sarvam API key தேவை) மற்றும் இது ஆங்கில docs-ஐ விட பின்தங்கியிருக்கலாம்.

## CI: Translation Coverage

`main`-க்கு docs-ஐத் தொடும் ஒவ்வொரு push-லும் ஒரு GitHub Actions workflow (`.github/workflows/translations.yml`) இயங்குகிறது. இது பின்வருவனவற்றைச் சரிபார்க்கிறது:

- **File coverage** — அனைத்து ஆங்கில docs-உம் ஒவ்வொரு மொழியிலும் உள்ளதா?
- **SUMMARY.md parity** — எல்லா மொழிகளிலும் ஒரே பக்க எண்ணிக்கை உள்ளதா?
- **Stale detection** — ஒரு ஆங்கில doc மாறும்போது, எந்த மொழிபெயர்ப்புகள் புதுப்பிக்கப்படவில்லை?

முடிவுகள் ஒவ்வொரு run-க்கும் GitHub Actions **Job Summary** tab-இல் தோன்றும்.

## Directory Structure

ஒவ்வொரு மொழிபெயர்ப்பு directory-யும் ஆங்கில `docs/` அமைப்பைப் பிரதிபலிக்கிறது, ஆனால் `api/` மற்றும் `wiki/` ஆகியவை ஆங்கிலத்தில் மட்டுமே உள்ளன:

```
docs-{lang}/
├── README.md
├── SUMMARY.md
├── about/
├── claude-code/
├── contributing/
├── data-sources/
├── skills/
├── tech-stack/
├── technical/
└── user-guide/
```

புதிய ஆங்கில doc-ஐச் சேர்க்கும்போது, அனைத்து மொழிபெயர்ப்பு directory-களிலும் அதற்கான கோப்பை உருவாக்கவும் (ஆரம்பத்தில் ஆங்கிலத்தில் இருந்தாலும் கூட — பின்னர் மொழிபெயர்க்கப்படலாம்).
