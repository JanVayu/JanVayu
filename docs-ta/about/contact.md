## பாதுகாப்புப் பிரச்சினை குறித்து தெரிவித்தல்

பாதுகாப்பு குறைபாட்டை நீங்கள் கண்டறிந்தால், **பொது GitHub Issue ஐத் திறக்க வேண்டாம்**. அதற்குப் பதிலாக, [SECURITY.md](https://github.com/JanVayu/JanVayu/blob/main/SECURITY.md) இல் விவரிக்கப்பட்டுள்ள பொறுப்பான வெளிப்படுத்தல் (responsible disclosure) செயல்முறையைப் பின்பற்றவும்.

---

## ஊடக மற்றும் ஆராய்ச்சி விசாரணைகள்

பத்திரிகையாளர்கள், ஆராய்ச்சியாளர்கள் மற்றும் கொள்கை வல்லுநர்கள் JanVayu-வின் தரவு மற்றும் பகுப்பாய்வுகளைப் பயன்படுத்தலாம். தயவுசெய்து:

1. குறிப்பிட்ட புள்ளிவிவரங்களுக்கு JanVayu-ஐ அல்லாமல், முதன்மை மூலத்தை (CPCB, Lancet, போன்றவை) மேற்கோள் காட்டவும்
2. ஒருங்கிணைக்கப்பட்ட தரவை நீங்கள் கண்டறிந்த தளமாக JanVayu-ஐக் குறிப்பிடவும்
3. தனிப்பயன் பகுப்பாய்வு அல்லது தரவு கோரிக்கைகளுக்கு, GitHub Issue-ஐத் திறக்கவும் அல்லது [contribute@janvayu.in](mailto:contribute@janvayu.in) என்ற மின்னஞ்சல் முகவரிக்கு மின்னஞ்சல் அனுப்பவும்
