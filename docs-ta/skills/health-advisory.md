# திறன்: பொது சுகாதார ஆலோசகர்

**பயன்படுத்தப்படுவது:** `netlify/functions/health-advisory.mjs`  
**மாடல்:** Groq வழியாக `openai/gpt-oss-120b` (இயல்புநிலை, `GROQ_MODEL` மூலம் அமைக்கப்படுகிறது; 16 ஆகஸ்ட் 2026 அன்று Groq அதை ஓய்வு பெறும் வரை Llama 3.3 70B)  
**தூண்டுதல்:** பயனர் ஒரு புரொஃபைலை (வயது, உடல்நல நிலைகள், வெளியே செலவிடும் மணிநேரம்) + ஒரு நகரத்தை சமர்ப்பிக்கிறார்

---

## இந்த திறன் என்ன செய்கிறது

தனிநபரின் பாதிப்பு புரொஃபைல் மற்றும் நகரத்தின் தற்போதைய PM2.5 அளவின் அடிப்படையில் தனிப்பயனாக்கப்பட்ட, செயல்படுத்தக்கூடிய சுகாதார ஆலோசனையை இது உருவாக்குகிறது. முக்கியமாக: இது தயக்கத்துடன் பதிலளிக்காது. இது ஒரு உறுதியான பரிந்துரையை வழங்கும் — "வெளிப்புற வெளிப்பாட்டை கட்டுப்படுத்துவதைக் கருத்தில் கொள்ளுங்கள்" என்று சொல்வதற்குப் பதிலாக "மதியம் 2 மணி வரை வீட்டிற்குள்ளேயே இருங்கள்" என்று சொல்லும்.

---

## சிஸ்டம் ப்ராம்ப்ட் (சரியானது)

```
நீங்கள் இந்தியாவில் காற்று மாசுபாட்டினால் ஏற்படும் பாதிப்புகள் குறித்து நிபுணத்துவம் பெற்ற ஒரு பொது சுகாதார ஆலோசகர். 
ஒரு நபரின் புரொஃபைல் மற்றும் தற்போதைய காற்றின் தரம் தரவைக் கொண்டு, குறிப்பிட்ட, 
செயல்படுத்தக்கூடிய ஆலோசனையை உருவாக்குங்கள். உறுதியாக இருங்கள்: 'வெளிப்புற வெளிப்பாட்டை கட்டுப்படுத்துவதைக் கருத்தில் கொள்ளுங்கள்' என்று சொல்வதற்குப் பதிலாக 'மதியம் 2 மணி வரை வீட்டிற்குள்ளேயே இருங்கள்' என்று சொல்லுங்கள். உண்மையான PM2.5 மதிப்பை குறிப்பிடுங்கள். அந்த நபருக்கு உடல்நலப் பிரச்சனை இருந்தால், அதை நேரடியாகக் குறிப்பிடுங்கள். தயங்க வேண்டாம் — தெளிவான பரிந்துரையை வழங்குங்கள். அதிகபட்சம் 3-4 வாக்கியங்கள். ஆங்கிலத்தில் பதிலளிக்கவும்.
```

## AI-க்கு முந்தைய ஆபத்து கணக்கீடு

Groq API அழைப்பிற்கு முன், இந்த ஃபங்ஷன் சாதாரண JavaScript-ல் ஒரு `riskLevel`-ஐ கணக்கிடுகிறது — AI ஆலோசனைடன் இது எப்போதும் திருப்பி அனுப்பப்படும், எனவே AI-க்காக காத்திருக்காமல் UI பதிலுக்கு நிறக் குறியீடு கொடுக்க முடியும்:

```javascript
function getRiskLevel(pm25, conditions) {
  const hasSensitive = conditions && conditions.some(c => c !== "none");
  if (pm25 <= 12) return "low";
  if (pm25 <= 35) return hasSensitive ? "moderate" : "low";
  if (pm25 <= 55) return hasSensitive ? "high" : "moderate";
  if (pm25 <= 150) return hasSensitive ? "severe" : "high";
  return "severe";
}
```

இந்த வரம்புகள் 2012 US EPA PM2.5 பிரேக் பாயிண்ட்களைப் பின்பற்றுகின்றன (12.0, 35.4, 55.4, 150.4 µg/m³), இதை EPA 2024-ல் திருத்தியது (Good இப்போது 9.0 வரை, Unhealthy 55.5 முதல் 125.4 வரை); இந்த குறியீடு 2024 மதிப்புகளுக்கு புதுப்பிக்கப்படவில்லை. ஏற்கனவே இருக்கும் உடல்நலப் பிரச்சனைகள் உள்ளவர்களை ஒரு பேண்ட் மேலே நகர்த்துவதன் மூலம் உணர்திறன் கையாளப்படுகிறது.

## முக்கிய வடிவமைப்பு முடிவுகள்
**"do not hedge" (முன்கூட்டியே தயங்குவதைத் தவிர்க்க) ஏன்?**
நேரடியான அறிவுரைகளை ("Y நடக்கும் வரை X செய்யுங்கள்") விட, தயக்கத்துடன் சொல்லப்படும் அறிவுரைகள் ("நீங்கள் X-ஐப் பற்றி யோசிக்கலாம்...") மக்கள் அதிகம் செயல்படுத்துவதில்லை என்று நாங்கள் கருதுகிறோம். ஆஸ்துமா அல்லது இதய நோய் உள்ளவர்களுக்கு உதவும் ஒரு பொது சுகாதாரக் கருவியைப் பொறுத்தவரை, தயங்குவது நடுநிலையானது அல்ல — அது பாதுகாப்பான நடத்தையைத் தீவிரமாகக் குறைக்கிறது.

**அதிகபட்சம் 3-4 வாக்கியங்கள் ஏன்?**
படித்துப் புரிந்துகொள்ள வேண்டிய ஒரு சுகாதார அறிவுரை, அதிக மாசுக் கால அவசர நிலையில் படிக்கப்படாது. அதை 10 வினாடிகளுக்கும் குறைவான நேரத்தில் எளிதாகப் படித்துப் புரிந்துகொள்ளும் வகையில் இருக்க வேண்டும்.

**மாடலை நம்பியிருக்காமல் JavaScript-ல் `riskLevel`-ஐ ஏன் கணக்கிட வேண்டும்?**
நம்பகத்தன்மைக்காக. ஆபத்து நிலை (risk level) UI-ன் நிறக் குறியீட்டையும் மாற்றுச் செய்தியையும் (fallback messaging) தீர்மானிக்கிறது. அதை LLM-விடம் ஒப்படைப்பது கணிக்க முடியாத தன்மையை (non-determinism) உருவாக்குகிறது. AI கிடைத்தாலும் இல்லாவிட்டாலும், விதி அடிப்படையிலான function எப்போதும் ஒரே மாதிரியான முடிவையே தருகிறது.

**Prompt-ல் நிபந்தனைகளின் பட்டியலை ஏன் சேர்க்க வேண்டும்?**
"நேரடியாகப் பதிலளிக்கவும்" என்பது, பொதுவான பதிலாக இல்லாமல் "ஆஸ்துமா உள்ள ஒருவருக்கு, இந்த அளவில் உள்ள PM2.5 என்றால்..." என்று சொல்ல மாடலை வற்புறுத்துகிறது. இதுவே தனிப்பயனாக்கலின் (personalisation) முக்கிய கருவியாகும்.

## மாற்றுச் செயல்பாடு (Fallback Behaviour)

```
AI analysis unavailable. Raw data: {pm25} µg/m³ PM2.5 (AQI {aqi}).
```

`riskLevel` இன்னும் JavaScript function மூலம் கணக்கிடப்பட்டு திருப்பி அனுப்பப்படுகிறது, எனவே AI உரை இல்லாவிட்டாலும் UI-ஆல் முடிவுக்கு நிறக் குறியீடு (colour-code) கொடுக்க முடியும்.

## பிற களங்களுக்கான தகவமைப்பு (Adapting for Other Domains)

இந்த skill pattern — profile + live data → concrete advisory — பின்வருவனவற்றிற்கும் மீண்டும் பயன்படுத்தக்கூடியது:

- **வெப்ப அறிவுரை (Heat advisory):** வயது + உடல்நலக் குறைபாடுகள் + வெப்பநிலை/வெப்பக் குறியீடு → வெளிப்புறச் செயல்பாடுகள் மற்றும் நீர்ச்சத்து பற்றிய உறுதியான அறிவுரை
- **நீர் மாசு எச்சரிக்கை (Water contamination alert):** இடம் + மாசு அளவு + மக்கள் தொகை விவரம் → குடிநீர்/பயன்பாட்டு அறிவுரை
- **இரைச்சல் பாதிப்பு (Noise exposure):** profile + டெசிபல் அளவு + நேரம் → செவித்திறன் பாதுகாப்பு அறிவுரை
