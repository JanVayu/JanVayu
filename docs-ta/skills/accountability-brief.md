# திறன்: பொறுப்புக்கூறல் சுருக்க எழுத்தாளர்

**பயன்படுத்தப்படுவது:** `netlify/functions/accountability-brief.mjs`  
**மாதிரி:** Groq வழியாக `openai/gpt-oss-120b` (இயல்புநிலை, `GROQ_MODEL` மூலம் அமைக்கப்பட்டது; 16 ஆகஸ்ட் 2026 அன்று Groq அதை நிறுத்தும் வரை Llama 3.3 70B)  
**தூண்டுதல்:** பயனர் ஒரு நகரம் + பகுதி (வார்டு/அயலகம்) + காலப்பகுதி ஆகியவற்றைச் சமர்ப்பிக்கிறார்

---

## இந்தத் திறன் என்ன செய்கிறது

இது ஒரு கட்டமைக்கப்பட்ட, வார்டு அளவிலான காற்று தரப் பொறுப்புக்கூறல் சுருக்கத்தை உருவாக்குகிறது. இதன் வெளியீடு ஒரு குறிப்பிட்ட, தொழில்நுட்பம் சாராத பார்வையாளர்களுக்காக வடிவமைக்கப்பட்டுள்ளது: வார்டு கவுன்சிலர்கள், உள்ளூர் பத்திரிகையாளர்கள் மற்றும் உறைவிட நலச் சங்கங்கள் (RWAs). தரவுகள் அவர்களின் பகுதிக்கு என்ன அர்த்தம் தருகின்றன என்பதையும், அவர்களுக்குக் கிடைக்கும் உண்மையான சட்ட மற்றும் ஒழுங்குமுறை வழிமுறைகளைப் பயன்படுத்தி அவர்கள் என்ன செய்ய முடியும் என்பதையும் இது அவர்களுக்குச் சொல்கிறது.

நான்கு திறன் கோப்புகளில் இதுவே மிகவும் கட்டமைக்கப்பட்டதாகும். இதன் வெளியீட்டு வடிவம் தூண்டில் (prompt) முழுமையாகக் குறிப்பிடப்பட்டுள்ளது.

## கணினித் தூண்டில் (சரியானது)

```
நீங்கள் இந்தியாவின் குடிமக்கள் காற்று தரத் தளமான JanVayu-க்காக ஒரு வார்டு அளவிலான காற்று தரப் பொறுப்புக்கூறல் சுருக்கத்தை உருவாக்குகிறீர்கள். ஒரு வார்டு கவுன்சிலர், உள்ளூர் பத்திரிகையாளர் அல்லது உறைவிடச் சங்கத் தலைவர் செயல்படக்கூடிய எளிய மொழியில் எழுதுங்கள். உங்கள் சுருக்கத்தை சரியாக இவ்வாறு கட்டமைக்கவும்:

AREA: [area name], [city]
PERIOD: [period]
CURRENT PM2.5: [value] µg/m³ ([x times] WHO safe limit of 5 µg/m³)
STATUS: [Normal / Elevated / Anomalous — one sentence explanation]

WHAT THE DATA SHOWS:
[2-3 sentences: practical meaning for this neighbourhood, reference the 
seasonal baseline, note if worse or better than typical]

LIKELY SOURCES:
[1-2 sentences: specific to this city and season — stubble burning, 
construction, vehicular, industrial, weather inversion]

WHAT LOCAL ACTORS CAN DO:
[2-3 specific actions a ward councillor or resident group could take now. 
Reference actual powers — GRAP, RTI, MCD complaint lines.]

DATA CAVEAT:
This brief is based on [station name] data. It reflects area-level air quality, 
not hyperlocal ward data. For ward-specific data, additional monitoring is needed.

Generated by JanVayu | janvayu.in | [timestamp]
```

## AI-க்கு முந்தைய முரண்பாடு கண்டறிதல்

Groq API அழைப்பிற்கு முன், தற்போதைய அளவீடு முரண்பாடானதா என்பதை இந்தச் செயல்பாடு கணக்கிடுகிறது:
```javascript
const baseline = getSeasonalBaseline(cityKey); // தோராயமான JanVayu செயல்பாட்டு அடிப்படை
const anomalyDetected = pm25 > baseline * 1.5;
```

பருவகால அடிப்படைகள் என்பவை கடினக் குறியீடு (hardcoded) செய்யப்பட்ட தோராயமான JanVayu செயல்பாட்டு அடிப்படைகளாகும் (ஏழு நகரங்கள், மற்றவற்றுக்கு இயல்புநிலை 60 µg/m³), இவை வெளியிடப்பட்ட CREA அல்லது IQAir புள்ளிவிவரங்களும் அல்ல, நேரடி அளவீடுகளிலிருந்து பெறப்பட்டவையும் அல்ல. இது முரண்பாடு கொடியை (anomaly flag) நிலையானதாகவும் விளக்கக்கூடியதாகவும் இருப்பதை உறுதி செய்கிறது.

## முக்கிய வடிவமைப்பு முடிவுகள்

**prompt-ல் வெளியீட்டு வடிவத்தை ஏன் குறிப்பிட வேண்டும்?**
இந்த சுருக்கம் நேரடியாக நகலெடுத்துப் பயன்படுத்தும் வகையில் உருவாக்கப்பட்டுள்ளது — ஒரு கவுன்சிலருக்கு WhatsApp செய்தி, ஒரு ட்வீட் த்ரெட் அல்லது RWA கூட்டத்திற்கான அச்சிடப்பட்ட துண்டுப் பிரசுரம் எனப் பயன்படுத்தலாம். வடிவத்தை மாடலுக்கே விட்டுவிடுவதால், முடிவுகள் சீரற்றதாக இருக்கும், அவற்றைச் சரிசெய்ய மனிதத் தலையீடு தேவைப்படும். ஒரு சரியான டெம்ப்ளேட் ஒவ்வொரு முறையும் பயன்படுத்தக்கூடிய வெளியீட்டை உறுதி செய்கிறது.

**குறிப்பிட்ட வழிமுறைகளுடன் "உள்ளூர் அமைப்புகள் என்ன செய்ய முடியும்" என்பதை ஏன் சேர்க்க வேண்டும்?**
பெரும்பாலான பொறுப்புக்கூறல் கருவிகள் தரவுகளோடு நின்றுவிடுகின்றன. இந்த சுருக்கம் கடைசி கட்டத்தை முடிக்க வடிவமைக்கப்பட்டுள்ளது — வாசகருக்கு இப்போது என்ன சட்ட மற்றும் ஒழுங்குமுறை அதிகாரங்கள் உள்ளன என்பதை *குறிப்பாக* சொல்கிறது (எ.கா., "CAQM-ல் GRAP விதிமீறல் புகாரைப் பதிவு செய்வது", "MCD-ன் 311 app-ல் புகாரைப் பதிவு செய்வது"). இது இல்லாமல், சுருக்கம் தகவல்களை மட்டுமே தரும், ஆனால் நடவடிக்கை எடுக்க உதவாது.

**"DATA Caveat"-ஐ ஏன் சேர்க்க வேண்டும்?**
இந்தியாவில் வார்டு அளவில் அடர்த்தியான தரைவழி கண்காணிப்பு இல்லை; வார்டுகளில் கணிக்கப்பட்ட (செயற்கைக்கோள்) மதிப்பீடுகள் மட்டுமே உள்ளன. இந்தக் குறிப்பு அறிவார்ந்த நேர்மையைக் காட்டுகிறது மற்றும் JanVayu-வை தவறாகப் பயன்படுத்துவதிலிருந்து பாதுகாக்கிறது (எ.கா., சட்ட நடவடிக்கையில் ஒரு உள்ளூர் அளவிலான உரிமைகோரலைச் செய்ய நகர அளவிலான தரவைப் பயன்படுத்துவது).

**`max_tokens: 1024` ஏன்?**
சுருக்கத்தின் வடிவம் போதுமான அளவு துல்லியமாகக் குறிப்பிடப்பட்டுள்ளதால், 1,024 டோக்கன்கள் போதுமான வரம்பாகும். அதிகமாக அனுமதித்தால், தேவையற்ற வார்த்தைகளும் திரும்பத் திரும்ப வருவதும் ஏற்பட்டு, முக்கிய உள்ளடக்கத்தின் மதிப்பு குறைந்துவிடும்.

## மற்ற களங்களுக்கு ஏற்ப மாற்றுதல்

கட்டமைக்கப்பட்ட சுருக்க முறை எந்தவொரு தரவு சார்ந்த பொறுப்புக்கூறல் சூழலுக்கும் மிகவும் மீண்டும் பயன்படுத்தக்கூடியது:

- **ஆற்றல் மாசு சுருக்கம்** — தொழில்துறை கழிவுநீர் வெளியேற்றத்திற்கு அருகிலுள்ள கிராம பஞ்சாயத்துகளுக்கு
- **நிலத்தடி நீர் மாசு சுருக்கம்** — புளோரைடு அல்லது ஆர்சனிக் அளவுகளைக் கண்காணிக்கும் பஞ்சாயத்துத் தலைவர்களுக்கு
- **காலநிலை மாற்றத் தழுவல் சுருக்கம்** — வெப்பம் அல்லது வெள்ள அபாயத்தை எதிர்கொள்ளும் உள்ளாட்சி அமைப்புகளுக்கு

பாதுகாக்க வேண்டிய முக்கிய கூறுகள்: **கட்டமைக்கப்பட்ட வடிவம்**, **குறிப்பிட்ட வழிமுறைகளுடன் உள்ளூர் அமைப்புகளின் நடவடிக்கைகள்**, **தரவு குறிப்பு**.
