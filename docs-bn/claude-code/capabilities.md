# Claude Code Setup — সম্পূর্ণ সক্ষমতা নির্দেশিকা

এই পেজটি JanVayu Claude Code সেটআপের সব সক্ষমতার একটি বিস্তারিত নির্দেশিকা — যেখানে ডেভেলপমেন্ট টুলস, এনফোর্সমেন্ট মেকানিজম, AI ফিচার, CI/CD অটোমেশন, ডিপ্লয়মেন্ট ইনফ্রাস্ট্রাকচার এবং ডকুমেন্টেশন ওয়ার্কফ্লো নিয়ে আলোচনা করা হয়েছে।

---

## 1. কোর ডেভেলপমেন্ট সক্ষমতা

### ফাইল অপারেশন
- রিপোজিটরির **যেকোনো ফাইল পড়া** — `index.html`, Netlify Functions, কনফিগস, ডকুমেন্টেশন
- **নতুন ফাইল তৈরি করা** — Netlify Functions, ডকুমেন্টেশন পেজ, কনফিগ ফাইল
- **বিদ্যমান ফাইল এডিট করা** — অপ্রাসঙ্গিক কোড নতুন করে না লিখে নির্দিষ্ট জায়গায় এডিট করা
- **ফাইলের নাম দিয়ে খোঁজা** — গ্লোব ম্যাচিং (যেমন, `**/*.mjs`, `docs/**/*.md`)
- **কন্টেন্ট দিয়ে খোঁজা** — কোডবেস জুড়ে রেজেক্স-ভিত্তিক ফুল-টেক্সট সার্চ

### শেল ও টার্মিনাল অ্যাক্সেস
- ডিপেন্ডেন্সি ম্যানেজ করতে `npm install` রান করা
- লোকাল ডেভেলপমেন্ট সার্ভারের জন্য `netlify dev` রান করা
- যেকোনো নন-ডেস্ট্রাকটিভ শেল কমান্ড চালানো
- `git`, `gh` (GitHub CLI), `ls`, `mkdir` ব্যবহার করা
- **নিয়ম অনুযায়ী ব্লক করা**: `rm -rf`, `git push --force`, `git reset --hard`

### মাল্টি-ফাইল কোঅর্ডিনেশন
একটি Claude Code সেশন একবারে এই সবগুলো স্পর্শ করতে পারে:
- `index.html` (মার্কআপ), `app.js` (লজিক) এবং `styles.css` (স্টাইলিং)
- Netlify Functions (`netlify/functions/*.mjs` বা `*.js`)
- কনফিগারেশন ফাইল (`netlify.toml`, `package.json`, `.editorconfig`)
- ডকুমেন্টেশন (`docs/**/*.md`, `CHANGELOG.md`, `README.md`)
- Git hooks (`.githooks/pre-commit`, `.githooks/commit-msg`)
- GitHub workflows (`.github/workflows/*.yml`)

## 2. Git Workflow সক্ষমতা

### ব্রাঞ্চিং ও কমিট
- ফিচার ব্রাঞ্চ তৈরি করা (যেমন, `claude/feature-name`)
- নির্দিষ্ট ফাইল স্টেজিং করা (যাতে ভুলবশত `.env` বা সিক্রেট যুক্ত না হয়)
- নির্দিষ্ট প্রিফিক্স নিয়ম মেনে মেসেজ দিয়ে কমিট করা:
  - `Add:` — নতুন ফিচার বা ফাইল
  - `Fix:` — বাগ ফিক্স
  - `Update:` — বিদ্যমান ফিচারের উন্নতি
  - `Translate:` — অনুবাদ করার কাজ
  - `Docs:` — ডকুমেন্টেশনে পরিবর্তন
  - `Refactor:` — কোড রিফ্যাক্টরিং (আচরণে কোনো পরিবর্তন নেই)
  - `Test:` — টেস্ট যোগ করা
  - `CI:` — CI/CD পাইপলাইন পরিবর্তন
  - `Chore:` — রক্ষণাবেক্ষণের কাজ
- সাবজেক্ট লাইন ৭২ ক্যারেক্টারের বেশি হলে হুক থেকে একটি ওয়ার্নিং আসবে (ব্লক হবে না); `Merge` ও একটি অনুমোদিত প্রিফিক্স

### পুল রিকোয়েস্ট ম্যানেজমেন্ট
- সুগঠিত টাইটেল, সামারি এবং টেস্ট প্ল্যান দিয়ে PR তৈরি করা
- মাল্টি-PR ওয়ার্কফ্লো ম্যানেজ করা (যেমন, প্রথমে ব্যাকএন্ড, তারপর ফ্রন্টএন্ড, তারপর ডকুমেন্টেশন)
- PR ডিফস রিভিউ করা এবং পরিবর্তনের পরামর্শ দেওয়া
- কমেন্ট যোগ করা এবং রিভিউ ফিডব্যাকের উত্তর দেওয়া
### Git Hook Enforcement
সেটআপে দুটি কাস্টম git hooks রয়েছে যা স্বয়ংক্রিয়ভাবে রান করে:

**Pre-commit hook** (`.githooks/pre-commit`):
| চেক | অ্যাকশন |
|-------|--------|
| `.env`, `.env.local`, `.env.production` | **কমিট ব্লক** |
| `credentials.json`, `*.pem`, `*.key` | **কমিট ব্লক** |
| `debugger` স্টেটমেন্ট, `breakpoint()` | **কমিট ব্লক** |
| মার্জ কনফ্লিক্ট মার্কার (`<<<<<<<`, `>>>>>>>`) | **কমিট ব্লক** |
| `console.log`, `console.debug`, `console.warn` | **সতর্কতা** (`// keep` দিয়ে বাইপাস করা যায়) |
| 500 KB-এর বেশি সাইজের ফাইল | **সতর্কতা** |

**Commit message hook** (`.githooks/commit-msg`):
| চেক | অ্যাকশন |
|-------|--------|
| প্রয়োজনীয় প্রিফিক্স না থাকা | **কমিট ব্লক** |
| সাবজেক্ট লাইন 72 ক্যারেক্টারের বেশি হলে | **সতর্কতা** |
| মার্জ/রিভার্ট/ফিক্সআপ কমিট | **এনফোর্সমেন্ট স্কিপ** |

## 3. এআই-চালিত ফিচার (Groq-hosted model)

> **আপডেট, 2 Oct 2026: Groq 16 Aug 2026-এ Llama 3.3 70B বন্ধ করে দিয়েছে (Groq deprecations page); ফাংশনগুলো এখন ডিফল্টভাবে `openai/gpt-oss-120b` ব্যবহার করে, যা `GROQ_MODEL` এনভায়রনমেন্ট ভেরিয়েবল দিয়ে পরিবর্তন করা যায়।**

সেটআপে চারটি প্রোডাকশন এআই ফিচার রয়েছে, যার প্রতিটি একটি স্ট্রাকচার্ড স্কিল ফাইলসহ Netlify Function হিসেবে ইমপ্লিমেন্ট করা হয়েছে:

### 3.1 Air Quality Assistant (`air-query.mjs`)
- **ইনপুট**: শহরের নাম + স্বাভাবিক ভাষার প্রশ্ন
- **আউটপুট**: বাস্তব তথ্যের ওপর ভিত্তি করে উত্তর (প্রায় 150 শব্দের মধ্যে), যেখানে আসল AQI নম্বর উল্লেখ থাকবে
- **ভাষা**: ইংরেজি এবং ভারতের নয়টি ভাষা (হিন্দি, তামিল, বাংলা, মারাঠি, তেলুগু, গুজরাটি, কন্নড়, মালয়ালম, পাঞ্জাবি)
- **মূল শর্ত**: অবশ্যই বাস্তব ডেটা উল্লেখ করতে হবে — কোনো সাধারণ বা জেনেরিক পরামর্শ দেওয়া যাবে না
- **ফলব্যাক**: Groq-এর রেট লিমিট থাকলে এটি র (raw) AQI ডেটা রিটার্ন করে
- **স্কিল ফাইল**: `docs/skills/air-quality-assistant.md`

### 3.2 Health Advisory (`health-advisory.mjs`)
- **ইনপুট**: শহর + বয়স + শারীরিক অবস্থা + বাইরে কাটানো সময়
- **আউটপুট**: কালার-কোডেড ঝুঁকির মাত্রা + সুনির্দিষ্ট পরামর্শ (3-4 বাক্যে)
- **মূল শর্ত**: সরাসরি পরামর্শ দিতে হবে, কোনো দ্বিধা বা এড়িয়ে যাওয়া যাবে না — "Consider staying indoors"-এর বদলে "Stay indoors"
- **প্রি-এআই ধাপ**: এআই-এর উত্তর আসার আগেই তাৎক্ষণিকভাবে UI-তে কালার-কোডিং করার জন্য একটি JavaScript ফাংশন ঝুঁকির মাত্রা হিসাব করে
- **ফলব্যাক**: এআই ব্যাখ্যা দিতে ব্যর্থ হলেও ঝুঁকির মাত্রা দেখানো হয়
- **স্কিল ফাইল**: `docs/skills/health-advisory.md`
### 3.3 অ্যাকাউন্টেবিলিটি ব্রিফ (`accountability-brief.mjs`)
- **ইনপুট**: শহর + ওয়ার্ড/এলাকা + সময়কাল
- **আউটপুট**: আটটি লেবেল করা সেকশনসহ স্ট্রাকচার্ড ব্রিফ (এলাকা, সময়কাল, বর্তমান PM2.5, স্ট্যাটাস, ডেটা কী বলছে, সম্ভাব্য উৎস, স্থানীয় কর্তৃপক্ষ কী করতে পারে, ডেটার সীমাবদ্ধতা)
- **সর্বোচ্চ আউটপুট**: 1,024 টোকেন
- **অডিয়েন্স**: ওয়ার্ড কাউন্সিলর, স্থানীয় সাংবাদিক, RWAs (রেসিডেন্ট ওয়েলফেয়ার অ্যাসোসিয়েশন)
- **মূল বৈশিষ্ট্য**: নির্দিষ্ট স্থানীয় নিয়ন্ত্রক ব্যবস্থা (GRAP, RTI এবং মিউনিসিপ্যাল অভিযোগের নম্বর) অন্তর্ভুক্ত
- **ফলব্যাক**: কোনো AI বিশ্লেষণ ছাড়াই র (raw) ডেটা প্রদান করে
- **স্কিল ফাইল**: `docs/skills/accountability-brief.md`

### 3.4 অ্যানোমালি ডিটেকশন (`anomaly-check.mjs`)
- **ইনপুট**: স্বয়ংক্রিয় — দিল্লি, মুম্বাই, কলকাতা, চেন্নাই, বেঙ্গালুরু মনিটর করে
- **থ্রেশহোল্ড**: PM2.5 > 2× মৌসুমী বেসলাইন = অ্যানোমালি
- **আউটপুট**: প্রতিটি স্পাইকের জন্য এক বাক্যের ব্যাখ্যা
- **মৌসুমী বেসলাইন**: হার্ডকোড করা আনুমানিক JanVayu ওয়ার্কিং বেসলাইন, প্রকাশিত CREA বা IQAir ফিগার নয় (ডায়নামিকভাবে গণনা করা হয় না)
- **ফলব্যাক**: AI ব্যাখ্যা ছাড়াই অ্যানোমালি ফ্ল্যাগ প্রদান করে
- **স্কিল ফাইল**: `docs/skills/anomaly-explainer.md`

### শেয়ার্ড AI আর্কিটেকচার
চারটি ফিচারের মধ্যে এই বিষয়গুলো কমন:
- শুধুমাত্র সার্ভার-সাইড এক্সিকিউশন (ক্লায়েন্টের কাছে কোনো API কী প্রকাশ করা হয় না)
- CORS প্রিফ্লাইট হ্যান্ডলিং (OPTIONS → 204)
- সঠিক স্ট্যাটাস কোডসহ JSON রেসপন্স
- প্রতিটি এক্সটার্নাল কলে try/catch
- গ্রেসফুল ডিগ্রেডেশন — প্রতিটি AI ফিচারের একটি নন-AI ফলব্যাক রয়েছে

## 4. Netlify Functions (28 Serverless Handlers)

নিচের টেবিলগুলোতে কোর ফাংশনগুলোর তালিকা দেওয়া হলো। রিপোজিটরিতে 28টি হ্যান্ডলার ফাইল এবং একটি শেয়ার্ড হেল্পার (`blob-store.js`) রয়েছে; এর মধ্যে পাঁচটি হ্যান্ডলার শিডিউল করা আছে।

### শিডিউলড ফাংশন
| Function | Schedule | Purpose |
|----------|----------|---------|
| `scheduled-fetch.mjs` | প্রতি 4 ঘণ্টা পরপর | সমস্ত সোশ্যাল মিডিয়া এবং নিউজ ফিড Netlify Blobs ক্যাশে প্রি-ফেচ করে |
| `daily-digest.mjs` | প্রতিদিন সকাল 8:00 AM IST | Resend API-এর মাধ্যমে সাবস্ক্রাইবারদের কাছে AQI ইমেইল ডাইজেস্ট পাঠায় |

### স্ট্যান্ডার্ড ফাংশন প্যাটার্ন
প্রতিটি ফাংশন এই টেমপ্লেট অনুসরণ করে:
1. CORS প্রিফ্লাইট হ্যান্ডলিং (`OPTIONS` → `204`)
2. `try/catch`-এর মধ্যে মূল লজিক র‍্যাপ করা
3. CORS হেডার সহ JSON রেসপন্স বডি
4. এরর হলে সুন্দরভাবে ফলব্যাক (খালি বডি নিয়ে কখনোই `500` রিটার্ন করে না)

| MCP Server | Tools Available | Use Case for JanVayu |
|------------|----------------|---------------------|

| **Notion** | পেজ তৈরি, ডেটাবেস কোয়েরি, সার্চ, আপডেট | প্রজেক্ট প্ল্যানিং, টাস্ক ট্র্যাকিং, মিটিং নোটস |
| **Gmail** | মেসেজ সার্চ, থ্রেড পড়া, ড্রাফট তৈরি | ফিচার সংক্রান্ত ইমেইল আলোচনাগুলো রেফারেন্স হিসেবে কাজে লাগায় |

## সারসংক্ষেপ
এই Claude Code সেটআপটি একটি প্রোডাকশন ওয়েব প্ল্যাটফর্মের জন্য একটি সম্পূর্ণ ডেভেলপমেন্ট পরিবেশ প্রদান করে, যার মধ্যে রয়েছে:
- **28 serverless handlers** (4 AI-চালিত, 5 নির্ধারিত, বাকিগুলো feeds, subscriptions এবং data APIs) এবং একটি শেয়ার করা helper
- git hooks-এর মাধ্যমে **স্বয়ংক্রিয় কোড কোয়ালিটি** (সিক্রেট ব্লকিং, কমিট কনভেনশন, ডিবাগ ডিটেকশন)
- link checking, translation coverage এবং dependency আপডেটের জন্য **CI/CD pipelines**
- `/docs/`-এ একটি সিঙ্গেল শেল থেকে পরিবেশিত **5টি ভাষায় মাল্টিলিঙ্গুয়াল Docsify ডকুমেন্টেশন**
- কনভেনশন এবং ডকুমেন্টেশন দ্বারা প্রয়োগকৃত **Zero-framework architecture**
- GitHub, Notion, Gmail, Figma, Calendar এবং Excalidraw-এর জন্য **MCP integrations**
- **ন্যূনতম খরচ** — প্রায় সবকিছুই ফ্রি টিয়ারে চলে
