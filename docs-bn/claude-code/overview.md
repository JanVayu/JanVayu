# Claude Code — JanVayu কীভাবে তৈরি করা হয়েছিল

JanVayu তৈরি করা হয়েছে **Claude Code** ব্যবহার করে, যা সফটওয়্যার ইঞ্জিনিয়ারিংয়ের জন্য Anthropic-এর অফিসিয়াল CLI এজেন্ট। এই অংশে সম্পূর্ণ সেটআপ, ওয়ার্কফ্লো এবং কনফিগারেশন ডকুমেন্ট করা হয়েছে — যাতে আপনি আপনার নিজের প্রজেক্টের জন্যও এটি হুবহু ব্যবহার করতে পারেন।

---

## Claude Code কী?

Claude Code হলো একটি টার্মিনাল-ভিত্তিক AI কোডিং এজেন্ট। আপনি এটিকে আপনার প্রজেক্ট ডিরেক্টরিতে রান করতে পারেন এবং এটি যা যা করতে পারে:

- ফাইল পড়া ও লেখা
- শেল কমান্ড রান করা
- কোডবেস সার্চ করা
- কমিট এবং পুল রিকোয়েস্ট তৈরি করা
- জটিল মাল্টি-ফাইল রিফ্যাক্টর ম্যানেজ করা
- ফুল কনটেক্সটসহ এরর ডিবাগ করা

এটি একটি ইন্টারেক্টিভ সেশন হিসেবে কাজ করে যেখানে আপনি যা চান তা বর্ণনা করেন এবং Claude তা এক্সিকিউট করে — আপনার কোড পড়ে, পরিবর্তন করে, টেস্ট রান করে এবং কাজ শেষ না হওয়া পর্যন্ত পুনরাবৃত্তি (iterate) করতে থাকে।

## JanVayu-এর জন্য Claude Code কীভাবে ব্যবহার করা হয়েছিল

### প্রাথমিক নির্মাণ

কোর প্ল্যাটফর্ম (`index.html`, সব Netlify Functions, ইনফ্রাস্ট্রাকচার কনফিগস) বারবার Claude Code সেশনের মাধ্যমে তৈরি করা হয়েছিল:

১. **ফিচারটি বর্ণনা করা** — যেমন, "একটি হেলথ ইমপ্যাক্ট ক্যালকুলেটর যোগ করুন যা বয়স, শারীরিক অবস্থা এবং বাইরে কাটানো সময় নেবে"
২. **Claude বর্তমান কোড পড়ে** — জিরো-ফ্রেমওয়ার্কের সীমাবদ্ধতা, বর্তমান প্যাটার্নগুলো বুঝতে পারে
৩. **Claude ইমপ্লিমেন্টেশন লেখে** — `index.html`, `app.js` এবং `styles.css`-এ, অথবা নতুন Netlify Function হিসেবে
৪. **রিভিউ এবং পুনরাবৃত্তি** — পরিবর্তনের অনুরোধ করা, এজ কেস ঠিক করা
৫. **Claude কমিট করে** — প্রজেক্টের নিয়ম অনুযায়ী সঠিক কমিট মেসেজ প্রিফিক্স দিয়ে

### v25.1 AI ফিচারস

সবগুলো AI ফিচার (Ask JanVayu, Health Advisory, Accountability Brief, Anomaly Detection) Claude Code সেশনে তৈরি করা হয়েছিল:

- Claude Netlify Functions (`.mjs` ফাইল) লিখেছিল
- Claude সিস্টেম প্রম্পট তৈরি করেছিল
- Claude `index.html`-এ ফ্রন্টএন্ড UI সেকশন যোগ করেছিল
- Claude CHANGELOG এন্ট্রি তৈরি করেছিল
- Claude PR এবং মার্জগুলো ম্যানেজ করেছিল

> **আপডেট, ২ অক্টোবর ২০২৬:** v25.1 Google Gemini 2.5 Flash-এ লঞ্চ হয়েছিল (CHANGELOG v25.1.0)। ফিচারগুলো পরে Groq (Llama 3.3 70B)-তে সরানো হয় এবং, ১৬ আগস্ট ২০২৬-এ Groq মডেলটি বন্ধ করে দেওয়ার পর, `openai/gpt-oss-120b`-তে (CHANGELOG v26.6.33) সরানো হয়।

## সেশন ওয়ার্কফ্লো

JanVayu-এর জন্য একটি সাধারণ Claude Code সেশন এই প্যাটার্ন অনুসরণ করে:
```
১. রিপো রুট থেকে Claude Code চালু করুন
   $ claude

২. কাজের বর্ণনা দিন
   > "দিল্লি, মুম্বাই, কলকাতা, চেন্নাই এবং বেঙ্গালুরুর জন্য PM2.5-কে মৌসুমী বেসলাইনের সাথে মিলিয়ে একটি অ্যানোমালি ডিটেকশন ব্যানার যোগ করুন"

৩. Claude কোডবেস এক্সপ্লোর করে
   - বিদ্যমান UI প্যাটার্নগুলো বোঝার জন্য index.html এবং app.js পড়ে
   - কোডিং স্টাইল বোঝার জন্য বিদ্যমান Netlify Functions পড়ে
   - উপলব্ধ ডিপেন্ডেন্সিগুলো চেক করতে package.json দেখে

৪. Claude ইমপ্লিমেন্টেশন করে
   - netlify/functions/anomaly-check.mjs তৈরি করে
   - index.html-এ ব্যানার মার্কআপ, styles.css-এ স্টাইলিং এবং app.js-এ লজিক যোগ করে
   - ফাংশনটিকে কল করার জন্য ক্লায়েন্ট-সাইড কোড আপডেট করে

৫. Claude কমিট করে এবং একটি PR তৈরি করে
   - কমিট মেসেজের নিয়ম মেনে চলে (Add:, Fix:, ইত্যাদি)
   - সামারি এবং টেস্ট প্ল্যান দিয়ে PR তৈরি করে

৬. রিভিউ, ইটারেট এবং মার্জ
```

## এই প্রজেক্টের মূল শক্তিগুলো

### কনটেক্সট অ্যাওয়ারনেস
Claude Code আপনার পুরো কোডবেস পড়ে। JanVayu-এর ক্ষেত্রে এর মানে হলো এটি বুঝতে পেরেছে:
- জিরো-ফ্রেমওয়ার্ক সীমাবদ্ধতা (কোনো React/Vue/Angular নেই)
- `index.html` (মার্কআপ), `styles.css` এবং `app.js`-এ ভাগ করা
- Netlify Functions স্ট্রাকচার এবং CORS হ্যান্ডলিং
- Netlify Blobs ব্যবহার করে ক্যাশ-ফার্স্ট প্যাটার্ন
- git হুকস দ্বারা প্রয়োগ করা কমিট মেসেজের নিয়ম

### মাল্টি-ফাইল কোঅর্ডিনেশন
"Ask JanVayu"-এর মতো একটি ফিচার যোগ করতে নিচের জায়গাগুলোতে পরিবর্তন করতে হয়:
- একটি নতুন Netlify Function (`air-query.mjs`)
- ফ্রন্টএন্ড HTML (`index.html`-এ নতুন সেকশন)
- ফ্রন্টএন্ড CSS (চ্যাট ইন্টারফেসের জন্য স্টাইলিং)
- ফ্রন্টএন্ড JS (ফাংশনে fetch কল, UI লজিক)
- CHANGELOG.md (ফিচারটি ডকুমেন্ট করা)

Claude Code একটি সিঙ্গেল সেশনে এই সব কাজ সামলে নেয়।

### Git ইন্টিগ্রেশন
Claude Code নেটিভভাবে নিচের কাজগুলো সামলায়:
- `git status`, `git diff`, `git log`
- সঠিক মেসেজ দিয়ে কমিট তৈরি করা
- `gh` CLI-এর মাধ্যমে ব্রাঞ্চ এবং PR তৈরি করা
- প্রজেক্ট-ভিত্তিক git হুকস মেনে চলা

## Claude Code যা করতে পারে না

স্বচ্ছতার জন্য, এখানে দেখানো হলো কোন কাজগুলোতে মানুষের হস্তক্ষেপ প্রয়োজন ছিল:

| কাজ | কারণ |
|------|-----|
| Netlify ড্যাশবোর্ড কনফিগারেশন | এনভায়রনমেন্ট ভেরিয়েবল, ডোমেইন সেটআপ, বিল্ড সেটিংস |

| কন্টেন্ট রিভিউ | ডেটা সোর্সের নির্ভুলতা, পলিসির সঠিকতা যাচাই করা |
| ডিপ্লয়মেন্ট ভেরিফিকেশন | ডিপ্লয় করার পর লাইভ সাইট চেক করা |
