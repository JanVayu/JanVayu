# এই সেটআপটি শেয়ার এবং রেপ্লিকেট করা

এই পৃষ্ঠায় ব্যাখ্যা করা হয়েছে কীভাবে আপনার টিমের সাথে JanVayu-এর Claude Code ওয়ার্কফ্লো শেয়ার করবেন অথবা নিজের প্রজেক্টের জন্য এটি রেপ্লিকেট করবেন।

---

## আপনার টিমের জন্য

### ডকুমেন্টেশন শেয়ার করুন

এই ডকুমেন্টেশনটি JanVayu-এর নিজস্ব সাইটে [`/docs/`](/docs/) হোস্ট করা আছে — এটি একটি সিঙ্গেল-পেজ Docsify শেল যা সরাসরি রিপোজিটরি থেকে মার্কডাউন পড়ে। যে কেউ নিচের বিষয়গুলো বুঝতে চান, তাকে এই URL-টি পাঠান:
- JanVayu কীভাবে তৈরি করা হয়েছে
- Claude Code ব্যবহার করে কীভাবে অবদান রাখবেন
- অন্য কোনো শহর বা ডোমেইনের জন্য JanVayu কীভাবে ফর্ক (fork) করবেন

### নতুন কন্ট্রিবিউটর যুক্ত করুন

১. **রিপোজিটরি ক্লোন করুন** — `git clone https://github.com/JanVayu/JanVayu.git`
২. **ডকুমেন্টেশন পড়ুন** — [`/docs/`](/docs/) থেকে শুরু করুন, বিশেষ করে:
   - [Tech Stack Overview](../tech-stack/overview.md)
   - [Architecture](../technical/architecture.md)
   - [Local Development](../technical/local-development.md)
৩. **Claude Code ইনস্টল করুন** — `npm install -g @anthropic-ai/claude-code`
৪. **একটি সেশন শুরু করুন** — `cd JanVayu && claude`
৫. **ওয়ার্কফ্লো অনুসরণ করুন** — [Workflow](workflow.md)-এ বর্ণিত আছে

## আপনার নিজের প্রজেক্টের জন্য

### ধাপ ১: কনস্ট্রেইন্ট-ফার্স্ট (Constraint-First) পদ্ধতি গ্রহণ করুন

JanVayu থেকে শেখার সবচেয়ে সহজে প্রয়োগযোগ্য বিষয়টি হলো **কনস্ট্রেইন্ট-ফার্স্ট প্রম্পটিং**। Claude Code-কে কিছু তৈরি করতে বলার আগে:

১. আপনার প্রজেক্টে কী কী ব্যবহার করা *হবে না* (ফ্রেমওয়ার্ক, বিল্ড টুলস ইত্যাদি) তা নির্ধারণ করুন
২. আপনার কোড স্টাইল এবং নিয়মকানুন নির্ধারণ করুন
৩. আপনার ডিপ্লয়মেন্ট টার্গেট নির্ধারণ করুন
৪. এগুলো আপনার রিপোজিটরির রুটে থাকা একটি `CLAUDE.md` ফাইলে রাখুন

### ধাপ ২: স্কিল ফাইল তৈরি করুন

আপনার প্রজেক্টে যদি এআই (AI) ফিচার ব্যবহার করা হয় (যেকোনো মডেল — Groq, OpenAI, Claude API), তবে প্রতিটি এআই ইন্টারঅ্যাকশনকে একটি স্কিল ফাইল হিসেবে ডকুমেন্ট করুন:

```markdown
# Skill: [Feature Name]

## Role
[What the model acts as]

## Data Context
[What real data gets injected into the prompt]

## Output Format
[Exact structure expected]

## Constraints
[Word limits, tone, language, what NOT to do]

## Fallback
[What happens if the AI call fails]
```

### ধাপ ৩: Git Hooks সেট আপ করুন

নিচের নিয়মগুলো মেনে চলতে JanVayu-এর গিট হুকস (`.githooks/`) কপি করে নিন:
- কমিট মেসেজের নিয়মকানুন
- কমিটে কোনো সিক্রেট (secrets) না থাকা
- কমিটে কোনো ডিবাগ স্টেটমেন্ট না থাকা

### ধাপ ৪: কোড তৈরির সাথে সাথে ডকুমেন্টেশন তৈরি করুন

আপনার কোডের পাশাপাশি Docsify (বা যেকোনো মার্কডাউন-ভিত্তিক) ডকুমেন্টেশন তৈরি করুন। Claude Code আপনার কোডবেস থেকে ডকুমেন্টেশন তৈরি করতে পারে — এটি ব্যবহার করুন।

## অন্য কোনো শহরের জন্য JanVayu ফর্ক করা

JanVayu-এর কোড MIT-লাইসেন্সপ্রাপ্ত (এর কনটেন্ট CC BY-NC-SA 4.0)। অন্য কোনো শহর বা দেশের জন্য এটি ফর্ক করতে:
১. **GitHub-এ রিপোটি ফর্ক করুন**
২. `app.js`-এর **শহরের তালিকা আপডেট করুন** এবং Netlify ফাংশনের `CITIES` টেবিলগুলো
৩. `anomaly-check.mjs`-এ **মৌসুমি বেসলাইন আপডেট করুন**
৪. আপনার অঞ্চলের জন্য **WAQI স্টেশন আইডি আপডেট করুন**
৫. স্থানীয় ভাষার জন্য **স্ট্রিংগুলো অনুবাদ করুন**
৬. এনভায়রনমেন্ট ভেরিয়েবল দিয়ে **নিজেদের Netlify সাইট সেট আপ করুন**
৭. **ঐচ্ছিক:** ডিফল্ট Groq মডেল (`openai/gpt-oss-120b`) অন্য কোনো মডেল দিয়ে রিপ্লেস করুন (স্কিল ফাইলগুলো মডেল-অ্যাগনস্টিক)

এই সব ধাপেই Claude Code সাহায্য করতে পারে।

## এই ডকুমেন্টেশন এক্সপোর্ট করা

### একটি স্ট্যান্ডঅ্যালোন সাইট হিসেবে

ডকুমেন্টেশনগুলো আগে থেকেই একটি স্ট্যান্ডঅ্যালোন সাইট। যেকোনো পাঠককে [`https://www.janvayu.in/docs/`](https://www.janvayu.in/docs/)-এ নির্দেশ করুন।

### Markdown হিসেবে

র (raw) Markdown ফাইলগুলো রিপো-র `docs/` (ইংরেজি) এবং `docs-{lang}/` (হিন্দি, বাংলা, মারাঠি, তামিল) ফোল্ডারে রয়েছে। এগুলো সরাসরি শেয়ার করতে পারেন অথবা Markdown রেন্ডার করে এমন যেকোনো জায়গায় হোস্ট করতে পারেন — GitHub, Notion, HackMD, আপনার নিজস্ব Docsify বা MkDocs সাইট।

### PDF হিসেবে

Docsify-তে বিল্ট-ইন PDF এক্সপোর্ট অপশন নেই। লাইভ ডকুমেন্টগুলোকে PDF-এ রূপান্তর করতে, `https://www.janvayu.in/docs/`-কে PDF-এ রেন্ডার করার জন্য `wkhtmltopdf` অথবা Puppeteer-এর মতো কোনো হেডলেস-Chrome টুল ব্যবহার করুন।

## Docs Stack

JanVayu-এর ডকুমেন্টেশন Docsify-তে চলে — এটি বেছে নেওয়া হয়েছে কারণ এখানে কোনো বিল্ড স্টেপ, কোনো সার্ভার এবং কোনো থার্ড-পার্টি হোস্টিং বিল নেই।

### মাল্টিলিঙ্গুয়াল সেটআপ কীভাবে কাজ করে

ইংরেজি Markdown থাকে `docs/`-এ। প্রতিটি অনূদিত ভাষা থাকে `docs-{lang}/`-এ। `/docs/index.html`-এ একটি মাত্র Docsify শেল একটি এলিয়াস ম্যাপ ঘোষণা করে যা হ্যাশ পাথগুলোকে সঠিক ডিরেক্টরিতে রাউট করে, যাতে দর্শনার্থীরা নিচের ঠিকানায় পৌঁছাতে পারেন:

| ভাষা | URL | সোর্স ডিরেক্টরি |
|----------|-----|------------------|
| ইংরেজি (ডিফল্ট) | [`/docs/`](/docs/) | `docs/` |
| হিন্দি | [`/docs/#/hi/`](/docs/#/hi/) | `docs-hi/` |
| বাংলা | [`/docs/#/bn/`](/docs/#/bn/) | `docs-bn/` |
| মারাঠি | [`/docs/#/mr/`](/docs/#/mr/) | `docs-mr/` |
| তামিল | [`/docs/#/ta/`](/docs/#/ta/) | `docs-ta/` |

অনূদিত ট্রি-গুলো একটি CI অটো-ট্রান্সলেট জব (`.github/workflows/translations.yml`, যার জন্য একটি Sarvam API key প্রয়োজন) দ্বারা রিফ্রেশ করা হয় এবং এগুলো ইংরেজি ডকস-এর চেয়ে পিছিয়ে থাকতে পারে: বর্তমানে ৬৫টি ইংরেজি পেজের মধ্যে ৪৭টিরই প্রতিটি ভাষায় একটি করে অনূদিত সংস্করণ রয়েছে।

### কাস্টম ডোমেইন

ডকসগুলো `https://www.janvayu.in/docs/` থেকে সার্ভ করা হয় (এটি মূল JanVayu সাইটের একটি পাথ, কোনো সাবডোমেইন নয়) — এর জন্য আলাদা কোনো DNS বা SSL কনফিগারেশনের প্রয়োজন নেই।

### ব্র্যান্ডিং

থিমের ভেরিয়েবলগুলো `docs/index.html`-এর `<style>` ব্লকের ভেতরে থাকে:
- প্রাইমারি রঙ: `#16A34A` (প্ল্যাটফর্মের ব্র্যান্ড সবুজ রঙের সাথে মিলে যায়)
- সাইডবারের অ্যাকসেন্ট: `#1a3a2a`
- ডার্ক মোড: শেয়ার্ড সাইট হেডার (`js/chrome.js`) থেকে টগল করা যায়; এই পছন্দটি `localStorage`-এ `janvayu-theme` হিসেবে সেভ করা থাকে
