# স্কিল: পাবলিক হেলথ অ্যাডভাইজার

**ব্যবহৃত হয়:** `netlify/functions/health-advisory.mjs`  
**মডেল:** Groq-এর মাধ্যমে `openai/gpt-oss-120b` (`GROQ_MODEL` দ্বারা নির্ধারিত ডিফল্ট, ১৬ আগস্ট ২০২৬-এ Groq এটি বাতিল করার আগে পর্যন্ত Llama 3.3 70B)  
**ট্রিগার:** ব্যবহারকারী একটি প্রোফাইল (বয়স, স্বাস্থ্যগত অবস্থা, প্রতিদিন বাইরে কাটানো সময়) + একটি শহরের নাম জমা দেন

## এই স্কিলটি কী কাজ করে

ব্যক্তির ঝুঁকির প্রোফাইল এবং শহরের বর্তমান PM2.5 রিডিংয়ের ওপর ভিত্তি করে এটি একটি ব্যক্তিগতকৃত এবং কার্যকরী স্বাস্থ্য পরামর্শ তৈরি করে। সবচেয়ে গুরুত্বপূর্ণ বিষয় হলো: এটি কোনো অস্পষ্ট কথা বলে না। এটি একটি সুনির্দিষ্ট সুপারিশ দেয় — "বিকেল ২টো পর্যন্ত ঘরের ভেতরে থাকুন" (stay indoors until 2pm), "বাইরে যাওয়া কমানোর কথা ভাবতে পারেন" (consider limiting outdoor exposure) এমন নয়।

## সিস্টেম প্রম্পট (হুবহু)

```
আপনি ভারতের বায়ুদূষণজনিত স্বাস্থ্য ঝুঁকির বিষয়ে বিশেষজ্ঞ একজন পাবলিক হেলথ অ্যাডভাইজার। 
একজন ব্যক্তির প্রোফাইল এবং বর্তমান বায়ুর গুণগত মান সম্পর্কিত তথ্য দেওয়া থাকলে, 
একটি সুনির্দিষ্ট এবং কার্যকরী পরামর্শ তৈরি করুন। সুনির্দিষ্ট হোন: 'limit outdoor exposure' না বলে 
'stay indoors until 2pm' বলুন। প্রকৃত PM2.5 মানের উল্লেখ করুন। যদি ব্যক্তির কোনো স্বাস্থ্যগত সমস্যা থাকে, 
তবে সরাসরি সেটির কথা উল্লেখ করুন। কোনো অস্পষ্ট কথা বলবেন না — একটি স্পষ্ট সুপারিশ দিন। 
সর্বোচ্চ ৩-৪টি বাক্য। ইংরেজিতে উত্তর দিন।
```

## প্রি-এআই (Pre-AI) ঝুঁকি হিসাব

Groq API-তে কল করার আগে, ফাংশনটি সাধারণ JavaScript-এ একটি `riskLevel` হিসাব করে — এটি সবসময় এআই (AI) পরামর্শের পাশাপাশি ফেরত পাঠানো হয়, যাতে এআই-এর উত্তরের জন্য অপেক্ষা না করেই ইউআই (UI) রেসপন্সটিকে রঙের মাধ্যমে কোড করতে পারে:

```javascript
function getRiskLevel(pm25, conditions) {
  const hasSensitive = conditions && conditions.some(c => c !== "none");
  if (pm25 <= 12) return "low";
  if (pm25 <= 35) return hasSensitive ? "moderate" : "low";
  if (pm25 <= 55) return hasSensitive ? "high" : "moderate";
  if (pm25 <= 150) return hasSensitive ? "severe" : "high";
  return "severe";
}
```

এই থ্রেশহোল্ডগুলো ২০১২ সালের ইউএস ইপিএ (US EPA) PM2.5 ব্রেকপয়েন্ট (12.0, 35.4, 55.4, 150.4 µg/m³) অনুসরণ করে, যা ইপিএ ২০২৪ সালে সংশোধন করেছে (Good এখন ৯.০ পর্যন্ত, Unhealthy ৫৫.৫ থেকে ১২৫.৪ পর্যন্ত); কোডটি ২০২৪ সালের মান অনুযায়ী আপডেট করা হয়নি। সংবেদনশীলতা (Sensitivity) সামলানোর জন্য আগে থেকে থাকা স্বাস্থ্যগত সমস্যাযুক্ত ব্যক্তিদের এক ধাপ ওপরে রাখা হয়।

## মূল ডিজাইনের সিদ্ধান্তগুলো


---
**"hedging" না কেন?**
আমরা ধরে নিই যে সরাসরি পরামর্শের ("Y পর্যন্ত X করুন") তুলনায় দ্ব্যর্থবোধক পরামর্শ ("আপনি হয়তো বিবেচনা করতে পারেন...") মানুষ কম মেনে চলে। হাঁপানি বা হৃদরোগে আক্রান্ত ব্যক্তিদের জন্য কাজ করে এমন একটি জনস্বাস্থ্য টুলের ক্ষেত্রে, দ্ব্যর্থবোধকতা নিরপেক্ষ নয় — এটি সক্রিয়ভাবে সুরক্ষামূলক আচরণকে কমিয়ে দেয়।

**কেন সর্বোচ্চ ৩-৪টি বাক্য?**
প্রদূষণ বেশি থাকাকালীন জরুরি অবস্থায় এমন কোনো স্বাস্থ্য পরামর্শ পড়া হবে না, যা পড়তে মানুষের পরিশ্রম করতে হয়। এটি ১০ সেকেন্ডেরও কম সময়ে চোখ বুলিয়ে পড়ার মতো হতে হবে।

**কেন মডেলের ওপর নির্ভর না করে JavaScript-এ `riskLevel` হিসাব করা হয়?**
নির্ভরযোগ্যতা। ঝুঁকির মাত্রা UI-এর রঙের কোডিং এবং ফলব্যাক মেসেজিং নির্ধারণ করে। এটি LLM-এর ওপর ছেড়ে দিলে অনিশ্চয়তা তৈরি হয়। নিয়ম-ভিত্তিক ফাংশনটি AI-এর উপস্থিতি বা অনুপস্থিতি নির্বিশেষে সর্বদা একটি সামঞ্জস্যপূর্ণ ফলাফল দেয়।

**কেন প্রম্পটে শর্তের তালিকা অন্তর্ভুক্ত করা হয়?**
"সরাসরি উত্তর দিন" মডেলটিকে একটি সাধারণ প্রতিক্রিয়ার পরিবর্তে "হাঁপানিতে আক্রান্ত কারও জন্য, এই মাত্রার PM2.5 মানে..." বলতে বাধ্য করে। এটি হলো প্রধান পার্সোনালাইজেশন লিভার।

## অন্যান্য ডোমেইনের জন্য মানিয়ে নেওয়া

এই স্কিল প্যাটার্নটি — প্রোফাইল + লাইভ ডেটা → সুনির্দিষ্ট পরামর্শ — নিচের ক্ষেত্রে পুনরায় ব্যবহার করা যেতে পারে:

- **হিট অ্যাডভাইজরি (Heat advisory):** বয়স + শারীরিক অবস্থা + তাপমাত্রা/হিট ইনডেক্স → বাইরের কাজকর্মে এবং হাইড্রেসন সম্পর্কে সুনির্দিষ্ট পরামর্শ
- **জলের দূষণ সতর্কতা:** অবস্থান + দূষকের মাত্রা + জনতাত্ত্বিক তথ্য → পান করা বা ব্যবহারের পরামর্শ
- **শব্দদূষণের প্রভাব:** প্রোফাইল + ডেসিবল রিডিং + সময়কাল → শ্রবণশক্তির সুরক্ষার পরামর্শ
