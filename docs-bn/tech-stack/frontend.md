# ফ্রন্টএন্ড স্ট্যাক

## HTML/CSS/JavaScript (ভ্যানিলা)

ফ্রন্টএন্ডটি কোনো বিল্ড স্টেপ বা বান্ডলার ছাড়াই ভ্যানিলা HTML, CSS এবং JavaScript দিয়ে তৈরি। এটি একটি **সিঙ্গেল ফাইল নয়**, এবং এই পেজটি দীর্ঘদিন ধরে এমন দাবি করে কাউকে বিভ্রান্ত করার মতো অবস্থা তৈরি করেছিল: `index.html` প্রায় ৬,৬০০ লাইনের, `styles.css` প্রায় ৩,৭০০ লাইনের, `app.js` প্রায় ১০,০০০ লাইনের, এবং `panels/`-এ ১৯টি প্যানেল ফ্র্যাগমেন্ট রয়েছে যা রানটাইমে পেজে লোড হয়।

### এর গঠন

| ফাইল | এটি কী |
|---|---|
| `index.html` | সিঙ্গেল-পেজ অ্যাপ: বারের জন্য, প্যানেল কন্টেইনার এবং ফার্স্ট পেইন্টের জন্য `styles.css`-এর একটি ইনলাইন **critical-CSS** সাবসেট |
| `styles.css` | ডিজাইন সিস্টেম। প্রতিটি টোকেন, উভয় থিম এবং শেয়ার্ড কম্পোনেন্টগুলো (`.bar`, `.ctl`, `.card`, `.container`) |
| `app.js` | প্যানেল রাউটিং, ডেটা ফেচিং, চার্ট, রোল এবং ল্যাঙ্গুয়েজ মেকানিজম |
| `js/chrome.js` | থিম প্রেফারেন্স এবং SPA নয় এমন পেজগুলোর জন্য একটি ছোট বার |
| `panels/*.html` | `index.html`-এ ইনজেক্ট করা ফ্র্যাগমেন্ট; এগুলো এর স্টাইলিং গ্রহণ করে |
| ১৮টি স্ট্যান্ডঅ্যালোন পেজ | `/pm25/`, `/try.html`, `/docs/`, `/blog/`, `/ask/`, ওয়াকথ্রু, এমবেড এবং বাকিগুলো |

**সব ১৯টি স্ট্যান্ডঅ্যালোন ডকুমেন্ট `styles.css` লোড করে।** 2026-09-22 পর্যন্ত এটি সত্য ছিল না: প্রতিটিতে একটি প্রাইভেট `<style>` ব্লক ছিল যা একই টোকেন নামগুলোকে ফিক্সড লাইট-থিম লিটারেল দিয়ে রিডিফাইন করত, তাই একটি টোকেন পরিবর্তন একটি পেজে পৌঁছাত কিন্তু অন্য কোনো পেজ থিম কন্ট্রোল অনুসরণ করত না।
`scripts/check-design-system.py` এমন একটি পেজকে ফেইল করে যা আবার বাদ পড়ে যায়।

### কেন কোনো বিল্ড স্টেপ নেই

1. **কোনো বিল্ড স্টেপ নেই** — রেপোটিই হলো ডিপ্লয় আর্টিফ্যাক্ট
2. **কন্ট্রিবিউটর-ফ্রেন্ডলি** — `python3 -m http.server` হলো সম্পূর্ণ ডেভ সেটআপ
3. **সোর্স এবং আউটপুটের মধ্যে পুরনো হওয়ার মতো কিছু নেই**

এর মূল্য হলো ক্যাশ-বাষ্টিং ম্যানুয়াল। `/styles.css` এবং `/app.js` `package.json`-এর ভার্সন থেকে নেওয়া একটি `?v=<stamp>` কোয়েরি দিয়ে রিকোয়েস্ট করা হয়, কারণ `sw.js` সেম-অরিজিন অ্যাসেটগুলোকে **কোনো রিভ্যালিডেশন ছাড়া ক্যাশ-ফার্স্ট** সার্ভ করে। দুটি গার্ড এটি ধরে রাখে: `check-asset-stamps.py` (প্রতিটি স্ট্যাম্পড URL বর্তমান স্ট্যাম্প বহন করে) এবং `check-asset-freshness.py` (ভার্সন অপরিবর্তিত থাকার সময় কোনো স্ট্যাম্পড ফাইল পরিবর্তন হয়নি)। দ্বিতীয়টি বিদ্যমান কারণ প্রথমটি পাস করেছিল যখন অপরিবর্তিত URL-এর অধীনে `app.js` পরিবর্তিত হয়েছিল।

### CSS আর্কিটেকচার
- **কাস্টম প্রপার্টির তিনটি লেয়ার।** একটি র (raw) র‍্যাম্প (`--w-0`…`--w-900` হালকা রঙের জন্য ওয়ার্ম নিউট্রাল, `--d-950`…`--d-50` ডার্কের জন্য), একটি সিম্যান্টিক লেয়ার যা এর দিকে নির্দেশ করে, এবং এমন কিছু কম্পোনেন্ট যা সবসময় শুধু সিম্যান্টিক লেয়ারকেই রেফারেন্স হিসেবে ব্যবহার করে।
- **কোনো প্রিপ্রসেসর নেই** (কোনো Sass, Less, বা PostCSS নেই)
- **মিডিয়া কোয়েরি সহ মোবাইল-ফার্স্ট** রেসপন্সিভ ডিজাইন
- **WCAG AA** কনট্রাস্ট, যা CI-তে উভয় থিমের প্রতিটি প্যানেল এবং প্রতিটি পৃষ্ঠার ওপর Playwright সুইপ দ্বারা নিয়ন্ত্রিত হয়

সিম্যান্টিক লেয়ার, যা ব্যবহার করে আপনার কোড লেখা উচিত:

```css
:root {
  --bg: var(--paper);          /* the page */
  --bg-section: var(--warm-white);
  --bg-card: var(--w-0);
  --text: var(--ink);
  --text-2: var(--ink-secondary);
  --text-3: var(--ink-tertiary);
  --accent: var(--green-700);
  --border: var(--w-300);
}

[data-theme="dark"] {
  --bg: var(--d-950);
  --bg-section: var(--d-900);
  --bg-card: var(--d-850);
  --text: var(--d-50);
  --accent: #4ADE80;
  --border: var(--d-700);
}
```

এগুলোর পাশাপাশি রয়েছে ইঙ্ক টোকেনগুলো — `--ink-red`, `--ink-blue`, `--ink-teal` এবং অন্যান্য — এগুলো রাখা হয়েছে কারণ সাদা ব্যাকগ্রাউন্ডে টেক্সট হিসেবে ভালো দেখায় এমন একটি স্যাচুরেটেড রঙ `#0e0e0c` ব্যাকগ্রাউন্ডে আর টেক্সট হিসেবে ভালো দেখায় না। JavaScript-এ লিটারেল হিসেবে লেখা কোনো রঙ বা `style=` অ্যাট্রিবিউটের রঙ বুঝতে পারে না যে এটি কোন থিমের মধ্যে পড়েছে, তাই একে একটি টোকেন দেওয়া হয় এবং CSS বাকি কাজটা করে দেয়।

### থিমিং

`<html>`-এ `data-theme="dark"` থাকে, যা `js/chrome.js` দ্বারা সেট করা হয় এবং `janvayu-theme`-এর অধীনে সেভ করা থাকে। প্রতিটি পৃষ্ঠার `<head>`-এ একটি ছোট ইনলাইন স্ক্রিপ্ট থাকে যা প্রথম পেইন্টের আগেই সেভ করা ভ্যালুটি প্রয়োগ করে, ফলে কোনো পৃষ্ঠায় কখনোই প্রথমে হালকা রঙ দেখা যায় না এবং পরে তা বদলে যায় না। কোনো `prefers-color-scheme` ব্লক যোগ করবেন না: আগে চারটি পৃষ্ঠায় এটি ছিল, যার মানে হলো সেগুলো অপারেটিং সিস্টেমকে ফলো করত এবং সাইটের নিজস্ব কন্ট্রোলকে এড়িয়ে যেত।

### JavaScript প্যাটার্ন

- **ES2020** — ব্রাউজারের সামঞ্জস্য বজায় রাখার জন্য এর চেয়ে নতুন কোনো ফিচার নেই
- সমস্ত HTTP কলের জন্য **Fetch API** (কোনো axios নেই)
- `document.getElementById` / `querySelector`-এর মাধ্যমে **DOM ম্যানিপুলেশন**
- **কোনো মডিউল বান্ডলার নেই** — সমস্ত JS `<script>` ট্যাগের মধ্যে থাকে
- লাইভ AQI ডেটার জন্য **১০-মিনিটের অটো-রিলোড**

## Chart.js

**সংস্করণ:** 4.x-এ পিন করা (4.4.7), SRI সহ jsDelivr থেকে লোড করা এবং লেজি-লোডেড
**কিসের জন্য ব্যবহৃত হয়:**
- মেট্রো বনাম আঞ্চলিক AQI তুলনামূলক বার চার্ট
- PM2.5 ট্রেন্ড লাইন
- স্বাস্থ্যগত প্রভাবের ডেটা ভিজ্যুয়ালাইজেশন
- মৌসুমী বেসলাইন তুলনা

**কেন Chart.js:**
- ছোট সাইজ (~70 KB gzipped, ~60 KB Brotli)
- কোনো বিল্ড স্টেপ ছাড়াই কাজ করে (CDN স্ক্রিপ্ট ট্যাগ)
- ক্যানভাস-ভিত্তিক রেন্ডারিং (মোবাইলে ভালো পারফরম্যান্স দেয়)
- ইন-বিল্ট রেসপন্সিভ/অ্যাক্সেসিবিলিটি ফিচার
## Leaflet.js + OpenStreetMap

**ভার্সন:** 1.9.4, unpkg থেকে SRI-এর সাথে লোড করা
**ব্যবহার করা হয়েছে:**
- AQI স্টেশন মার্কারসহ ১৬০টি শহরের (১৫৭টি ভারতীয়, সাথে বেইজিং, লন্ডন এবং সিঙ্গাপুর) ইন্টারেক্টিভ ম্যাপ
- AQI-এর তীব্রতা অনুযায়ী কালার-কোডেড মার্কার (সবুজ/হলুদ/কমলা/লাল/বেগুনি)
- ক্লিক করে স্টেশনের বিস্তারিত দেখা

**কেন Leaflet + OSM:**
- ফ্রি এবং ওপেন সোর্স (Google Maps API key-এর প্রয়োজন নেই)
- হালকা (~40 KB gzipped)
- OpenStreetMap ডেটা ফ্রি, তবে এর টাইল সার্ভারগুলো বেস্ট-এফোর্ট এবং পলিসি-লিমিটেড ([ব্যবহার নীতি](https://operations.osmfoundation.org/policies/tiles/)); বেশি ব্যবহারের জন্য কমার্শিয়াল বা সেলফ-হোস্টেড টাইল সোর্স প্রয়োজন। সাইটটি Carto বেসম্যাপ টাইলসও ব্যবহার করে

## মাল্টিলিঙ্গুয়াল সাপোর্ট

JanVayu একটি ক্লায়েন্ট-সাইড ল্যাঙ্গুয়েজ টগল-এর মাধ্যমে ৫টি ভাষা সাপোর্ট করে:

| ভাষা | কোড |
|----------|------|
| ইংরেজি | `en` |
| হিন্দি | `hi` |
| তামিল | `ta` |
| মারাঠি | `mr` |
| বাংলা | `bn` |

**বাস্তবায়ন:** ল্যাঙ্গুয়েজ স্ট্রিংগুলো JS অবজেক্ট হিসেবে সেভ করা থাকে এবং টগল করার সময় DOM এলিমেন্টগুলোতে অদলবদল করা হয়। কোনো i18n লাইব্রেরি ব্যবহার করা হয়নি — শুধু একটি সাধারণ key-value লুকআপ।
