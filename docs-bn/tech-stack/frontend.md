# ফ্রন্টএন্ড স্ট্যাক
## HTML/CSS/JavaScript (ভ্যানিলা)
ফ্রন্টএন্ডটি হলো ভ্যানিলা HTML, CSS এবং JavaScript, যেখানে কোনো বিল্ড স্টেপ বা বান্ডলার নেই। এটি **কোনো একক ফাইল নয়**, এবং এই পেজটি দীর্ঘদিন ধরে এমনটা বলেছিল যা কাউকে বিভ্রান্ত করতে পারে: `index.html` প্রায় 6,500 লাইনের, `styles.css` প্রায় 3,800 লাইনের, `app.js` প্রায় 10,200 লাইনের, এবং `panels/`-এ 19টি প্যানেল ফ্র্যাগমেন্ট রয়েছে যা রানটাইমে পেজে লোড হয়।
### এর গঠন
| ফাইল | এটি কী |
|---|---|
| `index.html` | সিঙ্গেল-পেজ অ্যাপ: বার, প্যানেল কন্টেইনার, এবং ফার্স্ট পেইন্টের জন্য `styles.css`-এর একটি ইনলাইন **ক্রিটিক্যাল-CSS** সাবসেট |
| `styles.css` | ডিজাইন সিস্টেম। প্রতিটি টোকেন, উভয় থিম, এবং শেয়ার্ড কম্পোনেন্টগুলো (`.bar`, `.ctl`, `.card`, `.container`) |
| `app.js` | প্যানেল রাউটিং, ডেটা ফেচিং, চার্ট, রোল এবং ভাষার মেকানিজম |
| `js/chrome.js` | থিম প্রেফারেন্স এবং SPA নয় এমন পেজগুলোর জন্য একটি ছোট বার |
| `js/air-sources.js` | একমাত্র জায়গা যা কোনো জায়গায় বাতাসের অবস্থা সম্পর্কে কী বলা হবে তা নির্ধারণ করে: একটি লাইভ WAQI স্টেশন, তারপর CPCB-এর দৈনিক বুলেটিন, তারপর একটি মডেল এস্টিমেট, প্রতিটিকে লেবেল করা হয়েছে |
| `panels/*.html` | `index.html`-এ ইনজেক্ট করা ফ্র্যাগমেন্ট; এগুলো এর স্টাইলিং গ্রহণ করে |
| স্ট্যান্ডঅ্যালোন পেজ | `/pm25/`, `/try.html`, `/docs/`, `/blog/`, `/ask/`, `/bulletins/`, `/delhi/`, ওয়াকথ্রু, এমবেড, জেনারেট করা ব্লগ পোস্ট পেজ এবং বাকিগুলো |
**প্রতিটি স্ট্যান্ডঅ্যালোন পেজ `styles.css` লোড করে।** `scripts/check-design-system.py` 21 November 2026 তারিখে এর মধ্যে 78টি গণনা করেছে (নিয়মটি চালু হওয়ার সময় 19টি ছিল)। 2026-09-22 পর্যন্ত এটি সত্য ছিল না: প্রতিটিতে একটি প্রাইভেট `<style>` ব্লক ছিল যা একই টোকেন নামগুলোকে ফিক্সড লাইট-থিম লিটারেল দিয়ে রিডিফাইন করত, ফলে একটি টোকেন পরিবর্তন একটি পেজে পৌঁছাতো কিন্তু অন্য কোনো পেজ থিম কন্ট্রোল অনুসরণ করত না।
`scripts/check-design-system.py` এমন একটি পেজে ব্যর্থ হয় যা আবার বাদ পড়ে যায়।
### কেন কোনো বিল্ড স্টেপ নেই
1. **কোনো বিল্ড স্টেপ নেই** — রিপোজিটরিই হলো ডিপ্লয় আর্টিফ্যাক্ট
2. **কন্ট্রিবিউটর-বান্ধব** — `python3 -m http.server` হলো সম্পূর্ণ ডেভ সেটআপ
3. **সোর্স এবং আউটপুটের মধ্যে পুরোনো হওয়ার মতো কিছু নেই**
এর অসুবিধা হলো ক্যাশ-বাস্টিং (cache-busting) ম্যানুয়াল। `/styles.css` এবং `/app.js` রিকোয়েস্ট করা হয় `package.json`-এর ভার্সন থেকে নেওয়া একটি `?v=<stamp>` কোয়েরি দিয়ে, কারণ `sw.js` একই-অরিজিন (same-origin) অ্যাসেটগুলোকে **কোনো রিভ্যালিডেশন ছাড়াই ক্যাশ-ফার্স্ট (cache-first)** সার্ভ করে। দুটি গার্ড এই ব্যবস্থা ধরে রাখে: `check-asset-stamps.py` (প্রতিটি স্ট্যাম্প করা URL বর্তমান স্ট্যাম্প বহন করে) এবং `check-asset-freshness.py` (ভার্সন অপরিবর্তিত থাকার সময় কোনো স্ট্যাম্প করা ফাইল পরিবর্তিত হয়নি)। দ্বিতীয়টি রাখা হয়েছে কারণ প্রথমটি পাস করেছিল, অথচ অপরিবর্তিত URL-এর অধীনে `app.js` পরিবর্তিত হয়েছিল।
### CSS আর্কিটেকচার
- **কাস্টম প্রপার্টির তিনটি স্তর।** একটি র র‍্যাম্প (`--w-0`…`--w-900` হালকা নিউট্রালের জন্য warm neutrals, `--d-950`…`--d-50` dark-এর জন্য), একটি সিম্যান্টিক স্তর যা এর দিকে নির্দেশ করে, এবং কম্পোনেন্টগুলো যা কেবল সিম্যান্টিক স্তরকে রেফারেন্স করে।
- **কোনো প্রিপ্রসেসর নেই** (কোনো Sass, Less, বা PostCSS নয়)
- মিডিয়া কোয়েরি সহ **মোবাইল-ফার্স্ট** রেসপন্সিভ ডিজাইন
- **WCAG AA** কন্ট্রাস্ট, যা CI-তে উভয় থিমের প্রতিটি প্যানেল এবং প্রতিটি পেজের ওপর Playwright সুইপের মাধ্যমে গেট করা হয়
সিম্যান্টিক স্তর, যার বিপরীতে আপনার কোড লেখা উচিত:
```css
:root {
  --bg: var(--paper);          /* the page */
  --bg-section: var(--warm-white);
  --bg-card: var(--w-0);
  --text: var(--ink);
  --text-2: var(--ink-secondary);
  --text-3: var(--ink-tertiary);
  --accent: var(--green-700);
  --border: var(--w-300);
}
[data-theme="dark"] {
  --bg: var(--d-950);
  --bg-section: var(--d-900);
  --bg-card: var(--d-850);
  --text: var(--d-50);
  --accent: #4ADE80;
  --border: var(--d-700);
}
```
এগুলোর পাশাপাশি রয়েছে ইঙ্ক টোকেনগুলো — `--ink-red`, `--ink-blue`, `--ink-teal` এবং বাকিগুলো — যেগুলো রাখা হয়েছে কারণ সাদা ব্যাকগ্রাউন্ডে টেক্সট হিসেবে পড়া একটি স্যাচুরেটেড রঙ `#0e0e0c`-এ টেক্সট হিসেবে পড়ে না। JavaScript-এ লিটারেল হিসেবে লেখা বা `style=` অ্যাট্রিবিউটের কোনো রঙ জানতে পারে না যে এটি কোন থিমে পড়েছে, তাই একে একটি টোকেন দেওয়া হয় এবং CSS ফ্লিপিং করে।
### থিমিং
`<html>`-এ `data-theme="dark"`, যা `js/chrome.js` দ্বারা সেট করা হয় এবং `janvayu-theme`-এর অধীনে স্টোর করা হয়। প্রতিটি পেজের `<head>`-এ একটি ছোট ইনলাইন স্ক্রিপ্ট থাকে যা প্রথম পেইন্টের আগেই স্টোর করা ভ্যালু প্রয়োগ করে, যাতে একটি পেজ কখনোই প্রথমে হালকা রঙে পেইন্ট করে পরে ফ্লিপ না করে। কোনো `prefers-color-scheme` ব্লক যোগ করবেন না: আগে চারটি পেজে এটি ছিল, যার মানে হলো সেগুলো অপারেটিং সিস্টেম অনুসরণ করত এবং সাইটের নিজস্ব নিয়ন্ত্রণকে উপেক্ষা করত।
### JavaScript প্যাটার্নস
- **সর্বোচ্চ ES2022**: `eslint.config.mjs`-এ সেট করা `ecmaVersion`
- সব HTTP কলের জন্য **Fetch API** (কোনো axios নয়)
- `document.getElementById` / `querySelector` এর মাধ্যমে **DOM ম্যানিপুলেশন**
- **কোনো মডিউল বান্ডলার নেই** — সব JS `<script>` ট্যাগে থাকে
- লাইভ AQI ডেটার জন্য **10-মিনিট অটো-রিফ্রেশ**, যা `waqi-proxy` ফাংশনের মাধ্যমে ফেচ করা হয়

## Chart.js
**সংস্করণ:** পিন করা 4.x (4.5.1), SRI সহ jsDelivr থেকে লোড করা এবং লেজি-লোড করা
**যেসব কাজে ব্যবহৃত হয়:**
- মেট্রো বনাম রিজিওনাল AQI তুলনার বার চার্ট
- PM2.5 ট্রেন্ড লাইন
- স্বাস্থ্যগত প্রভাবের ডেটা ভিজ্যুয়ালাইজেশন
- সিজনাল বেসলাইন তুলনা
**কেন Chart.js:**
- ছোট সাইজ (~70 KB গাজিপড, ~60 KB ব্রটলি)
- বিল্ড স্টেপ ছাড়াই কাজ করে (CDN স্ক্রিপ্ট ট্যাগ)
- ক্যানভাস-ভিত্তিক রেন্ডারিং (মোবাইলে পারফরম্যান্ট)
- বিল্ট-ইন রেসপন্সিভ/অ্যাক্সেসিবিলিটি ফিচার

## Leaflet.js + OpenStreetMap
**সংস্করণ:** 1.9.4, SRI সহ unpkg থেকে লোড করা
**যেসব কাজে ব্যবহৃত হয়:**
- 160টি শহরের ইন্টারেক্টিভ ম্যাপ (157টি ভারতীয়, সাথে বেইজিং, লন্ডন এবং সিঙ্গাপুর) যেখানে AQI স্টেশন মার্কার রয়েছে
- AQI তীব্রতা অনুযায়ী কালার-কোডেড মার্কার (সবুজ/হলুদ/কমলা/লাল/বেগুনি)
- স্টেশন ডিটেইলস দেখতে ক্লিক করা
**কেন Leaflet + OSM:**
- ফ্রি এবং ওপেন সোর্স (কোনো Google Maps API কী-এর প্রয়োজন নেই)
- হালকা (~40 KB গাজিপড)
- OpenStreetMap ডেটা ফ্রি, তবে এর টাইল সার্ভারগুলো বেস্ট-এফোর্ট এবং পলিসি-সীমাবদ্ধ ([ব্যবহার নীতি](https://operations.osmfoundation.org/policies/tiles/)); ভারী ব্যবহারের জন্য কমার্শিয়াল বা সেলফ-হোস্টেড টাইল সোর্স প্রয়োজন। সাইটটিতে Carto বেসম্যাপ টাইলও ব্যবহৃত হয়

## মাল্টিলিঙ্গুয়াল সাপোর্ট
JanVayu একটি ক্লায়েন্ট-সাইড ল্যাঙ্গুয়েজ টগল-এর মাধ্যমে 5টি ভাষা সমর্থন করে:
| ভাষা | কোড |
|----------|------|
| ইংরেজি | `en` |
| হিন্দি | `hi` |
| তামিল | `ta` |
| মারাঠি | `mr` |
| বাংলা | `bn` |
**বাস্তবায়ন:** ল্যাঙ্গুয়েজ স্ট্রিংগুলো JS অবজেক্ট হিসেবে সংরক্ষিত থাকে এবং টগল করার সময় DOM এলিমেন্টগুলোতে অদলবদল করা হয়। কোনো i18n লাইব্রেরি নেই — শুধু একটি সাধারণ কি-ভ্যালু লুকআপ।
