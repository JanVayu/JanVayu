# টেক স্ট্যাক ওভারভিউ
জ্যানভায়ু ইচ্ছাকৃতভাবেই একটি ন্যূনতম স্ট্যাকের ওপর তৈরি — শূন্য ফ্রন্টএন্ড ফ্রেমওয়ার্ক, ৩টি npm ডিপেন্ডেন্সি এবং একটি সার্ভারলেস ব্যাকএন্ড। এই পৃষ্ঠায় ব্যবহৃত প্রতিটি প্রযুক্তি এবং কেন এটি বেছে নেওয়া হয়েছে তা তুলে ধরা হয়েছে।

## এই স্ট্যাক কেন?
### জিরো-ফ্রেমওয়ার্ক ফ্রন্টএন্ড
জ্যানভায়ুর দর্শকদের মধ্যে ভারতের বিভিন্ন প্রান্তের 2G কানেকশন এবং লো-এন্ড অ্যান্ড্রয়েড ডিভাইস ব্যবহারকারীরাও রয়েছেন। React বা Vue-এর মতো ফ্রেমওয়ার্ক ব্যবহার করলে একটি ফিচার লোড হওয়ার আগেই ফ্রেমওয়ার্ক রানটাইম ডাউনলোড করতে হতো। এর পরিবর্তে:
- অ্যাপটি হলো `index.html` এবং এর সাথে `styles.css`, `app.js`, `games.js` এবং ১৯টি লেজি-লোডেড প্যানেল ফ্র্যাগমেন্ট, যেখানে কোনো বান্ডলার নেই
- কোনো ট্রান্সপাইলেশন, বান্ডলিং বা ট্রি-শেকিংয়ের প্রয়োজন নেই
- ডিপ্লয় আর্টিফ্যাক্ট = রিপোটি নিজেই
- বেসিক HTML/JS দক্ষতা সম্পন্ন যেকোনো কন্ট্রিবিউটর অবদান রাখতে পারেন
### মাত্র ৩টি npm ডিপেন্ডেন্সি
```json
{
  "@netlify/blobs": "^11.0.2",
  "resend": "^6.14.0",
  "web-push": "^3.6.7"
}
```
এই তিনটিই শুধুমাত্র সার্ভার-সাইডে ব্যবহৃত হয় (Netlify Functions দ্বারা)। এআই ফিচারগুলো সরাসরি `fetch`-এর মাধ্যমে Groq REST API (OpenAI-কম্প্যাটিবল) ব্যবহার করে — কোনো SDK-এর প্রয়োজন নেই। ক্লায়েন্টের শূন্য npm ডিপেন্ডেন্সি রয়েছে — Chart.js এবং Leaflet.js CDN থেকে লোড হয়।
### সার্ভারের বদলে সার্ভারলেস
###
Netlify Functions একটি স্থায়ী সার্ভারের প্রয়োজনীয়তা দূর করে। সুবিধাগুলো হলো:
- শূন্য অপারেশনাল বোঝা (কোনো সার্ভার প্যাচিং নেই, কোনো স্কেলিং নেই)
- স্বয়ংক্রিয় HTTPS, CDN, এবং এজ ডিপ্লয়মেন্ট
