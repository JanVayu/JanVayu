# এআই লেয়ার — Groq-এর মাধ্যমে OpenAI gpt-oss-120B

JanVayu-এর এআই ফিচারগুলো **OpenAI gpt-oss-120B** দ্বারা চালিত, যা Netlify Functions থেকে **Groq API** (OpenAI-কম্প্যাটিবল REST API)-এর মাধ্যমে পরিবেশিত একটি ওপেন-সোর্স LLM।

---

## Groq-এর মাধ্যমে OpenAI gpt-oss-120B কেন?

| মানদণ্ড | পছন্দ |
|-----------|--------|
| **খরচ** | Groq Console; প্ল্যান এবং বিলিং অ্যাকাউন্টে সেট করা থাকে |
| **গতি** | Groq-এর হোস্ট করা ইনফারেন্স সার্ভিস থেকে পরিবেশিত (এখানে ল্যাটেন্সি মাপা হয়নি) |
| **রেট লিমিট** | নিচের টেবিলে বেস লিমিট দেওয়া আছে |
| **বহুভাষিক** | হিন্দির ভালো সাপোর্ট (JanVayu-এর দর্শকদের জন্য অত্যন্ত গুরুত্বপূর্ণ) |
| **মান** | ডেটা-ভিত্তিক বাস্তবসম্মত উত্তরের জন্য যথেষ্ট (ক্রিয়েটিভ লেখার জন্য নয়) |
| **ওপেন সোর্স** | OpenAI gpt-oss-120B একটি ওপেন মডেল (OpenAI), যা স্বচ্ছতা এবং রিপ্রোডিউসিবিলিটি নিশ্চিত করে |

### মেনে নেওয়া ট্রেড-অফ

- **GPT-4 / Claude নয়** — JanVayu খরচ এবং গতির জন্য Groq দ্বারা পরিবেশিত একটি ওপেন-ওয়েট মডেল ব্যবহার করে।
- **আউটপুট টোকেন ক্যাপ** — ফাংশন অনুযায়ী আউটপুট 512 থেকে 1,024 `max_tokens`-এ সীমাবদ্ধ (air-query 700, accountability-brief 1,024, health-advisory 768, anomaly-check 512)। রিজনিং মডেলগুলো ক্যাপের একটি অংশ রিজনিংয়ের জন্য ব্যবহার করে, তাই ক্যাপটি শুধুমাত্র দৃশ্যমান টেক্সট নয়, বরং পুরো রেসপন্সকে সীমাবদ্ধ করে।
- **কোনো ফাইন-টিউনিং নেই** — শুধুমাত্র প্রম্পট ইঞ্জিনিয়ারিং। প্রতিটি স্কিল হলো একটি সিস্টেম প্রম্পট, কোনো ফাইন-টিউনড মডেল নয়।

## ইন্টিগ্রেশন আর্কিটেকচার

```
Browser (client)
    │
    │ POST /.netlify/functions/air-query
    │ POST /.netlify/functions/health-advisory
    │ POST /.netlify/functions/accountability-brief
    │ GET  /.netlify/functions/anomaly-check
    │
    ▼
Netlify Function (server-side)
    │
    │ 1. Parse user input
    │ 2. Fetch live AQI data from WAQI
    │ 3. Construct prompt with real data
    │ 4. Call Groq API
    │ 5. Return response (or fallback to raw data)
    │
    ▼
Groq API
    │
    │ openai/gpt-oss-120b model
    │ max_tokens: 512-1,024 (per function)
    │
    ▼
Structured response → Browser
```

**মূল নিরাপত্তা নীতি:** `GROQ_API_KEY` কখনোই ক্লায়েন্টের কাছে যায় না। সমস্ত এআই কল Netlify Functions-এর মাধ্যমে সার্ভার-সাইডে করা হয়।

## চারটি এআই ফিচার

### 1. Ask JanVayu (`air-query.mjs`)
- **ইনপুট:** শহরের নাম + মুক্ত-টেক্সট প্রশ্ন
- **প্রদত্ত কনটেক্সট:** WAQI থেকে লাইভ PM2.5 এবং AQI
- **আউটপুট:** আসল রিডিংয়ের ওপর ভিত্তি করে
- **ভাষা:** প্রশ্নের ভাষাতেই উত্তর দেওয়া হয়; Ask JanVayu UI ১০টি ভাষায় পাওয়া যায়
- **ফলব্যাক:** Groq-এ রেট-লিমিট থাকলে এটি র-AQI ডেটা রিটার্ন করে
### 2. হেলথ অ্যাডভাইজরি (`health-advisory.mjs`)
- **ইনপুট:** শহর + বয়স + স্বাস্থ্যগত অবস্থা + বাইরে কাটানো সময়
- **কনটেক্সট ইনজেক্ট করা:** ওই শহরের লাইভ AQI
- **আউটপুট:** কালার-কোডেড ঝুঁকির মাত্রা + সুনির্দিষ্ট সুপারিশ
- **ফলব্যাক:** সাধারণ WHO-নির্দেশনাভিত্তিক পরামর্শ

### 3. অ্যাকাউন্টেবিলিটি ব্রিফ (`accountability-brief.mjs`)
- **ইনপুট:** শহরের নাম
- **কনটেক্সট ইনজেক্ট করা:** লাইভ AQI + মৌসুমী বেসলাইন + GRAP স্টেজ
- **আউটপুট:** স্ট্রাকচারড ব্রিফ (বর্তমান অবস্থা, NCAP লক্ষ্যমাত্রা, ৫টি অ্যাকাউন্টেবিলিটি প্রশ্ন)
- **সর্বোচ্চ টোকেন:** 1,024
- **ফলব্যাক:** র-ডেটা টেবিল রিটার্ন করে

### 4. অ্যানোমালি ডিটেকশন (`anomaly-check.mjs`)
- **ইনপুট:** কিছু নেই (স্বয়ংক্রিয়ভাবে ৫টি মেট্রো মনিটর করে)
- **থ্রেশহোল্ড:** 2× মৌসুমী বেসলাইন = অ্যানোমালি
- **আউটপুট:** প্রতি অ্যানোম্যালির জন্য একটি বাক্যের AI ব্যাখ্যা
- **ক্যাশ:** 10-মিনিটের HTTP `Cache-Control` হেডার (Netlify Blobs নয়)
- **ফলব্যাক:** AI ব্যাখ্যা ছাড়াই অ্যানোমালি ফ্ল্যাগ রিটার্ন করে

## রেট লিমিটিং স্ট্র্যাটেজি

Groq-এর প্রকাশিত বেস লিমিট (পরিবর্তনশীল; অ্যাকাউন্টের নিজস্ব প্ল্যানের লিমিটের জন্য [console.groq.com](https://console.groq.com) চেক করুন):

| লিমিট | মান (openai/gpt-oss-120b, Groq-এর প্রকাশিত বেস লিমিট, চেক করা হয়েছে 25 Oct 2026) |
|-------|----------------------------------------------------------------------------------|
| প্রতি মিনিটে রিকোয়েস্ট | 30 |
| প্রতিদিন রিকোয়েস্ট | 1,000 |
| প্রতি মিনিটে টোকেন | 8,000 |
| প্রতিদিন টোকেন | 200,000 |

সূত্র: [Groq rate limits](https://console.groq.com/docs/rate-limits)। দীর্ঘ air-query সিস্টেম প্রম্পটের কারণে প্রতি মিনিটে 8,000 টোকেনের লিমিটটি বেশ টাইট, তাই 429 রেসপন্সগুলো মনিটর করা প্রয়োজন।

JanVayu এই বাজেটটি ফিচারগুলোর মধ্যে ভাগ করে দেয় (পরিকল্পনার অনুমান, Netlify লগ থেকে মাপা নয়):
- অ্যানোমালি চেক: ~144/দিন (ক্যাশ করা, পেজ লোড হওয়ার সময় ট্রিগার হয়)
- এয়ার কোয়েরি: ~50/দিন (ব্যবহারকারী-সূচিত)
- হেলথ অ্যাডভাইজরি: ~30/দিন (ব্যবহারকারী-সূচিত)
- অ্যাকাউন্টেবিলিটি ব্রিফ: ~20/দিন (ব্যবহারকারী-সূচিত)

লিমিট শেষ হয়ে গেলে, প্রতিটি ফাংশন সুন্দরভাবে র-ডেটায় ফলব্যাক করে। ব্যবহারকারী সবসময় একটি রেসপন্স পান — শুধু AI অ্যানালাইসিস ছাড়া।

## প্রম্পট ইঞ্জিনিয়ারিং

সব প্রম্পট এই নীতিগুলো অনুসরণ করে:

1. **সবসময় বাস্তব ডেটা ইনজেক্ট করা** — মডেল কখনোই মেমোরি থেকে জেনারেট করে না
2. **সঠিক আউটপুট ফরম্যাট নির্দিষ্ট করা** — বিশেষ করে স্ট্রাকচারড ব্রিফের জন্য
3. **শব্দের সংখ্যা সীমিত করা** — প্রতিটি প্রম্পটে সুস্পষ্ট লিমিট থাকে
4. **ফেইলিওর মোডের নাম দেওয়া** — "সাধারণ পরামর্শ দেবেন না", "অস্পষ্টতা এড়িয়ে চলুন"
5. **বহুভাষিক নির্দেশ** — "প্রশ্নের ভাষায় উত্তর দিন"
6. **গ্রেসফুল ডিগ্রেডেশন** — প্রতিটি ফাংশনের একটি নন-AI ফলব্যাক পাথ থাকে
সম্পূর্ণ প্রম্পট ডকুমেন্টেশনের জন্য [Skills & AI Prompts](../skills/README.md) বিভাগটি দেখুন।
