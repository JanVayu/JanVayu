# এআই লেয়ার — Groq-এর মাধ্যমে OpenAI gpt-oss-120B

JanVayu-এর এআই ফিচারগুলো **OpenAI gpt-oss-120B** দ্বারা চালিত, যা Netlify Functions থেকে **Groq API** (OpenAI-কম্প্যাটিবল REST API)-এর মাধ্যমে সার্ভ করা হয়।

---

## Groq-এর মাধ্যমে OpenAI gpt-oss-120B কেন?

| মানদণ্ড | পছন্দ |
|-----------|--------|
| **খরচ** | ফ্রি টিয়ার (Groq Console) — কোনো বিলিংয়ের প্রয়োজন নেই |
| **গতি** | Groq-এর হোস্ট করা ইনফারেন্স সার্ভিস থেকে সার্ভ করা হয় (ল্যাটেন্সি এখানে মাপা হয়নি) |
| **রেট লিমিট** | উদার ফ্রি টিয়ার — জনস্বার্থের প্ল্যাটফর্মের জন্য যথেষ্ট |
| **বহুভাষিক** | শক্তিশালী হিন্দি সাপোর্ট (JanVayu-এর দর্শকদের জন্য অত্যন্ত গুরুত্বপূর্ণ) |
| **মান** | তথ্যভিত্তিক উত্তরের জন্য পর্যাপ্ত (সৃজনশীল লেখার জন্য নয়) |
| **ওপেন সোর্স** | OpenAI gpt-oss-120B একটি ওপেন মডেল (OpenAI), যা স্বচ্ছতা এবং পুনরাবৃত্তিযোগ্যতা নিশ্চিত করে |

### গৃহীত ট্রেড-অফ

- **GPT-4 / Claude নয়** — Groq-এর ফ্রি টিয়ারের সাথে একটি ওপেন-সোর্স মডেল হলো মূল পার্থক্য। JanVayu সম্পূর্ণ শূন্য বাজেটে চলে।
- **আউটপুট টোকেন ক্যাপ** — প্রতি ফাংশনে আউটপুট 512 থেকে 1,024 `max_tokens`-এ ক্যাপ করা থাকে (air-query 700, accountability-brief 1,024, health-advisory 768, anomaly-check 512)। রিজনিং মডেলগুলো এই ক্যাপের একটি অংশ রিজনিংয়ের পেছনে ব্যয় করে, তাই ক্যাপটি পুরো রেসপন্সকে সীমাবদ্ধ করে, শুধু দৃশ্যমান টেক্সটকে নয়।
- **কোনো ফাইন-টিউনিং নেই** — শুধুমাত্র প্রম্পট ইঞ্জিনিয়ারিং। প্রতিটি স্কিল হলো একটি সিস্টেম প্রম্পট, কোনো ফাইন-টিউনড মডেল নয়।

## ইন্টিগ্রেশন আর্কিটেকচার

```
ব্রাউজার (ক্লায়েন্ট)
    │
    │ POST /.netlify/functions/air-query
    │ POST /.netlify/functions/health-advisory
    │ POST /.netlify/functions/accountability-brief
    │ GET  /.netlify/functions/anomaly-check
    │
    ▼
Netlify Function (সার্ভার-সাইড)
    │
    │ 1. ইউজারের ইনপুট পার্স করা
    │ 2. WAQI থেকে লাইভ AQI ডেটা ফেচ করা
    │ 3. আসল ডেটা দিয়ে প্রম্পট তৈরি করা
    │ 4. Groq API কল করা
    │ 5. রেসপন্স রিটার্ন করা (অথবা র-ডেটাতে ফলব্যাক করা)
    │
    ▼
Groq API
    │
    │ openai/gpt-oss-120b মডেল
    │ max_tokens: 512-1,024 (প্রতি ফাংশনে)
    │
    ▼
স্ট্রাকচার্ড রেসপন্স → ব্রাউজার
```

**মূল নিরাপত্তা নীতি:** `GROQ_API_KEY` কখনোই ক্লায়েন্টের কাছে যায় না। সমস্ত এআই কল Netlify Functions-এর মাধ্যমে সার্ভার-সাইডে করা হয়।

## চারটি এআই ফিচার

### ১. Ask JanVayu (`air-query.mjs`)
- **ইনপুট:** শহরের নাম + ফ্রি-টেক্সট প্রশ্ন
- **ইনজেক্ট করা কনটেক্সট:** WAQI থেকে লাইভ PM2.5 এবং AQI
- **আউটপুট:** আসল রিডিংয়ের ওপর ভিত্তি করে
- **ভাষা:** প্রশ্নের ভাষায় উত্তর দেওয়া হয়; Ask JanVayu UI ১০টি ভাষায় পাওয়া যায়
- **ফলব্যাক:** Groq রেট-লিমিটেড হলে র-AQI ডেটা রিটার্ন করে
### 2. হেলথ অ্যাডভাইজরি (`health-advisory.mjs`)
- **ইনপুট:** শহর + বয়স + স্বাস্থ্যগত অবস্থা + বাইরে কাটানো সময়
- **কনটেক্সট ইনজেক্ট করা:** ওই শহরের লাইভ AQI
- **আউটপুট:** কালার-কোডেড ঝুঁকির মাত্রা + বাস্তবসম্মত সুপারিশ
- **ফলব্যাক:** জেনেরিক WHO-নির্দেশিকাভিত্তিক পরামর্শ

### 3. অ্যাকাউন্টেবিলিটি ব্রিফ (`accountability-brief.mjs`)
- **ইনপুট:** শহরের নাম
- **কনটেক্সট ইনজেক্ট করা:** লাইভ AQI + সিজনাল বেসলাইন + GRAP পর্যায়
- **আউটপুট:** স্ট্রাকচারড ব্রিফ (বর্তমান অবস্থা, NCAP লক্ষ্য, ৫টি অ্যাকাউন্টেবিলিটি প্রশ্ন)
- **সর্বোচ্চ টোকেন:** 1,024
- **ফলব্যাক:** র-ডেটা টেবিল রিটার্ন করে

### 4. অ্যানোমালি ডিটেকশন (`anomaly-check.mjs`)
- **ইনপুট:** নেই (স্বয়ংক্রিয়ভাবে ৫টি মেট্রো মনিটর করে)
- **থ্রেশহোল্ড:** 2× সিজনাল বেসলাইন = অ্যানোমালি
- **আউটপুট:** প্রতি অ্যানোমালি-র জন্য একটি বাক্যের এআই ব্যাখ্যা
- **ক্যাশ:** 10-মিনিটের HTTP `Cache-Control` হেডার (Netlify Blobs নয়)
- **ফলব্যাক:** এআই ব্যাখ্যা ছাড়াই শুধু অ্যানোমালি ফ্ল্যাগ রিটার্ন করে

## রেট লিমিটিং স্ট্র্যাটেজি

ফ্রি-টিয়ার Groq লিমিট (পরিবর্তন সাপেক্ষ — বর্তমান মান জানতে [console.groq.com](https://console.groq.com) দেখুন):

| লিমিট | মান (openai/gpt-oss-120b, Groq ফ্রি প্ল্যান, চেক করা হয়েছে 2 Oct 2026) |
|-------|-------------------------------------------------------------------|
| প্রতি মিনিটে রিকোয়েস্ট | 30 |
| প্রতিদিনের রিকোয়েস্ট | 1,000 |
| প্রতি মিনিটে টোকেন | 8,000 |
| প্রতিদিনের টোকেন | 200,000 |

উৎস: [Groq রেট লিমিট](https://console.groq.com/docs/rate-limits)। লম্বা air-query সিস্টেম প্রম্পটের কারণে প্রতি মিনিটে 8,000 টোকেনের লিমিটটি বেশ টাইট, তাই 429 রেসপন্সগুলো মনিটর করা জরুরি।

JanVayu এই বাজেট বিভিন্ন ফিচারের মধ্যে ভাগ করে দেয় (এটি একটি আনুমানিক হিসাব, Netlify লগ থেকে মাপা নয়):
- অ্যানোমালি চেক: ~144/দিন (ক্যাশ করা, পেজ লোড হওয়ার সময় ফায়ার হয়)
- এয়ার কোয়েরি: ~50/দিন (ব্যবহারকারী শুরু করেন)
- হেলথ অ্যাডভাইজরি: ~30/দিন (ব্যবহারকারী শুরু করেন)
- অ্যাকাউন্টেবিলিটি ব্রিফ: ~20/দিন (ব্যবহারকারী শুরু করেন)

লিমিট শেষ হয়ে গেলে, প্রতিটি ফাংশন সুন্দরভাবে র-ডেটাতে ফিরে যায়। ব্যবহারকারী সবসময় একটি রেসপন্স পান — শুধু এআই অ্যানালাইসিস ছাড়া।

## প্রম্পট ইঞ্জিনিয়ারিং

সব প্রম্পট এই নীতিগুলো মেনে চলে:

1. **সবসময় আসল ডেটা ইনজেক্ট করতে হবে** — মডেল কখনোই মেমরি থেকে তৈরি করে না
2. **আউটপুটের সঠিক ফরম্যাট নির্দিষ্ট করতে হবে** — বিশেষ করে স্ট্রাকচারড ব্রিফের ক্ষেত্রে
3. **শব্দের সংখ্যা সীমিত রাখতে হবে** — প্রতিটি প্রম্পটে স্পষ্টভাবে লিমিট দেওয়া থাকে
4. **ফেইলিওর মোডগুলোর নাম দিতে হবে** — "জেনেরিক পরামর্শ দেবেন না", "এড়িয়ে যাবেন না"
5. **বহুভাষিক নির্দেশনা** — "প্রশ্নের ভাষায় উত্তর দিন"
6. **গ্রেসফুল ডিগ্রেডেশন** — প্রতিটি ফাংশনেরই একটি নন-এআই ফলব্যাক পথ থাকে
