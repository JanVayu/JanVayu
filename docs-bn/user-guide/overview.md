# প্ল্যাটফর্মের ওভারভিউ

JanVayu হলো একটি ওয়েব পেজ, যেখানে ৬০টি ডেস্টিনেশন রয়েছে। আপনি কী করতে চান তার ওপর ভিত্তি করে এগুলোকে ৮টি গ্রুপে সাজানো হয়েছে: My Air, Maps & Places, Health & Trends, Accountability, Take Action, Learn, Resources এবং About। এগুলো একসাথে লাইভ ডেটা, স্বাস্থ্য, নীতি এবং আইনি জবাবদিহিতা কভার করে।
