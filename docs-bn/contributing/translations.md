# অনুবাদ

ভারতের ভাষাগত বৈচিত্র্যের মধ্যে সবার কাছে পৌঁছাতে JanVayu প্রতিশ্রুতিবদ্ধ। প্ল্যাটফর্মটি বর্তমানে ইংরেজি, হিন্দি, তামিল, মারাঠি এবং বাংলা ভাষা সমর্থন করে। ইন্টারফেসটি পাঁচটি ভাষাতেই পুরোপুরি অনুবাদ করা হয়েছে; আর ডকুমেন্টেশনের একটি অংশ অনুবাদ করা হয়েছে (প্রতিটি অনুবাদিত ট্রি-তে ৬৫টির মধ্যে ৪৭টি পৃষ্ঠা)।

## অনুবাদে কীভাবে অবদান রাখবেন

### নতুন ভাষা যোগ করা

১. `Translation: Add [Language Name] support` শিরোনামে একটি Issue খুলুন।
২. এর মধ্যে যা যা উল্লেখ করুন:
   - আপনার নাম (বা ইউজারনেম) এবং ভাষার দক্ষতা
   - আপনি দীর্ঘমেয়াদে অনুবাদগুলো (কন্টেন্ট আপডেটের সাথে তাল মিলিয়ে) রক্ষণাবেক্ষণ করার দায়িত্ব নিতে পারবেন কি না
৩. একজন মেইনটেইনার একটি ব্রাঞ্চ তৈরি করে অনুবাদ করার জন্য সোর্স স্ট্রিংগুলো দিয়ে দেবেন।

### বিদ্যমান অনুবাদের উন্নতি করা

আপনি যদি কোনো ভুল বা বেমানান অনুবাদ খেয়াল করেন:

১. `Translation: Fix [Language Name] — [specific section/string]` লিখে একটি Issue খুলুন।
২. যা যা দিন: বর্তমান টেক্সট, সংশোধিত টেক্সট এবং একটি সংক্ষিপ্ত ব্যাখ্যা।

## অনুবাদের মূলনীতি

- **অক্ষরে অক্ষরে অনুবাদের চেয়ে নির্ভুলতা** — শব্দের পর শব্দ না অনুবাদ করে স্বাভাবিক ভাষায় সঠিক অর্থ তুলে ধরুন
- **প্রযুক্তিগত শব্দগুলো অপরিবর্তিত রাখুন** — PM2.5, AQI, NCAP, GEMM-এর মতো শব্দগুলো যেমন আছে তেমনই থাকা উচিত (এগুলো আন্তর্জাতিকভাবে প্রমিত)
- **সহজ ভাষা ব্যবহার করুন** — অনুবাদগুলো ইংরেজি সংস্করণের মতোই সাধারণ পাঠকদের জন্য বোধগম্য হওয়া উচিত: শিক্ষিত সাধারণ মানুষ, কোনো বিশেষজ্ঞ নয়
- **ধারাবাহিকতা** — একই ধারণার জন্য পুরোটা জুড়ে একই অনুবাদ ব্যবহার করুন (যেমন, "air quality index" সবসময় একইভাবে অনুবাদ করবেন)
- **নিরপেক্ষ সুর** — JanVayu অরাজনৈতিক; অনুবাদের ক্ষেত্রেও এই নিরপেক্ষতা বজায় রাখতে হবে

## সংবেদনশীল পরিভাষা

| ইংরেজি | নোটস |
|---------|-------|
| Non-Attainment City | এমন একটি শহর হিসেবে অনুবাদ করুন যা জাতীয় বায়ুদূষণ মানদণ্ড "অর্জন করতে পারেনি" (পূরণ করতে ব্যর্থ হয়েছে) |
| Graded Response Action Plan (GRAP) | প্রথমে পুরো নাম ব্যবহার করে পরে GRAP সংক্ষিপ্ত রূপটি ব্যবহার করুন |
| PM2.5 | সব ভাষায় PM2.5 হিসেবেই রাখুন |
| NCAP | NCAP হিসেবেই রাখুন; প্রথমে National Clean Air Programme হিসেবে বানান করে লিখুন |
| CPCB | CPCB হিসেবেই রাখুন; প্রথমে Central Pollution Control Board হিসেবে বানান করে লিখুন |

## লাইভ ট্রান্সলেটেড ডকুমেন্টেশন
রিপোতে প্রতিটি ভাষা একটি `docs-{lang}/` ডিরেক্টরিতে থাকে এবং এটি `/docs/`-এ একটি একক Docsify শেল দ্বারা সার্ভ করা হয়, যা হ্যাশ রুটের মাধ্যমে ভাষা-নির্দিষ্ট কন্টেন্ট রুট করে।

| ভাষা | লাইভ URL | সোর্স ডিরেক্টরি |
|----------|----------|------------------|
| English | [/docs/](/docs/) | `docs/` |
| Hindi | [/docs/#/hi/](/docs/#/hi/) | `docs-hi/` |
| Bengali | [/docs/#/bn/](/docs/#/bn/) | `docs-bn/` |
| Marathi | [/docs/#/mr/](/docs/#/mr/) | `docs-mr/` |
| Tamil | [/docs/#/ta/](/docs/#/ta/) | `docs-ta/` |

`.github/workflows/translations.yml`-এর `auto-translate` জব দ্বারা অনুবাদিত ডকুমেন্টগুলো রিফ্রেশ করা হয় (এর জন্য একটি Sarvam API key প্রয়োজন) এবং এগুলো ইংলিশ ডকুমেন্টগুলোর চেয়ে একটু পিছিয়ে থাকতে পারে।

## CI: Translation Coverage

`main`-এ ডকুমেন্ট স্পর্শ করে এমন প্রতিটি পুশের সময় একটি GitHub Actions ওয়ার্কফ্লো (`.github/workflows/translations.yml`) রান করে। এটি চেক করে:

- **File coverage** — সব ইংলিশ ডকুমেন্ট কি প্রতিটি ভাষায় মিরর করা আছে?
- **SUMMARY.md parity** — সব ভাষার কি পেজ কাউন্ট সমান?
- **Stale detection** — যখন কোনো ইংলিশ ডকুমেন্ট পরিবর্তন করা হয়, তখন কোন অনুবাদগুলো আপডেট করা হয়নি?

ফলাফলগুলো প্রতিটি রানের জন্য GitHub Actions-এর **Job Summary** ট্যাবে দেখা যায়।

## Directory Structure

প্রতিটি ট্রান্সলেশন ডিরেক্টরি ইংলিশ `docs/` স্ট্রাকচারকে মিরর করে, শুধু `api/` এবং `wiki/` ডিরেক্টরিগুলো ইংলিশ-অনলি:

```
docs-{lang}/
├── README.md
├── SUMMARY.md
├── about/
├── claude-code/
├── contributing/
├── data-sources/
├── skills/
├── tech-stack/
├── technical/
└── user-guide/
```

নতুন কোনো ইংলিশ ডকুমেন্ট যোগ করার সময়, সব ট্রান্সলেশন ডিরেক্টরিতে সংশ্লিষ্ট ফাইলটি তৈরি করুন (এমনকি শুরুতে এটি ইংলিশে থাকলেও — পরে এটি অনুবাদ করা যেতে পারে)।
