# কীভাবে অবদান রাখবেন

ভারতের বায়ু দূষণ সংকটকে বিস্তারিতভাবে তুলে ধরতে JanVayu সম্প্রদায়ের অংশগ্রহণের ওপর নির্ভর করে। গবেষক, সাংবাদিক, ডেভেলপার এবং সাধারণ নাগরিক — সবার অবদানই এখানে সাদরে গৃহীত।

---

## অবদানের ধরন

### গবেষক
- বায়ু দূষণের স্বাস্থ্যগত প্রভাব সম্পর্কিত ডেটাসেট ও গবেষণাপত্র শেয়ার করা
- বিদ্যমান কনটেন্ট যাচাই ও ফ্যাক্ট-চেক করতে সাহায্য করা
- বিশ্লেষণ এবং ভিজ্যুয়ালাইজেশন তৈরি করা
- গবেষণার সারসংক্ষেপ ভারতীয় ভাষায় অনুবাদ করা

### সাংবাদিক
- যাচাইকৃত অনুসন্ধানী প্রতিবেদন শেয়ার করা
- স্থানীয় বায়ু দূষণের ঘটনাগুলো তুলে ধরা
- গুরুত্বপূর্ণ মিডিয়া কভারেজ আর্কাইভ করা
- জবাবদিহিতা ট্র্যাকার-এ অবদান রাখা

### ডেভেলপার
- বাগ রিপোর্ট করা এবং উন্নতির পরামর্শ দেওয়া
- কোড ফিক্স এবং নতুন ফিচার যোগ করা
- ডেটা ভিজ্যুয়ালাইজেশন টুল তৈরি করা
- অ্যাক্সেসিবিলিটি এবং পারফরম্যান্স উন্নত করা

### সাধারণ নাগরিক
- সরাসরি অভিজ্ঞতা শেয়ার করা (চাইলে নাম গোপন রাখা যাবে)
- স্থানীয় বায়ু দূষণের পরিস্থিতি তুলে ধরা
- আঞ্চলিক ভাষায় কনটেন্ট অনুবাদ করতে সাহায্য করা
- সচেতনতা বাড়ানো

### ডিজাইনার
- ভিজ্যুয়াল অ্যাক্সেসিবিলিটি উন্নত করা
- ইনফোগ্রাফিক্স এবং শিক্ষামূলক উপকরণ তৈরি করা
- UI/UX উন্নত করতে সাহায্য করা

## কোড অবদানের জন্য

```bash
# 1. রিপোজিটরিটি ফর্ক করুন
# 2. আপনার ফর্ক ক্লোন করুন
git clone https://github.com/YOUR_USERNAME/JanVayu.git
cd JanVayu

# 3. একটি ব্রাঞ্চ তৈরি করুন
git checkout -b feature/your-feature-name

# 4. পরিবর্তনগুলো করুন এবং লোকালি টেস্ট করুন
netlify dev

# 5. একটি স্পষ্ট মেসেজ দিয়ে কমিট করুন
git commit -m "Add: PM10 toggle on city cards"

# 6. পুশ করুন এবং একটি পুল রিকোয়েস্ট খুলুন
git push origin feature/your-feature-name
```

[github.com/JanVayu/JanVayu](https://github.com/JanVayu/JanVayu)-এ `main` ব্রাঞ্চের বিপরীতে আপনার PR খুলুন।

## কনটেন্ট অবদানের জন্য

১. আপনি কী অবদান রাখতে চান তা বর্ণনা করে GitHub-এ একটি **Issue খুলুন**
২. **সোর্স দিন** — সব কনটেন্ট একটি URL বা ডকুমেন্টের মাধ্যমে যাচাইযোগ্য হতে হবে
৩. **প্রেক্ষাপট দিন** — JanVayu আর্কাইভে এটি কেন প্রাসঙ্গিক তা ব্যাখ্যা করুন
৪. অনুমোদন পেলে, একজন মেইনটেইনার এটি যোগ করতে আপনাকে গাইড করবেন

## ডেটা অবদানের জন্য

- ডেটা যেন একটি বৈধ ও যাচাইযোগ্য সোর্স থেকে আসে তা নিশ্চিত করুন
- স্পষ্ট অ্যাট্রিবিউশন এবং লাইসেন্সিং তথ্য দিন
- প্রযোজ্য হলে মেথডলজি ডকুমেন্টেশন যুক্ত করুন
- সম্ভব হলে RTI-এর উত্তর বা মূল ডকুমেন্ট সংযুক্ত করুন
