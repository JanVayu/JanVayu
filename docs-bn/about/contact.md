## মিডিয়া এবং গবেষণার অনুসন্ধান

সাংবাদিক, গবেষক এবং পলিসি প্রফেশনালরা JanVayu-এর ডেটা এবং বিশ্লেষণ ব্যবহার করতে পারেন। অনুগ্রহ করে:

১. নির্দিষ্ট পরিসংখ্যানের জন্য JanVayu-এর বদলে মূল উৎস (CPCB, Lancet ইত্যাদি) উল্লেখ করুন
২. একত্রিত ডেটাটি যে প্ল্যাটফর্মে পেয়েছেন, সেখানে JanVayu-এর নাম উল্লেখ করুন
৩. কাস্টম বিশ্লেষণ বা ডেটা অনুরোধের জন্য, একটি GitHub Issue খুলুন অথবা [contribute@janvayu.in](mailto:contribute@janvayu.in)-এ ইমেইল করুন
