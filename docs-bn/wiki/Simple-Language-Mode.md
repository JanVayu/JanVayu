# সিম্পল ল্যাঙ্গুয়েজ মোড
জ্যানবায়ুতে জটিল প্রযুক্তিগত বিষয়বস্তু রয়েছে (PM2.5 ঘনত্ব, GEMM মৃত্যুহার মডেল, নীতির সংক্ষিপ্ত রূপ)। সিম্পল ল্যাঙ্গুয়েজ মোড এই বিষয়বস্তুকে সহজ, পরিভাষা-মুক্ত ভাষায় পুনরায় লেখে যা যে কেউ সহজেই বুঝতে পারে।
---
## এটি কীভাবে কাজ করে
1. **টগল**: পৃষ্ঠার উপরের বারে সিম্পল-এ ক্লিক করুন (ফোনে মেনুর ভেতরে), অথবা গ্লোসারি প্যানেলের টগল ব্যবহার করুন
2. **সোয়াপ** — `data-simple` অ্যাট্রিবিউট থাকা সমস্ত উপাদানের বিষয়বস্তু সাধারণ ভাষার সংস্করণ দিয়ে প্রতিস্থাপিত হয়
3. **পারসিস্ট** — স্টেট `sessionStorage`-এ সংরক্ষিত থাকে, পৃষ্ঠা রিলোড করার সময় পুনরুদ্ধার করা হয়
4. **ভিজ্যুয়াল ইন্ডিকেটর** — সরলীকৃত পাঠ্যের পাশে একটি সবুজ "Simple language" ব্যাজ দেখা যায়
5. **রিভার্সিবল** — প্রযুক্তিগত ভাষা পুনরুদ্ধার করতে আবার ক্লিক করুন
---
## প্রযুক্তিগত প্রয়োগ
### HTML অ্যাট্রিবিউট
একটি `data-simple` অ্যাট্রিবিউট যোগ করে যেকোনো উপাদানকে সিম্পল-মোড-সচেতন করা যেতে পারে:
```html
<p data-simple="নোংরা বাতাস প্রতি বছর ভারতের অনেক টাকা খরচ করে।">
    ভারতে বাইরের বায়ুদূষণ থেকে অকাল মৃত্যুর আর্থিক মূল্য 2022 সালে ছিল $339.4 বিলিয়ন (GDP-এর 9.5%)।
</p>
```
### JavaScript
```javascript
let simpleMode = sessionStorage.getItem('janvayu-simple-mode') === 'true';
function toggleSimpleMode() {
    simpleMode = !simpleMode;
    sessionStorage.setItem('janvayu-simple-mode', simpleMode);
    applySimpleMode();
}
function applySimpleMode() {
    document.body.classList.toggle('simple-language', simpleMode);
    document.querySelectorAll('[data-simple]').forEach(el => {
        if (simpleMode) {
            if (!el.dataset.technical) el.dataset.technical = el.innerHTML;
            el.innerHTML = el.dataset.simple;
        } else {
            if (el.dataset.technical) el.innerHTML = el.dataset.technical;
        }
    });
}
```

## কভারেজ
- প্যানেল পরিচিতি অনুচ্ছেদ
- 20টি গ্লোসারি সংজ্ঞা (প্রযুক্তিগত / সহজ)
- মূল অন্তর্দৃষ্টি বক্স, অ্যালার্ট বক্স, পুল-কোয়েট
- বাজেট, নীতি, স্বাস্থ্য, শিশু, ইনডোর, আইনি, অ্যাকশন প্যানেল
### সহজ পাঠ্য যোগ করা
1. `index.html`-এ উপাদানটি খুঁজুন
2. `data-simple="আপনার সাধারণ ভাষার সংস্করণ এখানে"` যোগ করুন
3. বিশেষ অক্ষরগুলোর জন্য HTML এনটিটি ব্যবহার করুন: `&lt;strong&gt;`, `&amp;`
4. 12 বছরের শিশুর জন্য লিখুন: ছোট বাক্য, কোনো সংক্ষিপ্ত রূপ নয়, বাস্তব উদাহরণ
5. একই অর্থ বজায় রাখুন — ভাষা সহজ করুন, বিষয়বস্তু নয়
