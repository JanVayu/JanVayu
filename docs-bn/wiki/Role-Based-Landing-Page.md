# ভূমিকা-ভিত্তিক ল্যান্ডিং পেজ
জানবায়ু বিভিন্ন ধরনের ব্যবহারকারীদের সেবা দেয় — বাবা-মা থেকে শুরু করে যারা তাদের সন্তানের বাইরে যাওয়া নিরাপদ কি না তা যাচাই করেন, গবেষকরা যারা ডেটাসেট অ্যাক্সেস করেন, এবং সাংবাদিকরা যারা রাজনৈতিক জবাবদিহিতা ট্র্যাক করেন। ভূমিকা-ভিত্তিক ল্যান্ডিং পেজ প্রতিটি ব্যবহারকারীর অভিজ্ঞতাকে ব্যক্তিগতকৃত করে।
---
## এটি কীভাবে কাজ করে
1. **প্রথম পরিদর্শন** — পেজটি লাইভ বাতাসের রিডিং দিয়ে খোলে; এতে কোনো ফুল-স্ক্রিন ওভারলে নেই (এটি 2026 সালের সেপ্টেম্বর মাসে মুছে ফেলা হয়েছে)
2. **ভূমিকা নির্বাচন** — ব্যবহারকারী হেডার রোল সুইচার থেকে একটি ভূমিকা বেছে নেন (অথবা "Show Everything" বেছে নেন)
3. **ব্যক্তিগতকৃত ড্যাশবোর্ড** — ভূমিকা-ভিত্তিক কাজ এবং প্রস্তাবিত প্যানেলগুলো দেখায়
4. **স্থায়ী** — ভূমিকাটি `localStorage`-এ সেভ করা থাকে, ফিরে আসার সময় পুনরুদ্ধার করা হয়
5. **পরিবর্তনযোগ্য**: রোল সুইচারটি বারের প্রথম কন্ট্রোল ("আপনি কে", অথবা নির্বাচিত ভূমিকার লেবেল) এবং যেকোনো সময় পরিবর্তন করার সুযোগ দেয়। ফোনে এটি মেনুর ভেতরে থাকে

## ভূমিকা কনফিগারেশন
প্রতিটি ভূমিকা `index.html`-এর `ROLE_CONFIG` অবজেক্টে নিচের বিষয়গুলো দিয়ে সংজ্ঞায়িত করা হয়েছে:
```javascript
{
    icon: '<span class="si si-home"> <\/span>',
    label: 'Parent / Family',
    heading: 'Protect your family from air pollution',
    description: 'Real-time safety checks, school closure info...',
    actions: [
        { icon, panel, title, desc, cta }  // 3 action cards
    ],
    panels: [
        { panel, title, desc }  // 6 recommended panels
    ]
}
```

## প্রযুক্তিগত বিবরণ
- **স্টোরেজ:** `localStorage` কি `janvayu-role` (একটি পুরোনো `sessionStorage` ভ্যালু একবার মাইগ্রেট করা হয়)
- **সুইচার:** হেডার-এ `#rolePopover`, যার রোল বাটনগুলো `ROLE_CONFIG` থেকে জেনারেট হয়ে `#rolePopoverGrid`-এ বসানো হয়
- **ড্যাশবোর্ড টেমপ্লেট:** `#tmpl-role-dashboard`
- **ট্যুর:** প্রথমবার রোল নির্বাচনের পর ট্যুরটি ট্রিগার করা হয়, যদি ট্যুরটি আগে দেখা না হয়ে থাকে
