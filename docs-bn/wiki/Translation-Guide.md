# অনুবাদ নির্দেশিকা

JanVayu ৫টি ভাষা সমর্থন করে: ইংরেজি, হিন্দি, তামিল, মারাঠি এবং বাংলা।

---

## অনুবাদ কীভাবে কাজ করে

### UI টেক্সট (data-i18n)

```html
<span data-i18n="tagline">Citizen Air Quality Platform</span>
```

অনুবাদগুলো একটি JavaScript অবজেক্টে সংরক্ষণ করা হয় এবং `setLanguage()`-এর মাধ্যমে প্রয়োগ করা হয়।

### ডকুমেন্টেশন

অনুবাদ করা ডকুমেন্টেশনগুলো নির্দিষ্ট ভাষার ডিরেক্টরিতে থাকে:
- `docs/` — ইংরেজি (মূল)
- `docs-hi/` — হিন্দি
- `docs-ta/` — তামিল
- `docs-mr/` — মারাঠি
- `docs-bn/` — বাংলা

### সহজ ভাষা (data-simple)

বর্তমানে শুধুমাত্র ইংরেজি। ভবিষ্যতে: `data-simple-hi`, `data-simple-ta` ইত্যাদি।

## অনুবাদে অবদান রাখা

### বিকল্প ১: UI স্ট্রিং অনুবাদ করা

১. `index.html`-এ `data-i18n` যুক্ত এলিমেন্টগুলো খুঁজুন
২. ল্যাঙ্গুয়েজ অবজেক্টে অনুবাদ করা স্ট্রিংটি যোগ করুন
৩. হেডার থেকে ভাষা পরিবর্তন করে পরীক্ষা করুন

### বিকল্প ২: ডকুমেন্টেশন অনুবাদ করা

১. আপনার ভাষার ডিরেক্টরিতে নেই এমন কোনো ফাইল `docs/` থেকে বেছে নিন
২. `docs-{lang}/`-এ সমতুল্য ফাইলটি তৈরি করুন
৩. একই কাঠামো বজায় রেখে অনুবাদ করুন
৪. একটি PR জমা দিন

### বিকল্প ৩: সহজ ভাষার টেক্সট অনুবাদ করা

১. `data-simple` অ্যাট্রিবিউট যুক্ত এলিমেন্টগুলো খুঁজুন
২. আপনার ভাষায় অনুবাদ করুন

## Translation CI

`translations.yml` GitHub Action যা যা পরীক্ষা করে:
- প্রতিটি ভাষার ডিরেক্টরিতে কোন কোন ফাইল আছে
- প্রতিটি ভাষার কভারেজ শতাংশ
- CI আউটপুটে রিপোর্ট করা অনুপস্থিত ফাইলগুলো

## নির্দেশিকা

- অনুবাদগুলো স্বাভাবিক রাখুন — আক্ষরিক অনুবাদ করবেন না
- বাতাসের মানের পরিভাষা (PM2.5, AQI, NCAP) ইংরেজিতেই রাখা যেতে পারে
- যেখানে উপযুক্ত সেখানে স্ক্রিপ্টের নিজস্ব সংখ্যা ব্যবহার করুন
- মোবাইলে পরীক্ষা করুন — কিছু স্ক্রিপ্টে বেশি অনুভূমিক জায়গার প্রয়োজন হয়
- টোন ঠিক রাখুন: জরুরি কিন্তু আতঙ্কজনক নয়, প্রযুক্তিগত কিন্তু সহজবোধ্য
