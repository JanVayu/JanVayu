# JanVayu ডকুমেন্টেশন

**JanVayu** (जनवायु, "জনগণের বাতাস") হলো ভারতের একটি স্বাধীন, নাগরিক-পরিচালিত বায়ুমান জবাবদিহিতা প্ল্যাটফর্ম। এটি ১৫৭টি ভারতীয় শহরের (এবং তুলনার জন্য বেইজিং, লন্ডন ও সিঙ্গাপুরের) লাইভ দূষণের ডেটা ট্র্যাক করে, স্বাস্থ্যের ওপর প্রভাব পরিমাপ করে, NCAP-এর বাজেট ব্যয় পর্যবেক্ষণ করে এবং সরকারকে জবাবদিহিতার আওতায় রাখে।

> **লাইভ প্ল্যাটফর্ম:** [www.janvayu.in](https://www.janvayu.in)
> **GitHub:** [github.com/JanVayu/JanVayu](https://github.com/JanVayu/JanVayu)

## JanVayu কী?

বায়ুদূষণের কারণে ভারতে প্রতি বছর আনুমানিক ১.৭২ মিলিয়ন মানুষের মৃত্যু হয় (Lancet Countdown 2025)। PM2.5-এর সংস্পর্শে আসার ফলে ভারতীয়দের গড় আয়ু ৩.৫ বছর কমে যায় (AQLI 2025), যেখানে ইন্দো-গাঙ্গেয় সমভূমির বাসিন্দাদের আয়ু ৫-৮ বছর এবং দিল্লি-NCR-এর বাসিন্দাদের আয়ু ৮.২ বছর পর্যন্ত কমে যায়। দিল্লির বার্ষিক PM2.5 মাত্রা ৮২.২ µg/m³ যা WHO-এর ৫ µg/m³ নির্দেশিকার প্রায় ১৬ গুণ (IQAir 2025)। এর অর্থনৈতিক ক্ষতি বছরে ৩৩৯.৪ বিলিয়ন ডলার, যা জিডিপির প্রায় ৯.৫% (Lancet Countdown 2025)।

JanVayu রেকর্ড সংরক্ষণ করে কিন্তু কোনো প্রচার চালায় না। এটি বায়ুমান সংকটের একটি স্থায়ী পাবলিক আর্কাইভ: এর ডেটা, এর শিকার হওয়া মানুষ, এর নীতি এবং এর জনস্মৃতি।
