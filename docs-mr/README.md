# JanVayu डॉक्युमेंटेशन

**JanVayu** (जनवायु, "लोकांची हवा") हे भारतातील नागरिकांच्या नेतृत्वाखालील हवेच्या गुणवत्तेची जबाबदारी निश्चित करणारे प्लॅटफॉर्म आहे. हे १५७ भारतीय शहरांसाठी (आणि तुलनेसाठी बीजिंग, लंडन आणि सिंगापूरसाठी) रिअल-टाइम प्रदूषण डेटा ट्रॅक करते, आरोग्यावरील परिणामांचे मोजमाप करते, NCAP बजेट खर्चाचा मागोवा घेते आणि सरकारला जाब विचारते.

> **लाइव्ह प्लॅटफॉर्म:** [www.janvayu.in](https://www.janvayu.in)
> **GitHub:** [github.com/JanVayu/JanVayu](https://github.com/JanVayu/JanVayu)

## JanVayu म्हणजे काय?

हवा प्रदूषणामुळे दरवर्षी भारतात अंदाजे १.७२ दशलक्ष लोकांचा मृत्यू होतो (Lancet Countdown 2025). PM2.5 च्या संपर्कामुळे भारतीयांचे सरासरी आयुर्मान ३.५ वर्षांनी कमी होते (AQLI 2025), ज्यामध्ये इंडो-गंगेच्या मैदानी प्रदेशातील रहिवाशांचे ५-८ वर्षे आणि दिल्ली-NCR मधील लोकांचे ८.२ वर्षांपर्यंत नुकसान होते. दिल्लीतील वार्षिक PM2.5 पातळी ८२.२ µg/m³ आहे, जी WHO च्या ५ µg/m³ या मार्गदर्शक तत्त्वापेक्षा ~१६ पट जास्त आहे (IQAir 2025). याचा आर्थिक खर्च दरवर्षी $339.4 अब्ज आहे, जो GDP च्या ~९.५% आहे (Lancet Countdown 2025).

JanVayu केवळ रेकॉर्ड ठेवते आणि कोणतीही मोहीम चालवत नाही. हे हवा गुणवत्तेच्या संकटाचे कायमस्वरूपी सार्वजनिक आर्काइव्ह आहे: त्याचा डेटा, त्याचे बळी, त्याची धोरणे आणि त्याची सार्वजनिक स्मृती.
