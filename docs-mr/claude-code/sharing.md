# ही सेटअप शेअर करणे आणि रेप्लिकेट करणे

हे पेज JanVayu चा Claude Code वर्कफ्लो तुमच्या टीमसोबत कसा शेअर करायचा किंवा तुमच्या स्वतःच्या प्रोजेक्टसाठी तो कसा रेप्लिकेट करायचा हे स्पष्ट करते.
---
## तुमच्या टीमसाठी
### डॉक्युमेंट्स शेअर करा
हे डॉक्युमेंटेशन JanVayu च्या स्वतःच्या साईटवर [`/docs/`](/docs/ ':ignore') येथे होस्ट केले आहे, जी एक सिंगल-पेज Docsify शेल आहे जी रिपॉझिटरीमधून थेट मार्कडाऊन वाचते. ज्यांना खालील गोष्टी समजून घेणे आवश्यक आहे त्यांना URL पाठवा:
- JanVayu कसे बनवले आहे
- Claude Code वापरून योगदान कसे द्यावे
- दुसऱ्या शहरासाठी किंवा डोमेनसाठी JanVayu फोर्क कसे करावे
### नवीन कॉन्ट्रिब्युटरला ऑनबोर्ड करा
1. **रिपो क्लोन करा** — `git clone https://github.com/JanVayu/JanVayu.git`
2. **डॉक्स वाचा**: [`/docs/`](/docs/ ':ignore') पासून सुरुवात करा, विशेषतः:
   - [Tech Stack Overview](../tech-stack/overview.md)
   - [Architecture](../technical/architecture.md)
   - [Local Development](../technical/local-development.md)
3. **Claude Code इन्स्टॉल करा** — `npm install -g @anthropic-ai/claude-code`
4. **सेशन सुरू करा** — `cd JanVayu && claude`
5. **वर्कफ्लो फॉलो करा** — [Workflow](workflow.md) मध्ये वर्णन केलेले आहे
---
## तुमच्या स्वतःच्या प्रोजेक्टसाठी
### पायरी 1: कन्स्ट्रेंट-फर्स्ट ॲप्रोच स्वीकारा
JanVayu मधील सर्वात ट्रान्सफरेबल धडा म्हणजे **कन्स्ट्रेंट-फर्स्ट प्रॉम्प्टिंग**. Claude Code ला काहीही बनवण्यास सांगण्यापूर्वी:
1. तुमचा प्रोजेक्ट काय *वापरणार नाही* (फ्रेमवर्क्स, बिल्ड टूल्स इ.) हे ठरवा
2. तुमची कोड स्टाईल आणि कन्व्हेन्शन्स ठरवा
3. तुमचे डिप्लॉयमेंट टार्गेट ठरवा
4. हे तुमच्या रिपो रूटमधील `CLAUDE.md` फाईलमध्ये टाका
### पायरी 2: स्किल फाईल्स तयार करा
जर तुमचा प्रोजेक्ट AI फीचर्स वापरत असेल (कोणतेही मॉडेल — Groq, OpenAI, Claude API), तर प्रत्येक AI इंटरॅक्शन एका स्किल फाईलमध्ये डॉक्युमेंट करा:
```markdown
# Skill: [Feature Name]
## Role
[What the model acts as]
## Data Context
[What real data gets injected into the prompt]
## Output Format
[Exact structure expected]
## Constraints
[Word limits, tone, language, what NOT to do]
## Fallback
[What happens if the AI call fails]
```
### पायरी 3: Git Hooks सेट अप करा
खालील गोष्टी लागू करण्यासाठी JanVayu चे git hooks (`.githooks/`) कॉपी करा:
- कमिट मेसेज कन्व्हेन्शन्स
- कमिट्समध्ये कोणतेही सिक्रेट्स नसावेत
- कोणतेही डीबग स्टेटमेंट्स नसावेत
### पायरी 4: बिल्ड करताना डॉक्युमेंटेशन करा
तुमच्या कोडसोबत Docsify (किंवा कोणतेही मार्कडाऊन-आधारित) डॉक्स तयार करा. Claude Code तुमच्या कोडबेसवरून डॉक्युमेंटेशन जनरेट करू शकतो — त्याचा वापर करा.

## दुसऱ्या शहरासाठी JanVayu फोर्क करणे
JanVayu चा कोड MIT-लायसन्स केलेला आहे (त्याचा कंटेंट CC BY-NC-SA 4.0 आहे). दुसऱ्या शहरासाठी किंवा देशासाठी तो फोर्क करण्यासाठी:
 
---
1. **GitHub वर रेपो फोर्क करा**
2. `app.js` मधील **शहरांची यादी अपडेट करा** आणि Netlify फंक्शन्समधील `CITIES` टेबल्स अपडेट करा
3. `anomaly-check.mjs` मधील **हंगामी बेसलाइन्स अपडेट करा**
4. **तुमच्या प्रदेशासाठी WAQI स्टेशन आयडी अपडेट करा**
5. **स्थानिक भाषांसाठी स्ट्रिंग्स ट्रान्सलेट करा**
6. **एन्व्हायर्नमेंट व्हेरिएबल्ससह तुमची स्वतःची Netlify साइट सेट अप करा**
7. **पर्यायी:** डीफॉल्ट Groq मॉडेल (`openai/gpt-oss-120b`) दुसऱ्या मॉडेलने बदला (स्किल फाइल्स मॉडेल-अग्नोस्टिक आहेत)
या सर्व पायऱ्यांसाठी Claude Code मदत करू शकतो.

## हे डॉक्युमेंटेशन एक्सपोर्ट करणे
### स्टँडअलोन साइट म्हणून
डॉक्स आधीपासूनच एक स्टँडअलोन साइट आहेत. कोणत्याही वाचकाला [`https://www.janvayu.in/docs/`](https://www.janvayu.in/docs/) वर पाठवा.
### Markdown म्हणून
रॉ Markdown फाइल्स रेपोमध्ये `docs/` (इंग्रजी) आणि `docs-{lang}/` (हिंदी, बंगाली, मराठी, तमिळ) मध्ये आहेत. त्या थेट शेअर करा किंवा Markdown रेंडर करणाऱ्या कोणत्याही ठिकाणी होस्ट करा — GitHub, Notion, HackMD, तुमची स्वतःची Docsify किंवा MkDocs साइट.
### PDF म्हणून
Docsify मध्ये स्वतःचे इन-बिल्ट PDF एक्सपोर्ट नाही. लाईव्ह डॉक्सचे PDF मध्ये रूपांतर करण्यासाठी, `https://www.janvayu.in/docs/` चे PDF मध्ये रेंडर करण्यासाठी `wkhtmltopdf` किंवा Puppeteer सारखे हेडलेस-Chrome टूल वापरा.

## डॉक्स स्टॅक
JanVayu चे डॉक्स Docsify वर चालतात — हे निवडले गेले कारण यात कोणतीही बिल्ड स्टेप नाही, सर्व्हर नाही आणि थर्ड-पार्टी होस्टिंगचे बिल नाही.
### बहुभाषिक सेटअप कसा काम करतो
इंग्रजी Markdown `docs/` मध्ये असते. प्रत्येक अनुवादित भाषा `docs-{lang}/` मध्ये असते. `/docs/index.html` वरील एकच Docsify शेल एक एलियास मॅप घोषित करतो जो हॅश पाथ्सना योग्य डिरेक्टरीकडे रूट करतो, जेणेकरून अभ्यागत येथे पोहोचू शकतील:
| भाषा | URL | सोर्स डिरेक्टरी |
|----------|-----|------------------|
| इंग्रजी (डीफॉल्ट) | [`/docs/`](/docs/ ':ignore') | `docs/` |
| हिंदी | [`/docs/#/hi/`](/docs/#/hi/ ':ignore') | `docs-hi/` |
| बंगाली | [`/docs/#/bn/`](/docs/#/bn/ ':ignore') | `docs-bn/` |
| मराठी | [`/docs/#/mr/`](/docs/#/mr/ ':ignore') | `docs-mr/` |
| तमिळ | [`/docs/#/ta/`](/docs/#/ta/ ':ignore') | `docs-ta/` |
अनुवादित ट्रीज CI ऑटो-ट्रान्सलेट जॉबद्वारे (`.github/workflows/translations.yml`, ज्यासाठी Sarvam API की आवश्यक आहे) रिफ्रेश केले जातात आणि ते इंग्रजी डॉक्सच्या मागे असू शकतात. 21 November 2026 रोजी, 74 इंग्रजी Markdown पेजेसपैकी, 70 ची हिंदी आवृत्ती, 68 ची बंगाली आवृत्ती, 70 ची मराठी आवृत्ती आणि 71 ची तमिळ आवृत्ती होती. यातील बहुतांश गहाळ पेजेस दिनांकित फॅक्ट-चेक रिपोर्ट्स आहेत.
### प्लगइन्स
| प्लगइन | उद्देश |
|--------|---------|
| `docsify-themeable` | ब्रँड-रंगीत थीम (JanVayu हिरवा) आणि डार्क मोड टॉगल |
| `docsify-pagination` | पृष्ठांमधील मागील/पुढील नेव्हिगेशन |
| `docsify-copy-code` | प्रत्येक कोड ब्लॉकवर वन-क्लिक कॉपी बटण |
| `docsify-footer-enh` | कॉपीराइट आणि परवाना असलेली फुटर लाईन |
| `docsify` सर्च | सर्व 5 भाषा ट्रीजमधील बिल्ट-इन क्लायंट-साइड सर्च |
| Prism.js | bash, JS, JSON, YAML, TOML, Markdown साठी सिंटॅक्स हायलाइटिंग |
| Docsify झूम-इमेज | इमेजेसवर क्लिक-टू-झूम |
### कस्टम डोमेन

डॉक्युमेंट्स `https://www.janvayu.in/docs/` वरून सर्व्ह केले जातात (हा मुख्य JanVayu साइटवरील एक पाथ आहे, सबडोमेन नाही) — यासाठी वेगळ्या DNS किंवा SSL कॉन्फिगरेशनची आवश्यकता नाही.
### ब्रँडिंग

थीम व्हेरिएबल्स `docs/index.html` मधील `<style>` ब्लॉकच्या आत आहेत:
- प्राथमिक रंग: `#16A34A` (प्लॅटफॉर्मच्या ब्रँड हिरव्या रंगाशी जुळणारा)
- साइडबार ॲक्सेंट: `#1a3a2a`
- डार्क मोड: सामायिक साइट हेडरवरून (`js/chrome.js`) टॉगल केला जातो; ही पसंती `janvayu-theme` अंतर्गत `localStorage` मध्ये सेव्ह केली जाते.
