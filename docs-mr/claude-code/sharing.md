# ही सेटअप शेअर करणे आणि रेप्लिकेट करणे

या पेजवर JanVayu चा Claude Code वर्कफ्लो तुमच्या टीमसोबत कसा शेअर करायचा किंवा तुमच्या स्वतःच्या प्रोजेक्टसाठी तो कसा रेप्लिकेट करायचा हे सांगितले आहे.

---

## तुमच्या टीमसाठी

### डॉक्स शेअर करा

हे डॉक्युमेंटेशन JanVayu च्या स्वतःच्या साईटवर [`/docs/`](/docs/) वर होस्ट केलेले आहे — हे एक सिंगल-पेज Docsify शेल आहे जे थेट रेपोमधून मार्कडाऊन वाचते. ज्यांना हे समजून घ्यायचे आहे त्यांना URL पाठवा:
- JanVayu कसे बनवले आहे
- Claude Code वापरून योगदान कसे द्यायचे
- दुसऱ्या शहरासाठी किंवा डोमेनसाठी JanVayu कसे फोर्क करायचे

### नवीन योगदानकर्त्याला ऑनबोर्ड करा

1. **रिपो क्लोन करा** — `git clone https://github.com/JanVayu/JanVayu.git`
2. **डॉक्स वाचा** — [`/docs/`](/docs/) पासून सुरुवात करा, विशेषतः:
   - [Tech Stack Overview](../tech-stack/overview.md)
   - [Architecture](../technical/architecture.md)
   - [Local Development](../technical/local-development.md)
3. **Claude Code इन्स्टॉल करा** — `npm install -g @anthropic-ai/claude-code`
4. **सेशन सुरू करा** — `cd JanVayu && claude`
5. **वर्कफ्लो फॉलो करा** — [Workflow](workflow.md) मध्ये वर्णन केल्याप्रमाणे

## तुमच्या स्वतःच्या प्रोजेक्टसाठी

### पायरी १: Constraint-First दृष्टिकोन स्वीकारा

JanVayu मधील सर्वात उपयुक्त धडा म्हणजे **constraint-first prompting**. Claude Code ला काहीही बनवायला सांगण्यापूर्वी:

1. तुमचा प्रोजेक्ट काय *वापरणार नाही* (फ्रेमवर्क्स, बिल्ड टूल्स इ.) हे ठरवा
2. तुमची कोड स्टाईल आणि नियम ठरवा
3. तुमचे डिप्लॉयमेंट टार्गेट ठरवा
4. हे सर्व तुमच्या रेपो रूटमधील `CLAUDE.md` फाईलमध्ये टाका

### पायरी २: Skill फाइल्स तयार करा

जर तुमचा प्रोजेक्ट AI फीचर्स वापरत असेल (कोणतेही मॉडेल — Groq, OpenAI, Claude API), तर प्रत्येक AI इंटरॅक्शनची स्किल फाईल म्हणून नोंद करा:

```markdown
# Skill: [Feature Name]

## Role
[What the model acts as]

## Data Context
[What real data gets injected into the prompt]

## Output Format
[Exact structure expected]

## Constraints
[Word limits, tone, language, what NOT to do]

## Fallback
[What happens if the AI call fails]
```

### पायरी ३: Git Hooks सेट अप करा

खालील गोष्टी लागू करण्यासाठी JanVayu चे git hooks (`.githooks/`) कॉपी करा:
- कमिट मेसेजचे नियम
- कमिट्समध्ये सिक्रेट्स नसावेत
- डीबग स्टेटमेंट्स नसावेत

### पायरी ४: बनवताना डॉक्युमेंटेशन करा

तुमच्या कोडसोबत Docsify (किंवा कोणतेही मार्कडाऊन-आधारित) डॉक्स तयार करा. Claude Code तुमच्या कोडबेसवरून डॉक्युमेंटेशन तयार करू शकतो — त्याचा वापर करा.

## दुसऱ्या शहरासाठी JanVayu फोर्क करणे

JanVayu चा कोड MIT-लायसन्स केलेला आहे (त्यातील मजकूर CC BY-NC-SA 4.0 आहे). दुसऱ्या शहरासाठी किंवा देशासाठी तो फोर्क करण्यासाठी:
1. GitHub वर **रिपॉझिटरी फोर्क करा**
2. `app.js` मधील **शहरांची यादी** आणि Netlify फंक्शन्समधील `CITIES` टेबल्स **अपडेट करा**
3. `anomaly-check.mjs` मधील **हंगामी बेसलाइन्स** अपडेट करा
4. तुमच्या भागासाठी **WAQI स्टेशन आयडी** अपडेट करा
5. स्थानिक भाषांसाठी **स्ट्रिंग्स ट्रान्सलेट करा**
6. एन्व्हायर्नमेंट व्हेरिएबल्ससह **तुमची स्वतःची Netlify साईट** सेट अप करा
7. **पर्यायी:** डीफॉल्ट Groq मॉडेल (`openai/gpt-oss-120b`) च्या जागी दुसरे मॉडेल वापरा (स्किल फाइल्स मॉडेल-अग्नोस्टिक आहेत)

या सर्व पायऱ्यांमध्ये Claude Code मदत करू शकतो.

## हे डॉक्युमेंटेशन एक्सपोर्ट करणे

### स्टँडअलोन साईट म्हणून

ही डॉक्स आधीपासूनच एक स्टँडअलोन साईट आहेत. कोणत्याही वाचकाला [`https://www.janvayu.in/docs/`](https://www.janvayu.in/docs/) वर पाठवा.

### Markdown म्हणून

रॉ Markdown फाइल्स रिपॉझिटरीमधील `docs/` (इंग्रजी) आणि `docs-{lang}/` (हिंदी, बंगाली, मराठी, तमिळ) मध्ये आहेत. त्या थेट शेअर करा किंवा Markdown रेंडर करणाऱ्या कोणत्याही प्लॅटफॉर्मवर होस्ट करा — GitHub, Notion, HackMD, तुमची स्वतःची Docsify किंवा MkDocs साईट.

### PDF म्हणून

Docsify मध्ये स्वतःचे इनबिल्ट PDF एक्सपोर्ट नाही. लाईव्ह डॉक्सचे PDF मध्ये रूपांतर करण्यासाठी, `https://www.janvayu.in/docs/` चे PDF मध्ये रेंडर करण्यासाठी `wkhtmltopdf` किंवा Puppeteer सारखे हेडलैस-Chrome टूल वापरा.

## डॉक्स स्टॅक

JanVayu ची डॉक्स Docsify वर चालते — हे निवडण्याचे कारण म्हणजे यात बिल्ड स्टेप नाही, सर्व्हर नाही आणि थर्ड-पार्टी होस्टिंगचे बिल नाही.

### बहुभाषिक सेटअप कसा काम करतो

इंग्रजी Markdown `docs/` मध्ये असते. प्रत्येक ट्रान्सलेट केलेली भाषा `docs-{lang}/` मध्ये असते. `/docs/index.html` वरील एकच Docsify शेल एक एलियास मॅप डिक्लेअर करते जो हॅश पाथ्सना योग्य डिरेक्टरीकडे राऊट करतो, जेणेकरून भेट देणारे खालील ठिकाणी पोहोचू शकतात:

| भाषा | URL | सोर्स डिरेक्टरी |
|----------|-----|------------------|
| इंग्रजी (डीफॉल्ट) | [`/docs/`](/docs/) | `docs/` |
| हिंदी | [`/docs/#/hi/`](/docs/#/hi/) | `docs-hi/` |
| बंगाली | [`/docs/#/bn/`](/docs/#/bn/) | `docs-bn/` |
| मराठी | [`/docs/#/mr/`](/docs/#/mr/) | `docs-mr/` |
| तमिळ | [`/docs/#/ta/`](/docs/#/ta/) | `docs-ta/` |

ट्रान्सलेट केलेली ट्रीज CI ऑटो-ट्रान्सलेट जॉबद्वारे (`.github/workflows/translations.yml`, ज्यासाठी Sarvam API की आवश्यक आहे) रिफ्रेश केली जातात आणि इंग्रजी डॉक्सच्या मागे असू शकतात: सध्या ६५ इंग्रजी पृष्ठांपैकी ४७ पृष्ठांवर प्रत्येक भाषेत ट्रान्सलेट केलेले रूप आहे.

### प्लगइन्स
| प्लगइन | उद्देश |
|--------|---------|
| `docsify-themeable` | ब्रँड-रंगीत थीम (JanVayu हिरवा) डार्क मोड टॉगलसह |
| `docsify-pagination` | पेजेसमध्ये मागील/पुढील नेव्हिगेशन |
| `docsify-copy-code` | प्रत्येक कोड ब्लॉकवर वन-क्लिक कॉपी बटण |
| `docsify-footer-enh` | कॉपीराइट आणि परवान्यासह फुटर लाईन |
| `docsify` search | सर्व ५ भाषा ट्रीमध्ये बिल्ट-इन क्लायंट-साइड सर्च |
| Prism.js | bash, JS, JSON, YAML, TOML, Markdown साठी सिंटॅक्स हायलाइटिंग |
| Docsify zoom-image | इमेजेसवर क्लिक-टू-झूम |

### कस्टम डोमेन

डॉक्युमेंट्स `https://www.janvayu.in/docs/` वरून सर्व्ह केले जातात (ही मुख्य JanVayu साईटवरील एक पाथ आहे, सबडोमेन नाही) — यासाठी वेगळ्या DNS किंवा SSL कॉन्फिगरेशनची गरज नाही.

### ब्रँडिंग

थीम व्हेरिएबल्स `docs/index.html` मधील `<style>` ब्लॉकमध्ये असतात:
- प्रायमरी रंग: `#16A34A` (प्लॅटफॉर्मच्या ब्रँड हिरव्या रंगाशी जुळणारा)
- साईडबार ॲक्सेंट: `#1a3a2a`
- डार्क मोड: शेअर केलेल्या साईट हेडरवरून (`js/chrome.js`) टॉगल करता येतो; ही पसंती `janvayu-theme` अंतर्गत `localStorage` मध्ये सेव्ह केली जाते
