# भूमिका-आधारित व्ह्यूज

JanVayu चा रोल सिलेक्टर अभ्यागतांना त्यांच्यासाठी सर्वात संबंधित डेटा, टूल्स आणि कृतींकडे निर्देशित करतो. सर्वांना सुमारे ५८ पॅनेल्सचा पूर्ण डॅशबोर्ड दाखवण्याऐवजी, तो प्रत्येक अभ्यागताला एक छोटा, निवडक संच देतो.

## हे कसे काम करते

### पहिली भेट

पहिल्या भेटीत फक्त हवामान दाखवले जाते आणि सुरुवातीला काहीही विचारले जात नाही. १८ सप्टेंबर २०२६ पर्यंत, इतर कशाच्याही आधी होमपेजवर एक फुल-स्क्रीन ओव्हरले उघडायचे, त्यामुळे नवीन अभ्यागताला ज्या माहितीसाठी आले होते ती पाहण्यापूर्वी बारा पर्यायांच्या पिकरमधून जावे लागायचे. आता ते आपोआप उघडत नाही. शेअर्ड लिंकवरून येणाऱ्या व्यक्तीला थेट लाईव्ह PM2.5 ची आकडेवारी दिसते, आणि भूमिका निवडणे ऐच्छिक असते.

भूमिका हेडरवरून निवडता येतात. रोल स्विचरमध्ये सर्व बारा भूमिका आणि "Show Everything" (सर्व दाखवा) समाविष्ट आहे, मग भूमिका सेट केलेली असो वा नसो. यासाठी फक्त एक टॅप लागतो आणि यात कोणताही मधला स्क्रीन नाही, आणि प्रत्येक भूमिकेच्या बाजूला एक ओळीचे वर्णन आहे. जुने फुल-स्क्रीन ओव्हरले (`#roleOverlay`) कोडमधून काढून टाकण्यात आले आहे.

ज्या अभ्यागताने अद्याप भूमिका निवडलेली नाही, त्याला सत्रात एकदा स्विचरकडे लक्ष वेधणारा संकेत दिला जातो.

बारा भूमिका:

| Role | Key | Example action |
|------|-----|----------------|
| Parent / Family | `parent` | "Should my child go outside?" |
| Student | `student` | "Explore historical AQI trends" |
| Researcher | `researcher` | "Access the data archive" |
| Policymaker | `policymaker` | "Track NCAP mission targets" |
| Journalist | `journalist` | "Generate an accountability brief" |
| Citizen / Activist | `activist` | "File an RTI request" |
| Doctor / Health Worker | `doctor` | "Health risk calculator" |
| Teacher | `teacher` | "Should school close today?" |
| NGO / CSO | `ngo` | "Generate an advocacy brief" |
| Business Owner | `business` | "See the economic impact" |
| Woman / Caregiver | `woman` | "Indoor cooking and maternal exposure" |
| Citizen | `citizen` | "What is my city doing about it?" |

हेडर स्विचरमधील "Show Everything" पर्याय भूमिका काढून टाकतो आणि पूर्ण डॅशबोर्ड दाखवतो.

### रोल डॅशबोर्ड

भूमिका निवडल्यानंतर, अभ्यागताला ३ ॲक्शन कार्ड्स असलेला एक क्युरेटेड डॅशबोर्ड दिसतो, जे थेट बटणांसह (उदा. "Check now" किंवा "Calculate risk") उच्च-प्राधान्याची टूल्स असतात, आणि ६ सुचवलेले पॅनेल्स असतात, जे पूर्ण संचातील सर्वात संबंधित विभाग असतात. एक "Explore everything" बटण संपूर्ण डॅशबोर्ड उघडते.

### रोल स्विचर (हेडर)
हेडरमध्ये, लँग्वेज सिलेक्टर आणि थीम टॉगलच्या शेजारी नेहमी एक रोल स्विचर बटण दिसते. तुम्ही निवड करण्यापूर्वी, त्यावर युझर आयकॉनसह "Role" असे सामान्य लेबल दिसते. त्यानंतर त्यावर निवडलेल्या रोलचा सरागम आयकॉन आणि छोटे लेबल (उदाहरणार्थ "Parent") दिसते.

त्यावर क्लिक केल्यावर एक ड्रॉपडाउन उघडतो, ज्यामध्ये सर्व १२ रोल्स आणि "Show Everything" हा पर्याय असतो. तुमच्या पहिल्या निवडीनंतर, एक छोटा पल्स आणि एक टूलटिप ("Change your role anytime here") तुम्हाला या स्विचरकडे निर्देशित करतात.

### तुमचा रोल लक्षात ठेवणे

तुमची निवड ब्राउझरमध्ये `janvayu-role` या की अंतर्गत सेव्ह केली जाते (जुनी `sessionStorage` व्हॅल्यू एकदा मायग्रेट केली जाते). ती टॅब्स आणि नंतरच्या भेटींमध्येही राहते, त्यामुळे परत येणाऱ्या युझरला रोल स्क्रीनवर नाही तर थेट डेटावर नेले जाते. तिथे दाखवण्यासाठी किंवा वगळण्यासाठी कोणताही ओव्हरले नसतो, आणि डीप लिंक्स (उदाहरणार्थ `janvayu.in/#health`) थेट त्यांच्या पॅनेलवर जातात.

## कॉन्फिगरेशन (डेव्हलपर्ससाठी)

सर्व रोल डेफिनेशन्स `index.html` मधील `ROLE_CONFIG` ऑब्जेक्टमध्ये असतात. प्रत्येक रोलमध्ये खालील गोष्टी असतात:

```javascript
{
    icon: '<span class="si si-home"></span>',  // सरागम आयकॉन HTML
    label: 'Parent / Family',
    heading: 'Protect your family from air pollution',
    description: 'Real-time safety checks, school closure info...',
    actions: [
        { icon: '...', panel: 'go-outside', title: '...', desc: '...', cta: 'Check now →' },
        // एकूण ३ ॲक्शन कार्ड्स
    ],
    panels: [
        { panel: 'children', title: "Children's Health", desc: '...' },
        // एकूण ६ रेकमेंडेड पॅनेल्स
    ]
}
```

### नवीन रोल जोडणे

1. `ROLE_CONFIG` मध्ये `icon`, `label`, `heading`, `description`, `actions` (३), आणि `panels` (६) सह एक नवीन की जोडा.
2. HTML मध्ये कोणताही बदल करण्याची गरज नाही: रोल स्विचर आपोआप `ROLE_CONFIG` मधून `#rolePopoverGrid` मध्ये जनरेट होतो.
3. एक `data-i18n` ॲट्रिब्युट जोडा जेणेकरून रोलचे भाषांतर करता येईल.

### आयकॉन्स

सर्व रोल आणि ॲक्शन आयकॉन्स CSS mask-image द्वारे [Sargam Icons](https://sargamicons.com/) v1.6.7 वापरतात. आयकॉन्स `<span class="si si-{name}"></span>` म्हणून रेंडर होतात आणि त्यांच्या पॅरेंट एलिमेंटमधून रंग घेतात. उपलब्ध आयकॉन्स `<style>` ब्लॉक मध्ये `.si-*` क्लासेस म्हणून डिफाइन केले आहेत.

## डिझाईनचे निर्णय

युझर फीडबॅकद्वारे ओळखल्या गेलेल्या मुख्य प्रेक्षकांसाठी (काळजी करणाऱ्या पालकांपासून ते पॉलिसी रिसर्चर्सपर्यंत) १२ रोल्स आहेत, आणि प्रत्येकाला वेगवेगळे पॅनेल्स आणि ॲक्शन्स मिळतात.

ही निवड `localStorage` मध्ये ठेवली जाते, `sessionStorage` मध्ये नाही, कारण परत येणाऱ्या युझर्सना डेटावर यायला हवे आणि त्यांना पुन्हा त्यांचा रोल निवडण्याची गरज पडू नये. जुनी `sessionStorage` व्हॅल्यू एकदा मायग्रेट केली जाते.
रोल निवडणे हा कोणताही मार्ग नाही. JanVayu हे हॅश-बेस्ड राउटिंग असलेले एकच `index.html` आहे, त्यामुळे रोल हा फक्त एक वरचा थर आहे आणि तो पत्ता बदलत नाही.

स्विच नेहमी दिसत असतो, जेणेकरून ज्याने "Parent" निवडले आहे आणि नंतर त्याला बजेट डेटा हवा आहे, त्याला आपण अडकल्यासारखे वाटू नये.
