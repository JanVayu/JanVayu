# प्लॅटफॉर्मची रूपरेषा
जॅनवायु (JanVayu) हे ६० डेस्टिनेशन्स असलेले एक वेब पेज आहे, जे तुम्हाला काय करायचे आहे यावर आधारित ८ गटांमध्ये विभागले आहे: माय एअर (My Air), मॅप्स अँड प्लेसेस (Maps & Places), हेल्थ अँड ट्रेंड्स (Health & Trends), अकाउंटेबिलिटी (Accountability), टेक ॲक्शन (Take Action), लर्न (Learn), रिसोर्सेस (Resources) आणि अबाऊट (About). एकत्रितपणे ते लाइव्ह डेटा, आरोग्य, धोरण आणि कायदेशीर उत्तरदायित्व कव्हर करतात.
