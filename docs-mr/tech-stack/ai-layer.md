# एआय लेयर — Groq द्वारे OpenAI gpt-oss-120B

JanVayu ची एआय वैशिष्ट्ये **OpenAI gpt-oss-120B** द्वारे चालविली जातात, जे Netlify Functions मधील **Groq API** (OpenAI-सुसंगत REST API) द्वारे दिले जाणारे ओपन-सोर्स LLM आहे.

---

## Groq द्वारे OpenAI gpt-oss-120B का?

| निकष | निवड |
|-----------|--------|
| **खर्च** | मोफत टियर (Groq Console) — बिलिंगची आवश्यकता नाही |
| **गती** | Groq च्या होस्टेड इन्फरन्स सेवेवरून दिले जाते (लॅटेन्सी येथे मोजली जात नाही) |
| **रेट लिमिट्स** | उदार मोफत टियर — सार्वजनिक हिताच्या प्लॅटफॉर्मसाठी पुरेसे |
| **बहुभाषिक** | मजबूत हिंदी सपोर्ट (JanVayu च्या प्रेक्षकांसाठी महत्त्वाचे) |
| **गुणवत्ता** | डेटा-आधारित तथ्यात्मक प्रतिसादांसाठी पुरेसे (सर्जनशील लेखनासाठी नाही) |
| **ओपन सोर्स** | OpenAI gpt-oss-120B हे एक ओपन मॉडेल (OpenAI) आहे, जे पारदर्शकता आणि पुनरुत्पादनक्षमता सुनिश्चित करते |

### स्वीकारलेले तडजोडी

- **GPT-4 / Claude नाही** — Groq चा मोफत टियर ओपन-सोर्स मॉडेलसह हा मुख्य फरक आहे. JanVayu शून्य बजेटवर चालते.
- **आउटपुट टोकन कॅप** — आउटपुट प्रति फंक्शन 512 ते 1,024 `max_tokens` पर्यंत मर्यादित आहे (air-query 700, accountability-brief 1,024, health-advisory 768, anomaly-check 512). रिझनिंग मॉडेल्स त्या कॅपचा काही भाग रिझनिंगवर खर्च करतात, त्यामुळे कॅप संपूर्ण प्रतिसादाला मर्यादित करते, केवळ दृश्य मजकुराला नाही.
- **फायन-ट्युनिंग नाही** — केवळ प्रॉम्प्ट इंजिनिअरिंग. प्रत्येक कौशल्य हे एक सिस्टीम प्रॉम्प्ट आहे, फायन-ट्युन केलेले मॉडेल नाही.

## इंटिग्रेशन आर्किटेक्चर

```
Browser (client)
    │
    │ POST /.netlify/functions/air-query
    │ POST /.netlify/functions/health-advisory
    │ POST /.netlify/functions/accountability-brief
    │ GET  /.netlify/functions/anomaly-check
    │
    ▼
Netlify Function (server-side)
    │
    │ 1. Parse user input
    │ 2. Fetch live AQI data from WAQI
    │ 3. Construct prompt with real data
    │ 4. Call Groq API
    │ 5. Return response (or fallback to raw data)
    │
    ▼
Groq API
    │
    │ openai/gpt-oss-120b model
    │ max_tokens: 512-1,024 (per function)
    │
    ▼
Structured response → Browser
```

**मुख्य सुरक्षा तत्त्व:** `GROQ_API_KEY` कधीही क्लायंटपर्यंत पोहोचत नाही. सर्व एआय कॉल्स Netlify Functions द्वारे सर्व्हर-साइडवर असतात.

## चार एआय वैशिष्ट्ये

### 1. Ask JanVayu (`air-query.mjs`)
- **इनपुट:** शहराचे नाव + मुक्त-मजकूर प्रश्न
- **इंजेक्ट केलेला संदर्भ:** WAQI कडून लाईव्ह PM2.5 आणि AQI
- **आउटपुट:** वास्तविक रीडिंगवर आधारित
- **भाषा:** प्रश्नाच्या भाषेत उत्तरे; Ask JanVayu UI 10 भाषांमध्ये उपलब्ध आहे
- **फॉल-बॅक:** जर Groq ला रेट-लिमिट असेल तर कच्चे AQI डेटा परत करते
### 2. आरोग्य सल्ला (`health-advisory.mjs`)
- **इनपुट:** शहर + वय + आरोग्याच्या समस्या + बाहेर घालवलेला वेळ
- **संदर्भ:** त्या शहरातील लाईव्ह AQI
- **आउटपुट:** रंग-कोडित धोक्याची पातळी + ठोस शिफारसी
- **फॉलबॅक:** सामान्य WHO-मार्गदर्शक तत्त्वांचा सल्ला

### 3. जबाबदारीची माहिती (`accountability-brief.mjs`)
- **इनपुट:** शहराचे नाव
- **संदर्भ:** लाईव्ह AQI + हंगामी बेसलाईन्स + GRAP टप्पे
- **आउटपुट:** स्ट्रक्चर्ड माहिती (सध्याची स्थिती, NCAP उद्दिष्टे, 5 जबाबदारीचे प्रश्न)
- **मॅक्स टोकन्स:** 1,024
- **फॉलबॅक:** रॉ डेटा टेबल परत करते

### 4. विसंगती शोधणे (`anomaly-check.mjs`)
- **इनपुट:** काहीही नाही (5 मेट्रो शहरांवर आपोआप लक्ष ठेवते)
- **थ्रेशोल्ड:** 2× हंगामी बेसलाईन = विसंगती
- **आउटपुट:** प्रत्येक विसंगतीसाठी एक-वाक्याचे AI स्पष्टीकरण
- **कॅशे:** 10-मिनिटांचे HTTP `Cache-Control` हेडर (Netlify Blobs नाही)
- **फॉलबॅक:** AI स्पष्टीकरणाशिवाय विसंगतीचा फ्लॅग परत करते

## रेट लिमिटिंग स्ट्रॅटेजी

फ्री-टियर Groq लिमिट्स (बदलण्यायोग्य — सध्याच्या मूल्यांसाठी [console.groq.com](https://console.groq.com) तपासा):

| मर्यादा | मूल्य (openai/gpt-oss-120b, Groq फ्री प्लॅन, तपासले 2 ऑक्टोबर 2026) |
|-------|-------|
| प्रति मिनिट रिक्वेस्ट्स | 30 |
| प्रति दिवस रिक्वेस्ट्स | 1,000 |
| प्रति मिनिट टोकन्स | 8,000 |
| प्रति दिवस टोकन्स | 200,000 |

स्रोत: [Groq रेट लिमिट्स](https://console.groq.com/docs/rate-limits). लांब एअर-क्वेरी सिस्टीम प्रॉम्प्टमुळे 8,000 टोकन्स-प्रति-मिनिटची मर्यादा खूपच कमी पडते, त्यामुळे 429 रिस्पॉन्सवर लक्ष ठेवणे महत्त्वाचे आहे.

JanVayu हा बजेट विविध फीचर्समध्ये विभागते (हे प्लॅनिंगचे अंदाज आहेत, Netlify लॉग्सवरून मोजलेले नाहीत):
- विसंगती तपासणी: ~144/दिवस (कॅश केलेले, पेज लोड झाल्यावर चालते)
- एअर क्वेरी: ~50/दिवस (युझरने सुरू केलेले)
- आरोग्य सल्ला: ~30/दिवस (युझरने सुरू केलेले)
- जबाबदारीची माहिती: ~20/दिवस (युझरने सुरू केलेले)

जर मर्यादा संपल्या, तर प्रत्येक फंक्शन सहजपणे रॉ डेटावर फॉलबॅक होते. युझरला नेहमीच रिस्पॉन्स मिळतो — फक्त AI विश्लेषणाशिवाय.

## प्रॉम्प्ट इंजिनिअरिंग

सर्व प्रॉम्प्ट्स या तत्त्वांचे पालन करतात:

1. **नेहमी रिअल डेटा इंजेक्ट करा** — मॉडेल कधीही मेमरीवरून जनरेट करत नाही
2. **अचूक आउटपुट फॉरमॅट सांगा** — विशेषतः स्ट्रक्चर्ड माहितीसाठी
3. **शब्दांची मर्यादा ठरवा** — प्रत्येक प्रॉम्प्टमध्ये स्पष्ट मर्यादा
4. **अपयशाचे प्रकार सांगा** — "सामान्य सल्ला देऊ नका", "टाळाटाळ करू नका"
5. **बहुभाषिक सूचना** — "प्रश्नाच्या भाषेत उत्तर द्या"
6. **ग्रेसफुल डिग्रेडेशन** — प्रत्येक फंक्शनचा एक नॉन-AI फॉलबॅक मार्ग असतो

संपूर्ण प्रॉम्प्ट डॉक्युमेंटेशनसाठी [Skills & AI Prompts](../skills/README.md) विभाग पहा.
