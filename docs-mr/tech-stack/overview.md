# टेक स्टॅक ओव्हरव्ह्यू
JanVayu जाणीवपूर्वक एका किमान स्टॅकवर तयार केले आहे — शून्य फ्रंटएंड फ्रेमवर्क्स, तीन npm डिपेंडन्सीज आणि सर्व्हरलेस बॅकएंड. या पेजवर वापरलेल्या प्रत्येक तंत्रज्ञानाची आणि ते का निवडले गेले याची माहिती दिली आहे.

## हा स्टॅक का?
### शून्य-फ्रेमवर्क फ्रंटएंड
JanVayu च्या प्रेक्षकांमध्ये संपूर्ण भारतातील 2G कनेक्शन्स आणि लो-एंड अँड्रॉइड डिव्हाइसेस वापरणाऱ्या लोकांचा समावेश आहे. React किंवा Vue सारख्या फ्रेमवर्कमुळे एकही फीचर लोड होण्यापूर्वी डाउनलोड करण्यासाठी फ्रेमवर्क रनटाइम वाढेल. त्याऐवजी:
- ॲपमध्ये `index.html` सोबत `styles.css`, `app.js`, `games.js` आणि 19 लेझी-लोडेड पॅनेल फ्रॅगमेंट्स आहेत, यात कोणताही बंडलर नाही
- ट्रान्सपायलेशन, बंडलिंग किंवा ट्री-शेकिंगची गरज नाही
- डिप्लॉय आर्टिफॅक्ट = स्वतः रिपॉझिटरी
- मूलभूत HTML/JS कौशल्ये असलेला कोणताही योगदानकर्ता योगदान देऊ शकतो
### फक्त 3 npm डिपेंडन्सीज
```json
{
  "@netlify/blobs": "^11.0.2",
  "resend": "^6.14.0",
  "web-push": "^3.6.7"
}
```
या तिन्ही फक्त सर्व्हर-साइडवर वापरल्या जातात (Netlify Functions द्वारे). AI फीचर्स `fetch` द्वारे थेट Groq REST API (OpenAI-कम्पॅटिबल) वापरतात — SDK ची गरज नाही. क्लायंटमध्ये शून्य npm डिपेंडन्सीज आहेत — Chart.js आणि Leaflet.js CDN वरून लोड केले जातात.
### सर्व्हरपेक्षा सर्व्हरलेस
###
Netlify Functions मुळे कायमस्वरूपी सर्व्हरची गरज उरत नाही. फायदे:
- शून्य ऑप्सचा भार (सर्व्हर पॅचिंग नाही, स्केलिंग नाही)
- स्वयंचलित HTTPS, CDN आणि एज डिप्लॉयमेंट
