# फ्रंटएंड स्टॅक
## HTML/CSS/JavaScript (व्हॅनिला)
फ्रंटएंड हे व्हॅनिला HTML, CSS आणि JavaScript आहे, ज्यामध्ये कोणतीही बिल्ड स्टेप आणि बंडलर नाही. हे **एकच फाईल नाही**, आणि बऱ्याच काळापासून या पेजवर तसे म्हटले जात होते, ज्यामुळे कुणाची दिशाभूल होऊ शकते: `index.html` मध्ये सुमारे 6,500 ओळी आहेत, `styles.css` मध्ये सुमारे 3,800, `app.js` मध्ये सुमारे 10,200 ओळी आहेत, आणि `panels/` मध्ये 19 पॅनेल फ्रॅगमेंट्स आहेत जे रनटाइमला पेजमध्ये लोड केले जातात.
### त्याची रचना
| फाईल | ती काय आहे |
|---|---|
| `index.html` | सिंगल-पेज ॲप: बार, पॅनेल कंटेनर, आणि पहिल्या पेंटसाठी `styles.css` चा इनलाइन **क्रिटिकल-CSS** सबसेट |
| `styles.css` | डिझाईन सिस्टीम. प्रत्येक टोकन, दोन्ही थीम्स, आणि शेअर केलेले कंपोनंट्स (`.bar`, `.ctl`, `.card`, `.container`) |
| `app.js` | पॅनेल राउटिंग, डेटा फेचिंग, चार्ट्स, रोल आणि लँग्वेज यंत्रणा |
| `js/chrome.js` | थीम प्रेफरन्स आणि SPA नसलेल्या पेजेससाठी एक कट-डाऊन बार |
| `js/air-sources.js` | एका ठिकाणच्या हवेबद्दल काय सांगायचे हे ठरवणारी एकमेव जागा: एक लाईव्ह WAQI स्टेशन, त्यानंतर CPCB चे दैनिक बुलेटिन, आणि मग एक मॉडेल एस्टिमेट, प्रत्येकावर लेबल लावलेले असते |
| `panels/*.html` | `index.html` मध्ये इंजेक्ट केलेले फ्रॅगमेंट्स; ते त्याचे स्टायलिंग इनहेरिट करतात |
| स्टँडअलोन पेजेस | `/pm25/`, `/try.html`, `/docs/`, `/blog/`, `/ask/`, `/bulletins/`, `/delhi/`, वॉकथ्रू, एम्बेड्स, जनरेट केलेले ब्लॉग पोस्ट पेजेस आणि बाकीचे |
**प्रत्येक स्टँडअलोन पेज `styles.css` लोड करते.** `scripts/check-design-system.py` ने 21 नोव्हेंबर 2026 रोजी त्यापैकी 78 मोजल्या (जेव्हा हा नियम आणला गेला तेव्हा 19 होत्या). 2026-09-22 पर्यंत हे खरे नव्हते: प्रत्येकामध्ये एक प्रायव्हेट `<style>` ब्लॉक होता जो त्याच टोकन नावांना फिक्स्ड लाईट-थीम लिटरल्ससह रिडिफाईन करत असे, त्यामुळे टोकन बदलल्यास ते एका पेजवर दिसायचे आणि थीम कंट्रोल फॉलो न करणाऱ्या इतर कोणत्याही पेजवर दिसायचे नाही.
`scripts/check-design-system.py` अशा पेजवर फेल होते जे पुन्हा ड्रॉप आऊट होते.
### बिल्ड स्टेप का नाही
1. **बिल्ड स्टेप नाही** — रेपो हाच डिप्लॉय आर्टिफॅक्ट आहे
2. **योगदानकर्त्यांसाठी सोपे** — `python3 -m http.server` हे संपूर्ण डेव्ह सेटअप आहे
3. **सोर्स आणि आउटपुटमध्ये जुने होण्यासारखे काहीही नाही**
याचा तोटा असा आहे की कॅशे-बस्टिंग (cache-busting) मॅन्युअल करावे लागते. `/styles.css` आणि `/app.js` ची विनंती `package.json` मधील आवृत्तीवरून घेतलेल्या `?v=<stamp>` क्वेरीसह केली जाते, कारण `sw.js` समान-मूळ (same-origin) ॲसेट्स **कोणत्याही रीव्हॅलिडेशनशिवाय कॅशे-फर्स्ट (cache-first with no revalidation)** सर्व्ह करते. दोन गार्ड्स हे एकत्र ठेवतात: `check-asset-stamps.py` (प्रत्येक स्टॅम्प केलेल्या URL सोबत सध्याचा स्टॅम्प असतो) आणि `check-asset-freshness.py` (आवृत्ती स्थिर असताना कोणताही स्टॅम्प केलेला फाइल बदलत नाही). दुसरा गार्ड अस्तित्वात आहे कारण पहिल्याने पास केले होते, तर `app.js` न बदललेल्या URL अंतर्गत बदलले होते.
### CSS आर्किटेक्चर
- **कस्टम प्रॉपर्टीजचे तीन स्तर.** एक कच्चा रॅम्प (`--w-0`…`--w-900` प्रकाशासाठी वॉर्म न्यूट्रल्स, `--d-950`…`--d-50` गडद रंगासाठी), एक सिमेंटिक स्तर जो त्याच्याकडे निर्देश करतो, आणि घटक (components) जे फक्त सिमेंटिक स्तराचा संदर्भ देतात.
- **कोणताही प्रीप्रोसेसर नाही** (Sass, Less, किंवा PostCSS नाही)
- मीडिया क्वेरीजसह **मोबाइल-फर्स्ट** रिस्पॉन्सिव्ह डिझाइन
- **WCAG AA** कॉन्ट्रास्ट, दोन्ही थीम्समधील प्रत्येक पॅनेल आणि प्रत्येक पेजवर Playwright स्वीपद्वारे CI मध्ये नियंत्रित
सिमेंटिक स्तर, ज्याच्या आधारे तुम्ही कोडिंग केले पाहिजे:
```css
:root {
  --bg: var(--paper);          /* the page */
  --bg-section: var(--warm-white);
  --bg-card: var(--w-0);
  --text: var(--ink);
  --text-2: var(--ink-secondary);
  --text-3: var(--ink-tertiary);
  --accent: var(--green-700);
  --border: var(--w-300);
}
[data-theme="dark"] {
  --bg: var(--d-950);
  --bg-section: var(--d-900);
  --bg-card: var(--d-850);
  --text: var(--d-50);
  --accent: #4ADE80;
  --border: var(--d-700);
}
```
यांच्यासोबत इंक टोकन्स — `--ink-red`, `--ink-blue`, `--ink-teal` आणि बाकीचे — देखील आहेत, कारण पांढऱ्या पार्श्वभूमीवर मजकूर म्हणून वाचला जाणारा सॅच्युरेटेड रंग `#0e0e0c` वर मजकूर म्हणून वाचला जात नाही. JavaScript मधील लिटरल म्हणून किंवा `style=` ॲट्रिब्युटमध्ये लिहिलेला रंग कोणत्या थीममध्ये आला हे जाणून घेऊ शकत नाही, त्यामुळे त्याला एक टोकन मिळते आणि CSS फ्लिपिंग करते.
### थीमिंग
`<html>` वर `data-theme="dark"`, जे `js/chrome.js` द्वारे सेट केले जाते आणि `janvayu-theme` अंतर्गत स्टोअर केले जाते. प्रत्येक पेजच्या `<head>` मध्ये एक लहान इनलाइन स्क्रिप्ट असते जी पहिल्या पेंटपूर्वी स्टोअर केलेली व्हॅल्यू लागू करते, त्यामुळे पेज कधीही प्रकाश रंगात पेंट होत नाही आणि नंतर फ्लिप होत नाही. `prefers-color-scheme` ब्लॉक जोडू नका: चार पेजेसमध्ये पूर्वी असा ब्लॉक असायचा, ज्याचा अर्थ असा होता की ते ऑपरेटिंग सिस्टीमचे अनुसरण करत असत आणि साइटच्या स्वतःच्या नियंत्रणाकडे दुर्लक्ष करत असत.
### JavaScript पॅटर्न
- **जास्तीत जास्त ES2022**: `eslint.config.mjs` मध्ये सेट केलेला `ecmaVersion`
- सर्व HTTP कॉल्ससाठी **Fetch API** (axios नाही)
- `document.getElementById` / `querySelector` द्वारे **DOM मॅनिप्युलेशन**
- **कोणताही मॉड्यूल बंडलर नाही** — सर्व JS `<script>` टॅग्समध्ये आहे
- `waqi-proxy` फंक्शनद्वारे फेच केलेल्या लाईव्ह AQI डेटासाठी **10-मिनिटांचा ऑटो-रिफ्रेश**

## Chart.js
**आवृत्ती:** पिन केलेली 4.x (4.5.1), SRI सह jsDelivr वरून लोड केलेली आणि लेझी-लोड केलेली
**यासाठी वापरले जाते:**
- मेट्रो विरुद्ध प्रादेशिक AQI तुलना बार चार्ट्स
- PM2.5 ट्रेंड लाईन्स
- हेल्थ इम्पॅक्ट डेटा व्हिज्युअलायझेशन्स
- हंगामी बेसलाईन तुलना
**Chart.js का:**
- लहान आकार (~70 KB gzipped, ~60 KB Brotli)
- बिल्ड स्टेपशिवाय काम करते (CDN स्क्रिप्ट टॅग)
- कॅनव्हास-आधारित रेंडरिंग (मोबाईलवर उत्तम परफॉर्मन्स)
- अंगभूत रिस्पॉन्सिव्ह/अॅक्सेसिबिलिटी फीचर्स

## Leaflet.js + OpenStreetMap
**आवृत्ती:** 1.9.4, SRI सह unpkg वरून लोड केलेली
**यासाठी वापरले जाते:**
- AQI स्टेशन मार्कर्ससह 160 शहरांचा इंटरअॅक्टिव्ह नकाशा (157 भारतीय, तसेच बीजिंग, लंडन आणि सिंगापूर)
- AQI तीव्रतेनुसार कलर-कोडेड मार्कर्स (हिरवे/पिवळे/नारंगी/लाल/जांभळे)
- स्टेशनचे तपशील पाहण्यासाठी क्लिक करा
**Leaflet + OSM का:**
- मोफत आणि ओपन सोर्स (Google Maps API की ची गरज नाही)
- हलके (~40 KB gzipped)
- OpenStreetMap डेटा मोफत आहे, परंतु त्याचे टायल सर्व्हर्स बेस्ट-एफर्ट आणि पॉलिसी-मर्यादित आहेत ([वापर धोरण](https://operations.osmfoundation.org/policies/tiles/)); जास्त वापरासाठी व्यावसायिक किंवा सेल्फ-होस्टेड टायल सोर्सची आवश्यकता असते. साइट Carto बेसमॅप टायल्स देखील वापरते
