# परवाना

JanVayu दोन परवाने वापरते, एक त्याच्या कोडसाठी आणि एक त्याच्या कंटेंटसाठी.

## कोड: MIT परवाना

या रिपॉझिटरीमधील सर्व सोर्स कोड (HTML, CSS, JavaScript आणि सर्व्हर फंक्शन्स) **MIT License** अंतर्गत परवानाकृत आहे.

तुम्हाला खालील गोष्टी करण्याचे स्वातंत्र्य आहे:
- व्यावसायिक कारणांसह कोणत्याही उद्देशासाठी कोड वापरणे
- कोडमध्ये बदल करणे आणि तो वितरित करणे
- तो इतर प्रकल्पांमध्ये समाविष्ट करणे

यासाठी फक्त एकच अट आहे की कॉपीराइट नोटीस तशीच ठेवणे.
