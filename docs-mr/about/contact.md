## सुरक्षेची समस्या नोंदवणे

जर तुम्हाला सुरक्षेतील त्रुटी आढळली असेल, तर **सार्वजनिक GitHub Issue उघडू नका**. त्याऐवजी, [SECURITY.md](https://github.com/JanVayu/JanVayu/blob/main/SECURITY.md) मध्ये वर्णन केलेल्या जबाबदार प्रकटीकरण प्रक्रियेचे (responsible disclosure process) पालन करा.

## मीडिया आणि संशोधनासाठी चौकशी

पत्रकार, संशोधक आणि धोरणकर्त्यांना JanVayu चा डेटा आणि विश्लेषण वापरण्यासाठी स्वागत आहे. कृपया:

1. विशिष्ट आकडेवारीसाठी JanVayu ऐवजी मूळ स्रोत (CPCB, Lancet, इ.) उद्धृत करा
2. एकत्रित डेटा तुम्हाला ज्या प्लॅटफॉर्मवर सापडला त्याचे नाव JanVayu असे द्या
3. सानुकूल विश्लेषण किंवा डेटा विनंतीसाठी, GitHub Issue उघडा किंवा [contribute@janvayu.in](mailto:contribute@janvayu.in) वर ईमेल करा
