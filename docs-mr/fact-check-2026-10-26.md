WAQI API टोकन `app.js`, आठ Netlify फंक्शन्स, README आणि डॉक्युमेंटेशनमध्ये लिहिलेले होते. `app.js` मध्ये ते प्रत्येक ब्राउझरपर्यंत पोहोचले, त्यामुळे कोणीही प्लॅटफॉर्मचा WAQI कोटा वापरू शकत होते. आता ते Netlify व्हेरिएबल `WAQI_TOKEN` आहे, जे फक्त फंक्शन्सद्वारे वाचले जाते, आणि ब्राउझर `/.netlify/functions/waqi-proxy` ला कॉल करतो ( #434 मध्ये मर्ज केले, 27 ऑक्टोबर 2026 रोजी 26.6.246 आवृत्ती म्हणून लाईव्ह). लाईव्ह साईटवर मोजले: होम पेजने `api.waqi.info` ला कोणतीही रिक्वेस्ट केली नाही आणि प्रॉक्सीला 34, सर्वांना 200 उत्तर आले. CI मधील एक चेक (`scripts/check-no-waqi-token.py`) फेल होतो जर लिटरल टोकन परत आले.

जुने टोकन रद्द केलेले नाही. ते git हिस्ट्रीमध्ये आणि जुन्या `app.js` च्या कॅशे केलेल्या प्रतींमध्ये वाचता येण्याजोगे राहते. फक्त एक नवीन टोकनच ते बंद करू शकते: aqicn.org/data-platform/token वरून एक रिक्वेस्ट करा, ते Netlify मध्ये `WAQI_TOKEN` म्हणून सेट करा आणि व्हेरिएबल सिक्रेट म्हणून मार्क करा.
