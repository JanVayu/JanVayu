# आर्किटेक्चर

JanVayu हे एक **झिरो-फ्रेमवर्क, सिंगल-पेज ॲप्लिकेशन** आहे. हे Netlify वर डिप्लॉय केले आहे, ज्यामध्ये डेटा प्रॉक्सींग, कॅशिंग आणि शेड्यूल्ड टास्कसाठी सर्व्हर-साइड सर्व्हरलेस फंक्शन्स वापरले आहेत.

## प्रमुख डिझाइन निर्णय


---
### स्टॅटिक फ्रंट-एंड, नो बंडलर
फ्रंट-एंडमध्ये `index.html` सोबत `styles.css`, `app.js`, `games.js` आणि `panels/` मधील 19 लेझी-लोडेड पॅनेल फ्रॅगमेंट्स आहेत. यात कोणताही बंडलर किंवा फ्रेमवर्क नाही (पहा [Frontend Stack](../tech-stack/frontend.md)). यामुळे बेसिक HTML/JS स्किल्स असलेल्या कॉन्ट्रिब्युटर्सना कोडबेस समजणे सोपे जाते आणि बिल्ड-टाइमची गुंतागुंत जवळजवळ शून्य राहते.

### सर्व्हर-साइड प्रॉक्सींग
CORS समस्या टाळण्यासाठी आणि API कीज सुरक्षित ठेवण्यासाठी सोशल मीडिया आणि न्यूज APIs Netlify Functions द्वारे फेच केले जातात. क्लायंट या APIs ला थेट कधीही स्पर्श करत नाही.

### ब्लॉब कॅशिंग
`scheduled-fetch.mjs` फंक्शन दर 4 तासांनी रन होते आणि फीड डेटा (Reddit, न्यूज; Instagram चा प्रयत्न केला जातो पण सहसा काहीही मिळत नाही) Netlify Blobs मध्ये सेव्ह करते. जेव्हा युजर्स फीड्सची रिक्वेस्ट करतात, तेव्हा ऑन-डिमांड फंक्शन्स कॅशेमधून लगेच सर्व्ह करतात — यामुळे लेटन्सी आणि API रेट लिमिट्सचा प्रश्नच उरत नाही.

### क्लायंट-साइड AQI
WAQI API ला दर 10 मिनिटांनी थेट ब्राउझरमधून कॉल केले जाते. हा टोकन WAQI द्वारे त्यांच्या terms of service अंतर्गत इश्यू केला जातो आणि तो क्लायंट कोडमध्ये दिसतो. याचा अर्थ रिअल-टाइम AQI डेटा कोणत्याही सर्व्हर-साइड इन्फ्रास्ट्रक्चरशिवाय काम करतो.

### नो फ्रेमवर्क, नो बिल्ड स्टेप
यात `npm run build`, Webpack किंवा React नाही. एकमेव बिल्ड कमांड `node scripts/bump-version.mjs` आहे, जी व्हर्जन स्टॅम्प करते आणि डिप्लॉय आर्टिफॅक्ट अन्यथा रिपॉझिटरी स्वतःच असते. Netlify रूटमधून `index.html` सर्व्ह करते.

## ऑटो-अपडेट शेड्युल

| टास्क | फ्रिक्वेन्सी | फंक्शन |
|------|-----------|----------|
| सोशल/न्यूज फीड रिफ्रेश | दर 4 तासांनी | `scheduled-fetch.mjs` |
| डेली AQI ईमेल डायजेस्ट | रोज सकाळी 8:00 वाजता IST | `daily-digest.mjs` |
| लाइव्ह AQI डॅशबोर्ड | दर 10 मिनिटांनी | क्लायंट-साइड JS (WAQI API) |
| अ‍ॅनोमली डिटेक्शन | ऑन-डिमांड | `anomaly-check.mjs` |
| अपटाइम आणि फंक्शन हेल्थ चेक्स | दर 15 मिनिटांनी | `health-monitor.mjs` |
| वेब पुश नोटिफिकेशन्स | दर 3 तासांनी | `push-send.mjs` |
| फीड हेल्थ चेक | डेली | `feed-health.mjs` |

## फाइल स्ट्रक्चर
```
JanVayu/
├── index.html                    # SPA शेल (styles.css, app.js, games.js, panels/ सोबत)
├── favicon.svg
├── package.json                  # Node.js डिपेंडन्सीज (Netlify Blobs, Resend, web-push)
├── netlify.toml                  # बिल्ड आणि डिप्लॉय कॉन्फिगरेशन
├── CNAME                         # कस्टम डोमेन
├── docs/                         # हे डॉक्युमेंटेशन (Docsify)
├── downloads/                    # डाउनलोड करण्यायोग्य रिपोर्ट्स (PDF, PPTX, DOCX)
└── netlify/
    └── functions/
        ├── scheduled-fetch.mjs   # क्रॉन: सर्व फीड्स, दर 4 तासांनी
        ├── daily-digest.mjs      # क्रॉन: ईमेल डायजेस्ट, सकाळी 8 वाजता IST
        ├── reddit-feed.js        # API: कॅश केलेले Reddit पोस्ट्स
        ├── twitter-feed.js       # API: बंद केले आहे — Nitter वापरा, ज्याचे पब्लिक इन्स्टन्सेस आता उपलब्ध नाहीत
        ├── news-proxy.js         # API: कॅश केलेले न्यूज आर्टिकल्स
        ├── instagram-feed.js     # API: कॅश केलेले Instagram पोस्ट्स
        ├── feed-status.js        # API: फीड फ्रेशनेस हेल्थ चेक
        ├── subscribe.js          # API: ईमेल सबस्क्रिप्शन मॅनेजमेंट
        ├── blob-store.js         # शेअर्ड: Blobs स्टोअर हेल्पर
        ├── air-query.mjs         # AI: नॅचरल लँग्वेज AQI क्वेरीज
        ├── health-advisory.mjs   # AI: पर्सनलाइज्ड हेल्थ सल्ले
        ├── accountability-brief.mjs  # AI: वॉर्ड-लेव्हल अकाउंटेबिलिटी ब्रीफ्स
        └── anomaly-check.mjs     # AI: PM2.5 स्पाइक डिटेक्शन
```

ही यादी सर्वसमावेशक नाही: `netlify/functions/` मध्ये 28 फंक्शन फाइल्स आणि शेअर्ड `lib/` (उदाहरणार्थ `waqi-proxy`, `rankings`, `data-api`, `push-send`, `fire-tracker` आणि `terra-collab`) आहेत.
