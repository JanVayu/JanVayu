# नवीन भूमिका जोडणे

भूमिका प्रणाली `index.html` मधील `ROLE_CONFIG` जावास्क्रिप्ट ऑब्जेक्टमध्ये कॉन्फिगर केलेली आहे.

---

## टप्प्याटप्प्याने

### 1. ROLE_CONFIG मध्ये जोडा

```javascript
const ROLE_CONFIG = {
    yourRole: {
        icon: '<span class="si si-icon-name"></span>',
        label: 'भूमिकेचे प्रदर्शन नाव',
        heading: 'डॅशबोर्डसाठी एक लहान, आकर्षक शीर्षक',
        description: 'या भूमिकेला काय मिळते याबद्दल एक वाक्य.',
        actions: [
            {
                icon: '<span class="si si-icon"></span>',
                panel: 'panel-id',
                title: 'अॅक्शन कार्डचे शीर्षक',
                desc: 'वापरकर्त्याला काय दिसेल.',
                cta: 'कृती मजकूर'
            },
            // एकूण 3 कृती
        ],
        panels: [
            { panel: 'panel-id', title: 'पॅनेलचे नाव', desc: 'लहान वर्णन' },
            // 6 सुचवलेली पॅनेल्स
        ]
    }
};
```

### 2. HTML मध्ये बदल करण्याची गरज नाही

हेडरमधील रोल स्विच `#rolePopoverGrid` मध्ये `ROLE_CONFIG` वरून तयार केले जाते, त्यामुळे तिथे नवीन की आपोआप दिसते. जुना फुल-स्क्रीन रोल ओव्हरले आणि त्याचे `role-card` मार्कअप आता अस्तित्वात नाही.

### 3. ट्रान्सलेशन कीज जोडा (पर्यायी)

ट्रान्सलेशन JSON मध्ये `data-i18n` कीज आणि संबंधित नोंदी जोडा.

---

## मार्गदर्शक तत्त्वे

- **3 कृती** — ही भूमिका करू शकणाऱ्या 3 सर्वात प्रभावी गोष्टी निवडा
- **6 पॅनेल्स** — सर्वात संबंधित पॅनेल्स सुचवा
- **शीर्षक** — कृती करण्यायोग्य आणि सक्षम करणारे असावे
- **वर्णन** — एक वाक्य, ठोस, साधने/डेटाचा उल्लेख असावा
- **आयकॉन** — [Sargam Icons](https://sargamicons.com/) मधून निवडा
