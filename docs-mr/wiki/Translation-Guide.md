# भाषांतर मार्गदर्शक

JanVayu ५ भाषांना सपोर्ट करते: इंग्रजी, हिंदी, तमिळ, मराठी आणि बंगाली.

---

## भाषांतर कसे काम करते

### UI मजकूर (data-i18n)

```html
<span data-i18n="tagline">नागरिक वायू गुणवत्ता प्लॅटफॉर्म</span>
```

भाषांतरे एका JavaScript ऑब्जेक्टमध्ये साठवली जातात आणि `setLanguage()` द्वारे लागू केली जातात.

### डॉक्युमेंटेशन

भाषांतरीत डॉक्स भाषा-विशिष्ट डिरेक्टरीजमध्ये असतात:
- `docs/` — इंग्रजी (बेस)
- `docs-hi/` — हिंदी
- `docs-ta/` — तमिळ
- `docs-mr/` — मराठी
- `docs-bn/` — बंगाली

### सोपी भाषा (data-simple)

सध्या फक्त इंग्रजी. भविष्यात: `data-simple-hi`, `data-simple-ta`, इत्यादी.

---

## भाषांतरासाठी योगदान

### पर्याय १: UI स्ट्रिंग्स भाषांतरीत करा

१. `index.html` मध्ये `data-i18n` असलेले एलिमेंट्स शोधा
२. भाषा ऑब्जेक्टमध्ये भाषांतरीत स्ट्रिंग जोडा
३. हेडरमध्ये भाषा बदलून टेस्ट करा

### पर्याय २: डॉक्युमेंटेशन भाषांतरीत करा

१. `docs/` मधून तुमच्या भाषेच्या डिरेक्टरीमध्ये नसलेली फाईल निवडा
२. `docs-{lang}/` मध्ये समान फाईल तयार करा
३. समान रचना ठेवून भाषांतर करा
४. PR सबमिट करा

### पर्याय ३: सोप्या भाषेतील मजकूर भाषांतरीत करा

१. `data-simple` ॲट्रिब्युट्स असलेले एलिमेंट्स शोधा
२. तुमच्या भाषेत भाषांतर करा

---

## भाषांतर CI

`translations.yml` GitHub Action तपासते:
- प्रत्येक भाषेच्या डिरेक्टरीमध्ये कोणत्या फाईल्स आहेत
- प्रत्येक भाषेचे कव्हरेज टक्केवारी
- CI आउटपुटमध्ये नोंदवलेल्या गहाळ फाईल्स

---

## मार्गदर्शक तत्त्वे

- भाषांतरे नैसर्गिक ठेवा — शब्दशः भाषांतर करू नका
- वायू गुणवत्तेशी संबंधित संज्ञा (PM2.5, AQI, NCAP) इंग्रजीतच राहू शकतात
- योग्य असेल तिथे स्क्रिप्टचे स्वतःचे अंक वापरा
- मोबाईलवर टेस्ट करा — काही स्क्रिप्ट्सना अधिक आडव्या जागेची आवश्यकता असते
- टोन जुळवा: तातडीचा पण घाबरवणारा नाही, तांत्रिक पण समजण्यासारखा
