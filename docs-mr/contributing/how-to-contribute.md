# योगदान कसे द्यावे

भारतातील वायू प्रदूषणाची समस्या सर्वसमावेशकपणे मांडण्यासाठी JanVayu ला समाजाच्या सहभागाची गरज आहे. संशोधक, पत्रकार, डेव्हलपर्स आणि नागरिक अशा सर्वांचेच योगदान स्वागतार्ह आहे.

---

## योगदानाचे प्रकार

### संशोधक
- वायू प्रदूषणाच्या आरोग्यावरील परिणामांबद्दल डेटासेट आणि पेपर्स शेअर करणे
- सध्याच्या माहितीची पडताळणी आणि फॅक्ट-चेकिंगमध्ये मदत करणे
- विश्लेषण आणि व्हिज्युअलायझेशनमध्ये योगदान देणे
- संशोधनाचे सारांश भारतीय भाषांमध्ये भाषांतरित करणे

### पत्रकार
- पडताळणी केलेले तपास अहवाल शेअर करणे
- स्थानिक वायू प्रदूषणाच्या बातम्यांची नोंद करणे
- महत्त्वाच्या मीडिया कव्हरेजचा संग्रह तयार करणे
- अकाउंटेबिलिटी ट्रॅकरमध्ये योगदान देणे

### डेव्हलपर्स
- बग्स नोंदवणे आणि सुधारणा सुचवणे
- कोड फिक्स आणि नवीन फीचर्समध्ये योगदान देणे
- डेटा व्हिज्युअलायझेशन टूल्स तयार करणे
- ॲक्सेसिबिलिटी आणि परफॉर्मन्स सुधारणे

### नागरिक
- प्रत्यक्ष अनुभव शेअर करणे (हवे असल्यास निनावी)
- स्थानिक वायू प्रदूषणाच्या परिस्थितीची नोंद करणे
- प्रादेशिक भाषांमध्ये मजकूर भाषांतरित करण्यात मदत करणे
- जागरूकता पसरवणे

### डिझायनर्स
- व्हिज्युअल ॲक्सेसिबिलिटी सुधारणे
- इन्फोग्राफिक्स आणि शैक्षणिक साहित्य तयार करणे
- UI/UX सुधारणांमध्ये मदत करणे

---

## कोड योगदानासाठी

```bash
# 1. रिपॉझिटरी फोर्क करा
# 2. तुमची फोर्क क्लोन करा
git clone https://github.com/YOUR_USERNAME/JanVayu.git
cd JanVayu

# 3. एक ब्रांच तयार करा
git checkout -b feature/your-feature-name

# 4. तुमचे बदल करा आणि लोकली टेस्ट करा
netlify dev

# 5. स्पष्ट मेसेजसह कमिट करा
git commit -m "Add: PM10 toggle on city cards"

# 6. पुश करा आणि पुल रिक्वेस्ट ओपन करा
git push origin feature/your-feature-name
```

[github.com/JanVayu/JanVayu](https://github.com/JanVayu/JanVayu) वरील `main` ब्रांचवर तुमची PR ओपन करा.

---

## मजकूर योगदानासाठी

1. तुम्हाला काय योगदान द्यायचे आहे हे सांगण्यासाठी GitHub वर **एक Issue ओपन करा**
2. **सोर्स द्या** — सर्व मजकूर URL किंवा डॉक्युमेंटच्या मदतीने पडताळता येण्याजोगा असावा
3. **संदर्भ द्या** — हे JanVayu च्या संग्रहासाठी का महत्त्वाचे आहे ते स्पष्ट करा
4. जर मंजूर झाले, तर एक मेंटेनर ते जोडण्यासाठी तुम्हाला मार्गदर्शन करेल

---

## डेटा योगदानासाठी

- डेटा एका अधिकृत, पडताळता येण्याजोग्या स्रोताकडून आला आहे याची खात्री करा
- स्पष्ट श्रेय (attribution) आणि लायसन्सिंग माहिती द्या
- लागू असल्यास, पद्धतीचे (methodology) डॉक्युमेंटेशन समाविष्ट करा
- शक्य असेल तिथे RTI चे प्रतिसाद किंवा मूळ कागदपत्रे जोडा
