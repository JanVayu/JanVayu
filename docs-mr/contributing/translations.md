# भाषांतरे

भारतातील भाषिक विविधतेमध्ये सर्वांना सुलभता उपलब्ध करून देण्यास JanVayu वचनबद्ध आहे. ही प्लॅटफॉर्म सध्या इंग्रजी, हिंदी, तमिळ, मराठी आणि बंगाली भाषांना सपोर्ट करते. या पाचही भाषांमध्ये इंटरफेसचे पूर्ण भाषांतर केले आहे; तर डॉक्युमेंटेशनचे अंशतः भाषांतर केले आहे (प्रत्येक भाषांतरित ट्रीमध्ये ६५ पैकी ४७ पानांचे भाषांतर).

| भाषा | कोड | इंटरफेस स्थिती |
|----------|------|--------|
| इंग्रजी | `en` | पूर्ण |
| हिंदी (हिन्दी) | `hi` | पूर्ण |

| बंगाली (বাংলা) | `bn` | पूर्ण |

## भाषांतरात योगदान कसे द्यावे

### नवीन भाषा जोडणे

1. खालील शीर्षकासह एक Issue उघडा: `Translation: Add [Language Name] support`
2. यात खालील गोष्टी समाविष्ट करा:
   - तुमचे नाव (किंवा हँडल) आणि भाषेवरील प्रभुत्व
   - आशय अपडेट होत असताना भाषांतरे टिकवून ठेवण्यासाठी तुम्ही वेळ देऊ शकता का
3. एक मेंटेनर एक ब्रांच तयार करेल आणि भाषांतरासाठी सोर्स स्ट्रिंग्स देईल

### अस्तित्वात असलेल्या भाषांतरात सुधारणा करणे

जर तुम्हाला एखादे चुकीचे किंवा विचित्र भाषांतर दिसले:

1. खालीलप्रमाणे एक Issue उघडा: `Translation: Fix [Language Name] — [specific section/string]`
2. खालील गोष्टी द्या: सध्याचा मजकूर, दुरुस्त केलेला मजकूर आणि थोडक्यात स्पष्टीकरण

---

## भाषांतराची तत्त्वे

- **शाब्दिकतेपेक्षा अचूकता** — शब्दाशः भाषांतर करण्याऐवजी नैसर्गिक भाषेत योग्य अर्थ व्यक्त करा
- **तांत्रिक संज्ञा जतन करा** — PM2.5, AQI, NCAP, GEMM यांसारख्या संज्ञा तशाच राहिल्या पाहिजेत (त्या आंतरराष्ट्रीय स्तरावर प्रमाणित आहेत)
- **साधी भाषा वापरा** — भाषांतरे इंग्रजी आवृत्तीच्या वाचकांप्रमाणेच सामान्य लोकांसाठी समजण्यासारखी असावीत: सुशिक्षित सामान्य जनता, तज्ज्ञ नाही
- **सातत्य** — संपूर्ण डॉक्युमेंटमध्ये एकाच संकल्पनेसाठी एकच भाषांतरित शब्द वापरा (उदा. "air quality index" चे नेहमी एकाच प्रकारे भाषांतर करा)
- **तटस्थ टोन** — JanVayu हे बिगर-पक्षपाती आहे; भाषांतरांमध्ये ही तटस्थता टिकून राहिली पाहिजे

## संवेदनशील संज्ञा

| इंग्रजी | नोट्स |
|---------|-------|
| Non-Attainment City | ज्या शहराने राष्ट्रीय हवा गुणवत्ता मानके "प्राप्त" केली नाहीत (अपूर्णा राहिली आहेत) असे शहर म्हणून भाषांतर करा |
| Graded Response Action Plan (GRAP) | GRAP हे संक्षिप्त रूप वापरा; पहिल्यांदा वापरताना पूर्ण नाव लिहा |
| PM2.5 | सर्व भाषांमध्ये PM2.5 असेच ठेवा |
| NCAP | NCAP असेच ठेवा; पहिल्यांदा वापरताना National Clean Air Programme असे पूर्ण लिहा |
| CPCB | CPCB असेच ठेवा; पहिल्यांदा वापरताना Central Pollution Control Board असे पूर्ण लिहा |

## लाईव्ह अनुवादित डॉक्युमेंटेशन
प्रत्येक भाषा रिपॉझिटरीमधील `docs-{lang}/` डिरेक्टरीमध्ये असते आणि `/docs/` वरील एकाच Docsify शेलद्वारे सर्व्ह केली जाते, जे हॅश राऊट्सद्वारे भाषा-विशिष्ट आशय राऊट करते.

| भाषा | लाईव्ह URL | सोर्स डिरेक्टरी |
|----------|----------|------------------|
| English | [/docs/](/docs/) | `docs/` |
| Hindi | [/docs/#/hi/](/docs/#/hi/) | `docs-hi/` |
| Bengali | [/docs/#/bn/](/docs/#/bn/) | `docs-bn/` |
| Marathi | [/docs/#/mr/](/docs/#/mr/) | `docs-mr/` |
| Tamil | [/docs/#/ta/](/docs/#/ta/) | `docs-ta/` |

अनुवादित डॉक्स `.github/workflows/translations.yml` मधील `auto-translate` जॉबद्वारे रिफ्रेश केले जातात (यासाठी Sarvam API की आवश्यक आहे) आणि ते English डॉक्सच्या तुलनेत मागे असू शकतात.

## CI: Translation Coverage

प्रत्येक पुशवर जे डॉक्सला स्पर्श करते, तेव्हा एक GitHub Actions वर्कफ्लो (`.github/workflows/translations.yml`) `main` वर रन होतो. तो खालील गोष्टी तपासतो:

- **फाइल कव्हरेज** — सर्व English डॉक्स प्रत्येक भाषेत मिरर केले आहेत का?
- **SUMMARY.md पॅरिटी** — सर्व भाषांमध्ये पेजची संख्या समान आहे का?
- **स्टेल डिटेक्शन** — जेव्हा एखादे English डॉक बदलते, तेव्हा कोणते ट्रान्सलेशन्स अपडेट केले गेले नाहीत?

निकाल प्रत्येक रनसाठी GitHub Actions **Job Summary** टॅबमध्ये दिसतात.

## डिरेक्टरी स्ट्रक्चर

प्रत्येक ट्रान्सलेशन डिरेक्टरी English `docs/` स्ट्रक्चरला मिरर करते, फक्त `api/` आणि `wiki/` हे English-only आहेत:

```
docs-{lang}/
├── README.md
├── SUMMARY.md
├── about/
├── claude-code/
├── contributing/
├── data-sources/
├── skills/
├── tech-stack/
├── technical/
└── user-guide/
```

जेव्हा एखादे नवीन English डॉक जोडले जाते, तेव्हा सर्व ट्रान्सलेशन डिरेक्टरीमध्ये संबंधित फाइल तयार करा (जरी ती सुरुवातीला English मध्ये असली तरी — ती नंतर ट्रान्सलेट केली जाऊ शकते).
