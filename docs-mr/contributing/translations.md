# भाषांतरे

भारतातील भाषिक विविधतेमध्ये सर्वांना माहिती सहज उपलब्ध करून देण्यास JanVayu वचनबद्ध आहे. सध्या हे प्लॅटफॉर्म इंग्रजी, हिंदी, तमिळ, मराठी आणि बंगाली भाषांना सपोर्ट करते. या पाचही भाषांमध्ये इंटरफेसचे संपूर्ण भाषांतर केले आहे; तर डॉक्युमेंटेशनचे काही अंशतः भाषांतर झाले आहे (प्रत्येक भाषांतरित ट्रीमध्ये ६५ पैकी ४७ पाने).

---

## सध्या सपोर्ट असलेल्या भाषा

| भाषा | कोड | इंटरफेस स्थिती |
|----------|------|--------|
| इंग्रजी | `en` | पूर्ण |
| हिंदी (हिन्दी) | `hi` | पूर्ण |
| तमिळ (தமிழ்) | `ta` | पूर्ण |
| मराठी (मराठी) | `mr` | पूर्ण |
| बंगाली (বাংলা) | `bn` | पूर्ण |

---

## भाषांतरासाठी योगदान कसे द्यावे

### नवीन भाषा जोडणे

1. `Translation: Add [Language Name] support` या शीर्षकासह एक Issue उघडा
2. त्यात खालील गोष्टी समाविष्ट करा:
   - तुमचे नाव (किंवा हँडल) आणि भाषेवरील प्रभुत्व
   - आशय अद्ययावत होताना भाषांतरे टिकवून ठेवण्यासाठी तुम्ही नियमितपणे वेळ देऊ शकाल का
3. एक मेंटेनर एक ब्रांच तयार करेल आणि भाषांतरासाठी सोर्स स्ट्रिंग्स देईल

### विद्यमान भाषांतरात सुधारणा करणे

जर तुम्हाला एखादे चुकीचे किंवा विचित्र भाषांतर आढळले:

1. `Translation: Fix [Language Name] — [specific section/string]` यासह एक Issue उघडा
2. सध्याचा मजकूर, दुरुस्त केलेला मजकूर आणि थोडक्यात स्पष्टीकरण द्या

---

## भाषांतराची तत्त्वे

- **शब्दशः भाषांतरापेक्षा अचूकतेला प्राधान्य** — शब्दाला शब्द न जोडता, नैसर्गिक भाषेत योग्य अर्थ व्यक्त करा
- **तांत्रिक संज्ञा तशाच ठेवा** — PM2.5, AQI, NCAP, GEMM यांसारख्या संज्ञा जशाच्या तशा राहिल्या पाहिजेत (त्या आंतरराष्ट्रीय स्तरावर प्रमाणित आहेत)
- **साधी भाषा वापरा** — भाषांतरे इंग्रजी आवृत्तीच्या वाचकांना समजतील अशी असावीत: सुशिक्षित सामान्य जनता, तज्ज्ञ नाही
- **सातत्य** — एकाच संकल्पनेसाठी संपूर्ण डॉक्युमेंटमध्ये समान भाषांतरित संज्ञा वापरा (उदा. "air quality index" चे नेहमी एकाच प्रकारे भाषांतर करा)
- **तोच सूर** — भाषांतरांमध्ये कोणत्याही पक्षाचे समर्थन किंवा विरोध न करण्याचे इंग्रजी मजकुराचे धोरण कायम ठेवले पाहिजे

## संवेदनशील संज्ञा

| इंग्रजी | नोंदी |
|---------|-------|
| Non-Attainment City | राष्ट्रीय वायू गुणवत्ता मानके "प्राप्त न केलेले" (पूर्ती करण्यात अपयशी ठरलेले) शहर म्हणून भाषांतर करा |
| Graded Response Action Plan (GRAP) | GRAP हे संक्षिप्त रूप वापरा; पहिल्यांदा वापरताना पूर्ण नाव लिहा |
| PM2.5 | सर्व भाषांमध्ये PM2.5 असेच ठेवा |
| NCAP | NCAP असेच ठेवा; पहिल्यांदा वापरताना National Clean Air Programme असे पूर्ण लिहा |
| CPCB | CPCB असेच ठेवा; पहिल्यांदा वापरताना Central Pollution Control Board असे पूर्ण लिहा |

## लाईव्ह भाषांतरित डॉक्युमेंटेशन
प्रत्येक भाषा रेपोमधील `docs-{lang}/` डिरेक्टरीमध्ये असते आणि `/docs/` वरील एकाच Docsify शेलद्वारे सर्व्ह केली जाते, जे हॅश राउट्सद्वारे भाषेनुसार विशिष्ट आशय राउट करते.

| भाषा | लाईव्ह URL | सोर्स डिरेक्टरी |
|----------|----------|------------------|
| इंग्रजी | [/docs/](/docs/) | `docs/` |
| हिंदी | [/docs/#/hi/](/docs/#/hi/) | `docs-hi/` |
| बंगाली | [/docs/#/bn/](/docs/#/bn/) | `docs-bn/` |
| मराठी | [/docs/#/mr/](/docs/#/mr/) | `docs-mr/` |
| तमिळ | [/docs/#/ta/](/docs/#/ta/) | `docs-ta/` |

अनुवादित डॉक्स `.github/workflows/translations.yml` मधील `auto-translate` जॉबद्वारे रिफ्रेश केले जातात (यासाठी Sarvam API key आवश्यक आहे) आणि ते इंग्रजी डॉक्सच्या तुलनेत मागे राहू शकतात.

## CI: ट्रान्सलेशन कव्हरेज

`docs` मध्ये बदल करणारा प्रत्येक पुश `main` वर आल्यावर एक GitHub Actions वर्कफ्लो (`.github/workflows/translations.yml`) चालतो. तो खालील गोष्टी तपासतो:

- **फाईल कव्हरेज** — सर्व इंग्रजी डॉक्स प्रत्येक भाषेत मिरर केले आहेत का?
- **SUMMARY.md पॅरिटी** — सर्व भाषांमध्ये पृष्ठांची संख्या समान आहे का?
- **स्टेल डिटेक्शन** — जेव्हा एखादा इंग्रजी डॉक बदलतो, तेव्हा कोणते ट्रान्सलेशन्स अपडेट केले गेले नाहीत?

निकाल प्रत्येक रनसाठी GitHub Actions **Job Summary** टॅबमध्ये दिसतात.

---

## डिरेक्टरी स्ट्रक्चर

प्रत्येक ट्रान्सलेशन डिरेक्टरी इंग्रजी `docs/` स्ट्रक्चरची प्रतिकृती असते, फक्त `api/` आणि `wiki/` इंग्रजी-केवळ आहेत:

```
docs-{lang}/
├── README.md
├── SUMMARY.md
├── about/
├── claude-code/
├── contributing/
├── data-sources/
├── skills/
├── tech-stack/
├── technical/
└── user-guide/
```

नवीन इंग्रजी डॉक जोडताना, सर्व ट्रान्सलेशन डिरेक्टरीमध्ये संबंधित फाईल तयार करा (जरी ती सुरुवातीला इंग्रजीत असली तरी — तिचे नंतर भाषांतर केले जाऊ शकते).
