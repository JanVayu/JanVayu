# स्किल्स आणि AI प्रॉम्प्ट्स

हा विभाग JanVayu तयार करण्यासाठी आणि चालवण्यासाठी वापरल्या जाणाऱ्या AI स्किल फाइल्स — सिस्टीम प्रॉम्प्ट्स, सूचनांचे पॅटर्न आणि प्रॉम्प्ट इंजिनिअरिंगचे निर्णय — यांची माहिती देतो.

या केवळ अमूर्त मार्गदर्शक तत्त्वे नाहीत. हेल्थ ॲडव्हायझरी, अकाउंटेबिलिटी ब्रीफ आणि ॲनोमली-चेक प्रॉम्प्ट्स जसे कोडबेसमध्ये आहेत तसेच येथे दिले आहेत; Ask JanVayu प्रॉम्प्ट खूप मोठा आहे आणि त्याचा सारांश दिला आहे. या पानांवर डेव्हलपमेंट दरम्यान वापरल्या गेलेल्या व्यापक प्रॉम्प्टिंग दृष्टिकोनाचेही वर्णन केले आहे. जर तुम्ही दुसऱ्या शहरासाठी किंवा दुसऱ्या पर्यावरणीय क्षेत्रासाठी JanVayu फोर्क करत असाल, तर येथून सुरुवात करा.

## स्किल फाइल म्हणजे काय?

स्किल फाइल हा एक स्ट्रक्चर्ड सिस्टीम प्रॉम्प्ट असतो जो AI मॉडेलला विशिष्ट संदर्भात कसे वागावे हे सांगतो. "हवेच्या गुणवत्तेबद्दल प्रश्नांची उत्तरे द्या" असा जेनेरिक प्रॉम्प्ट लिहिण्याऐवजी, स्किल फाइल खालील गोष्टी ठरवते:

- मॉडेलची **भूमिका आणि व्यक्तिमत्त्व (role and persona)**
- संदर्भासाठी त्याला मिळणारा **डेटा**
- त्याने पाळायचा **आउटपुट फॉरमॅट**
- टोन, लांबी आणि दाव्यांवरील **मर्यादा**
- टाळायचे **फेल्युअर मोड्स (failure modes)**

JanVayu सर्व चार Groq-पॉवर्ड फीचर्ससाठी स्किल फाइल्स वापरते.

> **अपडेट, २ ऑक्टोबर २०२६:** हे पृष्ठ Llama 3.3 70B साठी लिहिले गेले होते, जे Groq ने १६ ऑगस्ट २०२६ रोजी बंद केले. आता हे फीचर्स `GROQ_MODEL` सेटिंगद्वारे `openai/gpt-oss-120b` (एक Apache-2.0 ओपन-वेट मॉडेल) चालवतात.

## JanVayu मध्ये वापरलेली सामान्य प्रॉम्प्टिंग तत्त्वे

सर्व स्किल फाइल्स कशा लिहिल्या गेल्या, याला या तत्त्वांनी दिशा दिली:
१. **वास्तविक डेटावर आधारित** — प्रत्येक प्रॉम्प्टला प्रत्यक्ष लाईव्ह आकडे मिळतात. मॉडेल केवळ स्मरणशक्तीवर आधारित माहिती तयार करत नाही.
२. **आउटपुट फॉरमॅट अचूकपणे सांगा** — विशेषतः अकाउंटेबिलिटी ब्रीफसाठी, मॉडेलला नेमके कोणते स्वरूप तयार करायचे आहे हे सांगितले जाते.
३. **लांबी मर्यादित करा** — ओव्हर-जनरेशन टाळण्यासाठी सर्व प्रॉम्प्ट्समध्ये शब्द किंवा टोकनच्या मर्यादा स्पष्टपणे दिल्या आहेत.
४. **अपयशाची कारणे स्पष्ट करा** — मॉडेलने काय करू नये हे प्रॉम्प्ट्समध्ये सांगितले जाते (उदा. "सामान्य सल्ला देऊ नका", "अस्पष्ट उत्तरे देऊ नका").
५. **डिफॉल्टनुसार बहुभाषिक** — योग्य असेल तिथे, मॉडेलला वापरकर्त्याच्या भाषेत उत्तर देण्याच्या सूचना दिल्या जातात.
६. **ग्रेसफुल फॉलबॅक** — API कॉल फेल झाल्यास कच्चे डेटा परत करण्यासाठी प्रत्येक फंक्शनमध्ये नॉन-AI फॉलबॅक असतो.
