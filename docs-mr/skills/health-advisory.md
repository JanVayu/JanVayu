# स्किल: पब्लिक हेल्थ ॲडव्हायझर

**वापरले जाते:** `netlify/functions/health-advisory.mjs`  
**मॉडेल:** Groq द्वारे `openai/gpt-oss-120b` (डिफॉल्ट, `GROQ_MODEL` द्वारे सेट केलेले; 16 ऑगस्ट 2026 रोजी Groq ने ते बंद करेपर्यंत Llama 3.3 70B)  
**ट्रिगर:** युजर प्रोफाइल (वय, आरोग्याच्या समस्या, बाहेर घालवलेले तास) + शहर सबमिट करतो

---

## हे स्किल काय करते

व्यक्तीच्या संवेदनशीलतेच्या प्रोफाईल आणि शहरातील सध्याच्या PM2.5 रीडिंगवर आधारित एक वैयक्तिकृत, कृतीयोग्य आरोग्य सल्ला तयार करते. महत्त्वाचे म्हणजे: हे स्पष्ट शिफारस देते. हे "बाहेरचा वेळ कमी करण्याचा विचार करा" असे म्हणण्याऐवजी "दुपारी 2 वाजेपर्यंत घरातच राहा" अशी ठोस शिफारस देते.

## प्री-एआय रिस्क कॅल्क्युलेशन

Groq API कॉल करण्यापूर्वी, हे फंक्शन साध्या JavaScript मध्ये `riskLevel` मोजते — हे नेहमी AI सल्ल्यासोबत परत केले जाते, जेणेकरून AI ची वाट न पाहता UI रिस्पॉन्सला कलर-कोड करू शकेल:

```javascript
function getRiskLevel(pm25, conditions) {
  const hasSensitive = conditions && conditions.some(c => c !== "none");
  if (pm25 <= 12) return "low";
  if (pm25 <= 35) return hasSensitive ? "moderate" : "low";
  if (pm25 <= 55) return hasSensitive ? "high" : "moderate";
  if (pm25 <= 150) return hasSensitive ? "severe" : "high";
  return "severe";
}
```

ही थ्रेशोल्ड्स 2012 च्या US EPA PM2.5 ब्रेकपॉइंट्स (12.0, 35.4, 55.4, 150.4 µg/m³) वर आधारित आहेत, जे EPA ने 2024 मध्ये सुधारित केले (Good आता 9.0 पर्यंत, Unhealthy 55.5 ते 125.4 पर्यंत); कोड 2024 च्या मूल्यांनुसार अपडेट केलेला नाही. ज्यांना आधीच आरोग्याच्या समस्या आहेत त्यांना एका बँडने वर नेऊन सेन्सिटिव्हिटी हाताळली जाते.

## महत्त्वाचे डिझाईन निर्णय
**"हेजिंग का करू नये"?**
आमचे असे गृहितक आहे की थेट सल्ल्यापेक्षा ("Y होईपर्यंत X करा") संदिग्ध सल्ल्यावर ("तुम्ही विचार करू शकता...") कमी अंमलबजावणी होते. दम्याचा किंवा हृदयविकाराचा त्रास असलेल्या लोकांसाठी काम करणाऱ्या सार्वजनिक आरोग्य साधनासाठी, संदिग्धता तटस्थ नसते — ती सक्रियपणे संरक्षणात्मक वर्तनात घट करते.

**जास्तीत जास्त ३-४ वाक्ये का?**
जास्त प्रदूषणाच्या आणीबाणीच्या वेळी, ज्या आरोग्य सल्ल्यासाठी वाचण्याचा प्रयत्न करावा लागतो तो वाचला जाणार नाही. तो १० सेकंदांच्या आत वाचून समजण्यासारखा असावा.

**मॉडेलवर अवलंबून राहण्याऐवजी `riskLevel` ची गणना JavaScript मध्ये का करावी?**
विश्वसनीयता. जोखीम पातळी UI कलर-कोडिंग आणि फॉलबॅक संदेश चालवते. हे LLM कडे सोपवल्याने अनिश्चितता येते. नियमांवर आधारित फंक्शन नेहमी सुसंगत निकाल देते, मग AI उपलब्ध असो वा नसो.

**प्रॉम्प्टमध्ये अटींची यादी का समाविष्ट करावी?**
"थेट उत्तर द्या" मॉडेलला सामान्य प्रतिसादाऐवजी "दम्याचा त्रास असलेल्या व्यक्तीसाठी, या पातळीवरील PM2.5 म्हणजे..." असे म्हणण्यास भाग पाडते. हे मुख्य पर्सनलायझेशन टूल आहे.

## इतर डोमेनसाठी अनुकूलन

हे कौशल्य पॅटर्न — प्रोफाईल + लाईव्ह डेटा → ठोस सल्ला — खालील गोष्टींसाठी पुन्हा वापरण्यायोग्य आहे:

- **उष्णतेचा सल्ला:** वय + आजार + तापमान/हीट इंडेक्स → बाहेरील हालचाली आणि हायड्रेशनवरील ठोस सल्ला
- **पाण्याच्या प्रदूषणाचा इशारा:** स्थान + दूषित घटकाची पातळी + लोकसंख्याशास्त्र → पिण्याच्या/वापराचा सल्ला
- **आवाजाचा संपर्क:** प्रोफाईल + डेसिबल वाचन + कालावधी → श्रवण संरक्षणाचा सल्ला
