# The May 26 Overhaul: 21 Fixes in One Day

**Published:** 26 May 2026 | **Author:** Team JanVayu | **Reading time:** 7 min

---

A domain expert tested the chatbot and found three wrong answers. A layperson said the navigation was confusing. Someone pointed out there was no gender section. By the end of the day, we had shipped 21 pull requests touching every layer of the platform. Here is what changed and why.

## The chatbot was giving wrong answers

Komal works on air quality in Patna. She asked the chatbot "how many monitoring stations are installed in Patna?" and got an incorrect answer. She knew it was wrong because she had worked there.

The root cause: the chatbot was querying WAQI's bounds API, which only returns a subset of stations. It had no knowledge of the full CPCB network.

**Fix:** We added a hardcoded reference dataset (`CPCB_STATION_DATA`) covering 27 cities with the exact count and type breakdown — CAAQMS (continuous, real-time) vs manual (gravimetric, 24-hour sampling). For Patna: 7 total = 3 CAAQMS + 4 manual, with station names.

```
Patna: 7 stations
  CAAQMS (3): IGSC Planetarium, Muradpur, Samanpura
  Manual (4): Rajbansi Nagar, Khajpura, Gardanibagh, Phulwari Sharif
```

This data now lives in an editable JSON file (`reference-data.json`) — anyone can update it without touching code.

## Delhi was always Mandir Marg

Komal also noticed that asking "how is the air quality in Delhi" always referenced a single station — Mandir Marg. The chatbot was using WAQI's geo-lookup, which returns the nearest station to the city centroid. For Delhi, that happens to be Mandir Marg.

**Fix:** Generic air quality queries now fetch all stations in the city and present a range:

**Fix:** We reorganized into 7 intent-based tabs. The first question is no longer "what type of data?" but "what do you want to do?"

## The map can now show history

The live map previously only showed current AQI. Users asked: "has it gotten better or worse?" You had to go to a separate trends panel, pick a city, and mentally compare.

**Fix:** A **History toggle** on the map with a month/year slider (January 2024 to present). Scrub the slider and see color-coded PM2.5 markers for 12 cities change in real time. Green is good (<30 µg/m³), purple is hazardous (>150 µg/m³).

## Seven systems that auto-update

We built infrastructure so the platform stays fresh without manual editing:

<div style="background: #f8f9fa; border-radius: 12px; padding: 24px; margin: 24px 0; border: 1px solid #e2e8f0;">

| System | What it does | How to use |
|--------|-------------|-----------|
| **Version sync** | One command bumps version across 4 files | `node scripts/bump-version.mjs 26.7.0` |
| **Reference data** | Chatbot reads from editable JSON | Edit `reference-data.json` |
| **Zotero integration** | Reading List auto-populates from Zotero | Add a paper to the Zotero group |
| **Sitemap** | Auto-generates from git history | `npm run sitemap` |
| **Feed health** | Daily check of all 5 social feeds | Scheduled Netlify Function |
| **Translation sync** | Detects stale terms in translated docs | `npm run check:translations` |
| **Data-stat** | Dashboard numbers from single JSON | Edit `scripts/stats.json` |

</div>
