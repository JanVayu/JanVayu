# Claude Code — JanVayu को कैसे बनाया गया

JanVayu को **Claude Code** का उपयोग करके विकसित किया गया था, जो सॉफ्टवेयर इंजीनियरिंग के लिए Anthropic का आधिकारिक CLI एजेंट है। यह सेक्शन पूरी सेटअप, वर्कफ़्लो और कॉन्फ़िगरेशन को डॉक्यूमेंट करता है — ताकि आप इसे अपने प्रोजेक्ट्स के लिए भी दोहरा सकें।

---

## Claude Code क्या है?

Claude Code एक टर्मिनल-आधारित AI कोडिंग एजेंट है। आप इसे अपने प्रोजेक्ट डायरेक्टरी में चलाते हैं और यह ये कर सकता है:

- फ़ाइलों को पढ़ना और लिखना
- शेल कमांड चलाना
- कोडबेस खोजना
- कमिट और पुल रिक्वेस्ट बनाना
- जटिल मल्टी-फ़ाइल रिफैक्टर को मैनेज करना
- पूरे कॉन्टेक्स्ट के साथ एरर को डिबग करना

यह एक इंटरैक्टिव सेशन की तरह काम करता है जहाँ आप बताते हैं कि आपको क्या चाहिए और Claude उसे पूरा करता है — आपका कोड पढ़ना, बदलाव करना, टेस्ट चलाना, और काम पूरा होने तक दोहराना।

---

## JanVayu के लिए Claude Code का उपयोग कैसे किया गया

### शुरुआती निर्माण

कोर प्लेटफ़ॉर्म (`index.html`, सभी Netlify Functions, इंफ्रास्ट्रक्चर कॉन्फ़िग्स) को बार-बार Claude Code सेशन के ज़रिए बनाया गया:

1. **फ़ीचर के बारे में बताना** — जैसे, "एक हेल्थ इम्पैक्ट कैलकुलेटर जोड़ें जो उम्र, स्वास्थ्य की स्थिति और बाहर बिताए गए समय को ले"
2. **Claude मौजूदा कोड पढ़ता है** — ज़ीरो-फ़्रेमवर्क की पाबंदी और मौजूदा पैटर्न को समझता है
3. **Claude इम्प्लीमेंटेशन लिखता है** — `index.html`, `app.js` और `styles.css` में, या एक नए Netlify Function के रूप में
4. **रिव्यू और सुधार** — बदलाव का अनुरोध करना, एज केस फिक्स करना
5. **Claude कमिट करता है** — प्रोजेक्ट के नियमों के अनुसार सही कमिट मैसेज प्रीफ़िक्स के साथ

### v25.1 AI फ़ीचर्स

सभी चार AI फ़ीचर्स (Ask JanVayu, Health Advisory, Accountability Brief, Anomaly Detection) Claude Code सेशन में बनाए गए थे:

- Claude ने Netlify Functions (`.mjs` फ़ाइलें) लिखे
- Claude ने सिस्टम प्रॉम्प्ट तैयार किए
- Claude ने `index.html` में फ़्रंटएंड UI सेक्शन जोड़े
- Claude ने CHANGELOG एंट्रीज़ बनाईं
- Claude ने PRs और मर्ज को मैनेज किया

> **अपडेट, 2 अक्टूबर 2026:** v25.1 को Google Gemini 2.5 Flash पर लॉन्च किया गया था (CHANGELOG v25.1.0)। बाद में फ़ीचर्स को Groq (Llama 3.3 70B) पर ले जाया गया और, 16 अगस्त 2026 को Groq द्वारा उस मॉडल को रिटायर किए जाने के बाद, `openai/gpt-oss-120b` पर ले जाया गया (CHANGELOG v26.6.33)।

## सेशन वर्कफ़्लो

JanVayu के लिए एक आम Claude Code सेशन इस पैटर्न का पालन करता है:
```
1. रिपॉजिटरी रूट में Claude Code शुरू करें
   $ claude

2. टास्क का वर्णन करें
   > "एक anomaly detection बैनर जोड़ें जो दिल्ली, मुंबई, कोलकाता, चेन्नई और बेंगलुरु के लिए PM2.5 की तुलना मौसमी बेसलाइन से करता है"

3. Claude कोडबेस को एक्सप्लोर करता है
   - मौजूदा UI पैटर्न को समझने के लिए index.html और app.js पढ़ता है
   - कोड स्टाइल समझने के लिए मौजूदा Netlify Functions पढ़ता है
   - उपलब्ध डिपेंडेंसीज़ के लिए package.json चेक करता है

4. Claude लागू करता है
   - netlify/functions/anomaly-check.mjs बनाता है
   - index.html में बैनर मार्कअप, styles.css में स्टाइलिंग और app.js में लॉजिक जोड़ता है
   - फंक्शन को कॉल करने के लिए क्लाइंट-साइड कोड अपडेट करता है

5. Claude कमिट करता है और PR बनाता है
   - कमिट मैसेज कन्वेंशन (Add:, Fix:, आदि) का पालन करता है
   - समरी और टेस्ट प्लान के साथ PR बनाता है

6. रिव्यू, इटरेट और मर्ज
```

## इस प्रोजेक्ट के लिए मुख्य खूबियाँ

### कॉन्टेक्स्ट अवेयरनेस
Claude Code आपके पूरे कोडबेस को पढ़ता है। JanVayu के लिए, इसका मतलब है कि यह समझ गया:
- ज़ीरो-फ्रेमवर्क की शर्त (कोई React/Vue/Angular नहीं)
- `index.html` (मार्कअप), `styles.css` और `app.js` में विभाजन
- Netlify Functions स्ट्रक्चर और CORS हैंडलिंग
- Netlify Blobs का उपयोग करके कैश-फर्स्ट पैटर्न
- git हुक्स द्वारा लागू कमिट मैसेज कन्वेंशन

### मल्टी-फाइल कोआर्डिनेशन
"Ask JanVayu" जैसे फीचर को जोड़ने के लिए इन चीज़ों में बदलाव की ज़रूरत होती है:
- एक नया Netlify Function (`air-query.mjs`)
- फ्रंटएंड HTML (`index.html` में नया सेक्शन)
- फ्रंटएंड CSS (चैट इंटरफ़ेस के लिए स्टाइलिंग)
- फ्रंटएंड JS (फंक्शन के लिए fetch कॉल, UI लॉजिक)
- CHANGELOG.md (फीचर को डॉक्यूमेंट करना)

Claude Code इन सभी को एक ही सेशन में संभालता है।

### Git इंटीग्रेशन
Claude Code मूल रूप से इन चीज़ों को संभालता है:
- `git status`, `git diff`, `git log`
- सही मैसेज के साथ कमिट बनाना
- `gh` CLI के माध्यम से ब्रांच और PR बनाना
- प्रोजेक्ट-विशिष्ट git हुक्स का पालन करना

## Claude Code क्या नहीं कर सकता

पारदर्शिता के लिए, यहाँ बताया गया है कि किन कामों के लिए इंसानी मदद की ज़रूरत पड़ी:

| टास्क | कारण |
|------|-----|
| Netlify डैशबोर्ड कॉन्फ़िगरेशन | एनवायरनमेंट वेरिएबल्स, डोमेन सेटअप, बिल्ड सेटिंग्स |
| API की जनरेशन | Groq Console, Resend, WAQI अकाउंट्स |
| डिज़ाइन के फैसले | कौन से फीचर्स बनाने हैं, प्राथमिकता का क्रम |
| कंटेंट रिव्यू | डेटा सोर्स की सटीकता, पॉलिसी की शुद्धता की जांच करना |
| डिप्लॉयमेंट वेरिफिकेशन | डिप्लॉय के बाद लाइव साइट की जांच करना |
