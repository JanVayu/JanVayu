# Claude Code सेटअप — पूरी क्षमताओं की गाइड

यह पेज JanVayu Claude Code सेटअप की हर एक क्षमता की विस्तृत गाइड है — जिसमें डेवलपमेंट टूल्स, एनफोर्समेंट मैकेनिज्म, AI फीचर्स, CI/CD ऑटोमेशन, डिप्लॉयमेंट इंफ्रास्ट्रक्चर और डॉक्यूमेंटेशन वर्कफ़्लो शामिल हैं।

---

## 1. कोर डेवलपमेंट क्षमताएं

### फ़ाइल ऑपरेशन्स
- रिपॉजिटरी में **किसी भी फ़ाइल को पढ़ें** — `index.html`, Netlify Functions, कॉन्फ़िग्स, डॉक्यूमेंटेशन
- **नई फ़ाइलें लिखें** — Netlify Functions, डॉक्यूमेंटेशन पेज, कॉन्फ़िग फ़ाइलें बनाएं
- **मौजूदा फ़ाइलों को एडिट करें** — बिना गैर-ज़रूरी कोड को दोबारा लिखे, सीधे और सटीक बदलाव करें
- **फ़ाइल के नाम के पैटर्न से खोजें** — ग्लोब मैचिंग (जैसे, `**/*.mjs`, `docs/**/*.md`)
- **कंटेंट से खोजें** — पूरे कोडबेस में रेजेक्स (regex) आधारित फुल-टेक्स्ट सर्च

### शेल और टर्मिनल एक्सेस
- डिपेंडेंसीज़ को मैनेज करने के लिए `npm install` रन करें
- लोकल डेवलपमेंट सर्वर के लिए `netlify dev` रन करें
- कोई भी ऐसा शेल कमांड चलाएं जिससे डेटा नष्ट न हो
- `git`, `gh` (GitHub CLI), `ls`, `mkdir` का एक्सेस
- **नियमों के अनुसार ब्लॉक**: `rm -rf`, `git push --force`, `git reset --hard`

### मल्टी-फ़ाइल कोआर्डिनेशन
एक Claude Code सेशन एक ही बार में इन सभी को छू सकता है:
- `index.html` (मार्कअप), `app.js` (लॉजिक) और `styles.css` (स्टाइलिंग)
- Netlify Functions (`netlify/functions/*.mjs` या `*.js`)
- कॉन्फ़िगरेशन फ़ाइलें (`netlify.toml`, `package.json`, `.editorconfig`)
- डॉक्यूमेंटेशन (`docs/**/*.md`, `CHANGELOG.md`, `README.md`)
- Git हुक्स (`.githooks/pre-commit`, `.githooks/commit-msg`)
- GitHub वर्कफ़्लो (`.github/workflows/*.yml`)

## 2. Git वर्कफ़्लो क्षमताएं

### ब्रांचिंग और कमिट्स
- फीचर ब्रांच बनाएं (जैसे, `claude/feature-name`)
- विशिष्ट फ़ाइलों को स्टेज करें (इससे `.env` या सीक्रेट्स गलती से जुड़ने से बचते हैं)
- लागू किए गए प्रीफिक्स नियमों का पालन करते हुए कमिट मैसेज के साथ कमिट करें:
  - `Add:` — नया फीचर या फ़ाइल
  - `Fix:` — बग फिक्स
  - `Update:` — मौजूदा फीचर में सुधार
  - `Translate:` — ट्रांसलेशन का काम
  - `Docs:` — डॉक्यूमेंटेशन में बदलाव
  - `Refactor:` — कोड का पुनर्गठन (बिहेवियर में कोई बदलाव नहीं)
  - `Test:` — टेस्ट जोड़ना
  - `CI:` — CI/CD पाइपलाइन में बदलाव
  - `Chore:` — मेंटेनेंस के काम
- 72 कैरेक्टर्स से ज़्यादा के सब्जेक्ट लाइन पर हुक से एक वॉर्निंग आती है (ब्लॉक नहीं होता); `Merge` भी एक मान्य प्रीफिक्स है

### पुल रिक्वेस्ट मैनेजमेंट
- स्ट्रक्चर्ड टाइटल, समरी और टेस्ट प्लान के साथ PR बनाएं
- मल्टी-PR वर्कफ़्लो मैनेज करें (जैसे, पहले बैकएंड, फिर फ्रंटएंड, फिर डॉक्स)
- PR डिफ़्स की समीक्षा करें और बदलाव सुझाएं
- कमेंट जोड़ें और रिव्यू फीडबैक का जवाब दें
### Git Hook Enforcement
सेटअप में दो कस्टम git हुक शामिल हैं जो अपने आप चलते हैं:

**Pre-commit hook** (`.githooks/pre-commit`):
| चेक | एक्शन |
|-------|--------|
| `.env`, `.env.local`, `.env.production` | **कमिट ब्लॉक करें** |
| `credentials.json`, `*.pem`, `*.key` | **कमिट ब्लॉक करें** |
| `debugger` स्टेटमेंट्स, `breakpoint()` | **कमिट ब्लॉक करें** |
| मर्ज कॉन्फ्लिक्ट मार्कर्स (`<<<<<<<`, `>>>>>>>`) | **कमिट ब्लॉक करें** |
| `console.log`, `console.debug`, `console.warn` | **चेतावनी दें** (`// keep` के साथ बायपास करें) |
| 500 KB से बड़ी फाइलें | **चेतावनी दें** |

**Commit message hook** (`.githooks/commit-msg`):
| चेक | एक्शन |
|-------|--------|
| ज़रूरी प्रीफिक्स का न होना | **कमिट ब्लॉक करें** |
| सब्जेक्ट लाइन > 72 कैरेक्टर्स | **चेतावनी दें** |
| मर्ज/रिवर्ट/फिक्सअप कमिट्स | **लागू न करें** |

## 3. AI-Powered Features (Groq-hosted model)

> **अपडेट, 2 Oct 2026: Groq ने 16 Aug 2026 को Llama 3.3 70B को बंद कर दिया (Groq deprecations page); अब ये फंक्शन डिफ़ॉल्ट रूप से `openai/gpt-oss-120b` पर सेट होते हैं, जिसे `GROQ_MODEL` एनवायरनमेंट वेरिएबल के ज़रिए बदला जा सकता है।**

सेटअप में चार प्रोडक्शन AI फीचर्स शामिल हैं, जिनमें से हर एक को एक स्ट्रक्चर्ड स्किल फाइल के साथ Netlify Function के रूप में लागू किया गया है:

### 3.1 Air Quality Assistant (`air-query.mjs`)
- **इनपुट**: शहर का नाम + प्राकृतिक भाषा में सवाल
- **आउटपुट**: ठोस जवाब (लगभग 150 शब्दों का), जिसमें असली AQI नंबरों का हवाला दिया गया हो
- **भाषाएं**: अंग्रेजी के साथ नौ भारतीय भाषाएं (हिंदी, तमिल, बंगाली, मराठी, तेलुगु, गुजराती, कन्नड़, मलयालम, पंजाबी)
- **मुख्य शर्त**: असली डेटा का हवाला देना ज़रूरी है — कोई सामान्य सलाह नहीं
- **फालबैक**: अगर Groq पर रेट लिमिट आ जाती है, तो यह रॉ AQI डेटा वापस करता है
- **स्किल फाइल**: `docs/skills/air-quality-assistant.md`

### 3.2 Health Advisory (`health-advisory.mjs`)
- **इनपुट**: शहर + उम्र + स्वास्थ्य की स्थितियां + बाहर बिताए गए घंटे
- **आउटपुट**: कलर-कोडेड जोखिम स्तर + ठोस सिफारिशें (3-4 वाक्य)
- **मुख्य शर्त**: सीधी सलाह, कोई घुमा-फिरा कर बात नहीं — "घर के अंदर रहें" (न कि "घर के अंदर रहने पर विचार करें")
- **AI से पहले का कदम**: JavaScript फंक्शन AI रिस्पॉन्स आने से पहले ही तुरंत UI कलर-कोडिंग के लिए जोखिम स्तर की गणना कर लेता है
- **फालबैक**: अगर AI की व्याख्या फेल हो जाती है, तब भी जोखिम स्तर दिखाई देता है
- **स्किल फाइल**: `docs/skills/health-advisory.md`
### 3.3 अकाउंटेबिलिटी ब्रीफ (`accountability-brief.mjs`)
- **इनपुट**: शहर + वार्ड/क्षेत्र + समय अवधि
- **आउटपुट**: आठ लेबल किए गए सेक्शन (क्षेत्र, अवधि, वर्तमान PM2.5, स्थिति, डेटा क्या दिखाता है, संभावित स्रोत, स्थानीय लोग क्या कर सकते हैं, डेटा की सीमा) के साथ स्ट्रक्चर्ड ब्रीफ
- **अधिकतम आउटपुट**: 1,024 टोकन
- **श्रोता**: वार्ड काउंसलर, स्थानीय पत्रकार, RWA (रेजिडेंट वेलफेयर एसोसिएशन)
- **मुख्य विशेषता**: इसमें विशिष्ट स्थानीय नियामक तंत्र (GRAP, RTI और नगर निगम शिकायत लाइनें) शामिल हैं
- **फॉलबैक**: AI विश्लेषण के बिना रॉ डेटा (raw data) लौटाता है
- **स्किल फ़ाइल**: `docs/skills/accountability-brief.md`

### 3.4 विसंगति का पता लगाना (`anomaly-check.mjs`)
- **इनपुट**: स्वचालित — दिल्ली, मुंबई, कोलकाता, चेन्नई, बेंगलुरु की निगरानी करता है
- **थ्रेशोल्ड**: PM2.5 > 2× मौसमी बेसलाइन = विसंगति (anomaly)
- **आउटपुट**: हर स्पाइक (तेजी) के लिए एक वाक्य का स्पष्टीकरण
- **मौसमी बेसलाइन**: हार्डकोडेड अनुमानित JanVayu वर्किंग बेसलाइन, प्रकाशित CREA या IQAir के आंकड़े नहीं (डायनामिक रूप से गणना नहीं की जाती)
- **फॉलबैक**: AI स्पष्टीकरण के बिना विसंगति का संकेत (anomaly flag) लौटाता है
- **स्किल फ़ाइल**: `docs/skills/anomaly-explainer.md`

### साझा AI आर्किटेक्चर
सभी चार फ़ीचर में ये बातें समान हैं:
- केवल सर्वर-साइड निष्पादन (क्लाइंट को कोई API key एक्सपोज़ नहीं की जाती)
- CORS प्रीफ़्लाइट हैंडलिंग (OPTIONS → 204)
- उचित स्टेटस कोड के साथ JSON रिस्पॉन्स
- हर बाहरी कॉल पर try/catch
- ग्रेसफुल डिग्रेडेशन — हर AI फ़ीचर का एक गैर-AI फॉलबैक होता है

## 4. Netlify Functions (28 सर्वरलेस हैंडलर)

नीचे दी गई टेबल मुख्य फ़ंक्शन्स को सूचीबद्ध करती हैं। रिपॉजिटरी में 28 हैंडलर फ़ाइलें और एक साझा हेल्पर (`blob-store.js`) है; इनमें से पाँच हैंडलर शेड्यूल्ड (scheduled) हैं।

### शेड्यूल्ड फ़ंक्शन्स
| फ़ंक्शन | शेड्यूल्स | उद्देश्य |
|----------|----------|---------|
| `scheduled-fetch.mjs` | हर 4 घंटे | सभी सोशल मीडिया और न्यूज़ फ़ीड को Netlify Blobs कैश में प्री-फ़ेच करता है |
| `daily-digest.mjs` | रोज़ सुबह 8:00 बजे IST | Resend API के माध्यम से सब्सक्राइबर्स को AQI ईमेल डाइजेस्ट भेजता है |

### ऑन-डिमांड फ़ंक्शन्स (AI)
| फ़ंक्शन | मेथड | उद्देश्य |
|----------|--------|---------|
| `air-query.mjs` | POST | प्राकृतिक भाषा में AQI Q&A |
| `health-advisory.mjs` | POST | व्यक्तिगत स्वास्थ्य सलाह |
| `accountability-brief.mjs` | POST | गवर्नेंस अकाउंटेबिलिटी ब्रीफ |
| `anomaly-check.mjs` | GET | PM2.5 स्पाइक डिटेक्शन |
### ऑन-डिमांड फंक्शन्स (डेटा)
| फंक्शन | मेथड | उद्देश्य |
|----------|--------|---------|
| `reddit-feed.js` | GET | एयर क्वालिटी के बारे में रेडिट (Reddit) पोस्ट्स |
| `twitter-feed.js` | — | **रिटायर्ड (Retired)।** निटर (Nitter) को रीड करता है, जिसके पब्लिक इंस्टेंस अब बंद हो चुके हैं; अब कोई इसका इस्तेमाल नहीं करता। |
| `youtube-feed.js` | GET | यूट्यूब चैनल RSS से इंडिया एयर-क्वालिटी वीडियो |
| `instagram-feed.js` | GET | इंस्टाग्राम पोस्ट्स |
| `news-proxy.js` | GET | न्यूज़ आर्टिकल्स |
| `subscribe.js` | POST | ईमेल सब्सक्रिप्शन मैनेजमेंट |
| `feed-status.js` | GET | फीड की ताज़गी की जांच (Feed freshness health check) |

### शेयर्ड यूटिलिटी
| फंक्शन | उद्देश्य |
|----------|---------|
| `blob-store.js` | नेटलाइफ ब्लॉब्स (Netlify Blobs) स्टोर इनिशियलाइज़ेशन (बाकी फंक्शन्स द्वारा इम्पोर्ट किया जाता है) |

### स्टैंडर्ड फंक्शन पैटर्न
हर फंक्शन इस टेम्पलेट को फॉलो करता है:
1. CORS प्रीफ्लाइट हैंडलिंग (`OPTIONS` → `204`)
2. `try/catch` में रैप की गई कोर लॉजिक
3. CORS हेडर्स के साथ JSON रिस्पॉन्स बॉडी
4. एरर आने पर ग्रेसफुल फॉलबैक (कभी भी खाली बॉडी के साथ `500` रिटर्न नहीं करता)

## 6. डिप्लॉयमेंट और इंफ्रास्ट्रक्चर

### होस्टिंग — नेटलाइफ CDN
- Let's Encrypt के साथ ऑटोमैटिक HTTPS
- ग्लोबल CDN डिस्ट्रीब्यूशन
- नॉन-www → www रीडायरेक्ट (कैनोनिकल डोमेन)
- SPA फॉलबैक: सभी रूट्स → `/index.html`
- `/robots.txt` और `/sitemap.xml` के लिए स्पेशल रूट्स
### Security Headers
| Header | Value | Purpose |
|--------|-------|---------|
| `X-Frame-Options` | `DENY` | क्लिकजैकिंग को रोकता है |
| `X-Content-Type-Options` | `nosniff` | MIME स्निफिंग को रोकता है |
| `Referrer-Policy` | `strict-origin-when-cross-origin` | रेफरर जानकारी को नियंत्रित करता है |

### Caching — Netlify Blobs
- स्ट्रॉन्ग कंसिस्टेंसी मॉडल
- शेड्यूल्ड फंक्शन्स द्वारा सोशल फीड्स और न्यूज़ को पहले से कैश करने के लिए उपयोग किया जाता है
- ऑन-डिमांड फंक्शन्स पहले कैश से पढ़ते हैं, फॉलबैक के रूप में लाइव डेटा लाते हैं
- `@netlify/blobs` पैकेज के ज़रिए एक्सेस किया जाता है

### Email — Resend API
- डेली डाइजेस्ट (`daily-digest.mjs`) और अन्य सर्वर-साइड मेलर्स (`health-monitor.mjs`, `terra-collab.mjs`, `workshop-submit.mjs`) के लिए ईमेल डिलीवरी; `subscribe.js` ईमेल नहीं भेजता
- केवल सर्वर-साइड (Netlify Functions के ज़रिए)

## 7. MCP Server Integrations

Claude Code उन Model Context Protocol (MCP) सर्वर्स को सपोर्ट करता है जो लोकल फ़ाइलसिस्टम से आगे इसके टूल एक्सेस को बढ़ाते हैं। रिपॉजिटरी में यह रिकॉर्ड नहीं है कि JanVayu के डेवलपमेंट के दौरान इनमें से किसका उपयोग किया गया था; टेबल में बताया गया है कि हर एक का उपयोग किस लिए किया जा सकता है:
| MCP Server | उपलब्ध टूल्स | JanVayu के लिए उपयोग |

| **GitHub** | PR management, issue tracking, code search, CI checks | PRs, reviews, issue comments को मैनेज करता है |
| **Notion** | पेज बनाना, databases में query करना, search, update | प्रोजेक्ट प्लानिंग, task tracking, meeting notes |
| **Gmail** | मैसेजेस search करना, threads पढ़ना, drafts बनाना | फीचर्स के बारे में ईमेल चर्चाओं को रेफर करना |
| **Figma** | डिज़ाइन कॉन्टेक्स्ट, स्क्रीनशॉट, मेटाडेटा प्राप्त करना | डिज़ाइन मॉकअप्स को HTML/CSS में ट्रांसलेट करना |

| **Excalidraw** | व्यूज़ बनाना, चेकपॉइंट्स सेव करना | आर्किटेक्चर डायग्राम्स और डेटा फ्लो विज़ुअलाइज़ेशन |
