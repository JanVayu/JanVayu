# इस सेटअप को शेयर और रेप्लिकेट करना

यह पेज बताता है कि अपनी टीम के साथ JanVayu के Claude Code वर्कफ़्लो को कैसे शेयर करें या इसे अपने प्रोजेक्ट के लिए कैसे रेप्लिकेट करें।

---

## अपनी टीम के लिए

### डॉक्स शेयर करें

यह डॉक्यूमेंटेशन JanVayu की अपनी साइट पर [`/docs/`](/docs/) पर होस्ट किया गया है — यह एक सिंगल-पेज Docsify शेल है जो सीधे रेपो से मार्कडाउन पढ़ता है। यह URL उन सभी लोगों को भेजें जिन्हें यह समझने की ज़रूरत है:
- JanVayu कैसे बना है
- Claude Code का उपयोग करके कैसे योगदान करें
- किसी दूसरे शहर या डोमेन के लिए JanVayu को कैसे फोर्क करें

### नए कॉन्ट्रिब्यूटर को ऑनबोर्ड करना

1. **रेपो क्लोन करें** — `git clone https://github.com/JanVayu/JanVayu.git`
2. **डॉक्यूमेंटेशन पढ़ें** — [`/docs/`](/docs/) से शुरुआत करें, खासकर:
   - [Tech Stack Overview](../tech-stack/overview.md)
   - [Architecture](../technical/architecture.md)
   - [Local Development](../technical/local-development.md)
3. **Claude Code इंस्टॉल करें** — `npm install -g @anthropic-ai/claude-code`
4. **एक सेशन शुरू करें** — `cd JanVayu && claude`
5. **वर्कफ़्लो को फॉलो करें** — [Workflow](workflow.md) में बताया गया है

---

## अपने प्रोजेक्ट के लिए

### स्टेप 1: कंस्ट्रेंट-फर्स्ट अप्रोच अपनाएं

JanVayu से सबसे ज़्यादा काम आने वाला सबक **कंस्ट्रेंट-फर्स्ट प्रॉम्प्टिंग** है। Claude Code को कुछ भी बनाने के लिए कहने से पहले:

1. तय करें कि आपका प्रोजेक्ट किन चीज़ों का *उपयोग नहीं* करेगा (फ्रेमवर्क, बिल्ड टूल्स, आदि)
2. अपने कोड स्टाइल और नियमों को तय करें
3. अपने डिप्लॉयमेंट टारगेट को तय करें
4. इन्हें अपने रेपो रूट में एक `CLAUDE.md` फ़ाइल में रखें

### स्टेप 2: स्किल फ़ाइलें बनाएं

अगर आपका प्रोजेक्ट AI फ़ीचर का उपयोग करता है (कोई भी मॉडल — Groq, OpenAI, Claude API), तो हर AI इंटरेक्शन को एक स्किल फ़ाइल के रूप में डॉक्यूमेंट करें:

```markdown
# Skill: [Feature Name]

## Role
[What the model acts as]

## Data Context
[What real data gets injected into the prompt]

## Output Format
[Exact structure expected]

## Constraints
[Word limits, tone, language, what NOT to do]

## Fallback
[What happens if the AI call fails]
```

### स्टेप 3: Git Hooks सेट अप करें

इन नियमों को लागू करने के लिए JanVayu के git hooks (`.githooks/`) को कॉपी करें:
- कमिट मैसेज के नियम
- कमिट में कोई सीक्रेट्स न हों
- कोई डीबग स्टेटमेंट्स न हों

### स्टेप 4: बनाते समय डॉक्यूमेंट करें

अपने कोड के साथ Docsify (या कोई भी मार्कडाउन-आधारित) डॉक्स बनाएं। Claude Code आपके कोडबेस से डॉक्यूमेंटेशन जनरेट कर सकता है — इसका उपयोग करें।

## किसी दूसरे शहर के लिए JanVayu को फोर्क करना

JanVayu का कोड MIT-लाइसेंस प्राप्त है (इसकी सामग्री CC BY-NC-SA 4.0 है)। इसे किसी दूसरे शहर या देश के लिए फोर्क करने के लिए:
1. GitHub पर **रिपॉजिटरी को फोर्क करें**
2. `app.js` और Netlify फ़ंक्शन्स में `CITIES` टेबल्स में **शहरों की सूची अपडेट करें**
3. `anomaly-check.mjs` में **मौसमी बेसलाइन्स अपडेट करें**
4. अपने क्षेत्र के लिए **WAQI स्टेशन IDs अपडेट करें**
5. स्थानीय भाषाओं के लिए **स्ट्रिंग्स ट्रांसलेट करें**
6. एनवायरनमेंट वेरिएबल्स के साथ **अपनी खुद की Netlify साइट सेट अप करें**
7. **वैकल्पिक:** डिफ़ॉल्ट Groq मॉडल (`openai/gpt-oss-120b`) को किसी अन्य मॉडल से बदलें (स्किल फ़ाइलें मॉडल-अज्ञेय हैं)

Claude Code इन सभी चरणों में मदद कर सकता है।

## इस डॉक्यूमेंटेशन को एक्सपोर्ट करना

### एक स्टैंडअलोन साइट के रूप में

डॉक्यूमेंटेशन पहले से ही एक स्टैंडअलोन साइट है। किसी भी पाठक को [`https://www.janvayu.in/docs/`](https://www.janvayu.in/docs/) पर भेजें।

### Markdown के रूप में

रॉ Markdown फ़ाइलें रिपॉजिटरी में `docs/` (English) और `docs-{lang}/` (Hindi, Bengali, Marathi, Tamil) में हैं। इन्हें सीधे शेयर करें या किसी भी ऐसी जगह होस्ट करें जो Markdown को रेंडर करती हो — GitHub, Notion, HackMD, आपकी अपनी Docsify या MkDocs साइट।

### PDF के रूप में

Docsify में इन-बिल्ट PDF एक्सपोर्ट नहीं है। लाइव डॉक्स को PDF में बदलने के लिए, `https://www.janvayu.in/docs/` को PDF में रेंडर करने के लिए `wkhtmltopdf` या Puppeteer जैसे हेडलेस-Chrome टूल का उपयोग करें।

## डॉक्स स्टैक

JanVayu के डॉक्स Docsify पर चलते हैं — इसे इसलिए चुना गया क्योंकि इसमें कोई बिल्ड स्टेप, कोई सर्वर और कोई थर्ड-पार्टी होस्टिंग बिल नहीं है।

### मल्टीलिंगुअल सेटअप कैसे काम करता है

English markdown `docs/` में रहता है। हर ट्रांसलेट की गई भाषा `docs-{lang}/` में रहती है। `/docs/index.html` पर एक सिंगल Docsify शेल एक एलियास मैप डिक्लेयर करता है जो हैश पाथ्स को सही डायरेक्टरी में रूट करता है, ताकि विज़िटर्स यहाँ पहुँच सकें:

| Language | URL | Source Directory |
|----------|-----|------------------|
| English (default) | [`/docs/`](/docs/) | `docs/` |
| Hindi | [`/docs/#/hi/`](/docs/#/hi/) | `docs-hi/` |
| Bengali | [`/docs/#/bn/`](/docs/#/bn/) | `docs-bn/` |
| Marathi | [`/docs/#/mr/`](/docs/#/mr/) | `docs-mr/` |
| Tamil | [`/docs/#/ta/`](/docs/#/ta/) | `docs-ta/` |

ट्रांसलेट किए गए ट्रीज़ को एक CI ऑटो-ट्रांसलेट जॉब (`.github/workflows/translations.yml`, जिसे Sarvam API key की ज़रूरत होती है) द्वारा रिफ्रेश किया जाता है और ये English डॉक्स से पीछे हो सकते हैं: 65 में से 47 English पेजों का वर्तमान में हर भाषा में एक ट्रांसलेटेड वर्ज़न मौजूद है।

### प्लगइन्स
| प्लगइन | उद्देश्य |

| `docsify-themeable` | ब्रांड-रंग वाली थीम (JanVayu ग्रीन) और डार्क मोड टॉगल |

| `docsify-footer-enh` | कॉपीराइट और लाइसेंस के साथ फुटर लाइन |

| Prism.js | bash, JS, JSON, YAML, TOML, Markdown के लिए सिंटैक्स हाइलाइटिंग |
| Docsify zoom-image | इमेजेस पर क्लिक-टू-ज़ूम |

### कस्टम डोमेन

डॉक्यूमेंटेशन `https://www.janvayu.in/docs/` (मुख्य JanVayu साइट पर एक पाथ, सबडोमेन नहीं) से सर्व किया जाता है — किसी अलग DNS या SSL कॉन्फ़िगरेशन की ज़रूरत नहीं है।

### ब्रांडिंग

थीम वेरिएबल्स `docs/index.html` के `<style>` ब्लॉक के अंदर मौजूद हैं:
- प्राइमरी रंग: `#16A34A` (प्लेटफ़ॉर्म के ब्रांड ग्रीन से मेल खाता है)
- साइडबार का रंग: `#1a3a2a`
- डार्क मोड: शेयर्ड साइट हेडर (`js/chrome.js`) से टॉगल किया जाता है; इस प्रेफरेंस को `localStorage` में `janvayu-theme` के तहत सेव किया जाता है।
