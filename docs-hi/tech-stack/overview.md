# टेक स्टैक ओवरव्यू
 
JanVayu को जानबूझकर एक न्यूनतम स्टैक पर बनाया गया है — शून्य फ्रंटएंड फ्रेमवर्क, तीन npm डिपेंडेंसीज़, और एक सर्वरलेस बैकएंड। यह पेज इस्तेमाल की गई हर तकनीक और उसे चुनने के कारणों को मैप करता है।
---

## यह स्टैक क्यों?
### ज़ीरो-फ्रेमवर्क फ्रंटएंड
JanVayu के दर्शकों में पूरे भारत में 2G कनेक्शन और कमज़ोर एंड्रॉइड डिवाइस इस्तेमाल करने वाले लोग शामिल हैं। React या Vue जैसे फ्रेमवर्क से एक भी फीचर लोड होने से पहले डाउनलोड करने के लिए एक फ्रेमवर्क रनटाइम जुड़ जाएगा। इसके बजाय:
- ऐप `index.html` के साथ `styles.css`, `app.js`, `games.js` और 19 लेज़ी-लोडेड पैनल फ़्रैग्मेंट्स से बनी है, और इसमें कोई बंडलर नहीं है
- किसी ट्रांसपाइलेशन, बंडलिंग या ट्री-शेकिंग की ज़रूरत नहीं है
- डिप्लॉय आर्टिफैक्ट = खुद रिपॉजिटरी
- बुनियादी HTML/JS स्किल्स वाला कोई भी योगदानकर्ता योगदान दे सकता है
### केवल 3 npm डिपेंडेंसीज़
```json
{
  "@netlify/blobs": "^11.0.2",
  "resend": "^6.14.0",
  "web-push": "^3.6.7"
}
```
ये तीनों केवल सर्वर-साइड पर हैं (Netlify Functions द्वारा उपयोग की जाती हैं)। AI फीचर्स सीधे `fetch` के ज़रिए Groq REST API (OpenAI-कम्पैटिबल) का उपयोग करते हैं — किसी SDK की ज़रूरत नहीं है। क्लाइंट में शून्य npm डिपेंडेंसीज़ हैं — Chart.js और Leaflet.js CDN से लोड होते हैं।
### सर्वर के बजाय सर्वरलेस
 
---
---
Netlify Functions एक लगातार चलने वाले सर्वर की ज़रूरत को खत्म कर देते हैं। फ़ायदे:
- शून्य ऑपरेशन्स बोझ (कोई सर्वर पैचिंग नहीं, कोई स्केलिंग नहीं)
- स्वचालित HTTPS, CDN, और एज डिप्लॉयमेंट
