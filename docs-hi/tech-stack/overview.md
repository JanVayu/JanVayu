# टेक स्टैक ओवरव्यू

JanVayu को जानबूझकर एक मिनिमल (कम से कम) स्टैक पर बनाया गया है — कोई फ्रंटएंड फ्रेमवर्क नहीं, तीन npm डिपेंडेंसीज़, और एक सर्वरलेस बैकएंड। यह पेज इस्तेमाल की गई हर तकनीक और उसके चुने जाने के कारण की जानकारी देता है।

---

## स्टैक की एक झलक

| लेयर | तकनीक | उद्देश्य |
|-------|-----------|---------|
| **फ्रंटएंड** | वैनिला HTML/CSS/JS | सिंगल-पेज एप्लिकेशन (कोई बिल्ड स्टेप नहीं) |
| **चार्ट्स** | Chart.js (CDN) | AQI ट्रेंड विज़ुअलाइज़ेशन |
| **मैप्स** | Leaflet.js + OpenStreetMap (CDN) | इंटरैक्टिव स्टेशन मैप्स |
| **बैकएंड** | Netlify Functions (Node.js 22) | सर्वरलेस API एंडपॉइंट्स |
| **कैश** | Netlify Blobs | परसिस्टेंट JSON कैश (स्ट्रॉन्ग कंसिस्टेंसी) |
| **ईमेल** | Resend API | डेली AQI डाइजेस्ट डिलीवरी |
| **AI** | Groq के ज़रिए OpenAI gpt-oss-120b (`GROQ_MODEL` env-overridable) | NL क्वेरीज़, हेल्थ एडवाइस, एनोमली डिटेक्शन |
| **होस्टिंग** | Netlify CDN | GitHub `main` से ऑटो-डिप्लॉय |
| **CI** | GitHub Actions | लिंक ऑडिट, एक्सेसिबिलिटी, Lighthouse, CodeQL, ट्रांसलेशन सिंक, साइट-फिगर गार्ड्स, Dependabot |
| **डोमेन** | Netlify DNS | janvayu.in कस्टम डोमेन |
| **डॉक्यूमेंट्स** | Docsify (5 भाषाएँ) | `/docs/` पर सिंगल शेल; लैंग्वेज हैश रूट्स (`/docs/#/hi/` आदि) `docs-{lang}/` मार्कडाउन लोड करते हैं |
| **डेवलपमेंट** | Claude Code (Anthropic) | AI-असिस्टेड डेवलपमेंट वर्कफ़्लो |

## यह स्टैक क्यों?

### ज़ीरो-फ्रेमवर्क फ्रंटएंड

JanVayu के यूज़र्स में पूरे भारत में 2G कनेक्शन और लो-एंड एंड्रॉइड डिवाइस इस्तेमाल करने वाले लोग शामिल हैं। React या Vue जैसे फ्रेमवर्क से कोई भी फीचर लोड होने से पहले ही एक फ्रेमवर्क रनटाइम डाउनलोड करना पड़ेगा। इसके बजाय:

- ऐप में सिर्फ `index.html`, `styles.css`, `app.js`, `games.js` और 19 लेज़ी-लोडेड पैनल फ्रैगमेंट्स हैं, और इसमें कोई बंडलर नहीं है
- किसी ट्रांसपाइलेशन, बंडलिंग या ट्री-शेकिंग की ज़रूरत नहीं है
- डिप्लॉय आर्टिफैक्ट = खुद रेपो
- बेसिक HTML/JS स्किल्स वाला कोई भी कॉन्ट्रिब्यूटर इसमें योगदान दे सकता है

### सिर्फ 3 npm डिपेंडेंसीज़

```json
{
  "@netlify/blobs": "^11.0.2",
  "resend": "^6.14.0",
  "web-push": "^3.6.7"
}
```

ये तीनों सिर्फ सर्वर-साइड पर इस्तेमाल होती हैं (Netlify Functions द्वारा)। AI फीचर्स सीधे `fetch` के ज़रिए Groq REST API (OpenAI-कम्पैटिबल) का उपयोग करते हैं — किसी SDK की ज़रूरत नहीं है। क्लाइंट में ज़ीरो npm डिपेंडेंसीज़ हैं — Chart.js और Leaflet.js CDN से लोड होते हैं।

### सर्वर के बजाय सर्वरलेस

Netlify Functions एक परसिस्टेंट सर्वर की ज़रूरत को खत्म कर देते हैं। फायदे:
- ज़ीरो ऑप्स बर्डन (कोई सर्वर पैचिंग नहीं, कोई स्केलिंग नहीं)
- ऑटोमैटिक HTTPS, CDN, और एज डिप्लॉयमेंट
