# रोल-आधारित लैंडिंग पेज

JanVayu कई तरह के यूज़र्स की सेवा करता है — अपने बच्चे के बाहर जाने के लिए सुरक्षित है या नहीं, यह जांचने वाले माता-पिता से लेकर, डेटासेट एक्सेस करने वाले शोधकर्ताओं और राजनीतिक जवाबदेही को ट्रैक करने वाले पत्रकारों तक। रोल-आधारित लैंडिंग पेज हर यूज़र के लिए अनुभव को उनके हिसाब से ढालता है।

---

## यह कैसे काम करता है

1. **पहली विज़िट** — पेज लाइव एयर रीडिंग पर खुलता है; इसमें कोई फुल-स्क्रीन ओवरले नहीं होता (इसे सितंबर 2026 में हटा दिया गया था)
2. **रोल चुनना** — यूज़र हेडर रोल स्विचर से एक रोल चुनता है (या "Show Everything" चुनता है)
3. **पर्सनलाइज़्ड डैशबोर्ड** — रोल के हिसाब से ज़रूरी एक्शन और सुझाये गए पैनल दिखाता है
4. **सेव रहता है** — रोल को `localStorage` में सेव किया जाता है, और अगली विज़िट पर वापस मिल जाता है
5. **बदला जा सकता है** — हेडर में रोल स्विचर आइकन (सबसे दायां आइकन) कभी भी रोल बदलने की सुविधा देता है

## रोल कॉन्फ़िगरेशन

हर रोल को `index.html` में `ROLE_CONFIG` ऑब्जेक्ट में इन चीज़ों के साथ डिफाइन किया गया है:

```javascript
{
    icon: '<span class="si si-home"></span>',
    label: 'Parent / Family',
    heading: 'Protect your family from air pollution',
    description: 'Real-time safety checks, school closure info...',
    actions: [
        { icon, panel, title, desc, cta }  // 3 action cards
    ],
    panels: [
        { panel, title, desc }  // 6 recommended panels
    ]
}
```

## तकनीकी विवरण
- **Storage:** `localStorage` key `janvayu-role` (एक बार पुराने `sessionStorage` value को माइग्रेट किया जाता है)
- **Switcher:** हेडर में `#rolePopover`, जिसमें `ROLE_CONFIG` से जनरेट किए गए रोल बटन `#rolePopoverGrid` में होते हैं
- **Dashboard टेम्पलेट:** `#tmpl-role-dashboard`
- **टूर:** अगर टूर पहले नहीं देखा गया है, तो पहला रोल चुनने के बाद ट्रिगर होता है
