# रोल-आधारित लैंडिंग पेज
JanVayu विभिन्न प्रकार के उपयोगकर्ताओं की सेवा करता है — उन माता-पिता से लेकर जो यह जांचते हैं कि उनके बच्चे का बाहर जाना सुरक्षित है या नहीं, डेटासेट तक पहुंचने वाले शोधकर्ताओं से लेकर, राजनीतिक जवाबदेही को ट्रैक करने वाले पत्रकारों तक। रोल-आधारित लैंडिंग पेज प्रत्येक उपयोगकर्ता के लिए अनुभव को व्यक्तिगत बनाता है।
---
## यह कैसे काम करता है
1. **पहली यात्रा** — पेज लाइव एयर रीडिंग पर खुलता है; इसमें कोई फुल-स्क्रीन ओवरले नहीं है (इसे सितंबर 2026 में हटा दिया गया था)
2. **रोल का चुनाव** — उपयोगकर्ता हेडर रोल स्विचर से एक रोल चुनता है (या "Show Everything" चुनता है)
3. **व्यक्तिगत डैशबोर्ड** — रोल-विशिष्ट क्रियाएं और अनुशंसित पैनल दिखाता है
4. **लगातार प्रभावी**: रोल को `localStorage` में सेव किया जाता है, और अगली बार आने पर वापस बहाल किया जाता है
5. **बदला जा सकने वाला**: रोल स्विचर बार में पहला कंट्रोल है ("आप कौन हैं", या चुने गए रोल का लेबल) और किसी भी समय बदलने की अनुमति देता है। फोन पर यह मेनू के अंदर स्थित है

## रोल कॉन्फ़िगरेशन
प्रत्येक रोल को `index.html` में `ROLE_CONFIG` ऑब्जेक्ट में निम्नलिखित के साथ परिभाषित किया गया है:
```javascript
{
    icon: '<span class="si si-home"> <\/span>',
    label: 'Parent / Family',
    heading: 'Protect your family from air pollution',
    description: 'Real-time safety checks, school closure info...',
    actions: [
        { icon, panel, title, desc, cta }  // 3 action cards
    ],
    panels: [
        { panel, title, desc }  // 6 recommended panels
    ]
}
```

## तकनीकी विवरण
- **स्टोरेज:** `localStorage` की (key) `janvayu-role` (एक पुरानी `sessionStorage` वैल्यू को एक बार माइग्रेट किया जाता है)
- **स्विच:** हेडर में `#rolePopover`, जिसके रोल बटन `ROLE_CONFIG` से जनरेट होकर `#rolePopoverGrid` में रखे गए हैं
- **डैशबोर्ड टेम्पलेट:** `#tmpl-role-dashboard`
- **टूर:** अगर टूर पहले नहीं देखा गया है, तो पहली बार रोल चुनने के बाद ट्रिगर होता है
