# सरल भाषा मोड

जनवायु (JanVayu) में जटिल तकनीकी सामग्री (PM2.5 सांद्रता, GEMM मृत्यु दर मॉडल, नीतिगत संक्षिप्त नाम) शामिल हैं। सरल भाषा मोड इस सामग्री को सरल, बिना मुश्किल शब्दों (जार्गन) वाली भाषा में फिर से लिखता है, जिसे कोई भी आसानी से समझ सकता है।
---
## यह कैसे काम करता है
1. **टॉगल**: पेज के शीर्ष पर बार में (फोन पर मेनू के अंदर) सरल पर क्लिक करें, या शब्दावली पैनल में टॉगल का उपयोग करें
2. **स्वैप** — `data-simple` एट्रिब्यूट वाले सभी तत्वों की सामग्री को सरल-भाषा वाले संस्करणों से बदल दिया जाता है
3. **परसिस्ट** — स्थिति `sessionStorage` में सहेजी जाती है, पेज को फिर से लोड करने पर बहाल की जाती है
4. **दृश्य संकेतक** — सरल पाठ के बगल में एक हरा "सरल भाषा" बैज दिखाई देता है
5. **रिवर्सिबल** — तकनीकी भाषा को बहाल करने के लिए फिर से क्लिक करें
---
## तकनीकी कार्यान्वयन
### HTML एट्रिब्यूट
किसी भी तत्व को `data-simple` एट्रिब्यूट जोड़कर सरल-मोड-जागरूक बनाया जा सकता है:
```html
<p data-simple="गंदी हवा के कारण भारत को हर साल बहुत पैसा खर्च करना पड़ता है।">
    भारत में बाहरी वायु प्रदूषण से होने वाली अकाल मौतों का मौद्रिक मूल्य 2022 में $339.4 बिलियन था (जीडीपी का 9.5%)।
</p>
```
### जावास्क्रिप्ट
```javascript
let simpleMode = sessionStorage.getItem('janvayu-simple-mode') === 'true';
function toggleSimpleMode() {
    simpleMode = !simpleMode;
    sessionStorage.setItem('janvayu-simple-mode', simpleMode);
    applySimpleMode();
}
function applySimpleMode() {
    document.body.classList.toggle('simple-language', simpleMode);
    document.querySelectorAll('[data-simple]').forEach(el => {
        if (simpleMode) {
            if (!el.dataset.technical) el.dataset.technical = el.innerHTML;
            el.innerHTML = el.dataset.simple;
        } else {
            if (el.dataset.technical) el.innerHTML = el.dataset.technical;
        }
    });
}
```

## कवरेज
- पैनल परिचयात्मक पैराग्राफ
- 20 शब्दावली परिभाषाएँ (तकनीकी / सरल)
- मुख्य अंतर्दृष्टि बॉक्स, अलर्ट बॉक्स, पुल-कोट
- बजट, नीति, स्वास्थ्य, बाल, इनडोर, कानूनी, एक्शन पैनल
### सरल पाठ जोड़ना
1. `index.html` में तत्व खोजें
2. `data-simple="यहाँ अपना सरल भाषा संस्करण लिखें"` जोड़ें
3. विशेष वर्णों के लिए HTML एंटिटी का उपयोग करें: `&lt;strong&gt;`, `&amp;`
4. 12 साल के बच्चे के लिए लिखें: छोटे वाक्य, कोई संक्षिप्त नाम नहीं, ठोस उदाहरण
5. समान अर्थ रखें — भाषा को सरल बनाएं, सामग्री को नहीं
### दिशानिर्देश
---
| तकनीकी | सरल |
|-----------|--------|
| PM2.5 concentration of 60 ug/m3 | pollution level of 60 (WHO की वार्षिक गाइडलाइन 5 है; भारत की वार्षिक सीमा 40 है) |
| GEMM mortality model | एक फॉर्मूला जो यह अनुमान लगाता है कि प्रदूषण से कितने लोगों की मौत होती है |
| source apportionment studies | प्रदूषण किस वजह से होता है, इस पर शोध |
| cost-effectiveness analysis | यह जांचना कि पैसा सही जगह खर्च हुआ या नहीं |
