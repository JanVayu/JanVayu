# आर्किटेक्चर

JanVayu एक **ज़ीरो-फ़्रेमवर्क, सिंगल-पेज एप्लिकेशन** है जिसे Netlify पर डिप्लॉय किया गया है। इसमें डेटा प्रॉक्सीइंग, कैशिंग और शेड्यूल्ड टास्क के लिए सर्वर-साइड सर्वरलेस फ़ंक्शन्स का इस्तेमाल किया गया है।

## प्रमुख डिज़ाइन निर्णय
### स्टैटिक फ्रंट-एंड, कोई बंडलर नहीं
फ्रंट-एंड `index.html` के साथ `styles.css`, `app.js`, `games.js` और `panels/` में 19 लेज़ी-लोडेड पैनल फ्रैगमेंट्स से बना है। इसमें कोई बंडलर और कोई फ्रेमवर्क नहीं है (देखें [Frontend Stack](../tech-stack/frontend.md))। इससे बेसिक HTML/JS स्किल्स वाले कॉन्ट्रिब्यूटर्स के लिए कोडबेस को समझना आसान हो जाता है और बिल्ड-टाइम की जटिलता लगभग शून्य रहती है।

### सर्वर-साइड प्रॉक्सीइंग
CORS की समस्याओं से बचने और API कीज़ को सुरक्षित रखने के लिए सोशल मीडिया और न्यूज़ APIs को Netlify Functions के ज़रिए फेच किया जाता है। क्लाइंट कभी भी इन APIs को सीधे एक्सेस नहीं करता।

### ब्लॉब कैशिंग
`scheduled-fetch.mjs` फंक्शन हर 4 घंटे में चलता है और फीड डेटा (Reddit, न्यूज़; Instagram को भी ट्राई किया जाता है लेकिन आमतौर पर कुछ नहीं मिलता) को Netlify Blobs में लिखता है। जब यूज़र्स फीड्स की रिक्वेस्ट करते हैं, तो ऑन-डिमांड फंक्शन्स तुरंत कैश से डेटा सर्व करते हैं — जिससे लेटेंसी और API रेट लिमिट्स की समस्या खत्म हो जाती है।

### क्लाइंट-साइड AQI
WAQI API को ब्राउज़र से सीधे हर 10 मिनट में कॉल किया जाता है। यह टोकन WAQI द्वारा उनकी terms of service के तहत जारी किया जाता है और क्लाइंट कोड में दिखाई देता है। इसका मतलब है कि रियल-टाइम AQI डेटा बिना किसी सर्वर-साइड इंफ्रास्ट्रक्चर के काम करता है।

### कोई फ्रेमवर्क नहीं, कोई बिल्ड स्टेप नहीं
इसमें कोई `npm run build`, कोई Webpack, और कोई React नहीं है। एकमात्र बिल्ड कमांड `node scripts/bump-version.mjs` है, जो वर्ज़न को अपडेट करता है, और डिप्लॉय करने वाली फ़ाइल (artefact) के रूप में रिपॉजिटरी का इस्तेमाल ही किया जाता है। Netlify रूट से `index.html` सर्व करता है।

## ऑटो-अपडेट शेड्यूल

| टास्क | फ्रीक्वेंसी | फंक्शन |
|------|-----------|----------|
| सोशल/न्यूज़ फीड रिफ्रेश | हर 4 घंटे | `scheduled-fetch.mjs` |
| डेली AQI ईमेल डाइजेस्ट | रोज़ाना सुबह 8:00 बजे IST | `daily-digest.mjs` |
| लाइव AQI डैशबोर्ड | हर 10 मिनट | क्लाइंट-साइड JS (WAQI API) |
| एनोमली डिटेक्शन | ऑन-डिमांड | `anomaly-check.mjs` |
| अपटाइम और फंक्शन हेल्थ चेक | हर 15 मिनट | `health-monitor.mjs` |
| वेब पुश नोटिफिकेशन्स | हर 3 घंटे | `push-send.mjs` |
| फीड हेल्थ चेक | रोज़ाना | `feed-health.mjs` |

## फ़ाइल स्ट्रक्चर
```
JanVayu/
├── index.html                    # SPA शेल (साथ ही styles.css, app.js, games.js, panels/)
├── favicon.svg
├── package.json                  # Node.js डिपेंडेंसीज़ (Netlify Blobs, Resend, web-push)
├── netlify.toml                  # बिल्ड और डिप्लॉय कॉन्फ़िग
├── CNAME                         # कस्टम डोमेन
├── docs/                         # यह डॉक्यूमेंटेशन (Docsify)
├── downloads/                    # डाउनलोड करने योग्य रिपोर्ट्स (PDF, PPTX, DOCX)
└── netlify/
    └── functions/
        ├── scheduled-fetch.mjs   # क्रॉन: सभी फ़ीड्स, हर 4 घंटे में
        ├── daily-digest.mjs      # क्रॉन: ईमेल डाइजेस्ट, सुबह 8:00 बजे IST
        ├── reddit-feed.js        # API: कैश्ड Reddit पोस्ट्स
        ├── twitter-feed.js       # API: बंद कर दिया गया है — Nitter का उपयोग करें, जिसके पब्लिक इंस्टेंस अब बंद हो चुके हैं
        ├── news-proxy.js         # API: कैश्ड न्यूज़ आर्टिकल्स
        ├── instagram-feed.js     # API: कैश्ड Instagram पोस्ट्स
        ├── feed-status.js        # API: फ़ीड की ताज़गी के लिए हेल्थ चेक
        ├── subscribe.js          # API: ईमेल सब्सक्रिप्शन मैनेजमेंट
        ├── blob-store.js         # शेयर्ड: Blobs स्टोर हेल्पर
        ├── air-query.mjs         # AI: प्राकृतिक भाषा में AQI क्वेरीज़
        ├── health-advisory.mjs   # AI: पर्सनलाइज़्ड हेल्थ सलाह
        ├── accountability-brief.mjs  # AI: वार्ड-लेवल अकाउंटेबिलिटी ब्रीफ्स
        └── anomaly-check.mjs     # AI: PM2.5 स्पाइक डिटेक्शन
```

यह सूची पूरी नहीं है: `netlify/functions/` में 28 फ़ंक्शन फ़ाइलें और शेयर्ड `lib/` मौजूद हैं (उदाहरण के लिए `waqi-proxy`, `rankings`, `data-api`, `push-send`, `fire-tracker` और `terra-collab`)।
