# Skill: Anomaly Explainer

**उपयोग:** `netlify/functions/anomaly-check.mjs`  
**Model:** `openai/gpt-oss-120b` via Groq (default, set by `GROQ_MODEL`; 16 Aug 2026 को Groq द्वारा retire किए जाने तक Llama 3.3 70B)  
**Trigger:** On-demand invoked; पांच प्रमुख शहरों को seasonal baselines के साथ चेक करता है

---

## यह Skill क्या करता है

यह स्किल पांच प्रमुख शहरों में live readings की तुलना hardcoded seasonal baselines से करके PM2.5 स्पाइक्स (spikes) का पता लगाती है। जब कोई स्पाइक डिटेक्ट होता है (reading > 2× baseline), तो यह Groq-hosted मॉडल से एक ही, India-specific वाक्य में सबसे संभावित कारण समझाने के लिए कहता है।

चार स्किल फाइलों में यह सबसे अधिक सीमित (constrained) है — एक वाक्य, एक कारण, और maximum specificity।

---

## System Prompt (हर शहर के लिए, सटीक)

```
In one sentence, explain why PM2.5 in {city} might be {pm25} µg/m³ right now 
— {month}, {hour}. Give the most likely cause. Be specific to the Indian context.
```

नोट: इसे एक **user message** के रूप में भेजा जाता है, न कि system instruction के रूप में। क्योंकि आउटपुट एक स्पष्ट तथ्यात्मक संरचना वाला एक ही वाक्य है, इसलिए user-turn prompt पर्याप्त है — एक पूरा system instruction बिना किसी लाभ के केवल ओवरहेड (overhead) बढ़ाएगा।

---

## स्पाइक डिटेक्शन लॉजिक (AI से पहले)

```javascript
const ratio = d.pm25 / baseline;
if (ratio > 2) {
  // flag as spike, then explain via Groq
}
```

थ्रेशोल्ड (Threshold): **2× seasonal baseline** (कोई निश्चित absolute नंबर नहीं)। यह महत्वपूर्ण है क्योंकि:
- दिल्ली का विंटर बेसलाइन ~95 µg/m³ है — जनवरी में 120 µg/m³ की रीडिंग असामान्य नहीं है
- मुंबई का बेसलाइन ~45 µg/m³ है — वहां 120 µg/m³ अत्यधिक असामान्य है
- एक फिक्स्ड थ्रेशोल्ड (जैसे, "150 µg/m³ से ऊपर की किसी भी चीज़ को flag करें") false positives (दिल्ली विंटर) और false negatives (तटीय शहर) दोनों पैदा करेगा

**Seasonal Baselines (अनुमानित JanVayu वर्किंग बेसलाइन, प्रकाशित CREA या IQAir के आंकड़े नहीं):**

| City | Oct–Mar (Winter) | Apr–Sep (Summer/Monsoon) |
|------|-----------------|--------------------------|
| Delhi | 95 µg/m³ | 55 µg/m³ |
| Mumbai | 45 µg/m³ | 45 µg/m³ |
| Kolkata | 80 µg/m³ | 35 µg/m³ |
| Chennai | 40 µg/m³ | 40 µg/m³ |
| Bengaluru | 40 µg/m³ | 40 µg/m³ |

## मुख्य डिज़ाइन निर्णय

**एक वाक्य क्यों?**
एनोमली (anomaly) की व्याख्या UI में एक टूलटिप या इनलाइन एनोटेशन के रूप में दिखाई देती है। एक वाक्य वह अधिकतम लंबाई है जिसे यूज़र के फ्लो (flow) को बाधित किए बिना पढ़ा जा सकता है। इससे लंबा कुछ भी एक पैराग्राफ बन जाता है, जिसके लिए एक अलग UI ट्रीटमेंट की आवश्यकता होती है।
**प्रॉम्प्ट में महीने और घंटे को क्यों शामिल करें?**
कारण का पता लगाना दिन के समय और मौसम पर बहुत ज्यादा निर्भर करता है:
मॉडल क्या कह सकता है, इसके उदाहरण (स्रोत-विभाजन के निष्कर्ष नहीं):
- नवंबर में सुबह 7 बजे दिल्ली → संभवतः पराली जलाना + सुबह का इन्वर्जन
- अप्रैल में दोपहर 2 बजे दिल्ली → संभवतः धूल भरी आंधी
- आधी रात को मुंबई → संभवतः औद्योगिक/शिपिंग गतिविधि
मॉडल को एक उपयोगी स्पष्टीकरण देने के लिए इस समय के संदर्भ की जरूरत होती है, न कि संभावित कारणों की कोई सामान्य सूची।

**ऐतिहासिक डेटा से गणना करने के बजाय बेसलाइन को हार्डकोड क्यों करें?**
सादगी और विश्वसनीयता। रोलिंग बेसलाइन की गणना करने के लिए एक स्थायी टाइम-सीरीज़ डेटाबेस की आवश्यकता होगी — जो मामूली सटीकता लाभ के लिए अनावश्यक बुनियादी ढांचा है। हार्डकोड किए गए मान अनुमानित JanVayu वर्किंग बेसलाइन हैं, CREA या IQAir द्वारा प्रकाशित आंकड़े नहीं, और इन्हें मैन्युअल रूप से अपडेट किया जाता है। साल-दर-साल भिन्नता बहुत अधिक हो सकती है (2017 से 2025 तक IQAir के दिल्ली वार्षिक औसत 84.1 से 113.5 µg/m³ तक हैं), इसलिए बेसलाइन को मोटे तौर पर थ्रेशोल्ड मानें।

**Groq API कॉल्स को समानांतर (`Promise.allSettled`) क्यों चलाएं?**
विसंगति जांच में एक साथ कई शहरों में स्पाइक्स मिल सकते हैं। क्रमिक रूप से चलाने में 3–5 गुना अधिक समय लगेगा। `Promise.allSettled` (न कि `Promise.all`) का मतलब है कि एक शहर के स्पष्टीकरण के लिए विफलता दूसरों को रद्द नहीं करती है।

## फॉलबैक व्यवहार

```javascript
if (!s.explanation) {
  s.explanation = `PM2.5 is ${s.ratio}x above JanVayu's approximate working baseline (not a published figure).`;
}
```

यदि Groq API उपलब्ध नहीं है, तो भी प्रतिक्रिया में स्पाइक डेटा और अनुपात शामिल होता है — बस AI-जनित कारण वाक्य के बिना।
