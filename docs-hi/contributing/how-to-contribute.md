# योगदान कैसे दें

भारत के वायु गुणवत्ता संकट का व्यापक रूप से दस्तावेजीकरण करने के लिए JanVayu समुदाय की भागीदारी पर निर्भर है। शोधकर्ताओं, पत्रकारों, डेवलपर्स और नागरिकों, सभी के योगदान का स्वागत है।

---

## योगदान के प्रकार

### शोधकर्ता
- वायु प्रदूषण के स्वास्थ्य प्रभावों पर डेटासेट और शोध पत्र साझा करें
- मौजूदा सामग्री को सत्यापित करने और तथ्य-जांच करने में मदद करें
- विश्लेषण और विज़ुअलाइज़ेशन में योगदान दें
- शोध सारांशों का भारतीय भाषाओं में अनुवाद करें

### पत्रकार
- सत्यापित खोजी रिपोर्ट साझा करें
- स्थानीय वायु गुणवत्ता की कहानियों का दस्तावेजीकरण करें
- महत्वपूर्ण मीडिया कवरेज को आर्काइव करें
- जवाबदेही ट्रैकर (accountability tracker) में योगदान दें

### डेवलपर्स
- बग रिपोर्ट करें और सुधार का सुझाव दें
- कोड फिक्स और नए फीचर्स का योगदान दें
- डेटा विज़ुअलाइज़ेशन टूल बनाएं
- एक्सेसिबिलिटी और परफॉरमेंस में सुधार करें

### नागरिक
- अपने प्रत्यक्ष अनुभव साझा करें (यदि चाहें तो गुमनाम)
- स्थानीय वायु गुणवत्ता की स्थिति का दस्तावेजीकरण करें
- क्षेत्रीय भाषाओं में सामग्री का अनुवाद करने में मदद करें
- जागरूकता फैलाएं

### डिज़ाइनर
- विज़ुअल एक्सेसिबिलिटी में सुधार करें
- इन्फोग्राफिक्स और शैक्षिक सामग्री बनाएं
- UI/UX सुधारों में मदद करें

---

## कोड योगदान के लिए

```bash
# 1. रिपॉजिटरी को फोर्क करें
# 2. अपने फोर्क को क्लोन करें
git clone https://github.com/YOUR_USERNAME/JanVayu.git
cd JanVayu

# 3. एक ब्रांच बनाएं
git checkout -b feature/your-feature-name

# 4. अपने बदलाव करें और स्थानीय रूप से टेस्ट करें
netlify dev

# 5. स्पष्ट संदेश के साथ कमिट करें
git commit -m "Add: PM10 toggle on city cards"

# 6. पुश करें और एक Pull Request खोलें
git push origin feature/your-feature-name
```

[github.com/JanVayu/JanVayu](https://github.com/JanVayu/JanVayu) पर `main` ब्रांच के विरुद्ध अपना PR खोलें।

---

## कंटेंट योगदान के लिए

1. आप जो योगदान देना चाहते हैं उसका वर्णन करते हुए GitHub पर एक **Issue खोलें**
2. **स्रोत प्रदान करें** — सभी कंटेंट को URL या दस्तावेज़ के साथ वेरिफाई किया जा सकना चाहिए
3. **संदर्भ शामिल करें** — बताएं कि यह JanVayu आर्काइव के लिए प्रासंगिक क्यों है
4. यदि स्वीकृत हो जाता है, तो एक मेंटेनर इसे जोड़ने में आपका मार्गदर्शन करेगा

---

## डेटा योगदान के लिए

- सुनिश्चित करें कि डेटा किसी वैध, वेरिफाई करने योग्य स्रोत से आया है
- स्पष्ट एट्रिब्यूशन और लाइसेंसिंग जानकारी प्रदान करें
- यदि लागू हो तो कार्यप्रणाली (methodology) दस्तावेज़ीकरण शामिल करें
- जहां संभव हो, RTI प्रतिक्रियाएं या मूल दस्तावेज़ संलग्न करें

## पुल रिक्वेस्ट चेकलिस्ट

PR सबमिट करने से पहले, यह सत्यापित करें:
- [ ] लोकल डेवलपमेंट (`netlify dev`) में बदलाव सही से काम कर रहे हैं
- [ ] किसी भी फ़ाइल में कोई सीक्रेट या API key हार्डकोड नहीं की गई है
- [ ] नए एनवायरनमेंट वेरिएबल्स (environment variables) को `docs/technical/environment-variables.md` में डॉक्यूमेंट किया गया है
- [ ] कोड [code standards](code-standards.md) का पालन करता है
- [ ] कंटेंट [content standards](content-standards.md) का पालन करता है
- [ ] साइट मोबाइल पर सही से रेंडर होती है (ब्राउज़र devtools में चेक करें)
